# PMR 醫療問題與功能問題清單

## 一句話定義

在 PM&R，`medical problem list + functional problem list` 是把 diagnosis、impairment、activity limitation、participation restriction 與 contextual factors 轉成 management plan 的結構化輸出。

## Definition and Boundary

### What It Is

- 它是 [[../03_疾病與臨床主題/PMR_評估總論]] 的核心輸出格式，不是附屬摘要。
- 它要同時寫出 impairment、performance deficit、community or role dysfunction，以及會影響功能目標的 medical conditions。
- 它的任務是把 H&P 收集到的資料轉成 precautions、goals、team tasks 與處置方向。

### What It Is Not

- 不是把 diagnosis 換一欄重抄一次。
- 不是只有 ADL level 的流水帳，而不交代限制原因與安全條件。
- 不是把 medical issues 與 rehabilitation issues 並列後，就不再說明兩者如何互相影響。

## Why It Matters

- textbook chapter 直接把 physiatric H&P 的終點定義成 problem list，而不是單純診斷命名。
- 若問題清單沒有把功能限制、環境障礙與 precautions 寫清楚，management plan 會退化成 generic therapy order。
- 這個格式也是 PM&R 與其他科別最容易被看見的差異之一：它要求把 disease、function 與 participation 放進同一個臨床句子。

## Preconditions or Conditions

- 需要完整的 chief complaint、HPI 與 functional history，而不是只有 symptom chronology。
- 需要 functional status 資料：mobility、ADLs、IADLs、communication、cognition、work、recreation。
- 需要 psychosocial 與環境資料：home accessibility、support system、vocation、finances、sexuality、psychological state、spirituality。
- 對 communication 或 cognition 受損者，常需要 collateral history；來源不是病人本人時要清楚標示，並提防 `chart lore`。
- 若要判斷功能惡化或恢復潛力，還需要知道 natural history 與 functional problem 的 time course。

## Mechanism

```text
Chief complaint + diagnosis
→ HPI 補上 impairment / activity / participation 影響
→ functional history 定位 mobility / ADL / IADL / cognition / work 缺口
→ psychosocial 與 home context 定義真實生活限制
→ 組成 medical problem list 與 functional problem list
→ 每一項問題對應 precaution、goal、team role、assistive device 或環境調整
→ management plan 才能落地
```

## Observable Patterns

- 好的 functional problem line 會寫成「哪個功能壞掉、為什麼壞、影響到哪個生活角色」，而不是只寫 diagnosis。
- 好的 medical problem line 會交代它如何限制 mobilization、training tolerance、safety 或 discharge planning。
- follow-up note 雖可更短，但仍應標示問題是 new、stable、improving 或 worsening。
- 來源中的範例把 ambulatory dysfunction、ADL dysfunction、bowel/bladder、hypertension、pain 等分開列出，再分別接 treatment logic。

## Clinical / Research Implication

- 臨床上，它直接影響 assistive device、wheelchair/seating、return-to-work、family education 與 interdisciplinary goal setting。
- 教學上，它是一個把 ICF 語言變成臨床文件的操作介面。
- 研究或品質管理上，它可作為 case formulation 骨架；但本來源沒有證明某種固定模板優於其他模板。

## Fact

- 本章直接指出 physiatric H&P 的用途之一，是建立 `medical and functional problem list` 以引導 management plan。
- 初始 treatment plan 應明確寫出 impairments、performance deficits、community or role dysfunction、會影響功能目標的 medical conditions，以及 interdisciplinary team goals。
- functional history 應涵蓋 mobility、ADLs、IADLs、communication、cognition、work、recreation。
- psychosocial history 應主動納入 home environment、family/friends support、substance use、sexual history、vocational activities、finances、psychological issues、spirituality。
- separate medical and functional problem lists 是可接受的，但 physiatrist 必須說清楚 medical issues 如何改變 treatment approach。
- follow-up documentation 可以比初診短，但必須交代重要 interval changes 與 treatment/goals 變化。

## Inference

- problem list 的品質高度依賴 upstream history 品質；history 若沒有 functional depth，後面的計畫只會變成泛用處方。
- 若 medical issues 沒有被明確連到 mobilization 或 participation，團隊容易忽略 safety bottleneck。
- 這個結構的真正價值不在「列很多問題」，而在「每個問題都能改變 plan」。

## Assumption

- clinician 能把 ICF 相關概念穩定轉譯成可操作的 problem list 用語。
- 團隊成員對 listed precautions、goals 與 role assignment 有共同理解。
- EMR 模板與 billing 需求不會迫使臨床內容退化成 copy-paste checklist。

## Uncertainty

- 本章是 textbook chapter，提供的是 consensus framework，不是比較不同 documentation structure 成效的實證研究。
- 哪些問題應拆成獨立 line item、哪些可合併，存在場域與個人書寫風格差異。
- 不同 institution 的 EMR、billing 與 medicolegal 要求不同，本章格式不能直接當成唯一標準。

## Limitations and Misreadings

- 反對論點：problem list 只是行政文件，therapy team 之後自然會補齊。  
  反駁：本來源把它定義成 management plan 的骨架，therapy assessment 是輸入資料，不是替代品。  
  結論：在 PM&R，problem list 是 clinical reasoning output，不是 clerical debris。

- 反對論點：diagnosis 已經明確時，functional problem list 可以簡寫。  
  反駁：本章反覆要求把 chief complaint 轉譯為 mobility、ADLs、IADLs、work、participation 的限制；只有 diagnosis 並不能決定 rehab plan。  
  結論：在 PM&R，diagnosis 是必要條件，但不是充分輸出。
