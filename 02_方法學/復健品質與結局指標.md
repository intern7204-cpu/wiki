# 復健品質與結局指標

## 一句話定義

quality measurement in rehabilitation 的核心，是把 **要測什麼、為什麼測、測到的數字能不能真的代表品質** 這三件事釐清。

## 核心機制

### 核心框架

- Donabedian：structure / process / outcome
- IOM 六大 aims：safety、timeliness、effectiveness、equity、efficiency、patient-centeredness
- value：outcomes / total cost of full episode of care

### measure 類型

- outcome measures：病人健康或功能結果
- process measures：照護是否依 evidence-based process 執行
- performance measures：機構 / 系統層級的比較與監測，常以 ratio / percentage 呈現

### 如何選 outcome measure

- relevance：對病人、團隊、機構是否重要
- validity / reliability / responsiveness
- feasibility、burden、ceiling / floor effect
- patient-reported vs clinician-assessed
- ICF level：body function、activity、participation

### QI 與 performance improvement

- process variation reduction 是核心策略。
- 可使用 PDSA / PDCA、Six Sigma 等框架。
- rehab program 常需同時看 functional gain、readmission、ACT rate、patient experience、safety event。

## 臨床表現

### 臨床重點

- 稀有但嚴重的 outcome 不能單獨代表整體品質，常需搭配 process measure。
- 同一 measure 在不同 case-mix 下可比性有限，risk adjustment 很重要。
- 為了報告而量測，和為了改善而量測，不應混為一談。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「只要有一個 outcome 數字，就能代表整個 rehab program 的品質。」
- 「value-based care 就是把成本壓低。」

### 反駁

- outcome、process、performance measures 分別回答不同問題，不能互相替代。
- Donabedian framework 指出 structure、process、outcome 要一起看。
- value 的分母是 **整個 care episode 的總成本**，不是單一服務價格。
- 沒有 risk adjustment 的橫向比較很容易失真。

### 結論

- rehab quality 需要 **measure taxonomy + methodological rigor + context-aware interpretation**，不是單看一個漂亮數字。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- Outcome measures, process measures, and performance measures are related but not interchangeable.
- Value-based care is not equivalent to reducing the cost of a single service in isolation.

## 理解缺口

- 復健品質與結局指標 量到的是什麼，不是什麼？
- 這個方法最常見的 protocol pitfall 是什麼？
- 如果結果異常，哪些情況不能直接跳到 treatment conclusion？
- 目前缺少完整評估框架：History、Physical examination、Scale / test、Imaging / lab 仍需補強。
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若 復健品質與結局指標 不能改變診斷、風險分層或 treatment plan，就不該例行使用。
- 先界定問題、輸入條件與輸出格式，再執行方法，否則結果很容易只有數字沒有決策價值。
