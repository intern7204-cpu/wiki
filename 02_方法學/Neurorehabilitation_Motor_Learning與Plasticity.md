# Neurorehabilitation Motor Learning 與 Plasticity

## One-Sentence Definition

Neurorehabilitation motor learning 是用 goal-directed practice、feedback、progression、motivation、self-management 與可用的 neural plasticity 改善或補償 neurologic task performance。

## Definition and Boundary

- 本頁整理 Neurological Rehabilitation 來源中的 motor learning、biological bases of recovery、technology adjuncts 與 self-management。
- 本頁不做 robotics、BCI、tDCS、FNS 或 pharmacologic adjunct 的最新證據統整。
- 本頁只使用單一來源：[[../09_來源摘要/Neurological_Rehabilitation]]。

## Why It Matters

- 神經復健的核心不是被動接受 modality，而是反覆、有目標、可回饋、逐步進階的 active learning。
- 技術若無法提高 relevant practice dose、feedback、access、measurement 或 self-management，臨床價值有限。

## Preconditions or Conditions

- Practice 必須對 task meaningful，且依 impairment、safety、fatigue、cardiopulmonary capacity、cognition、motivation 與 environment 調整。
- Technology or stimulation should be paired with clear functional target and outcome measure.

## Mechanism

```text
Task-specific practice + feedback + progressive challenge
-> attention, motivation, repetition, error correction, and self-management
-> activity-dependent neural and behavioral adaptation
-> improved or compensated task performance
```

```text
Neurologic injury recovery processes
-> reduced edema / conduction block / diaschisis
-> spared pathway recruitment, map expansion, parallel network use
-> synaptic efficacy and neurotransmitter changes
-> behaviorally expressed recovery or adaptation
```

## Observable Patterns

- Better learning environment：clear goal、high repetition、specific feedback、graded difficulty、patient engagement、home carryover。
- Weak learning environment：passive modality without task transfer、unclear goal、no progression、no feedback、poor relevance。
- Technology adjuncts in the source：robotics, FNS, noninvasive brain stimulation, BCI, mobile health, wearable monitoring, telerehabilitation。

## Clinical / Research Implication

- Robotic or treadmill-based systems should be evaluated against dose-matched conventional therapy and patient-relevant outcomes.
- FNS may be useful for grasp, standing, ambulation, peroneal stimulation, or cycling in selected contexts.
- Behavioral self-management should include education, goal setting, barriers, problem solving, feedback, tailored instruction, decision making, and ongoing support.
- Animal neuroplasticity findings should not be over-extrapolated to human protocols.

## Fact

- The source describes movement / skill training as active learning and self-management.
- Network plasticity mechanisms include resolution of ionic disequilibrium / conduction block, edema / blood, diaschisis, recruitment of adjacent or spared pathways, map expansion, pattern generators, neurotransmitter modulation, and alternative behavior.
- Neuronal plasticity mechanisms include synaptic efficacy changes, LTP / LTD, denervation hypersensitivity, delayed apoptosis, receptor changes, and neurotransmitter release / uptake changes.
- Robotic upper limb therapy and treadmill robotics are described as equal or modest rather than clearly superior to dose-matched conventional therapy in the source.
- The source cautions against over-extrapolating animal studies.

## Inference

- A device that increases repetitions but reduces attention, task relevance, or active problem solving may not improve meaningful learning.
- Motor learning should be measured at both clinic performance and real-world behavior when possible.

## Assumption

- The patient has enough arousal, medical stability, and communication / cueing access to participate in active learning, or the program adapts for these limitations.

## Uncertainty

- Evidence for stimulation, pharmacologic augmentation, BCI, exoskeletons, and some wearable / telerehab models is evolving and must be checked for current use.

## Limitations / Common Misreadings

- 「機器越新，復健越好」不成立。
- 「Plasticity 代表任何刺激都有用」不成立；practice specificity、dose、feedback 與 behavior target 仍是核心。
- 「動物實驗有效就能直接套用臨床」不成立；來源明確提醒需謹慎外推。
