# Return to Work 評估骨架

## 一句話定義

return to work 評估不是看 injury 是否「好了」，而是整合 patient factor、job demand、employer support、policy 與 workplace modification 的 work-ability 判讀。

## Definition and Boundary

- 它是 biopsychosocial / ICF 架構下的 work assessment。
- 它不是把傷病恢復程度直接等同於可否上班。

## Fact

- 本章明確指出 work ability 不等於 injury healed。
- 影響 outcome 的因素包括 patient factor、job demand、employer support、policy 與 mental health。
- early coordination、modified duty、schedule adjustment、ergonomics 與 assistive technology 都屬 workplace intervention。
- FCE、work conditioning、work hardening、FRP 在用途與適應症上需要區分。

## Mechanism Chain

```text
Medical status
→ job demand analysis
→ workplace and policy context
→ targeted accommodation / rehabilitation
→ sustainable return to work
```

## Inference

- 只改善 impairment，而不處理 job demand 與 workplace context，常不足以真正恢復 work outcome。

## Assumption

- clinician 能取得真實工作內容，而不是只有模糊的 job title。

## Uncertainty

- compensation、OSHA / ADA 實作與雇主制度差異，會改變同一 clinical picture 的實際 RTW 路徑。

## Clinical Use

- RTW 評估若卡住，可先問自己：現在缺的是 medical recovery，還是 job / workplace information。
