# Outcome Process Performance Measure 區分

## 一句話定義

outcome、process 與 performance measure 回答的是不同層次的問題；若把它們混寫，rehabilitation quality 判讀很容易失真。

## Definition and Boundary

- outcome measure 問「病人或系統最後變怎樣」；process measure 問「是否做了應做的事」；performance measure 問「團隊或系統表現如何」。
- 這不是名詞遊戲，而是 quality interpretation 的前提。

## Fact

- 本章把 clinical outcome、process、performance measure 明確拆開。
- functional outcome measure 需回到 ICF level 判斷：body function、activity、participation。
- Donabedian 的 structure-process-outcome 與 IOM 六大 aims 是 quality language 的骨架。
- cross-institution comparison 需要 risk adjustment，measure selection 也要看 validity、reliability、responsiveness、feasibility 與 floor/ceiling effect。

## Mechanism Chain

```text
Clear measure taxonomy
→ right question matched to right metric
→ adjusted interpretation
→ more defensible quality judgment
```

## Inference

- 若沒有 risk adjustment，就把 performance differences 直接歸因於團隊好壞，結論很容易誤導。

## Assumption

- 使用者先界定了要評估病人結果、照護流程，還是系統表現。

## Uncertainty

- 本章沒有主張單一 measure set 可適用所有 rehabilitation setting。

## Clinical Use

- 寫 QI proposal 或解讀 dashboard 前，先標記每個指標屬於哪一類。
