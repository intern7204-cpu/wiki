# 電生理診斷醫學（Electrodiagnostic Medicine）

## 一句話定義

Electrodiagnostic medicine 是把 **focused history、focused physical examination 與 neurophysiology** 串在一起的診斷方法；它不是獨立的 screening gadget。

## 核心機制

### 實務原則

- NCS 與 needle EMG 在許多臨床問題上不可任意拆開。
- 檢查設計要由 symptom distribution、weakness、sensory loss、reflex pattern 反推，不是固定套餐。
- 檢查設計需先知道 routine NCS / EMG 的生理邊界：DRG 位置會改變 SNAP pattern，standard NCS 只記錄 large fast myelinated fibers，CMAP / SNAP / MUAP 受 volume conduction 與 electrode position 影響。
- 檢查設計同時是統計問題：symptom / sign 決定 pre-test probability，而 pre-test probability 會改變 borderline positive EDX 的 true-positive probability。
- 每次 EDX encounter 應先有 brief history、directed neurologic examination 與 differential diagnosis，再決定 NCS / needle EMG 順序與範圍。
- NCS 通常先做，因為 NCS 結果會改變後續 needle EMG 的 muscle selection 與 interpretation。
- Basic NCS 判讀必須先說清楚 abnormal parameter：latency / conduction velocity 主要反映 fastest fibers，amplitude / area 反映 depolarized fiber population，duration 反映 synchrony / temporal dispersion。
- Normal routine NCS 不能排除 selective small-fiber neuropathy；normal SNAP 不能排除 proximal-to-DRG lesion。
- Routine NCS protocol 必須寫清 recording site、stimulation site、distance、limb position、temperature 與 comparison method；protocol 不完整時，normal value 不能單獨保證 localization 正確。
- Lower-extremity routine protocol 需特別標示 actual distance、side-to-side comparison、small sensory / plantar response limitation、APN clue 與 height adjustment for late responses。
- EDX interpretation 的前提是 technically accurate data；temperature、electrode impedance、filters、stimulus artifact、cathode orientation、supramaximal stimulation、co-stimulation、electrode placement、distance measurement 與 sweep / sensitivity 都可能製造假異常。
- Supramaximal stimulation 是 NCS 判讀前提；只因 response 進入 normal range 就停止加刺激，仍可能造成 false low amplitude 或 false conduction block-like pattern。
- Apparent conduction block 或不合解剖預期的 amplitude pattern 也可能來自 anomalous innervation，例如 Martin-Gruber anastomosis 或 accessory peroneal nerve；這不是 technical error，但會模仿 pathology。
- EDX 的主要目標是 localization；第一層先分 neuropathic、myopathic、NMJ、CNS，再往 neuron / root / plexus / peripheral nerve、fiber type、axonal vs demyelinating、time course 細分。
- 當 clinical findings、NCS 與 needle EMG 不一致時，先查 technical factors、必要時 reexamine patient，不要用單一 minor abnormality 硬下診斷。
- EDX normal / abnormal cutoff 會在 sensitivity 與 specificity 之間取捨；除 screening 外，需優先避免 type I error 導致 false diagnosis。
- 若一次做許多 tests 且任一 abnormal 即診斷，cumulative false-positive rate 會升高；診斷應依 clinical fit 與多個 convergent findings。
- 對 radiculopathy 這類問題，positive study 較有 specificity；normal study 不能直接當成排除。
- 周邊神經急性損傷的 EDX 判讀必須看 injury timing：Wallerian degeneration、denervation potentials 與 reinnervation signs 會隨時間演變。
- Late responses（F response、H reflex、axon reflex / A wave）擴展 NCS 至 proximal segment 與 reflex arc，但 site / disease specificity 低。F response 對 EMG-confirmed S1 radiculopathy sensitivity 約 4-8%（Mauricio et al.），prolonged F 可來自 distal slowing、long limb 或近端病變；absent / delayed H reflex 在 polyneuropathy、tibial / sciatic neuropathy、lumbosacral plexopathy 與 S1 radiculopathy 都可發生；A wave 是 reinnervation 或 demyelination 的 marker，也可能反映 distal 刺激不足 supramaximal。
- Repetitive nerve stimulation (RNS) 以 slow RNS 的 CMAP decrement、brief exercise / rapid RNS 的 increment 或 postexercise repair / exhaustion 評估 NMJ safety factor；>10% reproducible decrement 不等於 myasthenia gravis，increment 需排除 pseudofacilitation，並需控制 temperature、immobilization、supramaximal stimulation、acetylcholinesterase inhibitor status 與 denervation / myotonia confounders。
- Blink reflex 是 clinically evoked corneal reflex 的 electrical correlate，可用 supraorbital V1 stimulation、bilateral orbicularis oculi recording 與 R1 / R2 pattern 評估 trigeminal afferent、facial efferent、pons / medulla interneuron network 與 demyelinating pathway involvement；判讀需同時看 stimulus side 與 recording side。
- Neuromuscular ultrasound 補的是 structure，例如 focal compression、nerve enlargement 或 discontinuity；EDX 補的是 physiology、severity、chronicity 與 axonal continuity。
- Myopathy 評估中，sensory NCS 通常正常；conduction block、temporal dispersion 或明顯 conduction slowing 應提高 neuropathy / demyelinating process 的可能性。
- Suspected ALS / MND 中，EDX 的主要任務是確認 LMN loss 的分布，並排除 MMN、NMJ disorder、focal radiculomyelopathy 等 mimic。

### 判讀陷阱

- disease timing 會改變 sensitivity，必要時需 repeat study。
- 單一 subtle abnormality 很容易是假陽性；背景 polyneuropathy、糖尿病、手術史、anatomic variation 都會混淆判讀。
- Borderline abnormality 在 low pre-test probability 情境下常是 false positive；markedly abnormal finding 較可能是真陽性。
- EDX 不能完全 rule in 或 rule out condition；較精準的說法是 evidence level / post-test probability 改變。
- 報告用語宜寫成「no electrodiagnostic evidence of ...」，不要過度宣稱絕對排除。
- Cool limb 可造成 slowed conduction velocity、prolonged distal latency、increased amplitude / duration，模仿 polyneuropathy、distal entrapment 或 demyelination。
- Edema 或 recording electrode off nerve 可降低或消失 sensory response；此時 absent response 需加 technical caveat。
- Reversed cathode / anode、submaximal stimulation 或 co-stimulation 都可能製造 false latency、false axonal loss、false conduction block 或 false normal study。
- MGA 可讓 ulnar forearm segment 看似 conduction block，APN 可讓 peroneal EDB response 近端 amplitude 高於 ankle；未辨識時會誤診 demyelination、UNE、PNFN 或 technical error。
- Ulnar across-elbow NCS 若省略 below-elbow stimulation，或以 straight elbow 測距，會漏診或假造 across-elbow slowing。
- Peroneal fibular-neck NCS 若省略 below-fibular-neck stimulation，可能漏掉 focal slowing；tibial popliteal amplitude drop 或 peroneal below-fibular-head amplitude drop 也不能單獨當成 conduction block。
- Lower-extremity sensory study 若改用 shorter distance，不能沿用 standard peak latency cutoff；需用 actual distance 與 onset latency 計算 conduction velocity。
- RNS 的 false decrement / increment 可來自 electrode movement、submaximal stimulation、cold limb、facial CMAP baseline 太小、exercise timing 錯誤或 acetylcholinesterase inhibitor 未停用。
- Blink reflex 的 false / overcall 風險來自 patient not relaxed、baseline noise、repetitive stimulation 造成 R2 habituation、R1 在少數正常人 bilateral unreliable，以及未依 stimulus side + recording side 判讀。
- Saphenous、lateral femoral cutaneous 與 plantar responses 可在正常 older adults 或 technical difficulty 下很小或 absent；需 side-to-side comparison。
- Low amplitude 不能自動等於 axonal loss；需先排除 demyelinating conduction block、hyperacute pseudo-conduction block、NMJ disorder、myopathy 與 technical factors。
- Normal SNAP 不能排除 lesion proximal to the dorsal root ganglion；radiculopathy 或 CNS lesion 可有 sensory symptoms 但 SNAP preserved。
- Very early focal nerve injury 可能尚未出現 denervation；不可用太早的 needle EMG 排除 axonal injury。
- Steroid myopathy 等部分 myopathy 可有正常 EMG；normal EMG 不能單獨排除所有 muscle disease。
- Conduction block 若出現在非 entrapment site，需提高 MMN suspicion，而不是直接歸為 ALS。
- Mild cervical spondylosis 或 nonspecific MRI change 不能單獨推翻 clinical + EDX 支持的 ALS pattern。

### 報告最低要求

- referral question
- focused history / exam
- pre-test probability / clinical likelihood when borderline findings are present
- tabulated NCS / EMG data 與 normative reference values
- temperature 與 limbs studied
- technical limitations / artifact caveats：例如 cooling、edema、noise、submaximal stimulation、co-stimulation、distance limitation
- physiologic diagnosis
- test limitations / confounders

## 臨床表現

### 核心用途

- 縮小 differential diagnosis
- 區分 entrapment neuropathy、radiculopathy、plexopathy、polyneuropathy、myopathy、neuromuscular junction disorder、motor neuron disease
- 協助判定 severity、extent、time course、部分 prognosis

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### Pediatric caveats

- 兒童 conduction velocity 不可直接用 adult norms。
- 必須維持足夠溫度，必要時由 pediatric anesthesia 團隊協助 sedation。
- pediatric needle EMG 難做，但仍是 diagnosis 的必要部分。

## 理解缺口

- 電生理診斷醫學（Electrodiagnostic Medicine） 量到的是什麼，不是什麼？
- 這個方法最常見的 protocol pitfall 是什麼？
- 如果結果異常，哪些情況不能直接跳到 treatment conclusion？
- 目前缺少完整評估框架：History、Physical examination、Scale / test、Imaging / lab 仍需補強。
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若 電生理診斷醫學（Electrodiagnostic Medicine） 不能改變診斷、風險分層或 treatment plan，就不該例行使用。
- 先界定問題、輸入條件與輸出格式，再執行方法，否則結果很容易只有數字沒有決策價值。
