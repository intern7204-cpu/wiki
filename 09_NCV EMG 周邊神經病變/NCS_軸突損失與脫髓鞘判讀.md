# NCS 軸突損失與脫髓鞘判讀

## One-Sentence Definition

NCS 軸突損失與脫髓鞘判讀，是用 CMAP / SNAP 的 amplitude、latency、conduction velocity、area、duration、stimulation location 與 injury timing 來區分 axonal loss、demyelination、conduction block 與技術假象。

## Definition and Boundary

- 本頁只處理 basic NCS pattern interpretation，不整理特定疾病的完整 diagnostic criteria。
- 本頁不處理 repetitive nerve stimulation、late responses、blink reflex、needle EMG recruitment / spontaneous activity 或 neuromuscular ultrasound。
- 本頁以 [[../10_來源摘要/Basic_Nerve_Conduction_Studies]] 為主要來源，並用 [[../10_來源摘要/Anatomy_and_Neurophysiology_for_Electrodiagnostic_Studies]] 補足 DRG、fiber type、myelin / saltatory conduction、motor unit 與 volume conduction 基礎；另用 [[../10_來源摘要/Basic_Statistics_for_Electrodiagnostic_Studies]]、[[../10_來源摘要/Artifacts_and_Technical_Factors]]、[[../10_來源摘要/Anomalous_Innervations]]、[[../10_來源摘要/Routine_Upper_Extremity_Facial_Phrenic_NCS_Techniques]] 與 [[../10_來源摘要/Routine_Lower_Extremity_NCS_Techniques]] 補足 diagnostic statistics / artifact / anatomic variant / routine protocol pitfall。

## Why It Matters

- NCS 不是「正常 / 異常」二分法；不同參數代表不同 physiology。
- 把 low amplitude 直接寫成 axonal loss，會漏掉 demyelinating conduction block、hyperacute pseudo-conduction block、NMJ disorder、myopathy 或 technical artifact。
- 把 normal SNAP 當成排除 sensory pathology，會漏掉 lesion proximal to the dorsal root ganglion，例如 radiculopathy 或 CNS lesion。

## Preconditions or Conditions

- 必須先有 history、directed physical examination 與 localization hypothesis。
- NCS 必須在正確 limb temperature、electrode placement、distance measurement、stimulation site 與 lab-specific norms 下判讀。
- NCS abnormality 必須放回 cutoff specificity、pre-test probability 與 multiple-test false-positive risk 判讀。
- 判讀前需先確認 testable fiber population：routine NCS 主要反映 large fast myelinated fibers，不能排除 isolated small-fiber pathology。
- 每個 stimulation site 都要達到 supramaximal stimulation；不能只因 waveform 落在 normal range 就停止加刺激。
- 若存在 edema、cool limb、electrode impedance mismatch、reversed cathode / anode、co-stimulation、recording off nerve 或 inconsistent limb position，先修正或標示 limitation，再下 physiology conclusion。

## Mechanism

```text
NCS waveform
→ latency / conduction velocity: fastest conducting fibers
→ amplitude / area: depolarized axon or muscle-fiber population proxy
→ duration: synchrony / temporal dispersion
→ compare distal vs proximal responses
→ account for timing after injury and stimulation adequacy
→ classify as axonal loss, demyelination, conduction block, pseudo-block, or uncertainty
```

### Axonal loss pattern

```text
Fewer functioning axons
→ CMAP / SNAP / MNAP amplitude decreases
→ fastest surviving fibers may keep latency and conduction velocity near normal
→ severe loss can mildly slow velocity / prolong latency
→ pure axonal loss should not cause marked slowing
```

### Demyelination pattern

```text
Myelin dysfunction
→ saltatory conduction slows or fails
→ marked latency prolongation / conduction velocity slowing
→ nonuniform slowing causes temporal dispersion
→ phase cancellation lowers amplitude / area
→ focal block may produce proximal response drop
```

## Observable Patterns

- Axonal loss 的 primary abnormality 是 reduced amplitude。
- Axonal loss 中 conduction velocity 通常 normal 或 mildly reduced；source 給的邊界是不可低於 lower limit of normal 的 75%。
- Axonal loss 中 distal latency 通常 normal 或 mildly prolonged；source 給的邊界是不可超過 upper limit of normal 的 130%。
- Demyelination 會造成 marked conduction slowing、marked distal latency prolongation 或 conduction block。
- Source 指出 routine motor / sensory / mixed conduction velocity 若低於 arms 35 m/s 或 legs 30 m/s，除 rare regenerating nerve fibers after complete axonal injury 外，代表 unequivocal demyelination。
- Borderline slowing 要一起看 amplitude：amplitude normal 時偏向 demyelination；amplitude extremely low 時可能是 severe axonal loss with loss of faster fibers。
- Borderline abnormal values 需看 clinical likelihood；low pre-test probability 下，isolated borderline abnormality 常是 false positive。
- Hyperacute axonal injury 前 3 天可能呈現 distal response normal、proximal response reduced，形成 pseudo-conduction block。
- Wallerian degeneration 完成後，acute axonal loss 會轉成典型 low amplitude pattern；source 描述 motor fibers 約 days 3-5，sensory fibers 約 days 6-10。
- Lesion proximal to dorsal root ganglion 可有 sensory symptom / sensory loss 但 SNAP normal。
- Standard NCS 不記錄 small myelinated A-delta / B fibers 或 unmyelinated C fibers；pain、temperature 或 autonomic symptoms 可與 normal routine NCS 並存。
- Motor CMAP 若有 unexpected initial positive deflection，需先檢查 active electrode 是否偏離 motor point。
- Proximal sensory stimulation 可因 normal temporal dispersion / phase cancellation 造成 SNAP duration 增加、amplitude / area 下降，不可自動當成 pathology。
- Routine tibial motor study 在 popliteal fossa stimulation 可見 normal amplitude drop up to 50%；source 要求對 tibial conduction block 判讀保持謹慎。
- Routine peroneal motor study recording EDB 在 below-fibular-head stimulation 可見 average normal amplitude drop 14%，rare normal drop 20-30%；需謹慎判讀 partial conduction block。
- Peroneal fibular-neck focal slowing / block 的判讀需包含 ankle、below-fibular-neck、above-fibular-neck stimulation，且 TA recording 可能比 EDB 更容易顯示 abnormality。
- Small / absent plantar、saphenous 或 lateral femoral cutaneous responses 可能見於 normal controls，尤其 older adults 或 technically difficult studies；不可單靠 absent response 判斷 axonal sensory loss。
- Ulnar forearm segment apparent conduction block 可由 MGA 造成；peroneal EDB proximal amplitude 高於 ankle 可由 APN 造成。
- Median palmar motor / sensory amplitude ratio 可提示 across-wrist conduction block，但需建立在正確 wrist-palm distance、clear onset latency 與 stimulus artifact control 上。
- Ulnar across-elbow slowing 必須依 correct below-elbow site、elbow flexion 與 curved distance 解讀。

## Clinical / Research Implication

- Focal entrapment neuropathy 的 precise localization 需要證明 focal demyelination，例如 segmental conduction slowing 或 conduction block。
- Weakness 若主要來自 conduction block / demyelination，prognosis 與 recovery time course 通常不同於 substantial distal CMAP amplitude loss 所代表的 axonal loss。
- Polyneuropathy 中非 entrapment site conduction block 支持 acquired demyelinating process；inherited demyelinating neuropathy 較常呈 uniform slowing，除常見壓迫處外通常沒有 conduction block。

## Fact

- NCS 在 history 與 directed physical examination 後開始，needle EMG 通常在 NCS 後執行，因 NCS 會影響 needle EMG planning and interpretation。
- Motor NCS 通常先做，因其 technical demand 較低、noise 影響較少，且能協助確認 nerve course、stimulation site 與 required current。
- CMAP latency 包含 nerve conduction to NMJ、NMJ transmission time 與 muscle depolarization time；因此 motor conduction velocity 需要 distal + proximal stimulation 才能計算。
- Sensory conduction velocity 可由 one stimulation 的 onset latency 與 distance 計算，因 SNAP 不含 NMJ 或 muscle depolarization time。
- CMAP / SNAP latency 和 conduction velocity 主要反映 fastest conducting fibers；amplitude / area 反映 depolarized fiber population；duration 反映 synchrony。
- Myelin 透過 saltatory conduction 增加 conduction velocity；large myelinated fibers 是 routine latency / velocity 的主要來源。
- Supramaximal stimulation 應先讓 waveform plateau，再增加 20-25% current。
- Submaximal stimulation 會低估 true amplitude，並可能造成 false conduction block-like pattern。
- Excessive stimulation 可 co-stimulate nearby nerves 並增加疼痛。
- Reduced CMAP amplitude 可見於 axonal loss、demyelinating conduction block、NMJ disorders 與 some myopathies。
- SNAPs remain normal in lesions proximal to the dorsal root ganglion。
- Conduction block 和 abnormal temporal dispersion 都是 acquired demyelination markers；但 amplitude / area drop criteria 會受 temporal dispersion、phase cancellation、segment length 與 nerve studied 影響。

## Inference

- NCS report 應說明 abnormality 是 amplitude-dominant、latency / velocity-dominant、dispersion-dominant，或 block-like，而不是只列 abnormal values。
- NCS report 應把 isolated borderline abnormality 與 convergent abnormal pattern 分開寫。
- 若 clinical pattern、SNAP pattern 與 motor / needle EMG pattern 不一致，較合理的輸出通常是 localization uncertainty 或 repeat study plan，而不是硬塞成單一診斷。
- Acute nerve injury 太早檢查時，repeat NCS after Wallerian degeneration 可能比單次判讀更安全。

## Assumption

- Source 的 broad cutoffs 需套用在有 adequate temperature control、distance measurement、supramaximal stimulation 與正確 normative reference 的前提下。
- Lab-specific normal values 與 condition-specific criteria 仍是正式診斷必要背景。

## Uncertainty

- Source 沒有提供 CIDP、GBS、entrapment neuropathy、radiculopathy、NMJ disorder 或 myopathy 的完整 diagnostic criteria。
- Rigid cutoff 不能消除 normal / disease overlap；false positives and false negatives remain unavoidable。
- Borderline slowing with low amplitude 可能仍無法單靠一次 NCS 明確分出 severe axonal loss 與 demyelination。
- Proximal CMAP drop 可能來自 true conduction block、temporal dispersion / phase cancellation、pseudo-conduction block 或 technical factors。
- Segmental amplitude change 也可能來自 anomalous innervation；source 尤其強調 MGA 與 APN。
- Internal comparison abnormality 可能來自真正 focal slowing，也可能來自 paired distance mismatch 或 co-stimulation。
- Cool limb 可把 axonal neuropathy 的 velocity 拉到 demyelinating-like range；reversed cathode / anode 可製造 distal latency prolongation；submaximal proximal stimulation 可製造 false conduction block。
- Edema 或 recording electrode distance from nerve 可造成 low / absent sensory response，不能單獨解讀為 axonal sensory loss。

## Limitations and Misreadings

- 誤讀：「Low amplitude = axonal loss。」正確是先排除 conduction block、NMJ / myopathy pattern、hyperacute timing 與 technical inadequacy。
- 誤讀：「Low / absent sensory response = sensory axonal loss。」正確是還要排除 edema、recording electrode off nerve、filter setting、age 與 temperature。
- 誤讀：「Normal SNAP = 沒有 sensory lesion。」正確是 proximal-to-DRG lesion 可保留 SNAP。
- 誤讀：「Proximal amplitude drop = conduction block。」正確是需看 area、duration、segment length、nerve-specific exception、stimulation adequacy、injury timing 與 anomalous innervation。
- 誤讀：「Conduction velocity normal 代表 nerve normal。」正確是 latency / velocity 只看 fastest fibers，amplitude may reveal axonal loss。
- 誤讀：「NCS 數字落在 normal range 就技術合格。」正確是 stimulation 必須 supramaximal，否則 amplitude 與 velocity 仍可能失真。
- 誤讀：「單一 borderline abnormal NCS parameter 就能診斷 neuropathy。」正確是需結合 pre-test probability、technical validity 與其他支持性 abnormality。
