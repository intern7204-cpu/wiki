# 周邊神經病灶定位與 EDX / US 框架

## One-Sentence Definition

Peripheral nerve localization 是把 motor / sensory / reflex pattern、anatomic vulnerability、EDX physiology 與 neuromuscular ultrasound structure 對齊，而不是套用固定檢查套餐。

## Definition and Boundary

- 本頁聚焦 focal neuropathy、plexopathy、root-vs-nerve 鑑別與 EDX / ultrasound 的角色分工。
- 本頁不逐一整理所有 mononeuropathy treatment。
- 本頁以 [[../10_來源摘要/Peripheral_Nerve_Disorders]] 建立臨床定位框架，並連結 [[../10_來源摘要/Approach_NCS_EMG_Neuromuscular_Ultrasound]]、[[../10_來源摘要/Basic_Nerve_Conduction_Studies]]、[[../10_來源摘要/Anomalous_Innervations]]、[[../10_來源摘要/Routine_Upper_Extremity_Facial_Phrenic_NCS_Techniques]] 與 [[../10_來源摘要/Routine_Lower_Extremity_NCS_Techniques]] 補足 EDX workflow、NCS parameter interpretation、anatomic variant pitfall 與 routine protocol pitfall。

## Why It Matters

- 第五指麻木可能來自 ulnar nerve、medial cord、lower trunk 或 C8 root；只看一個症狀無法定位。
- Focal neuropathy 若伴隨 non-median muscle weakness、reflex asymmetry 或 prominent neck pain，就不能直接貼上 CTS label。

## Preconditions or Conditions

- 先用 history / exam 形成 localization hypothesis，再設計 NCS / needle EMG。
- 要問 onset、trauma / compression / traction、positioning、brace / assistive device use、repetitive load、systemic risk factor 與 prior surgery。

## Mechanism

```text
Symptom distribution
→ motor / sensory / reflex mapping
→ hypothesize nerve vs plexus vs root vs generalized neuropathy
→ EDX tests physiology, severity, chronicity, and axonal vs demyelinating process
→ ultrasound tests morphology, compression, enlargement, and continuity
→ management, prognosis, and referral decision
```

## Observable Patterns

- Median neuropathy at the wrist：thenar eminence sensation 通常 spared，因 palmar cutaneous branch 在 carpal tunnel 近端分出。
- CTS 早期常 intermittent、night symptoms、flick sign 改善；advanced cases 可有 fixed sensory deficit、thenar weakness / atrophy。
- EDX 對 CTS 的 sensitivity 來源報告約 80-90%；mild disease 以 sensory latency change 為主，severe disease 可見 axonal loss。
- CTS protocol 可用 median sensory palmar wrist-to-palm relative slowing、median-ulnar lumbrical-interossei comparison、digit 4 median-ulnar comparison、digit 1 median-radial comparison 或 median-ulnar palmar mixed comparison，但 paired distances 必須一致。
- MGA plus CTS 可造成 prolonged distal median motor latency、proximal positive dip 與 factitiously fast median forearm conduction velocity；不可把此 pattern 當成單純 forearm conduction physiology。
- UNE protocol 需要 wrist、below-elbow、above-elbow stimulation；dorsal ulnar cutaneous response helps separate Guyon's canal from proximal ulnar lesions but is not universally abnormal in UNE。
- Radial sensory sparing supports PIN neuropathy over more proximal radial / plexus lesion。
- Medial and lateral antebrachial cutaneous SNAPs can help localize lower trunk / medial cord versus upper trunk / lateral cord plexus patterns。
- APN 可讓 peroneal motor study recording EDB 出現 proximal amplitude 高於 ankle；若合併 PNFN，可能出現 low-high-low amplitude pattern。
- Peroneal neuropathy at fibular neck 的 routine NCS 必須包含 ankle、below-fibular-neck、above-fibular-neck stimulation；TA recording 可比 EDB 更容易顯示 focal slowing / block。
- Distal tibial neuropathy across the ankle 評估中，plantar mixed nerve studies 在此來源中比 orthodromic plantar sensory studies preferred，且 small / absent response 需 side-to-side context。
- H reflex delayed / absent 可出現在 polyneuropathy、tibial neuropathy、sciatic neuropathy、lumbosacral plexopathy 或 S1 radiculopathy，因此只能作為 proximal pathway clue。
- Ultrasound 在 CTS 可見 median nerve enlargement、flattening、flexor retinaculum bowing、increased vascularity 或 reduced mobility。
- Acquired demyelinating neuropathy 可有 multifocal nerve enlargement；hereditary demyelinating neuropathy 較傾向 diffuse symmetric enlargement。

## Clinical / Research Implication

- EDX 與 ultrasound 是互補工具：EDX 說明 conduction / axonal physiology，ultrasound 補 structural lesion。
- EDX 先回答 physiology / localization，neuromuscular ultrasound 才用來補 anatomy / etiology；來源明確指出 ultrasound 不取代 EDX。
- NCS localization value depends on protocol completeness; missing below-elbow ulnar stimulation or wrong elbow distance can change the localization conclusion.
- NCS 中 amplitude-dominant abnormality 較支持 axonal loss，但需排除 demyelinating conduction block、hyperacute pseudo-conduction block 與 technical inadequacy；marked conduction slowing / latency prolongation 則支持 demyelination。
- Normal SNAP with sensory symptoms should shift localization toward lesion proximal to the dorsal root ganglion only when the clinical pattern supports root / CNS localization。
- Apparent conduction block at an unexpected segment should trigger anatomic variant review, especially MGA in ulnar forearm studies and APN in peroneal EDB studies.
- Acute trauma 早期 needle EMG 可能尚未顯示 denervation；ultrasound 可提早顯示 focal compression 或 discontinuity。
- Postoperative persistent symptoms 不能只看 EDX，因 EDX abnormality 可能在 clinical improvement 後仍殘留；ultrasound 可能補結構資訊。

## Fact

- Peripheral nerve disorders 可是 focal injury，也可為 generalized neuropathy。
- Focal neuropathies 常由 laceration、compression、traction、repetitive motion、direct trauma、prolonged positioning、bracing 或 assistive devices 造成。
- EDX 可 confirm、localize、characterize severity / chronicity，並協助 prognosis。
- Basic NCS parameter interpretation 要區分 latency / conduction velocity、amplitude / area 與 duration 的 physiology，不應把單一 low amplitude 直接等同於 axonal loss。
- Neuromuscular ultrasound 可在 EDX 正常時找到 structural abnormality，並可用於 generalized neuropathy 的形態評估。
- Mononeuropathy 中，ultrasound 可在 EDX 已定位到單一 nerve 但無法精確 segmental localization 時，沿神經走向尋找結構異常。
- Pure lower motor neuron syndrome 中，ultrasound 可協助區分 motor neuron disorder 與可能可治療的 motor neuropathy，因 inflammatory motor neuropathy 可能出現 hypertrophic nerves，而 ALS / PMA 通常不會。
- Ultrasound 可協助區分 acquired inflammatory demyelinating pattern 與 hereditary diffuse symmetric enlargement pattern。

## Inference

- Provocative tests 如 Tinel / Phalen 的價值取決於前後脈絡；單獨陽性不能取代完整 localization。
- 若症狀橫跨多個 peripheral nerves 或 roots，但共同落在 plexus segment，應提高 plexopathy suspicion。

## Assumption

- 操作者熟悉 nerve anatomy、常見 anatomic vulnerability 與 EDX / ultrasound 技術限制。

## Uncertainty

- Ultrasound 閾值與 diagnostic performance 依 nerve、儀器、操作者與 reference standard 而異；不應把單一數值無條件外推。

## Limitations and Misreadings

- 誤讀：「手麻就是 CTS。」正確是 CTS 需符合 median distribution、thenar-sparing pattern、provocation context、EDX / US 或臨床嚴重度。
- 誤讀：「EDX 正常就沒有 focal neuropathy。」正確是部分 structural lesions 或 very early injury 仍可能需要 ultrasound / repeat EDX。
- 誤讀：「影像或 ultrasound 有變大就一定是症狀來源。」正確是仍需 clinical distribution 對齊。
- 誤讀：「不合 nerve map 的 EDX pattern 一定代表多重病灶。」正確是先排除 technical factors 與 anomalous innervation。
