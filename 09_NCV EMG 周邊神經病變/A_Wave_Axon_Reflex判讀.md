# A Wave / Axon Reflex 判讀

## One-Sentence Definition

A wave（俗稱 axon reflex）是在 reinnervated 或 demyelinated motor nerve 中，submaximal 刺激下 antidromic action potential 經 collateral branching point 折返 orthodromically 回到肌肉所形成的晚期 motor potential；它在每次刺激下 latency 與 configuration 完全一致，常出現在 M response 與 F response 之間，是 reinnervation、demyelination 或刺激不足夠 supramaximal 的 marker，而不是 true reflex。

## Definition and Boundary

- 本頁只處理 A wave (axon reflex) 的 circuitry、辨識方法、臨床意義與限制。
- 本頁不取代 [[F_Response_F_Estimate判讀]] 或 [[H_Reflex_臨床用途與限制]]。
- 本頁不建立 reinnervation timeline、collateral sprouting、Guillain-Barré syndrome、demyelinating polyneuropathy 或 axonal injury 的完整 diagnostic criteria。
- 本頁僅引用單一來源：[[../10_來源摘要/Late_Responses]]。

## Why It Matters

- A wave 在 F response trace 中很容易被誤判為 F response；正確分辨是基本判讀技能。
- A wave 是 chronic axonal injury 之後 reinnervation 的線索，也可在 early GBS 出現，因此可改變 differential。
- 一個原本沒有 A wave 的 nerve 突然出現新的 A wave，常是「distal stimulation 不夠 supramaximal」的品質警訊，而不是新的病理。
- 不認識 A wave，會把它解讀為 F response，誤估 F response persistence、chronodispersion 或 minimal latency。

## Preconditions or Conditions

- 至少 10 次 rastered F response trace；A wave 與 F 的關鍵區辨來自 latency / configuration 是否「stack 完美一致」。
- 維持嚴格的 supramaximal stimulation；A wave 在 supramaximal 時常會被 antidromic collision 消除，因此「supramaximal 時仍持續出現」可有不同解讀（reinnervation / demyelination / 刺激實際上仍不夠 supramaximal）。
- 必須先排除 F response 的可能：F latency 與 configuration 隨刺激而變動，A wave 不變動。
- 若研究 nerve 在臨床上預期 reinnervation（chronic axonal injury、postsurgical recovery、診斷 GBS 早期），辨識 A wave 的優先序更高。

## Mechanism

```text
Distal nerve stimulation (often submaximal or in reinnervated nerve)
→ orthodromic volley → M response
→ antidromic volley travels up axon
→ encounters collateral branching point proximal to stim site
   (proximal branching only typical after collateral sprouting / reinnervation)
→ at the branching point, action potential turns into the branching fiber
→ travels orthodromically distally past stim site to muscle
→ small late motor potential = A wave
→ stable latency and configuration with each stimulation
→ supramaximal stimulation usually produces antidromic volley in branch fiber
   that collides with the orthodromic A wave → A wave eliminated
```

### Demyelination variant

```text
Sites of inflammation / demyelination (e.g., early GBS)
→ ephaptic spread between adjacent fibers (speculated mechanism)
→ stable latency late potential indistinguishable on trace from collateral-sprout A wave
→ classified together as A wave
```

## Observable Patterns

- 在 rastered F trace 中，A wave 在每次 trace 出現於同一 latency、同一形狀，superimpose 完全重合。
- F response 在 rastered trace 中 latency / configuration 略變動、不會完美 superimpose。
- A wave 通常出現在 M response 之後、F response 之前；少數情況下 collateral fibers 速度極慢時，A wave 可出現在 F response 之後。
- A wave 在 submaximal / 接近 threshold 刺激下較易出現；supramaximal 時常被 antidromic collision 消除。
- 在 reinnervated nerve（chronic axonal injury、postsurgical 神經再生）上 A wave 較常見。
- 在 demyelinating polyneuropathy 中可見 A wave；early GBS 病程前幾天經典出現 A wave。
- 若刺激實際未真正 supramaximal，A wave 仍可保持，作為品質警訊。

## Clinical / Research Implication

- 在臨床報告中，A wave 應寫成「present, consistent with reinnervation/collateral sprouting」、「present in early/days of clinical Guillain-Barré syndrome, consistent with demyelination」，或「present, consider whether distal stimulation was truly supramaximal」。
- A wave 不能單獨定位 lesion，也不評估 severity，但可在 longitudinal NCS 中作為 reinnervation 進行的非定量訊號。
- 在 early GBS 評估中，A wave + prolonged / absent F response + temporal dispersion / partial conduction block 是支持 acquired demyelinating polyradiculoneuropathy 的多重線索之一。
- 在 quality control：F response trace 出現新的、stable latency 的「F-like」potential，先重新確認 supramaximal 與 distal CMAP 完整性，再下臨床解讀。

## Fact

- A wave 名為 axon reflex，但不含 synapse、不是 true reflex。
- 它在 rastered F response trace 中以「latency 與 configuration 每次完全一致」的特徵被辨識。
- A wave 通常 latency 短於 F response（因路徑較短）；極少數 collateral fiber 傳導極慢時可在 F 之後。
- 一般 motor nerve 的 axon 在離 muscle 很近處才分支；distal stim 通常不會跨越分支點。
- Reinnervated nerve 中 collateral sprouts 會讓 branching point 移到 stim 點 proximal 處，使 antidromic 折返成為可能。
- Submaximal stimulation 是 A wave 出現的常見條件；supramaximal 時 antidromic collision 通常消除 A wave。
- A wave 主要伴隨 axonal-loss 後 reinnervation；也可見於 demyelinating neuropathy。
- Early Guillain-Barré syndrome 病程前幾天經典出現 A wave；source 對其機制提出 ephaptic spread 的推測，未確認。
- A wave 可作為 distal stimulation 不足夠 supramaximal 的線索。

## Inference

- 任何「F response trace 上 latency / configuration 異常穩定」的晚期 potential，第一假設應為 A wave，而不是 F response。
- 在 chronic axonal injury 病人中追蹤 A wave 出現可作為 reinnervation 開始的非定量訊號，但不能取代 needle EMG reinnervation potentials。
- 早期 GBS 多項 EDX features 中，A wave 是 supportive 但非 specific 線索。

## Assumption

- F response trace 收集足夠次數（≥ 10 次 rastered），讓 latency 變動 vs. 不變動的辨識可靠。
- 操作者能準確分辨 M response、A wave、F response 三者在 trace 上的時間順序與穩定性。

## Uncertainty

- A wave 在 demyelinating disease（特別是 early GBS）的具體機制（ephaptic spread）為 source 推測，未確認。
- A wave 的 yield、sensitivity、specificity 對 reinnervation / demyelination 在 source 中無 quantitative 數據。
- 何種情境下「supramaximal 後仍持續存在的 A wave」應優先解讀為 demyelination、reinnervation 或 stimulation 不足，需以整體 EDX context 判斷。

## Limitations and Misreadings

- 誤讀：「Stable latency 的晚期 potential 都是 F response。」正確是 latency / configuration 完美一致時較可能是 A wave。
- 誤讀：「Axon reflex 是 reflex。」正確是它沒有 synapse、不是 reflex；命名僅為歷史用語。
- 誤讀：「A wave 出現 = reinnervation。」正確是它也可見於 demyelination（特別是 early GBS），且可能反映 stimulation 不足 supramaximal。
- 誤讀：「A wave 可定位 lesion 或量化 severity。」正確是它是 marker，不提供 localization 或 severity。
- 誤讀：「沒看到 A wave 就排除 reinnervation。」正確是 supramaximal 刺激下 A wave 常被 collision 消除；缺少 A wave 不等於沒有 reinnervation。
- 誤讀：「Late potential 出現在 F 之後，就一定是新的 wave 種類。」正確是極少數 collateral fibers 速度極慢時，A wave 也可在 F response 之後出現。
