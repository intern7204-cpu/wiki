# EDX 定位導向檢查流程

## One-Sentence Definition

EDX 定位導向檢查流程是先用 brief history 與 directed neurologic examination 建立 localization hypothesis，再用 targeted NCS、needle EMG 與必要時 neuromuscular ultrasound 做即時修正與臨床相關性判讀。

## Definition and Boundary

- 本頁只處理 EDX encounter 的檢查設計與判讀流程。
- 本頁不整理各疾病的完整 EDX diagnostic criteria。
- 本頁不主張 ultrasound 可取代 NCS / needle EMG；ultrasound 的角色是補足 structure / anatomy / etiology。
- 本頁以 [[../10_來源摘要/Approach_NCS_EMG_Neuromuscular_Ultrasound]] 建立 workflow，以 [[../10_來源摘要/Basic_Nerve_Conduction_Studies]] 補入 NCS parameter-level interpretation，以 [[../10_來源摘要/Artifacts_and_Technical_Factors]] 補入 technical validity 前提，以 [[../10_來源摘要/Anomalous_Innervations]] 補入 anatomic variant pitfall，並以 [[../10_來源摘要/Routine_Upper_Extremity_Facial_Phrenic_NCS_Techniques]] 補入 upper-extremity protocol pitfall。

## Why It Matters

- EDX 的主要任務是 localization；若沒有 clinical question，檢查會退化成大量數值與 incidental abnormalities。
- 同一個 EMG abnormality 在 ulnar neuropathy、C8-T1 radiculopathy、lower brachial plexopathy 或 motor neuron disease 中意義不同，必須先有臨床定位假說。
- 過度解讀 minor abnormality 會造成錯誤診斷、錯誤影像、錯誤手術或錯誤治療。

## Preconditions or Conditions

- 下單或執行前需明確知道症狀、時間軸、past medical history、weakness / atrophy、tone、reflex、sensory distribution 與 differential diagnosis。
- 檢查者需能在檢查中依早期結果改變 nerve / muscle selection。
- 每次 NCS / EMG 判讀前需確認 temperature、electrode impedance、filter settings、stimulator polarity、supramaximal stimulation、co-stimulation、electrode placement、distance measurement 與 limb position。
- Nerve-specific protocol 需依目標定位選擇；例如 suspected ulnar neuropathy at elbow 必須納入 wrist、below-elbow、above-elbow stimulations。
- 若 waveform pattern 不符合 standard nerve map，需同時檢查 technical artifact 與 anomalous innervation，而不是直接加上第二個診斷。
- 若病人耐受度有限，先做最可能回答問題的 nerve / muscle，而不是先做固定 routine panel。

## Mechanism

```text
Brief history + directed neurologic examination
→ differential diagnosis
→ localization hypothesis
→ targeted NCS first
→ modify NCS based on findings
→ targeted needle EMG
→ modify muscle sampling based on findings
→ clinical + NCS + EMG correlation
→ if residual structural question exists, targeted neuromuscular ultrasound
→ diagnosis / severity / time course / uncertainty statement
```

## Observable Patterns

- Pure weakness 的 first-order localization 需分 motor neuron / motor axon、NMJ、muscle 或 CNS。
- 第四、五指麻木與手部無力不能直接等同 ulnar neuropathy；需分 ulnar nerve、lower brachial plexus、C8-T1 root。
- NCS waveform 需以 parameter-level 解讀：latency / conduction velocity 主要反映 fastest fibers，amplitude / area 反映 depolarized fiber population，duration 反映 synchrony / temporal dispersion。
- Low amplitude 不能單獨指定為 axonal loss；conduction block、hyperacute pseudo-conduction block、NMJ / myopathy pattern 與 technical factors 都需先排除。
- Slow velocity with high-amplitude / long-duration sensory response 應先考慮 cooling artifact；proximal amplitude drop 應先排除 submaximal stimulation、co-stimulation 或 anomalous innervation。
- Ulnar forearm "conduction block" pattern 需考慮 MGA；peroneal EDB proximal amplitude 高於 ankle 需考慮 APN。
- Ulnar across-elbow NCS 需 elbow flexed 90-135 degrees 且用 curved distance；straight-line distance 會低估 nerve length 並造成假性 slowing。
- Median-ulnar / median-radial internal comparison studies 需 identical distances；distance error 會直接製造 false latency difference。
- 若 NCS 顯示 ulnar motor / sensory abnormality 且 across-elbow slowing，needle EMG 又只影響 ulnar-innervated muscles，臨床也符合，ulnar neuropathy at elbow 的診斷可信度高。
- 若只有低 ulnar sensory potential 加 mild biceps reinnervation，且臨床沒有對應 deficit，不應硬診斷 ulnar neuropathy + C5 radiculopathy。
- Neuromuscular ultrasound 對 mononeuropathy 可補 segmental localization 或 compressive lesion；對 demyelinating polyneuropathy 可補 hypertrophic nerve pattern；對 myopathy 可補 muscle involvement pattern 與 biopsy target。

## Clinical / Research Implication

- EDX report 應說明 clinical relevance，而不是只列 abnormal values。
- 正確報告可把結果分為：definite localization、physiologic pattern、severity / chronicity、uncertain-significance finding、technical limitation。
- Neuromuscular ultrasound 的最佳使用情境是回答 EDX 後仍殘留的 anatomy / etiology question。

## Fact

- NCS 與 needle EMG 是 EDX study 的核心，兩者互補。
- 每次 EDX study 應依 neurologic examination 與 differential diagnosis 個別化，並在檢查進行中修正。
- EDX 的 principal goal 是 localization。
- NCS 通常先做，因為 NCS 結果會影響後續 needle EMG strategy 與 interpretation。
- Basic NCS 的 amplitude、latency、conduction velocity、area 與 duration 對應不同 physiology，不能把所有 abnormality 混成單一診斷標籤。
- Technically inaccurate EDX data cannot be fixed by later interpretation。
- Temperature should ideally be maintained at 32-34°C; normal-range amplitude does not prove supramaximal stimulation.
- Lesion proximal to the dorsal root ganglion 可有 sensory symptoms 但 SNAP preserved。
- Cardinal rules 包含：EDX 是 clinical examination 的延伸、疑問時先想 technical factors、必要時重新檢查病人、報告需放回 clinical context、不要 overcall diagnosis、維持 clinical-electrophysiologic correlation。
- Neuromuscular ultrasound 補 anatomic / structural information，但不取代 EDX physiology。

## Inference

- 高品質 referral question 會提高 EDX 的決策價值；模糊的 "rule out neuropathy" 容易製造低價值或誤導性結果。
- 當 clinical findings、NCS 與 needle EMG 不一致時，最嚴謹的結論常是標示 uncertainty，而不是硬塞成多重診斷。

## Assumption

- 檢查環境有正確的 normative values、temperature control、stimulation / recording technique 與 needle EMG capability。
- 操作者有能力辨識 technical artifact、anatomic variation 與 incidental abnormality。

## Uncertainty

- 本來源沒有提供每一個疾病的 sensitivity / specificity。
- 即使流程正確，部分 lesion 仍可能只能定位到 "at or proximal to" 某個位置，不能強行給出精確壓迫點。
- Ultrasound 可能沒有增量價值，也可能成為關鍵；檢查前無法完全預測。

## Limitations and Misreadings

- 誤讀：「EDX 就是把常規 nerve conduction panel 做完。」正確是 EDX 要依 localization question 設計。
- 誤讀：「有 abnormal value 就有臨床診斷。」正確是 abnormality 需與 clinical pattern、NCS 與 EMG 互相支持。
- 誤讀：「技術細節只是報告附註。」正確是 technical validity 是 EDX diagnosis 的前提。
- 誤讀：「NCS 正常就不用 needle EMG。」正確是許多 root、plexus、motor neuron、myopathy 或 NMJ 問題需要 needle EMG / specialized testing。
- 誤讀：「Ultrasound 看到 nerve enlargement 就是症狀來源。」正確是 ultrasound 仍需 clinical-electrophysiologic correlation。
