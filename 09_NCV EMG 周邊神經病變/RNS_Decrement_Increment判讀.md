# RNS Decrement / Increment 判讀

## One-Sentence Definition

RNS decrement / increment 判讀，是用 repeated stimulation 或 exercise 後 CMAP amplitude / area 的下降或上升，推估 neuromuscular junction safety factor 是否不足，以及 abnormality 較像 postsynaptic 還是 presynaptic NMJ disorder。

## Definition and Boundary

- 本頁只處理 RNS 的 physiology 與 decrement / increment interpretation。
- 本頁不處理完整 disease-specific myasthenia gravis、Lambert-Eaton myasthenic syndrome、botulism diagnostic criteria。
- 本頁不取代 [[RNS_Protocol與技術陷阱]]；protocol validity 是本頁判讀的前提。
- 本頁僅引用單一來源：[[../10_來源摘要/Repetitive_Nerve_Stimulation]]。

## Why It Matters

- RNS 是 suspected NMJ disorder 的核心 EDX tool，但它量到的是 CMAP summation 變化，不是直接看見單一 synapse。
- Decrement / increment 若離開 technical validity 與 clinical context，會誤診 myasthenia gravis、Lambert-Eaton myasthenic syndrome 或 motor neuron disease。
- Postsynaptic 與 presynaptic NMJ disorders 的 RNS pattern 不同，因為前者主要是 receptor-side response 降低，後者主要是 quanta release 降低。

## Preconditions or Conditions

- 已排除主要 technical artifact：cold limb、submaximal stimulation、electrode movement、co-stimulation 與 inadequate immobilization。
- 已知 baseline CMAP amplitude；presynaptic disorder 常有 low baseline CMAP。
- 已完成 routine motor NCS；若 motor nerve 本身已有 severe axonal loss 或 conduction abnormality，RNS 判讀需加 caveat。
- 已知道 acetylcholinesterase inhibitor status；pyridostigmine 等藥物可減少 decrement。
- 已做 needle EMG 或至少知道 denervation / myotonia 是否可能造成 secondary decrement。

## Mechanism

```text
正常 NMJ
→ slow 2-3 Hz RNS 消耗 immediately available ACh quanta
→ EPP 下降但仍高於 threshold
→ 每條 muscle fiber 仍產生 MFAP
→ CMAP amplitude / area 穩定

Postsynaptic NMJ disorder
→ AChR 數量或 postsynaptic response 下降
→ baseline EPP 比正常低，safety factor 變小
→ slow RNS 後 quanta depletion
→ 部分 EPP 掉到 threshold 以下
→ 部分 MFAP 消失
→ CMAP decrement

Presynaptic NMJ disorder
→ VGCC dysfunction 或 quanta release 下降
→ baseline EPP / CMAP 偏低
→ brief exercise 或 rapid RNS 造成 calcium accumulation
→ release probability 上升
→ 更多 EPP 超過 threshold
→ CMAP increment
```

## Observable Patterns

- Normal slow RNS：EPP 可下降，但 CMAP amplitude / area 不應明顯改變。
- Postsynaptic pattern：3-Hz RNS 可出現 CMAP decrement，常在第 3 或第 4 response 最低。
- True NMJ decrement 常呈 U-shaped decrement：第 3-5 個 response 後，mobilization store 補充 primary store，decrement 開始 repair。
- Presynaptic pattern：baseline CMAP 可低；brief exercise 或 rapid RNS 後可有 marked CMAP increment。
- Postexercise facilitation：10 秒 maximal voluntary exercise 後，EPP 增加；postsynaptic disorder 中可 repair 先前 slow RNS decrement，presynaptic disorder 中可把 subthreshold fibers 拉回 threshold 以上。
- Postexercise exhaustion：1 分鐘 maximal exercise 後，2-4 分鐘內 slow RNS decrement 可能更明顯。
- Pseudofacilitation：正常人在 brief exercise 後 CMAP amplitude 可升高，但 duration 變短、area 幾乎不變；通常不超過 40%。
- Increment >100% 高度支持 presynaptic NMJ disorder；40-100% increment 為 equivocal。
- >10% decrement 定義為 abnormal；source 也指出任何 reproducible decrement 可能都不正常，但 10% cutoff 用來容納 technical factors。
- Decrement 可見於 severe denervating disorders、motor neuron disease、myotonic disorders 與 metabolic myopathies，因此不等同 primary NMJ disorder。

## Clinical / Research Implication

- RNS 結論應寫成 physiology statement，例如「reproducible decrement consistent with impaired neuromuscular transmission」，再依 clinical context 討論 differential diagnosis。
- 若出現 decrement，但 needle EMG 同一肌肉有 denervation 或 myotonia，不能直接診斷 primary NMJ disorder。
- 若 baseline CMAP low 且 exercise 後 increment >100%，應提高 presynaptic NMJ disorder 的可能性，但仍需結合 clinical / serologic context。
- 若 decrement 在 10 秒 exercise 後 repair，或 prolonged exercise 後 2-4 分鐘更明顯，再被 10 秒 exercise repair，更支持 true NMJ physiology。

## Fact

- RNS 應考慮於 suspected myasthenia gravis、Lambert-Eaton myasthenic syndrome、botulism、fatigability、proximal weakness、dysphagia、dysarthria 與 ocular abnormalities。
- ACh quanta 由 immediately available、mobilization 與 reserve stores 供應。
- Slow RNS 主要暴露 quanta depletion 下的 safety factor 不足。
- Rapid RNS 或 brief maximal exercise 可因 calcium accumulation 增加 quanta release。
- CMAP decrement 反映參與 CMAP summation 的 MFAP 數量下降。
- CMAP increment 反映更多原本 subthreshold 的 muscle fibers 被帶回 threshold 以上。
- 10 秒 exercise / rapid RNS 可造成 postexercise facilitation。
- 1 分鐘 exercise 後可觀察 postexercise exhaustion。
- Normal pseudofacilitation 可造成 CMAP amplitude 上升但 area 改變小。

## Inference

- RNS 的判讀單位不是「神經傳導速度」，而是「repeated activation 下 motor endplate 是否仍能可靠觸發 MFAP」。
- U-shaped decrement 比單一 response drop 更像 true NMJ physiology，因為它對應 mobilization store 開始補充 immediately available store。

## Assumption

- CMAP amplitude / area 的變化主要反映 activated muscle fiber population，而不是 electrode displacement。
- 受測肌肉與 clinical weakness 有足夠關聯。
- 技術前提已達可判讀標準。

## Uncertainty

- 本來源未提供各 NMJ disease 的 RNS sensitivity / specificity。
- Mild ocular myasthenia gravis 或受測肌肉不弱時，normal RNS 仍不能排除 NMJ disorder。
- Postexercise exhaustion 的完整生理機制仍未完全明確。

## Limitations and Misreadings

- 誤讀：「>10% decrement = myasthenia gravis。」正確是 >10% decrement 支持 abnormal neuromuscular transmission，但需排除 denervation、myotonia、metabolic myopathy 與 artifact。
- 誤讀：「No decrement = no NMJ disorder。」正確是 normal RNS 只能降低 probability，不能排除。
- 誤讀：「Amplitude increment 一定是 Lambert-Eaton myasthenic syndrome。」正確是 pseudofacilitation 可達約 40%，40-100% equivocal，>100% 才高度支持 presynaptic disorder。
- 誤讀：「Rapid RNS 是首選。」正確是 rapid RNS 痛且難耐受；能合作時 source 偏好 brief maximal voluntary exercise。
- 誤讀：「RNS 可以離開 clinical exam 與 needle EMG 判讀。」正確是 RNS 需和 history、exam、routine NCS 與 needle EMG 整合。
