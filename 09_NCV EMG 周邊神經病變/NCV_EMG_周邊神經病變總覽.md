# NCV EMG 周邊神經病變總覽

## One-Sentence Definition

NCV / EMG 周邊神經病變框架，是用 clinical localization 先定義問題，再以 NCS / needle EMG 檢查 physiology、severity、chronicity 與 pattern，最後回到 prognosis、rehabilitation risk 與 referral decision。

## Definition and Boundary

- 本頁是 `09_NCV EMG 周邊神經病變` 的 hub page，負責串接定位、技術品質、NCS interpretation、anatomic variant 與 peripheral neuropathy pattern。
- 本頁不建立 CTS、UNE、CIDP、GBS、radiculopathy 或 plexopathy 的完整 diagnostic criteria。
- 本頁不取代各 disease-specific source；若要建立疾病頁，需另用單一來源 ingest。

## Why It Matters

- NCV / EMG 的臨床價值來自問題設定；沒有 localization hypothesis 的檢查容易變成低效率 screening。
- Peripheral nerve disorder 的臨床後果不只診斷名稱，還包括 falls、foot breakdown、neuropathic pain、weakness、deconditioning 與 participation loss。
- 技術錯誤、temperature、co-stimulation、distance measurement 與 anomalous innervation 都可能把 physiology 誤讀成 pathology。

## Preconditions or Conditions

- 先確認 referral question：focal neuropathy、polyneuropathy、plexopathy、radiculopathy、motor neuron disease mimic、myopathy mimic，或 injury prognosis。
- 先確認 foundational anatomy / physiology：DRG 位置、myotome / dermatome overlap、large-fiber selectivity、motor unit 與 volume conduction 會決定可測與不可測的範圍。
- 先估計 pre-test probability：positive EDX 的意義取決於症狀、signs、differential diagnosis 與 test characteristics。
- 先做 clinical distribution mapping：motor、sensory、reflex、autonomic、pain distribution 與 time course。
- NCS / EMG 前要確認 technical validity：temperature、supramaximal stimulation、recording montage、distance、limb position、actual distance、pulse setting 與 artifact control。

## Mechanism

```text
Referral question
→ clinical localization hypothesis
→ choose nerve / muscle protocol
→ verify technical validity
→ interpret NCS: amplitude, latency, conduction velocity, area, duration, temporal dispersion
→ integrate needle EMG: denervation, reinnervation, chronicity, recruitment
→ separate focal lesion, generalized neuropathy, root / plexus lesion, variant, or artifact
→ prognosis and rehabilitation decision
```

## Observable Patterns

- Focal neuropathy：需要把 symptom distribution、motor / sensory territory、reflex pattern、EDX physiology 與 ultrasound structure 對齊。
- Peripheral nerve injury：prognosis 取決於 demyelination、axonal loss、connective tissue scaffold integrity 與 recovery mechanism。
- Typical polyneuropathy：常見 pattern 是 chronic、length-dependent、symmetric、axonal、sensory-motor process；偏離此 pattern 時需升級診斷。
- Diagnostic statistics pitfall：borderline abnormality 在 low pre-test probability 情境下常是 false positive；多重檢查若任一 abnormal 即診斷會升高 cumulative false-positive risk。
- NCS technical pitfall：submaximal stimulation、co-stimulation、wrong distance、temperature 與 anatomic variant 可造成 false slowing、false conduction block 或 false localization。
- Routine lower-extremity NCS pitfall：tibial popliteal amplitude drop、peroneal below-fibular-head normal amplitude drop、small / absent plantar or cutaneous sensory responses、APN、height-adjusted late responses 與 H-reflex nonspecificity 都可能被過度解讀。
- Late response pitfall：prolonged F response 不等於 radiculopathy（distal slowing、long limb 都可造成）；normal F response 也不能排除 radiculopathy（sensitivity 對 S1 radiculopathy 約 4-8%）；absent / delayed H reflex 在 polyneuropathy、tibial / sciatic neuropathy、lumbosacral plexopathy 與 S1 radiculopathy 都可能；在 F response trace 上 latency / configuration 完美一致的晚期 potential 是 axon reflex (A wave)，不是 F response。
- RNS pitfall：>10% reproducible CMAP decrement 支持 impaired neuromuscular transmission，但不能單獨診斷 myasthenia gravis；postexercise increment 需分 true facilitation 與 pseudofacilitation，且 cold limb、submaximal stimulation、electrode movement、acetylcholinesterase inhibitors、denervation 與 myotonia 都會改變判讀。
- Blink reflex pitfall：blink reflex 是 cranial nerve V1 afferent、pons / medulla interneuron network 與 cranial nerve VII efferent 的 true reflex；R1 / R2 必須依 stimulus side + recording side 判讀，R2 abnormal 不能直接等同 facial neuropathy。
- Foundational physiology pitfall：normal SNAP 不能排除 proximal-to-DRG sensory lesion；normal routine NCS 不能排除 selective small-fiber neuropathy；motor CMAP morphology 會受 motor-point electrode placement 影響。

## Fact

- EDX 檢查應由 clinical history、directed exam 與 localization hypothesis 引導。
- Routine NCS 主要記錄 large fast myelinated fibers；standard NCS 不記錄 small pain、temperature 或 autonomic fibers。
- EDX abnormality 不能完全 rule in / rule out condition；normal and disease distributions overlap creates false positives and false negatives。
- NCS parameter interpretation 需要同時看 amplitude、latency、conduction velocity、area、duration、temporal dispersion 與 stimulation location。
- Peripheral nerve injury 的 recovery mechanism 包含 remyelination、collateral sprouting 與 axonal regrowth。
- Typical polyneuropathy 與 atypical neuropathy 的型態區分會改變 diagnostic escalation。
- RNS 以 repeated stimulation 或 exercise 後的 CMAP decrement / increment 評估 neuromuscular junction safety factor。
- Blink reflex 以 supraorbital V1 stimulation 與 bilateral orbicularis oculi recording 評估 trigeminal-facial brainstem reflex arc。

## Inference

- 把 EDX / NCS 方法頁與周邊神經病變頁收在同一資料夾，可降低「技術判讀」與「臨床定位」被分開閱讀造成的誤判。
- Hub page 的主要功能是導流與邊界控制，不應承載過多 disease-specific criteria。

## Assumption

- 本資料夾目前以 peripheral nerve / EDX 為範圍，不擴張到所有 neuromuscular disorders。
- Myopathy、motor neuron disease、spasticity、central lesion 仍先留在原本 disease / methodology 脈絡，除非未來另建 broader neuromuscular folder。

## Uncertainty

- CTS、UNE、radiculopathy、plexopathy、CIDP、GBS 等 disease-specific 頁尚未依單一來源逐頁建立或校正。
- Disease-specific pages for peroneal neuropathy at fibular neck、tarsal tunnel syndrome、lateral femoral cutaneous neuropathy、sciatic neuropathy、lumbar plexopathy and S1 radiculopathy 尚未依單一來源建立。
- Specialized EDX testing 中 late responses 已拆 F response、H reflex、A wave 三頁；RNS 已拆 decrement / increment 判讀與 protocol / technical pitfalls 兩頁；blink reflex 已建立 R1/R2 pattern interpretation 頁。

## Limitations and Misreadings

- 不可把本頁當作完整 EDX protocol checklist。
- 不可把 normal table 當作唯一判讀依據；side-to-side comparison、internal comparison 與 technical context 仍需保留。
- 不可把 isolated borderline abnormality 當作 diagnosis；需看 pre-test probability、abnormal magnitude 與是否有 convergent evidence。
- 不可把 diabetes、aging 或常見 entrapment label 當作 atypical neuropathy 的自動解釋。
