# VO2-Work Rate Nonlinearity Above GET

## 一句話定義

在 constant-load exercise 高於 GET / LT 之後，V̇O2 不再只是依照 sub-GET 的線性 V̇O2-work rate gain 上升；[[VO2_Slow_Component]] 會讓 oxygen cost 隨時間額外增加，使同一外在 work rate 對應到更高、且可能持續變動的 V̇O2。

## 概念邊界

- 本頁只處理 Gaesser and Poole 1996 這一篇來源所支持的概念。
- 這不是 clinical guideline，也不是現代 systematic synthesis。
- 這個概念適用於 **constant-load exercise above GET / LT**，不可直接外推到所有 ramp CPET 或所有 disease populations。
- 這裡的重點不是「V̇O2 與 work rate 永遠不線性」，而是「sub-GET linear gain 不能全域外推到 high-intensity constant-load exercise」。

## 已知事實

- 快速 incremental exercise 中，V̇O2 可能看起來與 work rate 線性上升到 V̇O2max。
- 低於 lactate threshold / GET 的 constant-load exercise 通常能在約 3 分鐘內達到 V̇O2 steady state。
- 低於 threshold 的 V̇O2-work rate gain 約為 9-11 mL O2/min/W。
- 高於 lactate threshold / GET 時，constant-load exercise 會出現 delayed V̇O2 slow component。
- V̇O2 slow component 通常可操作性定義為運動第 3 分鐘後仍持續上升的 V̇O2。
- Heavy domain 中，slow component 可讓 V̇O2 在較高水準延遲穩定。
- Severe domain 中，V̇O2 可能無法穩定，並在疲勞前逐步逼近 V̇O2max。
- Slow component 可超過 1.0 L/min；極端情況約可達 1.0-1.5 L/min。
- Prolonged moderate exercise 的小幅 oxygen drift 不等同於 high-intensity V̇O2 slow component。

## 推導鏈

1. Work rate 固定在 GET / LT 以上。
2. 初期 V̇O2 先出現 rapid fundamental response。
3. 約 80-110 秒後，delayed slow component 開始疊加。
4. 第 3 分鐘後 V̇O2 仍繼續上升。
5. 實際 V̇O2 高於 sub-GET gain 對該 work rate 的推估值。
6. 因此同一 external work rate 的 oxygen cost 不是固定常數，而是會受時間與 domain 影響。
7. 若能穩定，這是 heavy-domain delayed steady state；若不能穩定並推向 V̇O2max，則符合 severe-domain behavior。

## 臨床與研究意義

- 用 ramp CPET 得到的 linear V̇O2-work rate relation，不應直接拿來估算 high-intensity constant-load exercise 的整段 oxygen cost。
- 在 heavy / severe domain，固定 %V̇O2max 不能完整描述運動強度，因為同一 work rate 的 V̇O2 會隨時間改變。
- 若要判讀 endurance interval、constant-load tolerance、CP / W' 相關測試，應同時標示 intensity domain。
- 若研究要測 V̇O2 kinetics，必須分開 fundamental component 與 slow component；不能只用單一平均 V̇O2 代表整段生理負荷。

## 推論

- 對臨床 CPET prescription 而言，GET / LT、CP / severe boundary 與 constant-load response，比單一 %V̇O2max 更能描述高強度區間的生理意義。
- 若病人在同一 wattage 下逐漸出現較高 ventilation、dyspnea 或 fatigue，不能只解讀為「意志力下降」；可能是 high-intensity domain 中 oxygen cost 與 efficiency 正在改變。
- 以 domain 命名訓練或測試，比用固定百分比更能避免跨個體與跨時間點誤判。

## 假設

- GET / LT 可作為 moderate-to-heavy boundary 的實用操作標記。
- Pulmonary V̇O2 在初期 cardiodynamic delay 之後，可近似反映 exercising muscle oxidative metabolism 的主要趨勢。
- Gaesser and Poole 1996 對 cycling evidence 的整理，可在概念層次上提示其他大肌群 dynamic exercise，但不能直接替代 mode-specific validation。

## 不確定與限制

- 1996 review 尚未解決 slow component 的單一主要機制。
- Slow component 的 mathematical model 可能依 protocol、domain 與 fitting 方法而不同。
- 這一篇來源不是疾病族群研究；HF、COPD、PAH、neuromuscular disease 或 older adult CPET 需另用 disease-specific source 校正。
- 不可把 lactate、temperature、ventilation、catecholamines 或 type II fiber recruitment 任一因素單獨寫成完整原因。

## 常見誤讀

- 誤讀 1：V̇O2 與 work rate 從來不線性。
  - 修正：在 sub-GET range 與特定 ramp 條件下，線性近似可以成立；問題在於不能全域外推到 above-GET constant-load exercise。
- 誤讀 2：slow component 就是 lactate 造成。
  - 修正：lactate 與 slow component 高度相關，但來源整理的證據不支持 lactate 作為充分單一原因。
- 誤讀 3：只要知道 %V̇O2max 就能描述 heavy exercise。
  - 修正：在 heavy / severe domain，同一 work rate 的 V̇O2 會隨時間改變，所以 %V̇O2max 不是唯一穩定 anchor。
