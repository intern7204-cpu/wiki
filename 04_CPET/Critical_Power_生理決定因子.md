# Critical Power 生理決定因子

## 一句話定義

Critical power 的生理決定因子，是 oxygen delivery、oxygen diffusion、muscle O2 utilization kinetics 與 motor unit recruitment 共同決定一個 work rate 是否能維持 metabolic steady state 的整合門檻。

## 概念邊界

本頁只處理 Goulding & Marwood 2023 所整理的 CP physiological determinants。它不重複 CP/W' 數學模型、W'BAL、CP 測試可靠性或 interval prescription 細節。

## 反對論點

「CP 就是 lactate threshold、anaerobic capacity 或某個固定肌肉代謝物濃度。」

## 反駁

來源明確把 CP 定義為 heavy 與 severe domain 的邊界，且指出 CP 受 oxygen transport and utilization cascade 的每一步影響。Hypoxia 可降低 CP，hyperoxia 可提高 CP；capillarity 與 diffusive capacity 會影響 CP；tauVO2 越慢，O2 deficit 與 fatigue-related metabolite accumulation 越大；whole-body CP 還會被 fiber-type composition、exercising muscle mass、localized fatigue 與 motor unit recruitment pattern 調節。

## 結論

CP 是 whole-system aerobic function 的 emergent threshold。臨床或訓練使用 CP 時，應把它理解成「氧輸送、氧擴散、氧利用速度與 recruitment / fatigue 的整合結果」，而不是單一器官或單一 biomarker。

## 事實

- CP 是 power-duration relationship 的 asymptote。
- CP 以上無法維持 systemic and intramuscular metabolic homeostasis。
- CP 以下可達 pulmonary VO2、lactate、PCr、Pi、pH 等 steady state；CP 以上則會持續失穩。
- CP 是 heavy-severe boundary，與 LT / GET 所代表的 moderate-heavy boundary 不同。
- CP 可受 oxygen pathway 每一步影響：pulmonary diffusion、convective O2 delivery、diffusive O2 delivery、mitochondrial O2 utilization。
- Convective O2 delivery 主要由 cardiac output 與 arterial O2 content 決定。
- Hypoxia 可降低 CP；hyperoxia 可提高 CP。
- Blood flow occlusion / altered duty cycle studies 支持 CP 依賴 muscle blood flow and O2 delivery。
- Diffusive O2 delivery 受 capillary-to-myocyte diffusion gradient 與 muscle diffusing capacity 影響。
- Muscle capillarity 與 capillary-to-fiber ratio 與 CP 有關。
- TauVO2 是 muscle O2 utilization kinetics 的實用讀出；tau 越慢，exercise onset 的 O2 deficit 越大。
- O2 deficit 會增加 PCr depletion、Pi / ADP / H+ accumulation、fatigue induction 與 efficiency loss。
- Faster VO2 kinetics 與 higher O2 delivery 可降低同一 ATP turnover 下的 intracellular perturbation，因此可提高 CP。
- Type I fibers 具有較快 VO2 kinetics、較佳 metabolic control 與較高 capillary / interstitial PO2。
- Whole-body CP 也受 exercising muscle mass、regional metabolite heterogeneity、lever mechanics、coordination、localized fatigue 與 motor unit recruitment pattern 影響。

## 推論

- CP 可作為 clinical exercise limitation 的 integrated physiological marker，但 interpretation 需分辨是 central delivery、peripheral diffusion、utilization kinetics、muscle phenotype 或 recruitment / fatigue 哪一層較可能受限。
- 低 CP 不應直接被寫成「單純體能差」；它可能反映 oxygen transport / utilization 的任一環節。
- 同一個人的 CP 不是不可改變常數；hypoxia、hyperoxia、priming、training、disease、body position、muscle mass 與 protocol 都可能改變 CP。

## 假設

- Critical Pi model 可作為理解 CP 的 mechanistic scaffold：Pi 超過 critical threshold 後，ATP cost、Pi accumulation 與 fatigue 形成 positive feedback。
- Pi 在此較像 fatigue-related intracellular state 的 proxy，而不是唯一 causal molecule。
- Pulmonary tauVO2 多數時候可作為 muscle O2 utilization kinetics 的 practical surrogate，但不是所有情境都等價。

## 不確定

- 不同疾病族群中，convective、diffusive、utilization kinetics 與 recruitment factors 的相對權重尚未完全定量。
- Small-muscle mass exercise 與 large-muscle mass cycling / running 的 limiting factors 不一定相同。
- In silico 與 animal data 對機制很有價值，但仍需 human whole-body validation。

## 機制

```text
external power demand
  -> ATP turnover demand
  -> oxygen transport response
     -> pulmonary diffusion
     -> cardiac output + arterial O2 content
     -> regional blood flow
     -> capillary-to-mitochondria diffusion
  -> muscle O2 utilization kinetics
  -> O2 deficit size
  -> PCr depletion + Pi / ADP / H+ accumulation
  -> fatigue and efficiency loss
  -> steady state if below critical intracellular threshold
  -> non-steady state and task failure trajectory if above threshold
```

## 可觀察模式

- CP 以下：VO2、blood lactate、PCr、Pi、pH 可達 steady state。
- CP 以上：VO2 被推向 VO2max，PCr 持續下降，Pi / H+ 持續上升，fatigue 與 efficiency loss 擴大。
- Hypoxia / lower O2 availability：CP 下降。
- Hyperoxia / higher O2 availability：CP 上升。
- Faster tauVO2：同一 transition 下 O2 deficit 較小，CP 較高。
- Greater capillarity / type I phenotype：較可能支持 higher CP，但不能直接由單一 biopsy 指標預測個人 CP。

## 臨床 / 研究意義

- CP 是 exercise tolerance 的 mechanistic threshold，對 CPET、training prescription 與 rehabilitation intensity planning 都有價值。
- 在 heart failure、COPD、pulmonary vascular disease 或 peripheral muscle dysfunction 中，低 CP 可能對應不同 limiting step，需結合症狀、gas exchange、ventilation、hemodynamics 與肌肉功能。
- CP 與 VO2 kinetics 應一起看：一個描述 steady-state boundary，一個描述 transition speed。
- 用 CP 設計訓練區間時，應記錄測試 protocol、mode、body position、環境 O2、疾病狀態與近期疲勞 / priming。

## 常見誤讀

- 把 CP 當成 lactate threshold。
- 把 CP 當成固定不變的個人常數。
- 把 W' 當成單一 anaerobic tank。
- 把 pulmonary VO2 kinetics 在所有情境都等同 muscle kinetics。
- 把 hypoxia / hyperoxia 或 analgesic intervention 的短期 CP 變化直接轉成治療建議。
