# Critical Power Testing Reliability（CP 測試可靠性）

## 一句話定義

CP testing 的可靠性不是單靠數學模型保證，而是取決於 **protocol、熟悉化、恢復控制、受試者 pacing 與 W' 的較高日內變異**。

## 核心機制

### 核心概念

- **CP 通常比 W' 更穩定。**
- 若 protocol 改變，得到的不只是 measurement noise，可能是不同生理操作條件下的不同估計值。
- 因此 reliability 問題與 validity 問題不能切開。

### 方法學重點

- 明確固定：
  - modality
  - warm-up
  - recovery interval
  - nutrition / glycogen / caffeine 狀態
  - encouragement 與 pacing instructions
- 若用 3-min all-out，需確認末段有合理 end-test power 穩定。
- 若用 3-min all-out，還要固定：
  - ergometer mode
  - cadence / resistance setting
  因為 `EP` 與 `WEP` 的 validity 行為不一樣。
- 若用 multi-bout CWR，需把每次測試之間的恢復與順序控制好。

## 臨床表現

### 臨床與研究重要性

- 對運動員：決定 CP 是否適合做週期化追蹤。
- 對研究：若沒有熟悉化與 protocol control，CP/W' 變化可能只是 measurement artifact。
- 對復健：大多數臨床族群目前仍缺足夠 reliability data，不能直接套用運動員數據。

## 臨床決策點

### 目前可支持的實務結論

### 1. Familiarization 很重要

- Triska 2017 顯示，在 laboratory fixed-duration TT 中，先做 familiarization 可改善 CP/W' 的 ICC 與 CoV。
- 若省略熟悉化，尤其在 all-out 或 self-paced protocol，誤差會更大。

### 2. inter-trial recovery 對 W' 的影響比對 CP 更大

- Karsten 2016 直接比較 `24 h`、`3 h`、`30 min` inter-trial recovery。
- 結果是：
  - `CP` 在三種設計下都相對接近
  - `W'` 則在短 recovery 下 agreement 明顯變差，尤其 `30 min` 最不穩
- practical implication：
  - 若 endpoint 是 `CP`，same-day multi-bout testing 有一定可行性
  - 若 endpoint 是 `W'`，短 recovery protocol 不能直接視為等價替代

### 3. CP 的 repeatability 通常優於 W'

- 在受控條件下，CP CoV 可低至約 2%–3%。
- W' 即使在同條件下，CoV 仍明顯較高，可到約 8% 或更高。
- 所以 longitudinal follow-up 時，小幅 W' 變動不宜過度解讀。

### 4. TT 與 TTE 不是單純誰更「真」

- Fixed-duration TT 較接近真實 pacing。
- TTE 在理論上直接對應 power-duration 關係，但受 motivation 與 day-to-day tolerance 影響大。
- 現階段較合理的說法是：**依研究問題與場景選 protocol，再把 protocol 固定下來。**

### 5. Karsten 2017：CP 可近似，W' 不一定

- 同日 laboratory TT 與 TTE 在 CP 上高度接近。
- 但 W' 在 TT 與 TTE 間仍有顯著差異。
- TT 的 standard error 較低，VO2 kinetics 也較快。
- practical implication：
  - 如果追蹤重點是 CP，TT 很有吸引力。
  - 如果 interval design 很吃 W'，就不能假設兩種 protocol 可互換。

### 6. 3-min all-out 的 `EP` 與 `WEP` 不能綁在一起看

- Wright 2017 在 trained cyclists 顯示：
  - isokinetic `EP` 可作 `CP` 的合理近似
  - linear `EP` 雖可靠，卻可能顯著偏高
  - `WEP` 在兩種模式都低估 `W'`
- practical implication：
  - `EP` 看起來穩，不代表 `WEP` 也可用
  - 3-min all-out 若要用於 longitudinal follow-up，必須先界定你追的是 `CP` 還是 `W'`

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### 限制 / 爭議

- 現有可靠性資料主要來自 trained cyclists / triathletes。
- W' 底層生理複雜，因此 measurement noise 與真正生理改變很難完全拆開。
- Original articles 主要補充方法細節，不能單獨改寫 CP 的 Tier 1 主框架。

## 理解缺口

- Critical Power Testing Reliability（CP 測試可靠性） 量到的是什麼，不是什麼？
- 這個方法最常見的 protocol pitfall 是什麼？
- 如果結果異常，哪些情況不能直接跳到 treatment conclusion？
- 目前缺少完整評估框架：History、Physical examination、Scale / test、Imaging / lab 仍需補強。
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若 Critical Power Testing Reliability（CP 測試可靠性） 不能改變診斷、風險分層或 treatment plan，就不該例行使用。
- 先界定問題、輸入條件與輸出格式，再執行方法，否則結果很容易只有數字沒有決策價值。
