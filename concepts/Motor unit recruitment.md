# 運動單位招募（motor unit recruitment）

## 本質（一句話）
運動單位招募就是「身體要出多少力，就**叫醒多少條肌纖維**來幫忙——而且是有順序的：先用省油、耐久的小單位，力氣不夠或累了才追加耗油、易疲勞的大單位」。

## 前置概念
- [[Muscle fiber types|肌纖維類型（muscle fiber types）]]
  （招募的對象就是不同類型的纖維——耐久的 Type I 與爆發的 Type II。先懂纖維分型，才懂「先招誰、後招誰」。）
- [[Muscle fatigue|肌肉疲勞（muscle fatigue）]]
  （已招募的纖維累了，身體就得追加招募新纖維來補足力氣——疲勞是「為什麼招募會隨時間變多」的關鍵推力。）

## 為什麼會這樣（first-principles 推導）
一步一步來，每步只用前面已建立的事實或常識：

1. **先定義「運動單位」。** 一條運動神經，加上它管的那一群肌纖維，合稱一個**運動單位（motor unit）**。神經一放電，它管的那群纖維就**全部一起**收縮——這是肌肉出力的最小「開關」。所以肌肉不是「無段調光」，而是由很多個開關（運動單位）一個個打開來疊出力氣。

2. **出力大小＝開幾個開關。** 要出小力，只打開少數運動單位；要出大力，打開更多。把更多運動單位「叫醒、加進來幫忙」，就叫**招募（recruitment）**。（另一條調力氣的路是讓已招募的單位放電更快，叫 rate coding／頻率調控——本頁聚焦招募。）

3. **招募有固定順序——這是重點（Henneman 大小原則）。** 運動單位不是隨機被叫醒的，而是**由小到大**：神經元體積小、興奮閾值低的先被招募，體積大、閾值高的後招募。而**小單位多半接耐久的 [[Muscle fiber types|Type I]] 纖維，大單位多半接爆發的 Type II 纖維**。所以實際後果是：**力氣由小漸增時，先用 Type I，愈出力才愈把 Type II 拉進來。** 這叫 orderly recruitment（有序招募）。
   - 為什麼身體要這樣排？因為日常多數動作只需小力，先用省油又抗疲勞的 Type I 最划算；把耗油、易累的 Type II 留到真的需要爆發力或前面的不夠用時才動用。這是一種「先省後爆」的節能設計。

4. **關鍵的時間維度：同一個固定負荷，招募也會隨時間「愈用愈多」。** 這點最容易被忽略，放慢講。即使外在功率不變，先被招募的 Type I 纖維**做久了會累（[[Muscle fatigue|疲勞]]）**、出力下滑；為了維持同樣的總力氣，神經系統只好**追加招募更多（且更高階的 Type II）纖維**來補上缺口。於是「招募量」在固定負荷下會**隨運動進行而增加**——這正是把「招募」與「時間變化的現象」連起來的橋。

5. **接到 VO2：為什麼追加招募會多花氧。** Type II 纖維比 Type I **不經濟**（同樣的功要燒更多 ATP、[[Exercise efficiency|效率]]較差）、[[VO2 kinetics|VO2 動力學]]也較慢。所以「固定負荷下被迫追加招募 Type II」＝「同樣功率卻愈燒愈多氧」——這就是 [[VO2 slow component|VO2 慢成分]]（耗氧該停卻一路往上漂）最被看好的成因之一。換句話說，慢成分是「招募的隊伍愈拉愈長、而且拉進來的是耗油兵」在耗氧上的影子。

6. **怎麼間接「看見」招募？用表面肌電（EMG）。** 招募愈多、放電愈密，肌肉表面量到的電訊號（integrated EMG, iEMG）愈大。所以研究者常用 iEMG 隨時間上升，當作「招募在增加」的代理指標。**但這裡有個重要限制**（見易誤解 #3）：雙極表面 EMG 只取一小塊肌肉、訊號又會彼此抵銷加總，並不能精確還原真正招募了哪些、多少運動單位——它只能粗略佐證趨勢，不能當鐵證。

## 文獻怎麼說 vs 為什麼這樣說
- **主張**（在本綜述脈絡下）：運動單位招募型態的**改變**，是 [[Priming effect|預熱效應]] 改寫 VO2 反應的主要機制之一——前一輪運動使次輪**從一開始就招募較多運動單位**，於是基礎相有氧貢獻墊高、後續不必再大量追加招募，慢成分因而縮小。
- **背後的推理／證據**：Burnley 等人（2002）量到，第二輪重度運動的**頭 2 分鐘 iEMG（取自股外側肌、股內側肌、臀大肌三條）升高約 19%**，正與基礎相振幅升高同時發生；Layec 等人用 ³¹P-MRS 加 EMG 顯示，預熱使次輪**氧化 ATP 成本提高、而 PCr 分解與醣解供能下降**——與「更早招募更多纖維、減少後續疲勞與追加招募」一致。但作者誠實指出：也有研究（如 Scheuermann 2001、Tordi 2003）未見 iEMG 變化，加上雙極 EMG 的解讀限制，所以「招募改變」是**有支持但未釘死**的機制，須等高密度 EMG 與訊號分解等更精細技術。

## 易誤解之處
1. **招募是「有順序」的，不是「全部一起上」。** 多數強度下只有一部分運動單位在工作；要更大力或前面累了，才把更高階的拉進來。「用力時所有纖維都在收縮」是錯的直覺。
2. **「招募更多 Type II」不必然代表強度變超高——也可能只是『前面的累了』。** 在固定的重度負荷下，追加招募 Type II 主要是因為 Type I 疲勞、需要補力，而不是因為你突然出更大力。把「招募增加」一律解讀成「強度上升」會誤判。
3. **iEMG 上升 ≠ 精確的招募量。** 雙極表面 EMG 取樣體積小、訊號會振幅加總與相消，無法精確反映神經驅動或真正招募了哪些運動單位。它能佐證「招募大概在變多」的趨勢，但不能當成定量鐵證——這也是為什麼「招募改變」這個機制至今仍未被完全證實。

## 用生活例子再講一次
把肌肉想成一間餐廳的排班。客人少時（出小力），只排幾個**老練又不喊累的資深員工**（Type I）就夠了。客人變多（出更大力），才追加排上**手腳快但容易爆走、又特別費薪水的工讀生**（Type II）。而即使客流量整晚固定不變，資深員工**站久了也會累**、出菜變慢，店長只好**陸續再加派工讀生**來補——於是「在場人手」整晚愈排愈多。多請的又都是費薪水的工讀生，所以「同樣的客流量、人事成本卻一路上升」——這筆愈來愈貴的成本，就是耗氧上的 [[VO2 slow component|慢成分]]。

（這個類比在哪裡會失準：餐廳店長是一個「中央決策者」在排班；真實的招募是脊髓運動神經元依興奮閾值**自動由小到大**被推開的物理結果，沒有一個誰在「決定先派誰」，順序是神經元大小本身決定的。）

## 換句話說
換句話說，運動單位招募是「身體按需要、由小到大叫醒肌纖維」的機制：先用省油耐久的 [[Muscle fiber types|Type I]]，力氣不夠或它們累了，才追加耗油易疲勞的 Type II。即使負荷固定，疲勞也會逼著招募隊伍愈拉愈長、且拉進來的是不經濟的纖維——這就是 [[VO2 slow component|VO2 慢成分]] 的成因之一，也是 [[Priming effect|預熱]] 能改寫 VO2 反應的著力點：讓次輪「一開始就多招一些」，後面就不必追加那麼多。
