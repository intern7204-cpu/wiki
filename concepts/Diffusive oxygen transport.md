# 擴散性氧氣輸送（diffusive oxygen transport, DO₂）

## 本質（一句話）
擴散送氧講的是運送的「最後一哩」：氧氣**從微血管滲進肌肉細胞**有多順——它由「推力」（微血管與細胞之間的氧壓差）和「通道大小」（擴散容量 DO₂，主要看有多少紅血球正貼在細胞旁）共同決定。

## 前置概念
- [[Convective oxygen delivery|對流性氧氣輸送（Q̇O₂）]]
  （氧氣得先被血流整批運到微血管口（對流），才談得上從微血管滲進細胞（擴散）。先懂第一棒。）
- [[Microvascular O2 delivery|微血管 O₂ 輸送（microvascular O2 delivery）]]
  （擴散的「推力」就是微血管氧壓 PmvO₂ 與細胞內氧壓之差；先懂微血管氧分壓這一端。）

## 為什麼會這樣（first-principles 推導）
1. 接著 [[Convective oxygen delivery|對流送氧]]：血流把含氧血整批運到肌肉的微血管。但氧要被用掉，還得**離開血、進到肌肉細胞、再進到細胞裡的粒線體**。這一步不是靠血流推，而是靠**擴散**。
2. 「擴散（diffusion）」一句白話：分子會**自己從濃度（壓力）高的地方往低的地方跑**，像香水味從噴的地方慢慢散開——不需要誰去推，是分子隨機運動的淨結果。氧氣從「血裡氧多」滲向「細胞裡氧少」，就是擴散。
3. 那「氧滲得多快」由什麼決定？兩件事相乘，這就是 **Fick 擴散定律**（放慢看）：
   $$\dot{V}O_2 = D_{O_2} \times \Delta P_{O_2}$$
   - **ΔPO₂（推力／壓力差）**：微血管裡的氧壓（PO₂cap）減去肌細胞內的氧壓（PO₂im）。差愈大、氧愈想往細胞裡跑。
   - **DO₂（擴散容量／通道有多寬）**：在固定壓力差下，組織「讓氧通過的本事」。它**主要由「此刻有多少紅血球正貼在肌細胞旁的微血管裡」決定**——因為氧得從紅血球出發，貼著細胞的紅血球愈多，可供擴散的表面積愈大。
4. 從定律可讀出「什麼會改變擴散送氧」：
   - **提高 ΔPO₂**：例如吸高氧 → 微血管氧壓 PO₂cap 升 → 壓力差變大 → 氧滲得更順。（反之缺氧縮小壓力差。）
   - **提高 DO₂**：例如**肌肉微血管密度高**（每條肌纖維旁邊的微血管多）→ 同時有更多紅血球貼著細胞 → 擴散表面積大 → DO₂ 大。耐力訓練長微血管（這條「微血管如何隨訓練生長」的適應端見 [[Skeletal muscle angiogenesis|血管新生]] 與 [[Skeletal muscle capillarization|微血管化]]：剪應力/牽張/缺氧三刺激、前 4 週自限飽和、僅未到中度訓練者），正是在加寬這條通道。
   - **縮短工作週期**（收縮短、放鬆長）→ 紅血球流速變快、被「攤」在更長一段微血管上參與交換（縱向微血管招募）→ DO₂ 升。
5. 怎麼證明擴散送氧**獨立地**影響 [[Critical power|CP]]（不只是對流的附帶效果）？
   - **微血管密度與 CP 強相關**：在攝氧能力相近的耐力運動員裡，CP 與「微血管對肌纖維比」相關 r=0.88、與「每條 Type I 纖維的微血管接觸數」相關 r=0.94——擴散通道愈寬、CP 愈高。
   - **拆解對流 vs 擴散的貢獻**：縮短工作週期時，DO₂ 的增幅（+69%）約是對流送氧增幅（+34%）的兩倍——在這個情境，**擴散才是 CP 上升的主要推手**。
   - **藥理證據**：用藥（glibenclamide）讓大鼠 DO₂ 降 25%，臨界速度也跟著降——直接證明 DO₂ 是 CP 的獨立決定因子。
   - **性別比較**：小肌群運動（對流不是限制）時，女性因微血管較密、Type I 較多，擴散容量較大，臨界力（CF）出現在較高的 %最大自主收縮；但在大肌群騎車（對流才是主要限制）就看不到這個性別差——說明「擴散在小肌群、對流在大肌群」各自主導。

## 文獻怎麼說 vs 為什麼這樣說
- **主張／建議**：本綜述主張，擴散送氧（由 DO₂ 與 ΔPO₂ 決定）是 [[Critical power|CP]] 的一個**獨立**決定因子，與[[Convective oxygen delivery|對流送氧]]、與肌肉氧利用（[[VO2 kinetics|τVO₂]]）並列。哪一個主導，視運動的肌肉量大小而定（小肌群→擴散主導；大肌群→對流相對更重要，因中樞神經會限制血流以保血壓）。
- **背後的推理／證據**：CP 與微血管化指標的高相關、工作週期實驗中 DO₂ 增幅倍於對流、藥理降 DO₂ 同步降 CS、性別差只見於小肌群——這幾條獨立證據都指向「擴散容量本身就能改 CP」，而非僅是對流的副產物。

## 易誤解之處
1. **擴散 vs 對流是接力的兩棒，限制點可能在不同棒。** 大肌群運動多半卡在對流（送不夠多血進來）；小肌群血流相對充裕，反而卡在擴散（滲不夠進細胞）。判斷瓶頸要看運動型態。
2. **DO₂ 主要不是「組織的固定性質」，而是「此刻有多少紅血球貼著細胞」。** 同一塊肌肉，靠加快紅血球流速、招募更多微血管，就能即時提高有效 DO₂——它是動態的，不是寫死的。
3. **ΔPO₂ 是「兩端之差」，不是單看一端。** 高氧讓微血管端與細胞端氧壓**都升**，但升的幅度不同，淨效果才是壓力差變大。只盯一端會誤判。
4. **「送到微血管」不等於「進得了細胞」。** 對流把氧運到門口，擴散才決定進不進得去——對流再強，若擴散通道窄或壓力差小，氧仍卡在血裡用不上。

## 用生活例子再講一次
把對流想成「貨車把貨運到社區門口」，擴散就是「貨從門口送進每一戶」。送進去多快，看兩件事：一是**門內外的『落差』**——門外貨堆得高、門內快空了，貨就拼命往裡送（這就是氧壓差 ΔPO₂）；二是**門開得多寬、有幾個送貨口**——口子多、表面積大，送得快（這就是擴散容量 DO₂，由貼著住戶的微血管/紅血球數量決定）。耐力訓練等於多開幾條送貨巷（長微血管），落差和通道一起改善。

（失準之處：送貨需要有人搬、要花力氣；氧的擴散是**被動的**，不耗能、不需要搬運工，純粹靠分子自己從高壓往低壓跑。比喻抓得到「落差×通道」的骨架，但別把它想成有人費力在搬。）

## 換句話說
換句話說，擴散送氧是氧氣運送的最後一哩——從微血管滲進肌細胞。它由 Fick 定律 V̇O₂ = DO₂ × ΔPO₂ 決定：推力是微血管與細胞間的氧壓差，通道寬窄是擴散容量（主要看貼著細胞的紅血球/微血管有多少）。它和[[Convective oxygen delivery|對流送氧]]、肌肉氧利用一樣，都是 [[Critical power|CP]] 的獨立決定因子；在小肌群運動裡，它往往才是真正的瓶頸。
