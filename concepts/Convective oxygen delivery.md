# 對流性氧氣輸送（convective oxygen delivery, Q̇O₂）

## 本質（一句話）
對流送氧就是「**心臟每分鐘把多少氧氣『泵送』到全身（或到運動的肌肉）**」——它是「每分鐘打多少血」乘以「每份血載多少氧」，講的是把氧氣**大量、整批運過去**這一步。

## 前置概念
- [[Arterial oxygen content|動脈血氧含量（CaO₂）]]
  （「每份血載多少氧」就是 CaO₂；對流送氧是它乘上血流速率。先懂這個乘數。）
- [[VO2|耗氧量（VO2, oxygen uptake）]]
  （送氧最終是為了讓肌肉用氧；先懂「用氧速率」這一端，才看得出送氧夠不夠用。）

## 為什麼會這樣（first-principles 推導）
1. 氧氣從肺進到血裡之後，要被「運」到肌肉。運送有兩段，性質不同：先是**整批被血流帶過去（對流）**，到了肌肉微血管再**一個一個擴散進細胞（擴散）**。本頁只講第一段——對流（見第二段：[[Diffusive oxygen transport|擴散性氧氣輸送]]）。
2. 「對流（convection）」一句白話：就是**靠流體的整批流動把東西帶著走**，像河水把樹葉沖向下游——不是樹葉自己游，而是水流帶它。血流把含氧血整批沖到肌肉，就是對流送氧。
3. 那「每分鐘送達多少氧」由什麼決定？只有兩件事相乘：
   - **心輸出（cardiac output, CO）**：心臟每分鐘打出多少血（L/min）。＝每跳打出的血量 × 每分鐘跳幾下。這是「水流多大」。
   - **[[Arterial oxygen content|動脈血氧含量 CaO₂]]**：每份血載多少氧。這是「每滴水帶多少葉子」。
4. 兩者相乘就是對流送氧速率（放慢看，它只是「流量 × 濃度」）：
   $$\dot{Q}O_2 = CO \times Ca_{O_2}$$
   - 直覺：要多送氧，要嘛打更多血（CO↑，運動時靠心跳加快、每跳打更多），要嘛讓每份血更滿（CaO₂↑）。任一個降，送氧就降。
5. 一個重要細節：這個公式算的是**全身**的對流送氧；但血流不是平均分給每塊肌肉的。身體會依「哪裡正在用力、血管怎麼控制、是什麼纖維型」**把血流重新分配**，所以運動肌肉拿到的那份，比例會被主動調高（運動時血流大量導向工作肌）。
6. 怎麼證明「對流送氧真的影響運動耐受／[[Critical power|CP]]」？做能改變 CO 或 CaO₂ 的實驗看 CP 怎麼動：
   - **缺氧（低 FiO₂）/上高海拔** → CaO₂↓ → 送氧↓ → **CP 降**（多份研究一致；海拔愈高、CP 降愈多）。
   - **高氧（FiO₂ 0.5–0.7）** → CaO₂ 微升、肌肉氧合升 → **CP 升約 10%**。
   - **改變肌肉收縮的工作週期**（縮短收縮、拉長放鬆）→ 放鬆時血管不被壓扁、血流灌得多 → 對流送氧↑ → **CP 升**（手握實驗用都卜勒直接量到肱動脈血流變大）。
   - **血流完全阻斷** → 送氧歸零 → **CP 降到負值**：因為沒有血流，連靜息代謝都撐不住，這個極端反證了「CP 依賴對流送氧」。

## 文獻怎麼說 vs 為什麼這樣說
- **主張／建議**：本綜述主張，凡是改變對流送氧（CO 或 CaO₂）的介入，都會改變 CP——因此 CP 是一個「橫跨整條氧氣運送鏈、任何一步都能影響它」的有氧能力參數。在年輕健康者，呼吸系統通常不是限制（肺把血氧充得很滿），所以瓶頸落在對流（與擴散、利用）這幾步。
- **背後的推理／證據**：缺氧降 CP、高氧升 CP、工作週期升 CP、阻斷使 CP<0——這一整排介入的方向完全一致地隨「對流送氧增減」而動（綜述 Table 1）。方向一致＋涵蓋多種操弄手段，是支持因果（而非巧合）的關鍵。

## 易誤解之處
1. **對流 ≠ 擴散。** 對流是「血流整批把氧帶到肌肉微血管」；擴散是「氧再從微血管滲進肌細胞」。兩者是接力的兩棒，限制點可能在不同棒上（見 [[Diffusive oxygen transport|擴散性氧氣輸送]]）。
2. **「全身送氧」看不到分配不均。** Q̇O₂=CO×CaO₂ 是整體值；真正決定某塊肌肉夠不夠氧的，是它**分到**的那份血流與供需比（見 [[Microvascular O2 delivery|微血管 O₂ 輸送]]）。
3. **負的 CP 不是錯誤。** 血流阻斷時 CP 算出負值，看似荒謬，其實合理：它的大小約等於「靜息代謝率」對應的負擔——沒有送氧，連不動都會持續耗竭 [PCr]、撐不住穩態。
4. **送氧高 ≠ 一定用得到。** 送到的氧還要能擴散進細胞、被粒線體用掉；對流只是「運到門口」，不保證「進得了門」。

## 用生活例子再講一次
把對流送氧想成一條「氧氣輸送帶」的總吞吐量。輸送帶每分鐘送達的貨量 ＝ **帶子跑多快（心輸出 CO）** × **每個格子裝多少貨（每份血的含氧量 CaO₂）**。想多送，就把帶子加速（運動時心跳加快）或把每格裝滿（別貧血、別缺氧）。把帶子停掉（血流阻斷），門口連基本補給都斷，店裡（肌肉）很快撐不住。

（失準之處：輸送帶把貨送到「門口」就算數；人體還有關鍵的下一步——氧得從微血管擴散進細胞才真正算數，那一步由 [[Diffusive oxygen transport|擴散]] 決定，輸送帶比喻看不到這層。）

## 換句話說
換句話說，對流送氧是「心臟每分鐘泵送多少氧到肌肉」，就是心輸出 × 動脈血氧含量這兩個乘數的積。它是氧氣運送的第一棒——把氧**整批**運到肌肉微血管口。改變這兩個乘數的任何介入（缺氧、高氧、貧血、阻斷、調收縮節律）都會連動 [[Critical power|CP]]，這正是「CP 是有氧能力參數」的有力證據之一。
