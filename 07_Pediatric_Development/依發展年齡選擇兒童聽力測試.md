# 依發展年齡選擇兒童聽力測試

## 一句話定義

兒童 audiologic evaluation 應依 developmental age 選測試，而不是按實際年齡硬套同一組工具。

## Definition and Boundary

- 這個 concept 講的是 test selection principle。
- 它不是各項 audiology test 的完整操作手冊。

## Fact

- 本來源指出 audiologic testing 需依 developmental age 選 VRA、CPA、ABR。
- 對 deaf child，認知 / 語言 assessment 也要避免把語言剝奪誤判成低 intelligence。
- nonverbal 或 deaf-informed tools 特別重要。

## Mechanism Chain

```text
Child developmental level
→ appropriate test modality selection
→ more valid hearing and developmental interpretation
→ fewer misclassification errors
```

## Inference

- 若測試工具和 developmental level 不匹配，失敗結果未必代表 hearing 或 cognition 真正異常。

## Assumption

- 臨床團隊能取得對應 developmental level 的 testing resource。

## Uncertainty

- 本來源提供 selection principle，但沒有展開成各測試的完整 protocol 差異。

## Clinical Use

- 對 motor、language 或 cognition 受限的 child，先調整 testing strategy，再解讀結果。
