# 早產兒的長期神經發展風險

## 一句話定義

preterm birth 的長期結局不只 CP；gestational age、NICU complication 與時間軸會共同塑造 motor、cognitive、language、learning、behavior 與 sensory outcome。

## Definition and Boundary

- corrected age 是 early developmental interpretation 的基本前提。
- 這個 concept 不是把 prematurity 的風險只縮成單一 neurologic diagnosis。

## Fact

- gestational age 越低、neonatal complication 越多，long-term risk 越高。
- major outcome 包含 CP、ID、vision / hearing impairment。
- language disorder、DCD、learning disability、behavioral phenotype 也屬高盛行 sequelae。
- sensory deficit 常較早顯現；motor problem 常在第一年後段更清楚；cognition / language 多在 2 到 3 歲後更可靠；behavior / learning 常更晚浮現。

## Mechanism Chain

```text
Prematurity severity + neonatal complication
→ multisystem developmental vulnerability
→ different sequelae emerge at different ages
→ staged follow-up need
```

## Inference

- 太早用單次 assessment 宣告「沒事」，容易漏掉之後才浮現的 language、learning 或 behavior problem。

## Assumption

- follow-up 會依 corrected age 與風險分層持續，而不是只追到嬰兒期。

## Uncertainty

- 個別孩子的長期結果仍受後續照護與環境支持影響。

## Clinical Use

- 追蹤早產兒時，要問的不只是 motor，還要把 language、learning、behavior 與 sensory 時程一起排進去。
