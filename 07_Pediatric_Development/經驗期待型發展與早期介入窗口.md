# 經驗期待型發展與早期介入窗口

## 一句話定義

early intervention 的 timing 之所以重要，是因為 postnatal brain development 部分依賴 **experience-expectant input** 在多個 sensitive / critical windows 內出現；因此臨床上要問的是「哪種輸入正在缺席」，而不是只問孩子幾歲。

## Definition and Boundary

- experience-expectant development 指 brain 預期所有 child 都會接收到的常見輸入，例如 patterned light、sound、language、caregiving。
- experience-dependent development 則指任何會因 experience 而發生的 change，不受單一 critical period 綁死。
- 這個 concept 講的是 timing logic，不是行政上的早療資格審查。

## Fact

- brain plasticity 會隨年齡下降，但不是斷崖式只在某一天終止。
- genes 在 prenatal brain development 中角色較大；出生後，experience 對 development 的影響逐漸變強。
- experience-expectant input 若在關鍵窗口缺席，或該窗口被 adverse experience 取代，development 可能被帶離原本軌跡。
- 沒有 single critical period 可以涵蓋所有 domain；vision、hearing、language、executive function 都有不同時序。
- experience-dependent learning 在整個 lifespan 都可發生，但 later plasticity 的上限通常較低。

## Mechanism Chain

```text
Domain-specific expected input is absent or distorted
→ synaptic production / pruning or network organization shifts
→ developmental trajectory deviates
→ timely support restores or approximates expected input
→ trajectory becomes more modifiable within that window
```

## Inference

- child 若缺的是某個特定 domain 的 expected input，轉介 urgency 應由該 domain 的窗口決定，而不是由「還有沒有滿三歲」決定。

## Assumption

- clinician 能辨識 child 缺的是哪類關鍵輸入，且介入內容真的能補回該輸入，而不只是增加 generic service time。

## Uncertainty

- critical period rescue / reopening 目前仍以 research implication 為主，不能當 routine clinical promise。

## Clinical Use

- hearing、vision、language、caregiving deprivation 或高風險 autism sign 出現時，不要等 global delay 明確化才行動。
- 對較大 child 或 adolescent，也不要因為錯過 infancy 就直接假設 intervention 無效；先分清他現在處在哪一個可塑性窗口。
