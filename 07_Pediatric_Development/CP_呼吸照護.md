# CP 呼吸照護

## 一句話定義

CP 呼吸照護是 **針對 CP 兒童特有的「aspiration（dysphagia + sialorrhea）+ scoliosis 與 chest wall 受限 + airway clearance 弱 + 反覆感染 + sleep-disordered breathing」多軸呼吸風險，用 GMFCS / EDACS-stratified 風險識別 + 多專科 baseline 評估 + 預防措施 + 低門檻 illness 處置的長期照護流程**，重點不是「等到肺炎才急救」，而是「在 stable 時就辨識 high risk、優化 modifiable factors，在每次感冒時用比一般兒童更積極的標準介入。」

## 已知

- **呼吸疾病是 CP 兒童 morbidity 與 mortality 的主因**。
- 已知的 hospitalization 高風險組合：**GMFCS V + 過去一年至少一次呼吸入院 + oropharyngeal dysphagia + active seizures + 頻繁呼吸症狀 + GERD + 過去一年至少兩個療程抗生素 + 進食時呼吸症狀 + 夜間打鼾**（Gibson 2021）。
- **20% CP 兒童有 sleep disorder；10–25% 有 sleep-disordered breathing**，特別是年紀大、GMFCS 高、合併共病者。
- AACPDM *Sialorrhea in Cerebral Palsy* care pathway 是 sialorrhea 評估與管理的當代 framework。
- Gibson 2021（DMCN）國際 consensus statement 是當前最重要的 CP 呼吸照護指引。
- 約 **50% CP 有吞嚥問題；54% 有 feeding 問題**，與 GMFCS 等級直接相關。

## 核心機制

### 為什麼 CP 兒童肺出問題

CP 兒童的肺是「**多重防線同時失效**」：

1. **Aspiration**（最大宗）
   - **Overt aspiration**：吞嚥時食物 / 液體進入氣道，可能引起咳嗽。
   - **Silent aspiration**：無咳嗽反射 → 反覆 micro-aspiration 累積。
   - **Sialorrhea**：唾液控制差 → 持續微量吸入。
   - **GERD**：胃內容物逆流到氣道。

2. **Airway clearance 弱**
   - 胸廓 mobility 差（scoliosis、postural abnormality）。
   - Cough 力量弱（abdominal / intercostal muscle weakness、coordination 差）。
   - Mucus clearance 受限。

3. **Chest wall / 結構限制**
   - **Neuromuscular scoliosis**（30% CP）→ restrictive 通氣障礙。
   - 胸廓不對稱 → V/Q mismatch。
   - 駝背、駝背性肺底壓迫。

4. **營養 / 免疫**
   - 慢性 underweight、低 albumin → 感染後恢復慢、repair 能力差。
   - Vitamin D 不足、micronutrient 缺乏。

5. **共病加乘**
   - **Active seizures** → loss of airway protection。
   - **Multiple antibiotics** → 抗生素抗藥菌定植。
   - **Repeat hospitalization** → 院內感染風險。

### Sleep-disordered breathing 的特殊性

- 不只 OSA：CP 的 SDB 包含 obstructive、central、mixed apnoea。
- 環境因子也很重要：bed-sharing、caregiver sleep issues、夜間 orthoses、postural changes。
- 夜間 hypoxemia 對 cognitive function、行為、QOL 都有影響。
- **Polysomnography** 是 gold standard，但取得困難；多數 case 仍以症狀 + clinical assessment 起步。

## 臨床表現

### High-risk 兒童的辨識

Gibson 2021 共識列出的高風險組合：

- GMFCS V 或 EDACS III–V
- 過去一年至少一次呼吸入院
- Oropharyngeal dysphagia
- Active seizures
- 頻繁呼吸症狀（咳嗽、wheeze）
- GERD
- 過去一年至少兩個療程呼吸抗生素
- 進食時呼吸症狀（咳嗽、 desaturation、wet voice）
- 夜間打鼾
- 反覆 sialorrhea + skin breakdown

### Aspiration 的臨床訊號

**Overt（容易辨識）**：

- 進食時咳嗽、噎住。
- 進食後 wet voice / wet breathing。
- 進食時 desaturation。
- 進食後嘔吐。
- 拒食、進食恐懼。

**Silent aspiration（難辨識）**：

- 反覆 unexplained 發燒、肺炎。
- 慢性 wet 咳嗽、wheeze。
- Chronic atelectasis（特別 RML、RUL）。
- 體重不增 + 反覆 antibiotic course。

### Sialorrhea 的影響

- 皮膚 breakdown（chin、anterior chest）。
- 反覆 aspiration（即使沒進食也吸入）。
- 社會 / 美觀（影響 participation）。
- 衣物換洗負擔。
- 牙齒問題（細菌量增加）。

### SDB 訊號

- 夜間打鼾、apnoeic pauses。
- 不安睡眠、夜醒、出汗。
- 早晨頭痛、易怒、白天嗜睡。
- 行為退化、學習困難。

## 評估方式

### 多專科 baseline 評估（Gibson 2021）

- **詳細病史**：GMFCS、EDACS、epilepsy、GERD、drooling、aspiration、wheezing/noisy breathing。
- **呼吸照護病史**：過去一年抗生素使用、住院、是否需 NIV。
- **理學檢查**：呼吸樣態、RR、work of breathing、chest wall 形狀、palpation、auscultation、tonsils、SpO2。
- **營養狀態 + aspiration risk** 評估。
- **Skeletal deformity** 評估（scoliosis、kyphosis）。

### 影像 / 儀器

- **VFSS（videofluoroscopic swallowing study）** 或 **FEES（fiberoptic endoscopic）**：定義 aspiration pathophysiology。
- **Sleep study**：sleep-disordered breathing 高風險者。
- **Chest imaging**：CXR baseline；持續症狀考慮 CT。
- **Pulmonary function tests**：可配合的兒童（多需 ≥ 5–6 歲）。

### Sialorrhea 評估（AACPDM care pathway）

- **嚴重度量表**：Drooling Frequency / Severity Scale、Drooling Impact Scale。
- **影響評估**：皮膚、社會、aspiration 風險。
- 共病確認：tone（dystonia 增加 sialorrhea）、posture、口腔 motor function。

### 排除其他原因

- **Common pediatric pathology** 仍要查：reactive airway disease、atypical pneumonia。
- **Foreign body aspiration**（特別在新發症狀）。
- **Tracheal / bronchial 結構異常**（部分早產 CP 兒童有 BPD、tracheomalacia）。

## 治療原則

### Gibson 2021 預防 framework

- 對 GMFCS V / EDACS III–V 家庭：**主動討論增加風險**，不是被動回應症狀。
- 管理 aspiration 共病：**dysphagia + 控制不佳 seizures + reflux + sialorrhea**。
- 提供 cough / secretion 管理技巧。
- 優化體位以擴肺。
- 早期轉介相關專科評估 apnoea / snoring。
- 考慮 chest wall mobility 治療；定期評估 + 管理 scoliosis。
- 優化營養。
- 規律牙科照護（降低 bacterial burden）。
- 全家年度流感疫苗。
- 避免菸害。

### Sialorrhea 管理階梯

1. **Behavior + position**：頭頸位置、口腔運動治療、教育。
2. **Anticholinergic 藥物**：glycopyrrolate（口服或局部）、scopolamine patch、benztropine、trihexyphenidyl（同時對 dystonia 有用）。
3. **Salivary gland BoNT 注射**：parotid + submandibular 可同時打。
4. **Surgery**：salivary duct rerouting、ligation、gland excision（refractory case）。

### Airway clearance

- **Chest physiotherapy + 體位引流**：傳統做法。
- **Suctioning**：high-need 兒童。
- **Cough assist / mechanical insufflation-exsufflation**：Gibson 2021 **未達共識**——個別評估，不是 routine。
- **Airway clearance regimen**：個別化 plan。

### 反覆感染處置

- **Low threshold for antibiotic** 治療呼吸感染（非 watch-and-wait 模式）。
- **Adequate nutrition** 促進復原。
- **PT 體位**：優化肺功能。
- **疾病期 reassess dysphagia**：暫時改 alternate route 餵食。
- **Sleep study** 若反覆 nocturnal 症狀。

### Feeding 路徑決策

- 多數 CP 兒童即使有 dysphagia，**少量食物 / 味道仍可作為 QOL / family meal 一部分**——不是 all-or-nothing。
- 完全 oral 進食的 EDACS V 兒童，aspiration 風險高 → 與家庭討論 gastrostomy。
- **Gastrostomy 不是 parenting failure**——需 reframe 為 nutrition + safety 工具。
- 目標 alignment：是 QOL 為主 vs safety 為主？多數需家庭—團隊持續對話。

### 不要做的事

- **不要等到肺炎才介入**。
- **不要對 silent aspiration 兒童只看「他不咳嗽，應該沒吸入」**。
- **不要對 CP 兒童的呼吸感染套用一般兒童 watch-and-wait**。
- **不要把 gastrostomy 當「不孝」或「parenting failure」框架** —— 這會延誤決策。
- **不要忽略 sleep-disordered breathing**：發生率不低，且影響 cognition。

## 臨床決策點

### 「他是 high-risk 嗎？」

- 對照 Gibson 2021 list（見上）。出現 ≥ 1 項即提高警覺；多項並現 → 應主動 baseline 多專科評估。

### 「該做 VFSS 嗎？」

- **進食時咳嗽 / wet voice / desaturation** → 是。
- **反覆 unexplained 肺炎** → 是。
- **體重不增 + dysphagia 病史** → 是。
- 沒有上述但 GMFCS V → 視 baseline 設計，多數中心 baseline + 每 1–2 年 reassess。

### 「該做 sleep study 嗎？」

- 打鼾 + 觀察到 apnoeic pauses → 是。
- 白天嗜睡、行為退化、學習問題 → 強烈考慮。
- GMFCS IV–V + 多重共病 → routine baseline。

### 「該做 gastrostomy 嗎？」

- 這是 **長期討論**，不是急診決策。
- **頻繁 aspiration pneumonia + 體重不增 + EDACS III–V** → 強烈傾向。
- 但 **family-centered**：QOL、文化、家庭觀點。
- 即使做 G-tube，**保留 oral tastes for QOL** 通常仍可。

### 反對論點與反駁

- 「他咳一咳就好了，不用太緊張。」 → **silent aspiration** 不咳；反覆「咳一咳」可能是反覆 micro-aspiration。
- 「打疫苗不用全家都打。」 → 家庭流感疫苗 reduces 兒童感染風險，是 herd protection。
- 「反正他將來都要 G-tube。」 → 不一定，且即使 G-tube，oral pleasure 仍可保留——這是 QOL 議題。

## 限制與未定論

- **Mechanical airway clearance devices（CoughAssist）在 CP 兒童的角色** 未達共識（Gibson 2021）。
- **Sialorrhea 的 BoNT 最佳 dose / interval** 在不同年齡仍有變異。
- **Sleep-disordered breathing 的真實流行率** 可能被低估（PSG 取得困難）。
- **NIV / CPAP 在 CP 兒童的長期 outcome** 證據較少。
- **疫苗效力**（流感、肺炎鏈球菌）在 CP 兒童的長期保護效力資料有限。
- **長期 micro-aspiration 與 chronic lung disease 的 dose-response** 還沒完全釐清。

## 理解缺口

- 為什麼有些 GMFCS V 兒童反覆肺炎、有些不？個體 protective factor？
- **Sialorrhea 介入對 aspiration pneumonia 真實 outcome** 的長期 RCT 證據仍不足。
- **GERD 對 CP 呼吸的相對貢獻** vs 直接 dysphagia aspiration 的 quantification。
- **Genetic phenotype**（如 epilepsy 嚴重度）對呼吸風險的角色。
- **Telehealth / 遠距監測** 在 high-risk CP 兒童家庭的可行性。
- **AI-assisted cough sound analysis** 是否能早期辨識惡化？

> 標記為下一輪要補的方向：CoughAssist 在 CP 的最新證據、Sialorrhea 治療的長期 outcome、CP NIV / CPAP 指引。

## 臨床使用版

- 教住院醫師時，先說一句：「**呼吸疾病是 CP 死亡與失能的主因 —— 比 spasticity 重要得多。**」
- 第二步：「**Aspiration（dysphagia + sialorrhea）+ scoliosis + airway clearance 弱 + 反覆感染 + SDB —— 五軸同時防。**」
- 第三步：「**Gibson 2021 的 high-risk list 背起來：GMFCS V、EDACS III+、過去一年住院、dysphagia、active seizures、GERD、≥ 2 抗生素、進食症狀、打鼾。**」
- 第四步：「**Silent aspiration 不咳；反覆肺炎要查 VFSS。**」
- 第五步：「**Sialorrhea 階梯：behavior → 抗膽鹼 → BoNT → 手術。」**
- 第六步：「**Sleep-disordered breathing 不少，PSG 不好做，但症狀問就要主動篩。**」
- 第七步：「**Low threshold for antibiotic + 體位 + 營養：感冒不能用一般兒童標準等。**」
- 第八步：「**Gastrostomy 不是 failure，是工具；oral pleasure 仍可保留。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 五軸風險因子能用一張地圖講完 → ✅
- Gibson 2021 high-risk list 能背 → ✅
- Sialorrhea 階梯處置 + AACPDM care pathway — 能講 → ✅
- 但 **「為什麼有些 GMFCS V 一直沒事，有些反覆住院」這個個體變異**目前我只能說「多重 modifiable factor 累加」這層次，更具體的 protective factor 我自己沒整理通 → 標為[理解缺口](#理解缺口) 的優先補強項。
- **「CoughAssist 該不該用、什麼時候用」** Gibson 2021 沒共識，我自己也沒形成 mental algorithm → 同上。
