# 晚語兒 Late Talker

## 一句話定義

late talker 是 early expressive language delay 的表面描述；臨床真正要分的是 **isolated expressive delay、合併 receptive weakness、hearing issue、ASD / GDD 線索與 broader communication profile**。

## 核心機制

### late talker 不是 etiologic diagnosis

- 它描述的是「說話晚」的現象，不是原因。
- 因此真正工作是把：
  - comprehension
  - gesture
  - social reciprocity
  - hearing
  - developmental context
  一起拆開。

## 臨床表現

### red flag

- 6 到 9 個月沒有 babbling
- 12 個月沒有功能性稱呼或 gesture
- 15 個月沒有單字，或不會 point to request
- 18 個月少於 3 個 spontaneous words、不能 follow simple command、沒有 point to share enjoyment
- 24 到 30 個月少於 50 個字，或沒有 novel 2-word combination
- loss of skill / regression

### 預後怎麼看

- 一部分 child 會 late bloom。
- 但 receptive language、symbolic play、joint attention 與 broader communicative function 會改變預後。
- 若困難持續到 4 至 5 歲，school-age literacy / learning risk 會明顯上升。

## 評估方式

### 初步評估要問什麼

- expressive language
- receptive language
- gesture / pointing / joint attention
- hearing status
- regression
- family history
- language environment 與 child care context
- parent report 與自然情境 observation

### 固定要補的評估

- formal audiologic testing
- targeted speech-language assessment
- bilingual child 的 dominant-language evaluation，必要時 interpreter support

### 常見 differential

- isolated expressive delay / late bloomer
- receptive-expressive language delay
- hearing loss / deafness
- ASD
- GDD / ID
- neurologic or structural problem

## 治療原則

- 有明顯 red flag 時，不要因沒有身體異常就延後功能評估。

## 臨床決策點

### 反對論點

- 「男生本來就比較晚講話。」
- 「雙語家庭慢一點很正常，先等等看。」

### 反駁

- 這些都不是有效的延後評估理由。
- late talking child 可能同時有 receptive delay、hearing loss、ASD、GDD 或 broader communication disorder。
- 只要 persistent concern 存在，就不能跳過 formal audiology 與 speech-language evaluation。

### 結論

- 對 late talker，正確做法是 **看 red flag、查 comprehension / gesture / hearing、及早完成 referral**。

## 限制與未定論

### 目前限制 / 爭議點

- `late talker` 不是 etiologic diagnosis。
- prognosis 受 receptive skill、gesture、comorbidity、家庭環境與介入影響。
- EI eligibility 與社區資源差異會改變實際可及性。

### frontmatter contradictions

- "Boys talk later" is not a valid reason to delay evaluation.
- Bilingual exposure does not explain a clear expressive or receptive language delay.
- The label "late talker" does not remove the need for formal audiologic testing and targeted speech-language assessment.

## 理解缺口

- 哪些 late talker 最接近 true late bloomer，哪些其實是 broader neurodevelopmental issue？
- 何時應更早談 school-age literacy / learning follow-up？

## 臨床使用版

- 若主訴只是「說話少」，先拆成理解、表達、gesture、hearing、互動，而不是直接等看看。
- 只要 concern 持續，late talker 這個標籤不應成為延後轉介的理由。
