# 嬰兒期的狀態調節與互動評估

## 一句話定義

infancy 的核心不是背 milestone，而是觀察 state regulation、attachment、joint attention、play 與 adversity buffer 是否正在同步組裝。

## Definition and Boundary

- 這是 infancy developmental assessment frame。
- 它不是只看幾個月會翻身或會不會坐。

## Fact

- sleep-wake state 被視為 neurologic integrity 指標。
- secure attachment 依賴 consistent、affectionate、responsive caregiving；mismatch 常見，但 repair 很重要。
- social synchrony、social referencing、joint attention 在第一年逐步出現，是後續 language / empathy / self-control 的起點。
- responsive relationship 可作為 adversity buffer。

## Mechanism Chain

```text
State regulation + responsive caregiving
→ attachment and synchrony
→ early communication and play
→ later development scaffold
```

## Inference

- 很多看似「很難帶」的嬰兒問題，其實是在暴露 state regulation 或 caregiver-infant mismatch。

## Assumption

- examiner 會把 infant、caregiver 與 environment 視為 transactional system，而不是單看孩子本體。

## Uncertainty

- adverse experience 的長期影響存在敏感期，但個別軌跡仍受後續照護品質修飾。

## Clinical Use

- 看嬰兒時，先看能否安撫、能否維持 alert state、能否進入互動，再看 milestone。
