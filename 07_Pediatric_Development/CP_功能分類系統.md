# CP 功能分類系統

## 一句話定義

CP 功能分類系統是 **以「兒童在日常生活中『通常做什麼』而非『能力極限做得到什麼』」為標準，將 CP 兒童的 gross motor、manual ability、eating/drinking、speech、communication、vision 等多軸功能分為五級的標準化量表組合**，目的是讓家長、團隊、研究之間可用同一語言溝通預後與處方，重點不是「他的 CP 多嚴重」，而是「在他的日常裡，他怎麼移動、怎麼吃、怎麼說話、怎麼互動」。

## 已知

- **GMFCS 是最廣泛使用、最早建立、預測性最強**的 CP 分類系統（Palisano et al. 1997，2008 修訂）。
- 五級分類在 GMFCS、MACS、EDACS、CFCS、VFCS 之間是 **平行但不重疊**的軸，**同一兒童在不同軸的等級可不同**（例：GMFCS V + MACS III + CFCS II 完全可能）。
- GMFCS 等級在兒童 2 歲後即 **across time stable**（即年紀大也不太會變等級），讓 prognostic discussion 成為可能。
- 衡量的是 **usual performance**，不是 capability —— 在 ideal 環境下做得到的不算，在自家、學校、社區「平常」做的才算。
- 結構與 [[ICF_功能框架]] 對齊：activity / participation 軸 + 個體 + 環境因子。

## 核心機制

### 為什麼需要功能分類

- 過去 CP 描述用 quality（spastic / dyskinetic / ataxic）+ topography（hemi / di / quad），但這兩軸只描述「motor type 與哪幾肢」，**完全捕捉不到功能差異**。
- 同樣是 spastic diplegia，可能 GMFCS I（無限制走路）也可能 GMFCS IV（需動力輪椅）。
- 功能分類補上「實際生活中能做什麼」這個缺口。

### 為什麼是「usual performance」

- Capability：標準化測驗中、最佳狀況下能做到的。
- **Usual performance**：在他自己的家、學校、社區，平常會做的。
- 治療與資源規劃要對應後者，因為那是他實際的生活。

### 為什麼穩定（stability over time）

- GMFCS 對 ≥ 2 歲兒童的等級在年齡內穩定，這讓 prognostic conversation 成為可能：
  - 「**GMFCS I 的兒童成年後絕大多數可獨立行走**」
  - 「**GMFCS V 的兒童一生都會用 manual wheelchair 移動**」
- 但 < 2 歲的等級會變，這也是為什麼早期「working classification」需謹慎。

## 臨床表現

### 七大功能分類系統

| 系統 | 評估軸 | 適用年齡 |
| --- | --- | --- |
| **GMFCS** | Gross motor function（移動方式） | ≥ 2 歲，2 / 4–6 / 6–12 / 12–18 歲分齡 |
| **MACS** | Manual ability（雙手操作物件） | 4–18 歲 |
| **EDACS** | Eating and Drinking ability | ≥ 3 歲 |
| **VSS** | Viking Speech Scale（語音清晰度） | ≥ 4 歲 |
| **FCCS** | Functional Communication（情境溝通） | ≥ 4 歲 |
| **CFCS** | Communication Function（送/收訊息） | 全年齡 |
| **VFCS** | Visual Function | 全年齡 |

### GMFCS 五級（最常用）

- **Level I**：行走無限制（可能在精細協調、跑步、跳躍受限）。
- **Level II**：行走有限制（在不平、樓梯、距離有困難）。
- **Level III**：使用 hand-held mobility device（拐杖、walker）行走。
- **Level IV**：自我移動有限制；可能用 powered mobility。
- **Level V**：以 manual wheelchair 移動，被推動。

### MACS 五級

- **Level I**：操作物件容易、成功。
- **Level II**：能操作多數物件，但 quality / speed 略下降。
- **Level III**：操作物件困難，需準備或調整。
- **Level IV**：只能操作有限選擇的容易物件，需協助。
- **Level V**：無法操作物件、無法用手完成簡單動作。

### EDACS 五級

- **Level I**：吃喝安全且有效率。
- **Level II**：安全，效率有限。
- **Level III**：安全有限制，效率可能有限。
- **Level IV**：安全顯著受限。
- **Level V**：無法安全吃喝，可考慮 tube feeding。

### CFCS 五級（送/收訊息）

- **Level I**：與多數人在多數環境獨立有效溝通。
- **Level II**：可獨立溝通但較慢。
- **Level III**：與熟人在多數環境有效溝通；陌生人不能。
- **Level IV**：與熟人不一定一致溝通。
- **Level V**：與熟人也很少有效溝通。

### VSS 四級（語音清晰度）

- **Level I**：語音不受運動障礙影響。
- **Level II**：語音不精確但通常可被陌生人理解。
- **Level III**：語音不清，陌生人通常聽不懂出脈絡的內容。
- **Level IV**：無可理解的語音。

## 評估方式

### 怎麼分類一個 CP 兒童

1. **觀察 + 病史**：家長描述「平常」怎麼做（不是診間表現）。
2. **依該系統的 description**對齊到一個 level（不是用 cut-off 數字，是質性描述比對）。
3. **每個系統獨立評**：GMFCS V 不一定 MACS V（dyskinetic CP 常 GMFCS V + MACS IV/V，但 spastic diplegia 可能 GMFCS III + MACS I）。
4. **記錄組合**：例如「Spastic quadriplegic CP, GMFCS IV, MACS IV, EDACS III, CFCS III」。

### 評估時的常見錯誤

- **問家長「他能不能走？」** → 偏向 capability。
- 應問「他在家、學校通常怎麼移動？」 → usual performance。
- **用單次診間觀察評等級** → 不夠穩定。
- 應同時參考家長報告 + 治療師長期觀察。

## 治療原則

### GMFCS-tailored 處方

- **GMFCS I–II**：聚焦 fine motor、跑步/跳躍、participation in community sport、scoliosis surveillance frequency 較低。
- **GMFCS III**：步行訓練 + adaptive sport + 輔具配置。
- **GMFCS IV**：powered mobility 評估、postural management、座位系統。
- **GMFCS V**：comprehensive seating、postural drainage、tube feeding 討論、hip surveillance 高頻。

### MACS-tailored 處方

- **MACS I–II**：bimanual training、CIMT（適用於 hemiplegic）。
- **MACS III**：環境改造、自助具。
- **MACS IV–V**：照顧者訓練、AAC（augmentative and alternative communication）。

### EDACS-tailored 處方

- **EDACS I–II**：定期吞嚥追蹤、進食姿勢調整。
- **EDACS III**：texture modification、VFSS / FEES 評估。
- **EDACS IV–V**：考慮 gastrostomy + 與家長的 QOL 討論。

## 臨床決策點

### 「他幾歲才能定 GMFCS？」

- ≥ 2 歲後等級穩定、可作為長期 prognostic 依據。
- < 2 歲只能作為「working classification」。

### 「不同軸不一致怎麼辦？」

- **這就是設計的目的**。同一兒童 GMFCS 與 MACS 不一致很常見 —— dyskinetic CP 是經典例（手很糟但腿可走）。
- 治療規劃要 **多軸獨立**：腿的處方對應 GMFCS、手的處方對應 MACS、吞嚥的處方對應 EDACS。

### 「GMFCS 等級會不會降級（變好）？」

- 整體 stable，但 **GMFCS III 與 IV 之間** 在學齡期過後有部分案例會「升級」（function 變差），原因是體型增加、痙攣惡化、scoliosis、weight 等。
- 「降級」（變好）較少發生。
- 早期積極介入可能改善 trajectory，但不會跨等級。

### 「家長說他在家會走，但診間沒走，算 GMFCS I 還是 II？」

- 看「**usual performance**」——若家長確認在家通常會走，至少 GMFCS II（有限制但會走）。
- 診間表現可能受焦慮影響低估。

### 反對論點與反駁

- 「分級是貼標籤。」 → 標籤是用詞問題；分級的功能是讓家長知道方向、讓治療有具體可以對應的處方、讓研究可以比較群體。
- 「太簡化，五級不夠細。」 → 是 trade-off。多年驗證顯示這個粒度在 inter-rater reliability、predictive validity、與 clinical utility 之間的最佳平衡。

## 限制與未定論

- **CFCS 與 VFCS 的全年齡 inter-rater reliability** 仍在累積。
- **不同分類系統間的「跨軸」相關性**研究較少（GMFCS V 是否一定 MACS IV+？沒那麼絕對）。
- **轉成成人後 GMFCS 是否仍適用**？目前資料 < 18 歲為主，成人 CP function 的標準化分類還在演化。
- **Dyskinetic CP 在 GMFCS / MACS 的分布**：fluctuating tone 讓 usual performance 評估較困難。
- **Cultural / regional variation** 在 usual performance 的解釋上仍存在；同樣 GMFCS III 在不同國家「usual」可能不同。

## 理解缺口

- **GMFCS / MACS / EDACS 在 telehealth 評估的 reliability** 還沒大規模驗證。
- **Dyskinetic CP 在 EDACS 與 CFCS 的 fluctuation impact** 仍未充分研究。
- **不同 GMFCS 等級的 secondary musculoskeletal complications**（hip displacement、scoliosis）的 risk gradient 已知，但其他系統的 risk gradient 較少 systemic data。
- **AI-based motion analysis** 是否能輔助 GMFCS 分級？是當前研究方向。

> 標記為下一輪要補的方向：成人 CP 功能分類、telehealth 分級的 reliability、AI-assisted classification 進度。

## 臨床使用版

- 教住院醫師時，先說一句：「**CP 分類不是『多嚴重』，是『在他的日常裡他怎麼動、怎麼吃、怎麼說』。**」
- 第二步：「**七個系統評不同軸；GMFCS 是最常用、最穩定、最能講預後的那一個。**」
- 第三步：「**評的是 usual performance，不是 capability —— 問家長『平常』，不是『最好』。**」
- 第四步：「**多軸要分開評；同一兒童在不同軸可以等級不同（dyskinetic CP 經典：手糟腿可走）。**」
- 第五步：「**寫 progress note 要寫『Spastic quadriplegic CP, GMFCS IV, MACS IV, EDACS III』而不是只寫『severe CP』。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 七系統 + GMFCS / MACS / EDACS 五級的核心描述 — 能背能講 → ✅
- 「為什麼 usual performance 而不是 capability」— 能解釋兩者區別與臨床意義 → ✅
- 「GMFCS 是預後談話的基石」— 能講「I 走路無限制 / V 一生需 manual chair」這種錨點 → ✅
- 但 **「為什麼 GMFCS 在 2 歲後特別穩定，背後的神經發展原因是什麼」**我目前只能說「motor cortex 已 mature」這個層次，更深的神經發展機制（CST refinement timeline、myelin maturation）還沒整理通 → 標為[理解缺口](#理解缺口) 的優先補強項。
