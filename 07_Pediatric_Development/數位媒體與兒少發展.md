# 數位媒體與兒少發展

## 一句話定義

數位媒體對兒少發展的影響取決於 **content、context、caregiver mediation、developmental stage 與被擠掉的活動**，不是只看每天幾分鐘。

## 核心機制

### 不只看時數

- portable device 讓 screen media 同時改變：
  - 內容型態
  - 使用頻率
  - 使用情境
  - parent monitoring 難度

### 主要影響面向

- sleep
- obesity
- language development
- executive functioning

### parent mediation 很關鍵

- coviewing
- instructive mediation
- restrictive mediation
- parent technoference 也會反向影響 child development

## 臨床表現

### 臨床重要性

- bedtime 前與 bedroom 內的 device access 常直接影響 sleep。
- digital media 可能提供教育或連結，也可能擠掉：
  - shared interaction
  - physical activity
  - homework
  - in-person social activity

## 評估方式

### media history 重點

- duration
- content
- parent involvement
- bedroom access
- what activity is displaced
- family stress and access issue

## 治療原則

- choose high-quality content
- use together when possible
- keep unplugged activity
- set realistic boundary
- discuss privacy / safety / citizenship

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### 目前限制 / 爭議點

- 新型態裝置研究仍追不上產品更新速度。
- 不同平台、內容與年齡層差異很大，不能把所有 screen media 一概而論。

### frontmatter contradictions

- Screen exposure cannot be judged by duration alone.
- High-quality digital content still depends on context and caregiver involvement to become developmentally useful.

## 理解缺口

- 哪些孩子最容易把 media 用成 self-regulation crutch？
- 何時該優先介入睡眠與環境，而不是直接討論「上網成癮」？
- digital inequality 要如何納入 pediatric counseling？

## 臨床使用版

- 問 media 時，請一起問睡眠、親子互動、學校表現與活動取代。
- 只有 screen hours，通常不足以做出好建議。
