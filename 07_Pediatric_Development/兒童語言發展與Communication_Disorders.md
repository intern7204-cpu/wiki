# 兒童語言發展與 Communication Disorders

## 一句話定義

兒童語言發展與 communication disorders 的評估核心，是把 **speech、language、hearing、pragmatics 與 broader neurodevelopmental context** 分開看，因為 speech / language impairment 是 presentation，不是單一 diagnosis。

## 核心機制

### communication 需要完整機制與環境

- 正常發展至少需要：
  - hearing sensitivity
  - perception
  - motor skill
  - structural integrity
  - cognitive capacity
  - emotional regulation
  - language-rich environment

### language 不是只有字數

- 需要分：
  - receptive language
  - expressive language
  - phonology / articulation
  - morphology / syntax
  - pragmatics
  - speech motor production

### bilingualism 是語言脈絡，不是預設病因

- 雙語 exposure 本身不等於 delay。
- 判讀時要看 child across languages 的整體 communication repertoire。

## 臨床表現

### red flag 思維

- regression / loss of acquired language
- poor comprehension
- limited gesture / joint attention
- restricted communicative function
- speech unintelligibility beyond expected range
- hearing concern
- associated neurologic or syndromic clue

### differential 不能太窄

- developmental language disorder
- speech sound disorder / apraxia
- hearing loss
- ASD / social communication difference
- GDD / ID
- neurologic or structural disorder

## 評估方式

### 基本評估架構

- expressive language
- receptive language
- speech clarity and fluency
- play / pragmatics / social reciprocity
- developmental / neurologic / psychosocial context
- medical history and physical examination

### formal audiology 與 SLP 都是主軸

- child with speech / language impairment 應納入 formal audiologic testing。
- SLP in-depth assessment 用來定義 profile、追蹤基線與 intervention target。
- standardized test 有價值，但不能單獨代表全部 communication function。

### bilingual child 的評估原則

- 盡量在 dominant / primary language 進行評估。
- 若沒有對應語言 SLP，需用 trained interpreter。
- bilingual exposure 不能當作延後評估的理由。

## 治療原則

- 及早 referral to SLP 通常優於被動等待。
- 介入常需要：
  - caregiver coaching
  - play-based therapy
  - school / EI support
  - AAC when indicated
- auditory integration、Fast ForWord、sensory integration 等不應被當成 routine standard treatment。

## 臨床決策點

### 反對論點

- 「男生講話慢一點正常。」
- 「雙語家庭難免慢一點，先等等看。」

### 反駁

- 這些說法都不足以排除真正的 language disorder。
- 關鍵要看 comprehension、gesture、play、hearing、社交互動與整體發展。
- screening 正常也不等於 formal assessment 永遠不需要。

### 結論

- 對語言問題 child，最有效的做法是 **精確拆分 problem、保留 differential、完成 audiology 與 SLP referral**。

## 限制與未定論

### 目前限制 / 爭議點

- 不同 speech / language phenotype 的治療強度與長期結果並不完全一致。
- isolated speech problem、mixed speech-language impairment 與 broader neurodevelopmental condition 的 prognosis 差很多。

### frontmatter contradictions

- Speech and language impairment is a presentation, not a single diagnosis.
- Bilingual exposure is not a default explanation for a true language disorder.
- Developmental screening, parent report, and formal speech-language assessment serve different purposes and should not be conflated.
- Formal audiologic testing is a routine part of initial evaluation for child speech or language impairment.

## 理解缺口

- 哪些 child 更像 primary language disorder，哪些更像 broader neurodevelopmental issue？
- school-age reading difficulty 與早期 language concern 之間要如何追蹤？
- AAC 何時該更早進場，而不是當最後手段？

## 臨床使用版

- 問「會不會講話」不夠，要拆成理解、表達、發音、互動與 hearing。
- 對 persistent concern case，screening 與安慰句都不能取代 formal audiology 與 SLP assessment。
