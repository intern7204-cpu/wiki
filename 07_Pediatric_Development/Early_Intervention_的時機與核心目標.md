# Early Intervention 的時機與核心目標

## 一句話定義

EI 當然要早，但「早」不是抽象口號；它真正指的是 **在 domain-specific plasticity window 內，盡快把需要的 experience 與 support 放回 child 與 family 的 daily routine**，而不是把 age 3 當成神經生物學終點。

## Definition and Boundary

- 這頁聚焦 intervention timing 與 core target，不是完整 Part C 行政流程頁。
- EI 可以包含 Part C system，但 timing 判斷不能只看制度資格。

## Fact

- plasticity 隨年齡下降，因此及早介入通常較有利。
- 但沒有 single critical period 可涵蓋所有 developmental domain；較合理的想法是 multiple / cascading critical periods。
- 出生後的 brain development 越來越依賴 experience，尤其是 language、caregiving、social input 等 experience-expectant input。
- EI 的 delivery 不該只剩 clinic-based session；routine-based support、natural environment 與 family-centered planning 仍是核心。
- program eligibility 與 biologic timing 不是同一件事；不符合某個 public EI threshold，不代表沒有需要及時支持的 development concern。
- adolescence 仍有重要神經重組，例如 prefrontal-related executive function、planning、reward 與 prosocial learning。

## Mechanism Chain

```text
Developmental risk or missing expected input appears
→ still-modifiable developmental window is identified
→ support is embedded in routine, caregiving, and environment
→ child receives more developmentally relevant input
→ better trajectory or less deviation over time
```

## Inference

- 不要等 diagnosis 完整或 delay 擴大才開始 support。
- 也不要因 child 已超過傳統早療年齡，就直接把 later intervention 視為低價值。

## Assumption

- 介入內容真的對準 child 缺少的 input 或 bottleneck，而不只是增加 service hours。

## Uncertainty

- 早做通常較有利，但 later intervention 的最佳 timing 與 effect size 會依 domain、mechanism 與 child heterogeneity 改變。
- critical period rescue 仍偏研究層次，不可直接承諾臨床可行性。

## Clinical Use

- referral 時除了送單，還要想 child 現在缺的是哪種 expected input。
- 若 child 已較大或進入 adolescence，仍應評估是否存在 later plasticity window、compensatory opportunity 或 secondary effect 需要新的 intervention。
