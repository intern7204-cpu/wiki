# Executive Function 支持策略

## 一句話定義

Executive Function 支持策略的核心，不是叫 child 更自律，而是把 **task demand、external scaffold、feedback loop 與 developmental stage** 對齊，讓 child 更容易把已有能力表現出來。

## 核心機制

### 支持策略在處理什麼

- task initiation
- working memory load
- planning / organization
- time management
- emotion-linked derailment
- monitoring / error recovery

### 基本原則

- 先降低不必要的 task complexity
- 把 invisible demand 變成 visible cue
- 先外部支架，再逐步退場
- 用即時 feedback，不要只用事後責備

## 臨床表現

### 常見需要支架的情境

- homework 卡住但不是不會
- 早晨 routine 散掉
- transition 容易爆炸
- assignment 明明懂卻交不出來
- adolescent 有目標但無法切成可執行步驟

## 評估方式

### 先分清問題在哪一段

- task representation：孩子知不知道任務其實要做什麼？
- working memory load：是不是步驟太多、資訊留不住？
- inhibition / self-control：是不是會被即時刺激拉走？
- monitoring / feedback：是不是做錯了也抓不到？
- stress / sleep / language：是不是根本不是純 EF 問題？

### 必須回 formal evaluation 的情況

- persistent school impairment
- language / learning concern
- severe emotional dysregulation
- suspected ADHD / ASD / ID / anxiety / sleep disorder
- regression 或 neurologic red flag

## 治療原則

### home support

- checklist / visual schedule
- predictable routine
- task breakdown
- one-step cueing
- body doubling / co-working

### school support

- written directions
- smaller chunks
- external time anchor
- reduced simultaneous load
- explicit feedback and recheck routine

### adolescence support

- goal mapping
- trigger planning
- autonomy-supportive coaching
- real-life problem solving
- planning backward from deadline

### infancy to childhood practice ideas

- turn-taking game
- imitation
- rule-based play
- role play
- reflective conversation

## 臨床決策點

### 反對論點

- 「這些孩子就是不夠自律，盯緊一點就會好。」

### 反駁

- 很多 EF complaint 的問題不是知道規則，而是 task structure、cue visibility、feedback timing 與 stress load 不對。
- 單靠責備或增加口頭提醒，通常只會增加 friction，不會增加 execution。

### 結論

- 有效的 EF 支持策略，重點是 **把環境與任務重新設計成 child 能成功啟動、持續與修正的形式**。

## 限制與未定論

### 目前限制 / 爭議點

- activity guide 與 popular book 多屬 lower-tier support material。
- 很多 practical strategy 合理且可用，但不是每一項都已有高品質 trial。

### frontmatter contradictions

- Practical scaffolding can improve executive-function performance, but it does not replace formal evaluation when broader neurodevelopmental or psychiatric conditions are suspected.
- Executive-function support must be matched to the task, context, and developmental stage rather than delivered as one generic routine.
- Many activity-based suggestions are developmentally plausible but not uniformly validated as standalone treatments.

## 理解缺口

- 哪些 strategy 最適合 monitoring problem，哪些更適合 initiation problem？
- external scaffold 何時該退場，何時反而要加強？

## 臨床使用版

- 若家長或學校主訴是「知道要做，但做不出來」，先從 task design 與 cueing 開始，不要先把問題道德化。
- 若支持策略做了仍普遍失效，要回頭想 diagnosis、sleep、language、anxiety 與 school fit。
