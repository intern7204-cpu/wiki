# 聽損兒童的發展脈絡評估

## 一句話定義

deaf child 的 developmental outcome 不是只由分貝數決定，而是由早期辨識、持續 audiologic monitoring、家庭支持與 language access 共同決定。

## Definition and Boundary

- newborn hearing screen 只是起點，不是終點。
- 這個 concept 聚焦 deaf-aware developmental evaluation，而不是單純聽力數值判讀。

## Fact

- school-age prevalence 高於 newborn period。
- cCMV 與 NICU risk factor（如 NICU stay >5 days、hyperbilirubinemia、aminoglycoside、meningitis、trauma、noise exposure）都需納入 surveillance。
- developmental disability child 更容易被漏掉 hearing loss。
- 真正介入核心是 language access；ASL、spoken language、total communication、AAC 應 individualized planning。

## Mechanism Chain

```text
Early identification + ongoing monitoring
→ better language access planning
→ more accurate developmental assessment
→ better developmental outcome
```

## Inference

- 若把 deaf child 只當 speech problem，常會漏掉真正關鍵的 language access decision。

## Assumption

- 評估時會使用 deaf-informed 或 nonverbal tool，避免把語言剝奪誤判成低 intelligence。

## Uncertainty

- 最佳 communication mode 需依 child profile 與 family context individualized，不存在單一路徑。

## Clinical Use

- developmental delay child 若合併風險因子或 additional disability，要主動回頭檢查 hearing，而不是假設問題都來自主診斷。
