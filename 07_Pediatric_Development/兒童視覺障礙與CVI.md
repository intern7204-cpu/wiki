# 兒童視覺障礙與 CVI

## 一句話定義

兒童視覺障礙評估不能只看眼球本身，還要同時看 **ocular disease、visual pathway 與 cerebral visual impairment (CVI)** 對 development、mobility 與 learning 的影響。

## 核心機制

### 核心概念

- 視覺障礙來源可分為：
  - pregeniculate：cornea、lens、retina、optic nerve
  - postgeniculate：delayed visual maturation、CVI
- developmentally delayed children 的 refractive error、strabismus、nystagmus、optic pathology 盛行率高。
- 在 prematurity population，視覺問題不一定都由 ROP 解釋；brain injury 常同時參與。

### 方法學重點

- 視覺評估不能只做 distance acuity。
- 需同時看：
  - ocular alignment
  - refractive issue
  - visual field / ocular motility
  - functional vision
  - developmental context
- 對 infants / low-participation children，functional visual assessment 常比標準量表更重要。

## 臨床表現

### 高風險族群

- extreme prematurity / NICU history
- cerebral palsy
- global developmental delay / intellectual disability
- craniofacial syndrome、genetic syndrome、metabolic disease
- known brain injury 或 suspected CVI

### screening / red flags

- poor eye alignment
- nystagmus
- excessive photophobia
- 不穩定 visual attention
- 對 visual target reach 時 head/eye strategy 異常
- 極近距離看物
- red reflex / pupil / fundus 異常

### CVI 的臨床意義

- CVI 是功能性 visual problem，不一定能用單純 acuity 解釋。
- 孩子的困難常出現在：
  - visual attention
  - cluttered environment processing
  - visual-motor planning
  - mobility / orientation
  - school learning
- 對 preterm child，ROP 與 CVI 可同時存在。

### 臨床或研究上的重要性

- routine ophthalmologic evaluation 對 children with disabilities 很重要。
- 視覺問題常先於 motor/cognitive diagnosis 被看見，也會直接改變後續治療方式。
- 視覺障礙若未及時辨識，會放大 language、motor、behavior 與 educational difficulty。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### 目前限制 / 爭議點

- broad pediatric visual impairment chapter 不等於 CVI-specific intervention review。
- 某些 visual behavior 也可能被 motor impairment、attention problem 或 ASD-like behavior 混淆。

### frontmatter contradictions

- Vision problems in children are not reducible to acuity or glasses prescription alone.
- In preterm and neurodisabled children, brain-based visual dysfunction may be more functionally important than ocular diagnosis alone.

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 兒童視覺障礙與 CVI 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
