# Speech Disorder 與 Language Disorder 的區分

## 一句話定義

speech / language concern 不能只用「講話慢」概括；至少要分 comprehension、expression、play、hearing 與 broader differential。

## Definition and Boundary

- speech 問題偏 articulation / output；language 問題涉及 comprehension、symbolic use 與 broader communication。
- 它不是用民間說法去解釋所有 late talker。

## Fact

- bilingualism 與 chronic otitis media 都不足以單獨解釋 clinically important delay。
- prognosis 要看 receptive language 與 symbolic play；即使早期追上，school age 仍可能有 reading difficulty。
- screening 與 diagnostic testing 功能不同。
- differential 要保留 hearing loss、autism、cognitive disorder、oral-motor / anatomic disorder。

## Mechanism Chain

```text
Observed communication concern
→ separate speech from broader language function
→ check receptive language, play, hearing, social use
→ more accurate differential and prognosis
```

## Inference

- 若只看字數，很容易把 language disorder、hearing issue 與 social communication problem 混在一起。

## Assumption

- young child assessment 會納入 parent report、observation 與 naturalistic assessment。

## Uncertainty

- 大約半數 2 歲 delayed child 可能追上，但個別預後仍需靠 receptive language 與 play 線索細分。

## Clinical Use

- 遇到晚講話的孩子，先問懂不懂、會不會 pretend play、聽力如何，而不是先用性別或家庭排行解釋。
