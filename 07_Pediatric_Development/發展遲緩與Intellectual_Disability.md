# 發展遲緩與 Intellectual Disability

## 一句話定義

GDD 是 5 歲前的 provisional developmental description；Intellectual Disability (ID) 則是 **intellectual function + adaptive function 皆顯著受限，且起始於發展期** 的 neurodevelopmental disorder。

## 核心概念

### GDD 與 ID 先分清

- `GDD`：
  - 常用於 <5 歲
  - 至少 2 個 developmental domains 顯著落後
  - 是 provisional / descriptive diagnosis
- `ID`：
  - limitations in intelligence
  - limitations in adaptive skills
  - onset during developmental period
- pediatric practical frame 通常仍用 childhood-onset；定義細節上 DSM 與 AAIDD 的 cutoff 不完全相同。

### adaptive function 比 IQ 更接近臨床現實

- adaptive domain 包含：
  - conceptual
  - social
  - practical
- severity 主要看 adaptive impairment 與 support need，而不是單一 IQ score。
- 臨床上真正要寫的是 child 在：
  - communication
  - self-care
  - safety
  - school
  - community participation
  的功能限制。

### 病因骨架

- 已知病因中，genetic cause 佔很重要比例。
- 但不能把病因只縮成 genetics；還要保留：
  - prenatal / perinatal / postnatal insult
  - metabolic disorder
  - infectious / toxic exposure
  - nutritional deficiency
  - environmental adversity / poverty
  - idiopathic

## 臨床或研究上的重要性

### presentation pattern

- severe ID 常在 2 歲前就浮現。
- mild ID 可能先以：
  - language delay
  - immature play / self-help skill
  - school difficulty
  - adaptive limitation
  呈現，甚至到 school age 才被辨識。

### 常見共病與臨床延伸

- ASD
- ADHD
- learning disorder
- feeding / eating disorder
- depression / anxiety / PTSD
- sleep disorder
- hearing / vision problem
- abuse vulnerability

### 為什麼這頁重要

- etiologic diagnosis 會改變 prognosis、comorbidity surveillance、family counseling 與 condition-specific treatment thinking。
- 但即使還沒找到原因，也不應延誤 [[Early_Intervention_總論]]、school service 與 family support。

## 評估方式

### diagnostic frame

- history：
  - prenatal / perinatal / postnatal history
  - regression / episodic decompensation
  - family history / 3-generation pedigree
  - school data
  - adaptive function
  - sleep、behavior、abuse risk、social context
- exam：
  - dysmorphology
  - detailed neurologic exam
  - hearing / vision thinking
  - growth / head circumference

### cognitive 與 adaptive assessment

- cognitive testing 與 adaptive testing 要一起看。
- 常見 adaptive tool 包含：
  - Vineland-3
  - ABAS-3
  - DABS
- 有明顯 language 或 motor limitation 的 child，測驗選擇要避免低估真實能力。

### etiologic workup 重點

- 有 syndrome clue 時，先 targeted testing。
- unexplained GDD/ID 可考慮 first-line：
  - exome sequencing
  - genome sequencing
  - CMA
- diagnostic yield 可作為粗略 anchor：
  - CMA：約 15% 到 20%
  - exome：約 30% 到 55%
  - genome：約 35% 到 60%
- review newborn screening 是基本步驟。
- metabolic testing 較適用於：
  - regression
  - seizure
  - episodic decompensation
  - hepatomegaly
  - abnormal neurologic finding

### 何時要懷疑不是單純 nonprogressive delay / ID

- true regression / loss of skills
- new seizure 或明顯 neurologic deterioration
- progressive motor loss、spasticity、feeding decline
- systemic clue：hepatosplenomegaly、dysmorphism、metabolic clue

## 治療原則

### long-term management 主軸

- early、individualized、multidisciplinary support
- speech-language、OT、PT、hearing / vision service
- school support 與 family counseling
- preventive care 不應少於 typical child
- syndromic cause 需加上 syndrome-specific surveillance

### behavioral / psychiatric management

- 先排 sleep problem、pain、medical illness、psychiatric disorder、abuse。
- psychopharmacology 只處理明確 target behavior / comorbidity。
- 原則是：
  - 先有 behavioral / environmental plan
  - measurable goals
  - `start low, go slow`

### transition

- transition planning 應在 12 歲前後開始。
- 14 歲前後應有可追蹤書面計畫，之後 yearly review。
- 美國制度下 IEP transition plan 法規節點是 16 歲；回寫時要明確標示這是制度脈絡，不是 universal medical threshold。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「IQ 很低就等於 ID。」
- 「這只是慢一點，以後自己會追上。」
- 「ID 的原因找不到也沒差，反正 treatment 都一樣。」

### 反駁

- 現代 ID 定義要求 adaptive functioning 也受損，嚴重度更看 support need，而不是單一 IQ number。
- 有些 child 是 GDD 後續改善，有些則 reclassify 成 ASD / ADHD / DCD；不能一開始就用單一路徑想像所有孩子。
- etiologic diagnosis 會改變 surveillance、genetic counseling、treatable-cause recognition 與部分 syndrome-specific management。

### 結論

- 對發展遲緩 child，臨床重點是先搞清楚 **這是 descriptive delay、stable ID，還是有 regression / progressive clue 的其他病程**；接著再把 adaptive function、etiology 與 long-term supports 串起來。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### 目前限制 / 爭議點

- adaptive behavior measurement 仍有工具、語言與文化偏差問題。
- GDD 與教育系統的 `developmental delay` 標籤不能混用。
- genetic testing sequence 持續更新，且受 availability / cost / insurance 影響。
- 很多 transition / service 細節來自美國制度語境，不能直接當成本地制度。

### frontmatter contradictions

- Intellectual disability severity should not be determined by IQ alone without adaptive-function framing.
- Global developmental delay in children younger than 5 years is a provisional developmental description, not automatically permanent intellectual disability.
- Regression is not expected in nonprogressive developmental delay or intellectual disability and should widen the differential.

## 理解缺口

- 發展遲緩與 Intellectual Disability 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 發展遲緩與 Intellectual Disability 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
