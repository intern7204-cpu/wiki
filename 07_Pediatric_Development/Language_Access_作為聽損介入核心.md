# Language Access 作為聽損介入核心

## 一句話定義

對 deaf child，介入核心不是單純追求 speech，而是確保 language access。

## Definition and Boundary

- language access 是 developmental support 的核心目標。
- 它不是單一 communication philosophy 的宣傳頁。

## Fact

- 本來源最重要的臨床訊息之一是 deaf children need language access。
- ASL、spoken language、total communication、AAC 等模式，應依 child profile 與 family context individualized planning。
- 若 child 有 additional disability，更要避免單一路徑思維。
- speech-only framing 不是 adequate developmental framework。

## Mechanism Chain

```text
Deafness
→ risk of limited language input
→ language access planning
→ better communication and developmental support
```

## Inference

- 若介入只把目標寫成「講出聲音」，容易忽略更上位的 language deprivation 風險。

## Assumption

- 家庭、團隊與服務系統能接受 individualized communication planning，而不是先預設單一模式。

## Uncertainty

- 最佳 communication mode 沒有 universal answer，必須依 child 與 family context 調整。

## Clinical Use

- 討論聽損 child 時，先問「language access 怎麼建立」，再問「speech 走哪條路」。
