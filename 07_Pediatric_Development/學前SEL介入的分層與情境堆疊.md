# 學前 SEL 介入的分層與情境堆疊

## 一句話定義

對 preschool child，SEL 介入的效果不只看「有沒有上」，而要看 **是 universal 還是 targeted、是否有 home + school continuity，以及 program 本身是否 developmentally matched**。

## Definition and Boundary

- 這裡談的是 preschool social and emotional learning intervention 的設計邏輯。
- 它不是泛稱任何 social skills 課程都有一樣效果。
- 它也不是在宣稱某個單一 program 必然最好。

## Why It Matters

- preschool years 的 school readiness 很大一部分來自 self-regulation、social reciprocity 與 behavior organization。
- 如果 child 已有明確風險，仍只給 universal classroom-level exposure，效果可能不足。
- preschool child 的日常生活同時受 home 與 school 影響，intervention 若只留在單一場域，常無法形成穩定 carryover。

## Preconditions or Conditions

- 需要先辨識 child 是一般 universal support 對象，還是已屬 at-risk / 需要額外 supports。
- 需要知道 intervention 是誰 deliver：
  - teacher
  - parent
  - researcher / specialist
  - parent + teacher stack
- 需要評估 fidelity、家庭參與可行性與 program 的 developmental appropriateness。

## Mechanism

```text
Preschool child in home + school mesosystem
→ choose universal or targeted intervention tier
→ decide whether support stays in classroom only or extends across home and school
→ repeated practice of regulation / social-emotional skills in real contexts
→ outcome depends on program type, fidelity, risk status, and context continuity
```

## Observable Patterns

- universal preschool SEL 有整體正向效果，但 effect size 中等偏小，且異質性很大。
- at-risk preschooler 在 universal intervention 下的 effect size 較小。
- targeted intervention 的 effect size 較大，而且多半帶有 parent-training / home-based component。
- home + school 雙場域堆疊，在 preschool 比 teacher-only school delivery 更值得注意。

## Clinical / Research Implication

- 臨床或教育實務上，遇到 school readiness / behavior concern 時，不能只問「學校有沒有 SEL」；要問：
  - 現在是 universal 還是 targeted tier？
  - home 有沒有同步 carryover？
  - child 的 risk level 是否已超出 universal dose？
- 研究上，未來比起再把所有 program 混成一類，更重要的是拆解：
  - program active ingredient
  - parent vs teacher contribution
  - fidelity 與長期 outcome

## Fact

- preschool universal SEL 的 overall grand mean effect size 為 `g = .35`。
- preschool targeted SEL 的 overall grand mean effect size 為 `g = .48`。
- universal intervention 裡，at-risk samples 的 effect size 為 `g = .21`，小於 non-at-risk samples 的 `g = .29`。
- universal intervention 中，teacher-only delivery 的 effect size 為 `g = .28`。
- universal intervention 中，parent + teacher、home + school stack 的 effect size 為 `g = .53`。
- intervention program type 解釋 universal effect heterogeneity 的大部分，meta-regression `R2 = .83`。

## Inference

- 對已知 at-risk preschooler，單靠 universal classroom SEL 常常不夠，需要更明確的 targeted support。
- preschool child 的介入成效，可能比 school-age child 更依賴 home-school continuity。
- `SEL` 這個標籤本身資訊量不夠，真正需要看的是 tier、program 與 delivery architecture。

## Assumption

- 家庭有機會參與 intervention，且 parent-training component 具可行性。
- program 有基本 fidelity，而不是名義上存在但實際執行鬆散。
- child 的困難確實與 social-emotional / behavioral regulation 有關，而不是主要來自 hearing、language、trauma、sleep 或 broader neurodevelopmental disorder 未被辨識。

## Uncertainty

- 不同 program 間效果差異來自 moderator analysis，不能直接做因果排名。
- publication bias 與 cluster-randomization correction 不完整，可能使效應量被高估。
- 長期 school readiness、academic achievement 與 participation outcome，這篇沒有充分回答。

## Limitations and Misreadings

- 反對論點：只要在班上全面推 SEL，所有孩子都會受益，不需要再分層。  
  反駁：本來源顯示 at-risk preschooler 在 universal intervention 下的 effect size 較小，而 targeted intervention 的 overall effect 較大。  
  結論：universal support 很重要，但不能拿它取代 targeted support。

- 反對論點：SEL 就是課堂 curriculum，家長參與不是核心。  
  反駁：在 preschool universal interventions 中，home + school stack 的 effect size 高於 teacher-only school delivery。  
  結論：對 preschool child，介入情境本身就是 intervention design 的一部分。
