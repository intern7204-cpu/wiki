# ASD 藥物與共病管理

## 一句話定義

ASD psychopharmacology 的邏輯是 **先定義最 impairing 的 target symptom，先優化 nonpharmacologic support，再用 low-dose, slow-titration 的方式處理 comorbidity 或 dangerous behavior**。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### 先做什麼，再談藥

- educational / behavioral intervention 要先在位，或至少已明確規劃。
- 先找 target symptom：inattention、irritability、aggression、self-injury、anxiety、sleep、rigidity、mood symptom。
- 若有條件，Functional Behavioral Assessment 能幫忙分清 behavior function。

### 哪些 medical factor 常被忽略

- pain、dental issue、constipation、GI distress、infection、sleep disorder、seizure、menstrual cycle。
- ASD child 因 communication limitation，side effect 與身體不適更容易被誤讀成「behavior problem」。

### 常見用藥情境

- ADHD-like symptom：
  - stimulant 仍是常見 first-line，但 effect size 通常比 neurotypical ADHD 小，side effect 也可能更明顯。
  - alpha-2 agonist、atomoxetine 可作 second-line / alternative。
- irritability / aggression / self-injury：
  - risperidone 與 aripiprazole 證據相對最好，但需監測 weight、metabolic risk、sedation、movement issue。
- anxiety / depression：
  - SSRIs 可用，但 evidence 不是很強，且 behavioral activation / suicidality monitoring 很重要。
- rigidity / repetitive behavior：
  - 若背後主要是 anxiety / OCD-like symptom，可考慮 SSRI；但對 core stereotypy 的直接效益有限。

### 用藥原則

- start low and go slow。
- 每次只處理最重要或最可介入的 symptom，避免同時上太多藥。
- 監測 BP / HR、weight、sleep、GI、QTc interaction、sedation、behavior change。

### 共病與 safety surveillance

- common comorbidity：ADHD、anxiety、depression、sleep disorder、feeding / GI problem、epilepsy、motor issue。
- safety concern：elopement、drowning risk、self-injury、bullying / victimization、adolescent suicidality。
- true management 需要 family、school、primary care、specialist 共同追蹤。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- medication 處理的是 target symptom / comorbidity，不是 core ASD deficits 本身。
- risperidone / aripiprazole 不是所有 tantrum、aggression 或 self-injury 的自動答案。
- 新出現的 behavior worsening 要先查 pain、sleep、GI、seizure、environmental trigger，不能直接假設是 psychiatric escalation。

## 理解缺口

- ASD 藥物與共病管理 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- 目前缺少完整評估框架：History、Physical examination、Scale / test、Imaging / lab 仍需補強。
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 ASD 藥物與共病管理 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
