# 兒童聽覺障礙與 Deafness

## 一句話定義

兒童 hearing loss / deafness 的核心不是只有 audiogram，而是 **hearing status、language access、developmental monitoring 與 family-centered intervention** 的整合照護。

## 核心機制

### 核心概念

### terminology 與臨床姿態

- `Deaf` 可能牽涉文化認同。
- `deaf` / `hard of hearing` 較接近 audiologic description。
- 臨床重點不是套哪個字，而是避免 pathologizing 並尊重 communication identity。

### 為什麼 newborn screen 不夠

- 很多 child 的 hearing loss 是 delayed-onset 或 progressive。
- cCMV、NICU history、hyperbilirubinemia、ototoxic medication、meningitis、head trauma、noise exposure 都會改變後續風險。
- 這個 surveillance 問題可獨立見 [[新生兒聽力篩檢之後的持續監測]]。

### high-risk child 特別容易被漏

- Down syndrome
- cerebral palsy
- ASD
- intellectual disability
- other syndromic / medically complex child
- 這種 diagnostic overshadowing 可獨立見 [[發展障礙兒童的聽損遮蔽效應]]。

## 臨床表現

### 臨床重要性

- 未辨識或管理不足的 hearing loss 會放大：
  - language delay
  - learning difficulty
  - behavior frustration
  - social participation problem
- 在多重障礙 child，hearing loss 常不是最顯眼的問題，卻可能是最可修正的 barrier 之一。

## 評估方式

### 評估重點

- caregiver concern 不能忽略，即使 newborn screen 正常。
- audiologic evaluation 需依 developmental age 選擇：
  - OAE / AABR
  - ABR
  - VRA
  - CPA
- 對有語言遲緩 child，要把 hearing loss 放進 routine differential。
- 測試選擇原則可獨立見 [[依發展年齡選擇兒童聽力測試]]。

## 治療原則

### 發展與介入的主軸

- 早期辨識
- 持續 audiologic monitoring
- language access
- family-centered planning
- 與 EI / speech-language / vision / AAC 等跨專業協作
- `language access` 的核心概念可獨立見 [[Language_Access_作為聽損介入核心]]。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### 目前限制 / 爭議點

- communication modality choice 需個別化，不能用單一理念強壓所有 child。
- 認知與語言測驗若未調整 deaf context，容易低估能力。
- 美國 Deaf culture / service system 需與本地制度分開理解。

### frontmatter contradictions

- Passing newborn hearing screening does not exclude later-onset or progressive hearing loss.
- Language development in deaf children should not be framed only as speech acquisition; language access is the core issue.

## 理解缺口

- 兒童聽覺障礙與 Deafness 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 兒童聽覺障礙與 Deafness 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
