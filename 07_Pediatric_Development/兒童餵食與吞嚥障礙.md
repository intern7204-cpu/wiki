# 兒童餵食與吞嚥障礙

## 一句話定義

兒童餵食與吞嚥障礙是 **developmental mealtime skill、medical physiology、airway safety 與 caregiver-child interaction** 同時失衡的問題，不是只看挑食或 aspiration 其中一項。

## 核心機制

### 先把 feeding 與 swallowing 分開

- feeding 包含：
  - hunger / satiety cue
  - food acceptance
  - positioning
  - self-feeding progression
  - mealtime learning
- swallowing 則聚焦 oral / pharyngeal / esophageal transport 與 airway protection。

### pediatric feeding 是 developmental skill

- eating 需要 modeling、interaction 與 support。
- cue-based feeding 可用來看：
  - flow rate 是否合適
  - infant 是否準備好進食
  - 何時該停下
- 強迫餵食會把 experiential problem 疊加上去。

### dysphagia 要回到 physiology

- oral、pharyngeal、esophageal phases 任何一段失序都可能造成問題。
- pharyngeal phase 對 aspiration 最關鍵。
- aspiration 可有 symptom，也可能 silent。

### 三大 contributing factors

- structural
- physiologic
- experiential

這三軸會一起決定：

- 安全性
- 效率
- 成長
- mealtime participation

## 臨床表現

### 臨床重點

- coughing、choking、wet voice、recurrent pneumonia、pain with swallowing、growth faltering 都是 red flag。
- selective eating 不一定只是 behavior；可能來自反覆不舒服、窒息感、food insecurity、sensory difference。
- medically complex child 尤其要主動想 feeding/swallowing issue。

## 評估方式

### 評估框架

- growth / hydration / pulmonary history
- GI / neurologic / cardiorespiratory contributor
- oral motor 與 positioning
- meal observation
- caregiver-child feeding interaction
- 是否需要 VFSS / FEES

### instrumental assessment 的位置

- VFSS：看 aspiration、laryngeal penetration、trigger、residue、strategy response。
- FEES：看 secretion、swallow 前後 pharyngeal event，且無 radiation。
- upper GI 不能拿來取代 swallow study。

## 治療原則

### 原則

- 先定義 contributing factor，再談 intervention。
- 常見介入包含：
  - postural / positional change
  - pacing
  - texture / liquid modification
  - adaptive utensil
  - direct feeding therapy
  - sensory / behavioral support
- multidisciplinary collaboration 是主軸，不是附加選項。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「孩子只是挑食，不用想那麼多。」
- 「先把食物弄稠就好，不一定要做進一步評估。」

### 反駁

- pediatric feeding problem 常同時含有 structural、physiologic、experiential 三軸。
- silent aspiration 存在，單靠表面觀察可能低估風險。
- IDDSI 與 thickened liquid 只是 shared language / management tool，不是 etiologic diagnosis。

### 結論

- 儿童 oral intake 問題若影響 growth、respiration、safety 或 participation，就應系統化評估，而不是只貼上 picky eater 標籤。

## 限制與未定論

### 目前限制 / 爭議點

- pediatric feeding intervention 文獻異質性高，很多做法仍混有 expert opinion。
- 單次 instrumental study 只代表特定條件下的 snapshot。

### frontmatter contradictions

- Feeding disorder and dysphagia are not interchangeable labels.
- Texture modification or thickened liquids should not be used as a surrogate for physiologic swallow assessment.

## 理解缺口

- 兒童餵食與吞嚥障礙 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside 線索足以推動 VFSS / FEES？
- sensory / behavioral feeding issue 與 true dysphagia 常如何疊加？

## 臨床使用版

- 問題若是「吃得慢、只吃少數食物、常咳、長不好」，先拆 feeding 與 swallowing。
- 先分清 airway safety 問題、mealtime learning 問題，還是兩者都有。
