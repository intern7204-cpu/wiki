# 學齡期的同儕歸屬與自我概念

## 一句話定義

middle childhood 的核心任務不只是 academic performance，而是 school adaptation、peer belonging、self-regulation 與 self-concept 的同步重組。

## Definition and Boundary

- 這是 school-age developmental frame。
- 它不是把 school problem 簡化成成績差或注意力差。

## Fact

- school 被定義為 middle childhood 的主要發展場域。
- self-regulation 橫跨行為、情緒、學習、社交，而不只是注意力。
- early childhood delay 若未 resolve，常在學校年齡以 learning / behavior / disability 形式再出現。
- internalizing problem 可能 masquerade as learning issue；teacher relationship、family support、trauma、anxiety 都會改變功能。

## Mechanism Chain

```text
School and peer environment
→ mastery / belonging experiences
→ self-concept and regulation
→ school-age function
```

## Inference

- school-age child 的問題若只從學科成績切入，常會漏掉 peer、anxiety 與 identity 層面的障礙。

## Assumption

- assessment 會同時納入 school、peer、family 與 emotion / behavior 脈絡。

## Uncertainty

- 同樣的 school underperformance 可能來自不同 intrinsic / extrinsic factor 組合。

## Clinical Use

- 面對學齡兒童的「學不好」，先問他在同儕與學校系統中的位置，而不是只追成績單。
