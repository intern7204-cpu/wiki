# Developmental Delay 的鑑別起點

## 一句話定義

GDD 是 early-life descriptive diagnosis，不等於 ID；鑑別的起點要看 adaptive function、發展軌跡，以及有沒有 regression 或 progressive clue。

## Definition and Boundary

- ID 需要 intellectual function deficit、adaptive behavior deficit 與 onset before adulthood。
- GDD 則是 <5 歲、至少 2 個 developmental domains 顯著落後的描述性用語。

## Fact

- adaptive behavior 是診斷核心，severity 應依 adaptive function / support need，而不是單看 IQ。
- regression 不是 ID 的自然病程；若有 true loss of skills、new seizure、motor loss，要想 progressive encephalopathy。
- 並非每個 GDD 最後都會成為 ID。
- etiologic workup 已進入 genetics-first era，包含 CMA、FMR1、MECP2、PTEN、ES 等思路。

## Mechanism Chain

```text
Observed developmental delay
→ define domains and adaptive impact
→ check for regression / progression
→ choose descriptive diagnosis and etiologic workup
```

## Inference

- 只看 IQ 或只說「再等等」，都容易延誤真正需要的病因評估。

## Assumption

- clinician 會把 adaptive function 當成核心資料，而不是附錄。

## Uncertainty

- reclassification 在成長與介入後很常見，GDD 的最終類別不一定固定。

## Clinical Use

- developmental delay 的第一步不是下結論，而是先分清 GDD、ID 與 progressive process。
