# CP 骨骼健康與骨折

## 一句話定義

CP 骨骼健康與骨折管理是 **針對 CP 兒童因 immobility、營養不良、藥物（特別是抗癲癇藥）、puberty 異常、合併 fragility 的多因子骨質下降，用「預防 + 早期偵測（DXA + 個體化追蹤）+ 階梯式介入（營養 → 承重 → bisphosphonate）」減少 fragility fracture 與其 cascade 的長期照護流程**，重點是「fracture 一旦發生，下次 fracture 風險每年加倍」——所以重點是事前預防而不是事後處理。

## 已知

- **CP 是兒童最常見的低骨密度（low BMD）相關疾病**。
- 骨折最常發生在 **distal femur**；**non-ambulatory 兒童發生率高出 ambulatory 約 20%**。
- **每次骨折後一年內，再骨折風險 nearly doubles**。
- AACPDM 2017 *Osteoporosis in Cerebral Palsy* care pathway 是當代主要 framework。
- **Novak 2020 traffic light**：bisphosphonates 為 BMD treatment **probable evidence**；Vitamin D / calcium 為 **possible evidence**；weight-bearing activities 為 **insufficient evidence** —— 這意味臨床慣用 standing program 仍前無 strong RCT 支持。
- 多數骨折是 **fragility fracture**：minimal / no trauma 即發生。

## 核心機制

### 為什麼 CP 兒童骨頭弱

CP 兒童的骨頭品質下降是 **多因子協同**：

1. **承重 / 機械刺激不足**
   - 骨骼 remodeling 由 muscle activity + mechanical stress 驅動。
   - GMFCS III–V 的兒童 weight-bearing 顯著減少 → osteoblast stimulation 不足。
   - Acute immobilization（casting、術後）短期內也能顯著降 BMD。

2. **營養不良**
   - 慢性 underweight、protein-energy malnutrition。
   - 鈣、磷、Vitamin D、鋅、鎂攝取不足。
   - 進食 / 吞嚥困難 + GI 吸收問題（GERD、constipation 用 PPI 影響鈣吸收）。

3. **藥物副作用**
   - **Anticonvulsants**（特別 enzyme-inducing：phenytoin、phenobarbital、carbamazepine）→ 加速 vitamin D 代謝。
   - **Chronic steroids** → 直接抑 osteoblast。
   - **PPIs**（GERD 治療）→ 鈣吸收下降。
   - **Antidepressants**（特別 SSRIs）→ 部分研究顯示降 BMD。
   - **Medroxyprogesterone acetate**（青春期管理）→ 顯著降 BMD。

4. **延遲 / 異常 puberty**
   - Sexual maturation 延遲 → peak bone mass 累積期縮短或變弱。
   - 部分 CP 兒童 puberty 起步早但 menarche 晚 + 不規則 → 性激素 exposure 不夠。

5. **基因 / 結構基礎弱**
   - 部分 CP 兒童本身有 underlying genetic syndrome（例如 Rett、HSP）影響骨骼。
   - 早產 + NICU 病史 → 嬰兒期 baseline BMD 已較低。

### 為什麼骨折常發生在 distal femur

- 該部位是 weight-bearing 兒童 normally 承受 bending stress 的關鍵點。
- non-ambulatory 兒童此處未承受 axial load → trabecular thinning。
- Transfer、physical therapy、even diaper change 的 torque 是常見 trigger。

### 為什麼第一次骨折後風險倍增

- 初次骨折反映 **structural reserve 已耗盡**。
- 復原期常需 immobilization → 進一步 BMD 下降。
- 疼痛 / 恐懼 → 進一步減少 weight-bearing → 惡性循環。

## 臨床表現

### 高風險 phenotype

- **GMFCS IV–V** 非走路兒童。
- 服用 anticonvulsant、PPI、chronic steroid、medroxyprogesterone。
- 過去 fragility fracture 病史。
- 進食困難 / underweight / chronic underweight history。
- 早產 + low birth weight。
- 延遲 puberty。

### 骨折的臨床表現

- 常 **無明確外傷**（fragility）。
- 兒童可能無法表達疼痛 → 表現為：
  - 突然不願 transfer / 拒絕 ROM。
  - Posture 改變、座椅姿勢不穩。
  - 局部腫脹、發紅。
  - 不安、易怒、新發 spasticity 增加。
- 在 communication-impaired 兒童，疼痛常被誤判為「behavioral issue」、「便秘」、「seizure」。

### 「Asymptomatic low BMD」的問題

- 低 BMD 本身無症狀。
- 必須 **proactively screen**，否則只在第一次骨折時才發現。

## 評估方式

### 病史 + 風險因子盤點

- GMFCS 等級、weight-bearing 時間。
- 用藥（anticonvulsant、PPI、steroid、SSRI、medroxyprogesterone）。
- 營養：身高、體重、BMI（CP-specific growth chart）、食物攝取、鈣 / 維生素 D 補充。
- 過去骨折病史（部位、機轉、頻率）。
- Puberty status / 月經狀態。
- 維生素 D level、calcium、phosphorus、albumin。

### DXA（dual-energy x-ray absorptiometry）

- 當前 **gold standard** 評 BMD。
- **CP 兒童 DXA 的限制**：
  - **Contractures** 影響 standardized positioning。
  - **Indwelling devices**（orthopedic hardware、ITB pump、feeding tube、shunts）造成 artifact。
  - **Pediatric reference values** 在 CP 族群可能不適用。
- 解讀必須考慮：ambulatory status、physical development、gender、pubertal status。

### 何時做 DXA

- 首次 fragility fracture 後。
- 高風險 phenotype 且計畫長期 anticonvulsant / steroid。
- Pre-op assessment（特別 spinal fusion）。
- 用 bisphosphonate 治療的 baseline + 監測。

### 鑑別 / 共病排除

- **Vitamin D deficiency**：直接補充，不一定要全面評估。
- **Hyperthyroidism / hyperparathyroidism**：罕見但需排除。
- **Renal disease**：影響鈣磷代謝。
- **Endocrine disorder**（GH deficiency、cortisol excess）。
- **Genetic syndrome**（OI、X-linked hypophosphatemia）。

## 治療原則

### 預防階梯

1. **營養 + 維生素 D / Calcium**
   - 確保 calcium、phosphorus、Vitamin D、zinc、magnesium 攝取充足。
   - Vitamin D 不足者補充至正常。
   - **Possible evidence**（Novak 2020）—— 不是 strong RCT，但安全性高、cost 低。

2. **Weight-bearing / standing program**
   - 部分小型研究支持對 BMD 有正面影響。
   - **Insufficient evidence**（Novak 2020），但臨床慣用。
   - GMFCS IV–V 可用 standing frame、tilt table、supported standing。
   - 每天累積時間（多數方案 ≥ 30 分鐘 / 天）。

3. **減少修飾性 bone-toxic 藥物**
   - 與神經科 / 精神科討論：anticonvulsant 是否能換 less bone-toxic（valproate、levetiracetam）；steroid course 是否能縮短；PPI 是否仍 indicated。
   - 與婦科討論：menstrual management 是否能避開 medroxyprogesterone（特別在已有低 BMD 者）。

4. **Tone management**：CP_張力管理 改善承重姿勢與 transfer，間接降低骨折機轉。

5. **避免 acute immobilization 過長**
   - Cast、術後限制：與骨科討論最短 immobilization。

### 治療階梯（已有 fracture / 顯著低 BMD）

- **Bisphosphonates**
  - **Probable evidence** 對 CP BMD treatment 有效。
  - **Possible evidence** for reducing fragility fractures。
  - 適應症：fragility fracture history + low BMD + 非單純 vitamin D deficiency。
  - **Acute phase reaction**：fever、bone pain、nausea、vomiting（首次給藥常見）。
  - **Hypocalcemia、hypophosphatemia** 監測。
  - **長期影響不確定**：兒童不建議單純 prevention（uncertain long-term impact on growing bones）。
  - **Osteonecrosis of jaw / atypical femur fracture**：成人罕見、兒童尚未報告，但需牙科 baseline。

### 不要做的事

- **不要單純預防性用 bisphosphonate**（無 fracture history 也沒明確低 BMD）。
- **不要忽略疼痛訊號**——fragility fracture 常無外傷，溝通受限的兒童只能用 nonverbal 訊號表達。
- **不要把 medroxyprogesterone 當 routine menstrual management** 對已有低 BMD 兒童。
- **不要用單一 DXA 數字定義「he 沒事」**——對 CP 兒童 DXA artefact 多，需臨床整合判讀。
- **不要因為「他不會走，承重沒意義」就放棄 standing program**——standing 對 hip displacement、scoliosis、bowel function 都有 secondary benefit。

## 臨床決策點

### 「該不該做 DXA？」

- 高風險 phenotype（GMFCS IV–V + chronic anticonvulsant / steroid / underweight）→ baseline。
- 第一次 fragility fracture → 是。
- Pre-op spinal fusion → 是。
- Bisphosphonate 治療前 + 治療中追蹤 → 是。
- 對 GMFCS I–II + 無明顯風險因子 + 無 fracture history → routine 不必。

### 「該不該開始 bisphosphonate？」

- **First fragility fracture + low BMD（DXA Z-score ≤ −2）+ 高風險 phenotype** → 強烈考慮。
- **多次 fragility fracture** → 是。
- 預防性使用（無 fracture）→ 證據不足，多數中心不建議。

### 「Standing program 真的有用嗎？」

- 對 BMD 的 evidence **insufficient**（Novak 2020）。
- 但對 hip displacement、bowel function、participation、postural management 有 multimodal benefit。
- 不應只用「對骨頭好不好」判斷 —— 是 multi-purpose 介入。

### 「Anticonvulsant 該換嗎？」

- 與神經科討論。
- 若 seizure 已用 less bone-toxic 藥物（levetiracetam、lamotrigine）控制可，**不應為了 BMD 換到不易控制的藥**。
- Enzyme-inducing 藥物（phenytoin、phenobarbital、carbamazepine）長期使用者，更積極補 vitamin D 並監測。

### 反對論點與反駁

- 「不會走，骨頭弱沒影響。」 → fragility fracture 的痛、住院、進一步 immobilization、對家庭照顧負擔都是顯著影響。
- 「骨折就裝回去就好。」 → 復原期 immobilization 加深 BMD 下降；下次骨折風險倍增。
- 「Bisphosphonate 兒童不能用。」 → **Treatment** 層次有 probable evidence；不是不能用，是要 indication 對。
- 「Standing program 沒用。」 → 對 BMD 證據不足，但 multi-purpose benefit 存在。

## 限制與未定論

- **DXA Z-score cut-off** 在 CP 兒童的 fracture prediction 仍未完全標準化。
- **Bisphosphonate 治療的最佳 dose / interval / duration** 對兒童 CP 仍在演化（多數 protocol 從成人 osteoporosis 外推）。
- **長期 bisphosphonate 對成長中骨骼的影響** —— 跨成人期的 follow-up 資料有限。
- **Vibration therapy / whole-body vibration** 對 CP BMD 的效益 evidence 持續累積但未確立。
- **Genetic phenotype**（如 specific syndromic CP）對 bone health 的相對影響。
- **第一次 fragility fracture 後 secondary prevention 的最佳組合**（bisphosphonate + nutrition + standing）尚無 RCT。

## 理解缺口

- 為什麼有些 GMFCS V 兒童不發生 fragility fracture？個體 protective factor？
- **Standing program 的 dose-response**（每天多少分鐘、總週數才有 BMD effect）仍未確立。
- **Vibration therapy** 在 CP 兒童的角色。
- **Bisphosphonate 兒童期使用對成年後骨骼結構**的長期影響。
- **基因檢測 + 個體化 bone health risk score** 的可行性。
- **Hip displacement 與 fragility fracture 的時序與因果**：兩者常共存，誰先誰後？

> 標記為下一輪要補的方向：Vibration therapy 在 CP 的最新 RCT、bisphosphonate 兒童長期 outcome、Hip displacement 與 BMD 的交互作用。

## 臨床使用版

- 教住院醫師時，先說一句：「**CP 兒童骨頭弱不是運氣 —— 是 immobility + 營養 + 藥物 + puberty 四件事一起壓下來的結果。**」
- 第二步：「**第一次 fragility fracture 後，下次風險每年倍增。所以重點是事前。**」
- 第三步：「**預防階梯：營養 → standing → 修飾藥物 → 治療階梯（DXA → bisphosphonate）。**」
- 第四步：「**Bisphosphonate 是 treatment 不是 prevention；要 indication 對才用。**」
- 第五步：「**DXA 在 CP 有限制（contracture、hardware artefact、reference value），不能單看數字。**」
- 第六步：「**Communication-impaired 兒童的骨折常無明確外傷 —— 突然 transfer 痛、不安、新增 spasticity 都要警覺。**」
- 第七步：「**Standing program 對 BMD 證據不足，但對髖、姿勢、腸道、參與都有用——不要只用骨頭一個指標決定。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 多因子病理（immobility + 營養 + 藥物 + puberty + 結構）能用一張圖講完 → ✅
- Distal femur 為何最常骨折 — 能講「未承受 axial load + transfer torque trigger」 → ✅
- Bisphosphonate 的 treatment vs prevention 差別 — 能講「probable evidence for treatment, 不建議純 prevention」 → ✅
- 但 **「Standing program 的最佳 dose-response」** 我目前只能講「每天 ≥ 30 分鐘」這一句，更具體的 weeks-to-effect、持續性需求、年齡—劑量交互作用我自己沒整理通 → 標為[理解缺口](#理解缺口) 的優先補強項。
- **「Bisphosphonate 兒童期使用對成年後骨骼的長期影響」** 我目前只能說「不確定」，沒有具體 follow-up data 整理過 → 同上。
