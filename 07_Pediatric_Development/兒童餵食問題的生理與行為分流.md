# 兒童餵食問題的生理與行為分流

## 一句話定義

pediatric feeding problem 不能只當挑食，也不能只當 aspiration；至少要先分 feeding 與 swallowing，再分 physiologic 與 mealtime-experiential 問題。

## Definition and Boundary

- feeding 包含 cue recognition、food acceptance、positioning、self-feeding progression 與 mealtime learning experience。
- swallowing 則聚焦 oral / pharyngeal / esophageal phase 的 transport 與 airway protection。

## Fact

- eating 是 developmental skill，需要 modeling、interaction 與 support。
- cue-based feeding 要看 hunger / satiety cue、flow rate，且不 force feeding。
- pharyngeal phase 是 aspiration risk 最高區段，absence of overt symptom 不能排除 dysphagia。
- VFSS / FEES 是為了回答具體機制問題；upper GI / esophagram 不等於 swallow study。

## Mechanism Chain

```text
Feeding behavior and experience
→ swallowing physiology
→ specific mealtime problem type
→ targeted behavioral or instrumental pathway
```

## Inference

- 若沒有先分名詞，常會把 caregiver-child interaction 問題與 true dysphagia 混成一個 diagnosis。

## Assumption

- clinicians 會同時觀察 mealtime interaction 與 airway safety，而不是只看一端。

## Uncertainty

- IDDSI 提供共同語言，但不能單獨取代完整評估。

## Clinical Use

- 遇到吃飯困難的孩子，先問是「不會吃／不想吃／吞不安全／三者並存」。
