# CP 髖部監測

## 一句話定義

CP 髖部監測（Hip Surveillance in Cerebral Palsy）是 **以兒童的 GMFCS 等級為風險分層基準，利用 standardized AP pelvis radiograph 與 migration percentage（MP）追蹤股骨頭逐步從髖臼外位移的過程，在出現疼痛、結構不可逆破壞、或骨盆斜位前主動偵測並介入的長期照護流程**，重點不是「等到孩子喊痛」，而是「在 still asymptomatic 時用影像找到趨勢，主動轉介。」

## 已知

- **GMFCS V 兒童髖部 displacement 累積發生率 68–90%；GMFCS I 接近一般兒童**。
- AACPDM 2017 *Hip Surveillance in Cerebral Palsy* care pathway 是當代 reference framework。
- 髖部 displacement 會在 **skeletal maturity 後仍持續進展**，特別是合併 [[CP_神經肌肉性脊柱側彎]] 暫待頁、pelvic obliquity、leg length discrepancy、GMFCS III–V 者。
- 一旦 femoral head 完全脫位，介入時機已過：windswept hips + 骨盆 obliquity + 體位不良 + 疼痛 + 個人衛生困難。
- **migration percentage (MP)** 是當代主要影像追蹤指標。

## 核心機制

### 為什麼 CP 兒童髖部會位移

CP 髖部位移是 **動態的、漸進的多因子失衡**：

1. **Spasticity 的內收 + 屈曲 + 內旋優勢**（adductor、iliopsoas、medial hamstring）→ 把股骨頭「往外+上」推。
2. **Abductor 與 extensor 弱**：無法平衡內收屈曲群。
3. **承重不足 / 不對稱**：GMFCS III–V 兒童髖臼缺乏典型 weight-bearing 刺激 → 髖臼發育不良（acetabular dysplasia）→ 容納能力下降。
4. **股骨近端異常**：coxa valga + 過度 anteversion → 股骨頭與髖臼幾何不匹配。
5. **生長期肌肉跟不上骨骼**：骨頭快速生長、肌腱相對短 → contracture → 進一步壓迫。

這五個因子協同 → 股骨頭從髖臼漸進「擠出」 → subluxation → dislocation。

### Migration Percentage（MP）

- 在 standardized AP pelvis 上量。
- 沿 Hilgenreiner line 與 Perkin line（沿髖臼外緣）。
- **MP = 股骨頭超出 Perkin line 的部分 ÷ 股骨頭總橫寬 × 100%**。
- 解讀：
  - **MP < 30%**：正常。
  - **MP 30–40%**：at risk，需追蹤頻率提高。
  - **MP > 40%**：需手術評估。
  - **MP > 90%**：dislocation。

### 為什麼 GMFCS 是最強的 risk gradient

- GMFCS I：可獨立行走 → 髖臼接受充足承重刺激 → 風險接近一般兒童。
- GMFCS V：完全 non-ambulatory + spastic + 對稱差 → 髖臼缺乏承重刺激 + spasticity 持續推擠 → 風險最高。
- GMFCS III、IV 是中間風險，需依個體情況決定追蹤頻率。

## 臨床表現

### 早期（往往無症狀）

- 髖部活動度（特別是 **abduction**）逐漸下降。
- Asymmetric posturing：windswept appearance（兩髖一收一展）。
- 換尿布、會陰護理變困難。
- 坐姿不對稱、骨盆 obliquity。

### 中後期

- **疼痛**：被誤以為「孩子情緒」、「便秘」、「牙痛」—— communication-impaired 兒童疼痛表達常被誤判。
- 行走（若 ambulatory）惡化、步態 deviation。
- 站立、轉位變困難。
- 皮膚壓瘡（座位壓力分布不均）。

### 已脫位（不可逆）

- **持續疼痛**（即使夜間）。
- 骨盆 obliquity 嚴重 → scoliosis 加重（雙向惡化）。
- 衛生與照顧負擔顯著上升。
- 介入難度與失敗率大增（即使做 reduction 也常 redislocate）。

## 評估方式

### 病史 + 觀察

- GMFCS 等級（決定追蹤頻率的核心變數）。
- 移動方式、站立 / 承重時間。
- 換尿布是否變困難、痛苦反應。
- 對稱坐姿 / windswept appearance。

### 床邊檢查

- Hip ROM（特別是 **abduction**：< 30° 是強警訊）。
- Galeazzi sign（兩膝高度差 → 股骨短化或 dislocation）。
- 骨盆 obliquity、leg length discrepancy。
- 觸診：trochanter prominence asymmetry。

### 影像

- **Standardized AP pelvis radiograph**：兩髖完全伸直、髕骨朝前、骨盆中立。
- 量 **migration percentage**（MP）。
- 量 **acetabular index** 評髖臼發育。
- Frog-leg lateral 評 femoral head shape。

### 監測時程（AACPDM 2017）

| GMFCS | Baseline | 接下來 |
| --- | --- | --- |
| **I** | 2 歲（一次） | 若臨床檢查正常，可不再 routine |
| **II** | 2 歲 | 每 1–2 年 |
| **III–V** | 2 歲 | 每 6–12 個月，依 MP 與症狀加密 |

- **MP 在追蹤中上升 > 10% / 年** → 加密追蹤 + 轉介小兒骨科。
- **MP > 30%** → 主動介入（[[CP_張力管理]] 暫待頁 + 可能 soft tissue surgery）。
- **MP > 40%** → 結構性手術（bony procedure）評估。

## 治療原則

### 預防階段

- 規律 stretching（特別 adductor、iliopsoas、medial hamstring）。
- Postural management（standing program、night-time positioning）。
- 主動 weight-bearing（gait trainer for GMFCS III–IV、assisted standing for V）。
- 整合 [[CP_張力管理]] 暫待頁：oral medications、BoNT、ITB。

### Soft tissue surgery（MP 30–40%）

- **Adductor tenotomy**（多數）+ **iliopsoas release / lengthening**。
- 目標：減少 deforming forces，讓髖臼有機會繼續發育。
- 在年幼兒童（< 8 歲）效果較好；過了骨骼成熟，soft tissue 已不夠。

### Bony surgery（MP > 40% / dislocation）

- **Femoral varus derotation osteotomy (VDRO)**：矯正 coxa valga + anteversion。
- **Pelvic osteotomy**（Dega、San Diego、Pemberton）：矯正髖臼發育不良。
- 通常 femoral + pelvic 同時做（**reconstructive surgery**）。
- 已脫位、症狀嚴重、無法 reconstruct 者：salvage procedures（McHale、Castle、Girdlestone）—— 接受 functional 但非 anatomic 的結果。

### 不要做的事

- **不要等到孩子喊痛才做影像** —— communication-impaired 兒童常被低估。
- **不要因為「他不會走，不需要好髖」就放棄監測** —— 即使 GMFCS V，疼痛、衛生、座位、骨盆 obliquity 都是要保護的 outcome。
- **不要單看臨床 ROM 而省略影像** —— 早期髖位移常無 ROM 變化。

## 臨床決策點

### 「Baseline AP pelvis 該幾歲做？」

- **2 歲**（AACPDM 共識）。GMFCS 已足夠定型，且髖位移風險已可累積。

### 「GMFCS I 還需要監測嗎？」

- 2 歲做一次 baseline；正常後可不 routine（風險接近一般兒童）。
- 若臨床 ROM 變差、出現症狀 → 仍需檢查。

### 「MP 30% 要不要立刻手術？」

- MP 30–40%：先優化 [[CP_張力管理]] 暫待頁 + 加密追蹤。若仍持續上升 → 轉介 soft tissue surgery。
- MP > 40% / 上升速率快：直接 bony reconstruction 評估。

### 「該不該術後做 BoNT 或 ITB？」

- 術後 spasticity 仍存在 = recurrent displacement 風險仍存在。
- 多數共識：手術不是 spasticity 的替代，而是「結構修復」；術後仍需積極 [[CP_張力管理]] 暫待頁，否則容易復位失敗。

### 反對論點與反駁

- 「孩子不會走，髖好不好不重要。」 → **完全錯誤**。Pain、座位、衛生、轉位、骨盆 obliquity（會帶動 scoliosis）都依賴髖部結構。
- 「等他長大再開刀。」 → 髖位移在 skeletal maturity 後仍會進展；過晚介入會錯過 reconstructive window，落入 salvage。
- 「臨床檢查正常就不必影像。」 → ROM 可能晚於 MP 變化；asymptomatic displacement 是規則不是例外。

## 限制與未定論

- **MP 的精確度** 受 patient positioning、影像技師訓練影響大；inter-rater variability 不小。
- **bony surgery 的長期 outcome** 在 GMFCS IV–V 仍有相當高的 redislocation rate（10–30% 視 cohort）。
- **Salvage procedures（McHale、Castle、Girdlestone）的優劣** 仍有爭議。
- **3D imaging（CT、low-dose MRI）vs 2D radiograph** 在 surveillance 的 cost-effectiveness 尚未確立。
- **成人 CP 的髖部監測指引** 缺乏；多數指引止於 18 歲。

## 理解缺口

- 為什麼有些 GMFCS V 兒童一輩子髖部不脫位？個體 protective factor 是什麼？
- BoNT 對 hip surveillance trajectory 的真實長期效益（vs 自然病程）證據仍不一致。
- ITB 是否能延緩 hip displacement？目前證據以 case series 為主。
- 成人 CP 的髖部 deterioration 模式與介入時機尚不清楚。
- 不同 ethnic / population 的 acetabular development trajectory 是否不同？

## 臨床使用版

- 教住院醫師時，先說一句：「**CP 髖部不會自己看到症狀才壞掉。它是漸進、安靜、按 GMFCS 分流的高風險病灶。」**
- 第二步：「**2 歲做 baseline AP pelvis，量 migration percentage。GMFCS I 一次足夠；II 每 1–2 年；III–V 每 6–12 個月。**」
- 第三步：「**MP 30% 警戒、40% 要手術評估、90% 是脫位。」**
- 第四步：「**Communication-impaired 的孩子不會喊痛，影像才是真實指標。」**
- 第五步：「**手術不能取代 spasticity 管理；術後若 tone 沒控好，會 redislocate。」**
- 第六步：「**GMFCS V 不會走也要監測 —— 為了痛、為了衛生、為了照顧、為了不要 windswept.」**

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 病理機制（spasticity + 承重不足 + 髖臼發育不良 + femoral 異常 + 生長失衡）能用一張箭頭圖講完 → ✅
- MP cut-off 與 surveillance 時程能背能寫 → ✅
- 何時 soft tissue vs bony 手術 — 能用 MP + 年齡 + 骨骼成熟度三軸決策 → ✅
- 但 **「為什麼有些 GMFCS V 兒童一輩子不脫位」這個保護因子問題**我目前只能講「個體變異」，更具體的 anatomy / muscle balance / ITB use / 早期介入 contribution 我沒整理通 → 標為[理解缺口](#理解缺口) 的優先補強項。
