# 數位媒體對兒童發展的風險分層

## 一句話定義

digital media 的臨床問題不該只問每天幾小時，而要同時看 content、context、parent mediation、developmental stage 與 displacement effect。

## Definition and Boundary

- quantity 重要，但不再是唯一主角。
- 這個 concept 不是單純 screen time total 的粗略風險標籤。

## Fact

- 本章將問題框架轉為 content、frequency、context 與 displaced activity。
- parent mediation 包括 coviewing、instructive mediation、restrictive mediation。
- 主要 outcome 聚焦 sleep、obesity、language development、executive functioning。
- parent own device use / technoference 可能削弱 responsive caregiving；digital inequality / access 也是結構議題。

## Mechanism Chain

```text
Media content and context
→ parent mediation or technoference
→ sleep / language / EF / obesity pathway
→ different developmental risk
```

## Inference

- 問「一天幾小時」若不加上下文，常不足以支持真正的臨床建議。

## Assumption

- 同一媒體暴露在不同年齡階段與家庭互動脈絡下，風險型態會不同。

## Uncertainty

- adolescent digital media 不是一律負面，部分社交連結可能有益，但過量後效益下降。

## Clinical Use

- 問 screen use 時，除了時間，也要問看什麼、跟誰看、擠掉了什麼。
