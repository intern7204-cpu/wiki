# 小兒復健評估

## 一句話定義

小兒復健評估是把 **developmental stage、family context、play / observation、school function、age-dependent normal variation** 一起納入的 function-oriented assessment。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### 本批補強的 pediatric assessment anchor

- neurologic concern 不能只靠門診短暫 impression；要把 history、play-based observation、age-adapted neurologic exam、primitive reflexes、gait 與 general physical clues 一起完成。
- preterm child 的 developmental interpretation 要用 corrected age，並依 gestational age、NICU complication 與高風險時點安排 staged follow-up。
- developmentally delayed、premature 或 CP risk child，要主動想到 vision / hearing 問題；視覺評估尤其不能只看 acuity，而要把 CVI 一起納入。
- CP assessment 不能只停在 tone 或 topography；functional classification、feeding、vision、hearing、sleep、behavior、pain 與 caregiver burden 都要一起問。
- 托育與 ECE 是 developmental environment，history 要補 child care setting、inclusion support、IFSP / IEP 連結與 expulsion risk。
- obesity / sleep / bullying / sedentary pattern 在 pediatric rehab population 也可能直接改變 participation、pain 與 activity tolerance。
- developmental surveillance 應視為 routine visit 的固定輸出；periodic screening 是補漏工具，不是 surveillance 替代品。
- 有 late talking 或 broader developmental concern 時，history 不能只問會不會講話，還要問 gesture、joint attention、receptive language、hearing 與 regression。
- persistent speech / language concern 時，要把 formal audiologic testing、SLP assessment 與 dominant-language / interpreter planning 直接放進 workup。
- EI referral 不應等待 definitive diagnosis；而 program eligibility 門檻也不等於臨床重要性。
- GDD / ID thinking 不能只靠 IQ；adaptive function、daily routine 與 support need 都要寫進 assessment。
- mild ID 可能以 language / learning / school-function concern 遲發呈現；早期 screen 沒抓到不等於後續不會浮現。
- ID child 的 ROS 不能漏 sleep、mental health、abuse vulnerability、wandering 與安全風險。
- feeding concern 不能只寫 picky eating；需補 growth、airway symptom、positioning、texture tolerance 與 caregiver mealtime interaction。
- sensory complaint 可以用 participation framing 整理，但不能把所有 behavior / feeding / language difficulty 都縮成 sensory issue。
- foster / adoptive history child 的問題要補 placement chronology、preadoptive adversity、identity 與 school support，不能只記「被收養」。
- developmental expectation 需依 stage 調整；infancy、preschool、school age 的 function question 本來就不一樣。
- digital media history 在 school-age 與 preschool visit 都值得 routine 補問，因為它會改變 sleep、language reciprocity 與 homework / play balance。
- school-age / adolescent function 若主訴是拖延、沒組織、轉換困難，要把 executive function component 寫清楚，不要只寫「專注差」。
- sleep history 不是旁支；snoring、weekend catch-up sleep、delayed sleep phase、night waking 都可能直接改變 daytime regulation 與 school participation。
- joint developmental assessment 若要形成可執行報告，需把 family resource、parenting function 與環境支持一起寫進 team summary。
- 對 transition-age youth，要開始問 self-determination、decision-making support、school-to-adult service transition，而不是等畢業前才第一次談。

### Developmental tools 的使用原則

- developmental screen、perceptual tests、intellectual tests、achievement tests 要依問題選，不是每個孩子都同一套。
- motor impairment 或 language impairment 的孩子，應優先考慮 nonverbal / motor-reduced tests，避免低估真實能力。

### 臨床提醒

- 小兒 gait / posture 很多是 age-dependent variation，不能直接套 adult abnormality。
- speech delay 需要主動想到 hearing problem；gait concern 也要看 shoes wear pattern、torsion、anteversion、foot deformity。
- social communication concern 若只靠門診短暫 observation，容易漏掉 milder ASD phenotype；caregiver / teacher history 仍是骨架。
- family education 本身就是治療的一部分。
- sociocultural context、language、school experience 與 clinician bias 都可能改變 developmental concern 被看見與被回應的方式。

## 評估方式

### History 重點

- birth history：pregnancy exposure、prematurity、delivery complications、Apgar、NICU course。
- developmental history：gross motor、fine motor、language、social milestones，必要時用 corrected age。
- adaptive function history：communication、self-care、safety、school participation、daily routine 與 support need。
- sleep history：bedtime、sleep onset、wake time、snoring、devices、weekend shift、daytime sleepiness / irritability。
- social / educational history：home layout、caregiver、school supports、IEP / 504、peer interaction、early intervention。
- family / parenting history：caregiver concern、parenting capacity、resource gap、transport / access barrier、team coordination need。
- adolescent / transition history：vocational goal、transport、decision-making support、adult-care transition readiness。
- attention / behavior concern 不能只記「坐不住」；應主動問 teacher feedback、sleep、learning / language issue、school function。
- ASD concern 要主動問 response to name、joint attention、pretend play、language / social regression、repetitive behavior 與 sensory pattern。
- adolescent interview 可用 HEEADSSS，並需先說明 confidentiality 邊界。

### Physical examination 重點

- exam 從 observation 開始：play、eye contact、speech、movement pattern、self-regulation。
- growth、head circumference、dysmorphism、spine、ROM、tone、joint alignment 都要依年齡看。
- **obligatory primitive reflex is never normal**；若 primitive reflex 持續存在，需懷疑 CNS pathology。

## 治療原則

- 目前頁面尚未整理出 Non-pharmacologic、Pharmacologic、Injection / procedure、Rehabilitation program 的決策順序。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

## 理解缺口

- 小兒復健評估 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 小兒復健評估 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
