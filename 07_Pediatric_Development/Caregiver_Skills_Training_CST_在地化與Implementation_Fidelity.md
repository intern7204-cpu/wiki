# Caregiver Skills Training CST 在地化與Implementation Fidelity

## One-Sentence Definition

WHO CST 在地化是一個受控的 implementation process：只改必要的語言、文化、情境與可近性因素，同時保留 key messages、guided practice、home visits、goal-setting、home practice 與 facilitator supervision 等核心成分。

## Definition and Boundary

- CST 指 *Caregiver Skills Training for Families of Children with Developmental Delays or Disabilities*。
- 目標族群是 2-9 歲、具 developmental delays or disabilities 的兒童照顧者，特別聚焦 social / communication domain；不要求兒童已取得正式診斷。
- 標準 course structure 是 9 次 group sessions 加 3 次 home visits，由 trained and supervised non-specialist facilitators 執行。
- 本頁處理的是 CST 的 local adaptation 與 implementation fidelity，不是完整評估 CST efficacy，也不是 ASD 或 GDD 的全套治療總論。

## Why It Matters

- developmental service 常見問題不是「有沒有教材」，而是教材一進入真實社區後被翻譯、縮短、換場地、換人力、刪 home practice，最後變成不同介入。
- 來源的核心判斷是：local fit 需要被設計，但 core components 不能在沒有 consultation、documentation 與 evaluation 的情況下被任意刪改。
- 對臨床轉介而言，CST-like program 是否有效，取決於它是否仍是 skills training，而不是一次性 parent education。

## Preconditions or Conditions

- 需有 project manager 或等效角色負責 adaptation process。
- 需建立 local adaptation team；核心成員需熟悉 child development、mental health、public health、local language、culture 與 target participants 的 socioeconomic / political context。
- 需先 map local services、legal frameworks、child protection reporting、health / mental health resources、NGO、food / housing / respite 等 supports。
- 需決定 translation / back-translation 或由 bilingual specialists 驗證 key messages and tips。
- 需處理 attendance barriers：transportation、childcare、scheduling、food、stigma、caregiver overload、第二照顧者參與。

## Mechanism

```text
Local service mapping
-> adaptation team reviews language, culture, context, barriers, and legal pathways
-> stakeholders and caregivers provide feasibility / acceptability input
-> minimal documented adaptations are made
-> pre-pilot field-test checks comprehensibility, relevance, attendance, fidelity, and pacing
-> final adaptation preserves core CST components while fitting local implementation conditions
```

## Observable Patterns

- 高品質 CST adaptation 會留下 adaptation documentation form，而不是只留下「已翻譯」。
- local version 會保留：
  - key messages and tips
  - demonstrations / role-plays / case stories / group discussions
  - home visits
  - guided practice during home visits
  - individualized goal-setting
  - home practice
  - supervision and fidelity monitoring
- 可合理修改的內容通常是 names、role-play details、local toys / household items、literacy level、terms for developmental disability、schedule、location、childcare、transportation support、welcome/closing rituals。
- 需要高度警覺的修改包括 removing sessions、removing home visits、removing guided practice、changing sequence、changing facilitator-to-participant ratio、expanding/restricting target population、group-to-individual redesign。

## Clinical / Research Implication

- 臨床上，轉介到 CST-like program 時應問：這是完整 skills training，還是只有家長衛教課？
- 計畫書或服務設計至少要寫清楚：
  - target population 是否仍符合 developmental delay / disability 與年齡邊界
  - facilitator training 與 supervision
  - home visits / guided practice 是否保留
  - fidelity 如何記錄
  - caregiver attendance barrier 如何處理
  - child protection、family violence、caregiver mental health 與 material insecurity 如何轉介
- 研究上，任何 significant structural changes 都應搭配 pre-pilot、process evaluation、fidelity checklist 與 outcome monitoring；否則不能把結果直接歸因到原本 CST package。

## Fact

- WHO 2022 CST adaptation guide 指出，CST 的 intended audience 是 2-9 歲 developmental delays or disabilities 兒童的 caregivers，且 child 不必有正式 diagnosis。
- 標準 delivery 包含 9 group sessions 與 3 home visits，由 trained and supervised non-specialist facilitators 執行。
- 來源建議只先做 recommended adaptations 與 essential adaptations，並記錄每個改動的 rationale。
- Local adaptation 應透過 adaptation team、stakeholder consultation、pre-pilot field-test 與 adaptation documentation form 進行。
- 來源把 core components 分成 content / conceptual、instructional、implementation components；不建議在沒有 expert consultation 與 evaluation 的情況下移除或大幅修改。
- 來源明確要求考慮 transportation、childcare、scheduling、caregiver involvement、stigma reduction 與 service-resource mapping。

## Inference

- CST 的最小可行版本不是「把九堂課縮成一堂」，而是先確認哪些 core skills 與 practice loops 必須保留。
- 若 local system 只買教材、沒有 facilitator supervision 與 home-practice feedback，應視為 fidelity risk。
- 對 developmental delay / ASD 評估等待期很長的系統，CST 的 non-diagnosis requirement 可能提供早期 caregiver-mediated support，但仍不能取代 diagnostic evaluation、therapy eligibility assessment 或 child protection pathway。

## Assumption

- 來源中的 core components 確實代表 intervention active ingredients；本來源支持此 implementation stance，但不是逐一驗證每個 component 的 trial。
- Local adaptation team 有能力辨識文化禁忌、family power differential、literacy barrier 與 service gap。
- Pre-pilot feedback 能被回寫到 final package，而不是形式化完成。

## Uncertainty

- 目前無法從本來源判斷每一種 structural adaptation 對 clinical outcome 的量化影響。
- 不同國家或族群中，哪些 cultural adaptations 會提高 engagement、哪些會削弱 mechanism，需要 local evaluation。
- 若服務資源極少，source mapping 可以揭露缺口，但不保證能補足缺口。

## Limitations and Misreadings

- 誤讀 1：CST 可以用衛教單取代。錯；來源的設計包含 group learning、home visits、guided practice、goal-setting 與 home practice。
- 誤讀 2：在地化就是把教材翻成中文。錯；translation 只是其中一段，還要處理 local services、legal frameworks、attendance barriers、stakeholders、pilot feedback 與 fidelity。
- 誤讀 3：為了可近性可以直接砍掉 home visits。錯；home visits 與 guided practice 被列為不應任意移除的 core components。
- 誤讀 4：只邀請母親最有效率。錯；來源建議標準作法邀請每個家庭最多兩位 caregivers，除非第二位 caregiver 會因權力差距削弱 primary caregiver 的參與與學習。
- 誤讀 5：brief format 等同 full CST。錯；若必須縮短，仍應保留 foundational sessions，並將重大結構改變文件化與評估。
