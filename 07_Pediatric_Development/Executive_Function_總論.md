# Executive Function 總論

## 一句話定義

Executive Function (EF) 是 **organizing, regulating, monitoring, and flexibly directing thought and action toward goals** 的一組 neurocognitive processes；若用 control-systems 語言，這個領域也與 cognitive control 高度重疊，但不完全同義。

## 核心概念

### EF 的主要組件

- inhibition / impulse control
- cognitive flexibility / shifting
- emotional control
- initiation
- planning
- organization
- working memory
- self-monitoring

### EF 與 cognitive control 的關係

- executive function 較常被當成 skill set。
- cognitive control 較強調：
  - context-dependent stimulus-response controllability
  - monitoring / feedback control
  - task representations
- 臨床上兩者可互相支援，但不要硬當完全同義詞。

### EF 是 neurodevelopmental function，不是單一疾病

- EF 問題可以出現在 ADHD、language disorder、learning disorder、ID、ASD、brain injury、trauma、sleep deprivation 等不同情境。
- 先分 component，再談 diagnosis。

### 發展軌跡很長

- infancy 就開始萌芽。
- preschool 是快速建立期。
- school age 到 adolescence 持續成熟。
- early experience、stress 與 adult scaffolding 都會改變 skill expression。

## 臨床或研究上的重要性

- EF 直接影響：
  - classroom participation
  - task initiation
  - homework completion
  - transitions
  - emotional self-regulation
  - social problem-solving
- 若只把 complaint 讀成「不專心」或「沒自制力」，常會漏掉更精確的 task representation / monitoring problem。

## 評估方式

### history 重點

- family / school complaint 要具體拆解
- teacher comments、report cards、daily routine、transition difficulty、forgetfulness、messiness、emotional outburst 都很重要
- 需主動排 hearing、vision、sleep、language、medical / neurologic cause

### assessment 工具與分層

- behavior rating：如 BRIEF-2
- cognitive / language / academic testing：依問題選擇
- 複雜個案可升級 neuropsychological evaluation

## 治療原則

### 主軸是跨場域 scaffolding

- demystification 與 strengths-based framing
- routine、external cue、task breakdown
- school accommodation / modification
- parent training 與 teacher collaboration
- targeted therapy

### 藥物角色

- 若合併 ADHD 或 attention-related symptom，藥物可改善某些部分
- 但不能把藥物當成完整 EF intervention

### 實作頁

- 具體 home / school / adolescent support，見 [[Executive_Function_支持策略]]。

## 臨床決策點

### 反對論點

- 「孩子沒組織、拖拖拉拉，就是 ADHD。」
- 「executive function 可以靠某個訓練程式一次處理。」

### 反駁

- EF 問題本身是跨診斷現象，必須回到 component、task demand 與功能情境。
- 最有效的介入通常不是單一 app，而是 routine、school support、behavioral scaffold 與跨場域整合。

### 結論

- EF 評估與介入的核心是 **先拆 component，再把 intervention 放回真實生活情境**。

## 限制與未定論

### frontmatter contradictions

- Executive function problems are not synonymous with ADHD.
- Cognitive control and executive function overlap, but they are not perfectly synonymous.
- Medication may help selected attention-related symptoms but does not correct the full executive-function profile.
- Unsupported cognitive or sensory therapies should not be framed as standard treatment for executive dysfunction.

## 理解缺口

- 哪些 EF 抱怨最常其實是 sleep、language 或 anxiety 問題？
- school accommodation 與 true remediation 的界線在哪裡？
- 何時要把一般 developmental assessment 升級到 neuropsychological testing？

## 臨床使用版

- 若家長只說孩子「不專心、很亂、做事慢」，先回 EF component 拆解，而不是直接貼診斷。
- 若 complaint 是「知道該做什麼卻做不出來」，要特別想到 monitoring、feedback 與 task representation。
