# ASD 評估與診斷

## 一句話定義

ASD diagnosis 是 **multi-informant, developmental, function-oriented comprehensive assessment**，不是單一量表、單次 observation 或單顆 biomarker 可以完成的工作。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### primary care 的角色

- 一旦懷疑 ASD，就要啟動 evaluation 與 referral，不應等到 specialist slot 才開始。
- 若 clinician 對 DSM-5-TR criteria 與工具使用足夠熟悉，可做 initial clinical diagnosis 並協助家庭先進入服務。
- 即使 definitive diagnosis 尚未完成，仍應先轉 Early Intervention / school-based service。

### comprehensive evaluation 內容

- multi-informant history：parent / caregiver、teacher、therapist、school / daycare 都要納入。
- developmental history：early social milestone、joint attention、pretend play、regression、language、sensory、behavior、family history。
- psychosocial history：family stress、trauma、language / cultural context、service access。
- physical / neurologic exam：growth、head circumference、tone / reflex、dysmorphism、focal neurologic finding。

### diagnostic tool 的位置

- 常用工具包括 ADOS-2、ADI-R、CARS-2、SRS-2 等。
- 這些工具用來 **結構化蒐集行為資料**，不是離開臨床脈絡就能自己下結論。
- tool choice 要看年齡、語言能力、setting 與 evaluator training。

## 評估方式

### medical workup 與其他檢查

- audiology 對 speech delay / inconsistent response 必須主動安排。
- genetic evaluation 常需納入，尤其有 dysmorphism、macrocephaly / microcephaly、ID、family history 或 syndromic clue 時。
- MRI / EEG 只在 history / exam 指向 focal neurologic issue、seizure 或特定結構異常時考慮，不是 routine。

### differential diagnosis

- language disorder：social interest 與 play 多半與語言發展程度相稱，且沒有明顯 repetitive phenotype。
- social communication disorder：有 pragmatic deficit，但 **沒有** restricted / repetitive behavior。
- hearing loss：poor response to name 可能相似，但 nonverbal communication / play pattern 不同。
- ID / GDD：若 social communication 與 adaptive level 與 overall developmental age 相稱，未必是 ASD。
- ADHD、anxiety、trauma / attachment issue 也都可能 mask 或 mimic ASD。

### 診斷穩定性與 follow-up

- experienced clinician 在第二年 life 就可相對穩定地辨識一部分 ASD，但 milder phenotype 仍可能後面才變清楚。
- 早期 borderline case、high-risk sibling、female / camouflaging phenotype 都需要 longitudinal reassessment。

## 治療原則

- 目前頁面尚未整理出 Non-pharmacologic、Pharmacologic、Injection / procedure、Rehabilitation program 的決策順序。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- diagnostic tool 不能脫離 clinical judgment 單獨使用。
- ASD 與 intellectual disability / language disorder 可共存，不是互斥選項。
- primary care clinician 可以啟動診斷與轉介，但 clinical diagnosis、school eligibility 與 insurance requirement 不是同一件事。

## 理解缺口

- ASD 評估與診斷 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 ASD 評估與診斷 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
