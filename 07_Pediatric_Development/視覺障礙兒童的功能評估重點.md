# 視覺障礙兒童的功能評估重點

## 一句話定義

pediatric visual impairment 評估不能只找 ocular disease；必須同時看 pregeniculate、postgeniculate 與 cerebral visual impairment。

## Definition and Boundary

- 這是 functional visual assessment frame。
- 它不是把所有視覺問題都當 refractive error。

## Fact

- cornea、lens、retina、optic nerve 到 CVI 都需納入同一框架。
- developmentally delayed children 的 ocular abnormality 盛行率高，routine eye exam 有價值。
- prematurity 可同時連到 ROP 與 prematurity-related brain injury 所致的 functional visual impairment。
- warning signs 與 developmental / educational implication 都要一起看。

## Mechanism Chain

```text
Visual pathway problem location
→ different functional visual phenotype
→ different developmental and educational impact
→ different evaluation need
```

## Inference

- 若只看視力表或只問看不看得到，會低估 CVI 與 broader functional impairment。

## Assumption

- routine ophthalmologic evaluation 能被納入 developmentally delayed child 的追蹤流程。

## Uncertainty

- 同樣 prematurity-related visual difficulty，ocular 與 cerebral component 的比例可能不同。

## Clinical Use

- 有發展遲緩的孩子若出現視覺相關線索，routine eye assessment 不應被當成可選項。
