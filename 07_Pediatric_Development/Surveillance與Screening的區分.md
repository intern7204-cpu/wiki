# Surveillance 與 Screening 的區分

## 一句話定義

surveillance 是 routine clinical responsibility，screening 是 standardized risk detection；兩者互補，但都不能取代 evaluation。

## Definition and Boundary

- surveillance 包含 caregiver concern、risk / resilience factor、developmental history、observation 與 collaboration。
- screening 是用 standardized tool 在沒有明顯症狀的 child 中找 high risk。

## Fact

- 本來源明確區分 surveillance、screening 與 evaluation 三者。
- surveillance + screening 的組合比單靠任一項更能提升早期辨識。
- screening 有 false positive、false negative、workflow burden 與 referral burden。
- tool 選擇需考慮 sensitivity / specificity、語言、可近性、家長 literacy 與 practice workflow。

## Mechanism Chain

```text
Routine surveillance
→ standardized screening at key points
→ positive concern or positive screen
→ evaluation / referral
```

## Inference

- positive screen 的下一步若只是「下次再看看」，screening 的價值會大幅流失。

## Assumption

- clinic 有能力追蹤結果與轉介，而不是只做量表分數。

## Uncertainty

- 不同 clinic workflow 會改變 screening 的實際成本與落地方式。

## Clinical Use

- 看到疑似 delay 時，先分清現在是在做 surveillance、screening，還是已經進入 evaluation。
