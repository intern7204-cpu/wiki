# Rehabilitation Principles of the Injured Runner

## 一句話定義

這份 textbook chapter 把 injured runner rehabilitation 拆成兩個必須同時處理的旋鈕：**restore tissue tolerance for load** 與 **reduce / redistribute load per stride**。

## 核心機制

### 1. 跑者復健不是只有「先休息」

- running injury 常來自 training error，但真正受傷與恢復都同時受每一步的 load magnitude 與 load distribution 影響。
- 因此 rehab 不能只管 mileage，也不能只管 biomechanics。

### 2. acute painful phase 可先從 isometric 開始

- 當 runner 敏感到 walking 或 sit-to-stand 都痛時，initial loading 可能需要用 isometric。
- 本章把 isometric 的角色放在 analgesia、減少 edema / atrophy 與恢復正常 muscle recruitment。
- 文中提到常見研究設定為 `5 x 45 秒`、約 `70% 1RM`，但臨床上應由病人症狀反應決定實際負荷。

### 3. progressive loading 可容許有限疼痛

- 所有 tissues 都可對 moderate progressive load 有正向適應。
- 本章明確下修了 eccentric-versus-concentric 的教條化說法。
- 更重要的是 symptom-guided progression 與 self-efficacy。

### 4. acceptable pain rules 是實用 rehab 邊界

- pain increase 不超過 `2/10`
- pain 不可持續超過 `24 小時`
- repeated similar bout 不應越做越糟

### 5. return to run 需要最低功能門檻

- walk `30 分鐘` 不增加症狀
- single-leg squat `10 次` 不增加症狀
- single-leg hop `10 次` 不增加症狀
- 達標後再進 walk/jog progression，通常 every other day。

### 6. gait retraining 是 load redistribution 工具

- cadence increase 是縮短 step length 的手段，不是目標本身。
- 章節指出 recreational runner average cadence 約 `164 spm`。
- 臨床上若要調 cadence，最好先從 `<=5%` increase 開始，較不容易付出明顯 running economy 成本。
- foot strike、forward lean、quiet steps 等 cue 都可改變 load distribution，但沒有 universal best form。

### 7. 不能跑時仍可用功能測試推估問題

- single-leg squat 可當 running mechanics proxy。
- weight-bearing lunge test 可幫助辨識 ankle dorsiflexion restriction。
- heel-elevated single-leg squat 可幫助區分 ankle restriction 與 proximal control 問題。

## 評估方式

- 本來源的高價值輸入不是單一 special test，而是：
  - tissue irritability
  - acceptable pain behavior
  - functional criteria before return to run
  - mechanics that plausibly change load per stride

## 治療原則

- 這份章節最重要的貢獻是把 runner rehab 寫成 **capacity restoration + load redistribution + staged running progression** 的整體流程。

## 臨床決策點

### 核心 caveat

- 本來源支持 painful-but-controlled exercise 的臨床角色，但不支持無限制硬撐。
- `10% rule` 與 `ACWR` 可作 conservative guide，不能取代臨床判斷。

## 限制與未定論

### frontmatter contradictions

- Injured runner rehabilitation should not be reduced to rest until completely pain free.
- Gait retraining is an adjunct for load redistribution, not a substitute for restoring tissue capacity.
- The 10 percent rule and acute-to-chronic workload ratio are practical heuristics, not universal biologic laws.

## 理解缺口

- 哪些 injury pattern 最適合先從 gait retraining 切入，哪些應先把 tissue capacity 補上？
- acceptable pain rule 在 bone stress injury 或 high-morbidity diagnosis 應如何收緊？
- ACWR 在 injured runner 的實務價值，哪些部分只是風險提醒而不是決策閾值？

## 臨床使用版

- 若要規劃 injured runner rehab，不要在「先練肌力」和「先改跑姿」之間二選一。
- 先界定 runner 現在是卡在 tissue tolerance、load per stride，還是兩者都卡住，再決定主軸。
