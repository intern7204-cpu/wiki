# Intellectual disability (ID) in children: Clinical features, evaluation, and diagnosis

## 一句話定義

這份 UpToDate 把 pediatric ID 的診斷骨架講得很清楚：**先分 GDD 與 ID，再用 adaptive function、developmental context 與多專業評估決定診斷與嚴重度**。

## 核心機制

### 定義與 presentation

- `GDD` 是 <5 歲 child 的 provisional term。
- `ID` 需要：
  - intellectual impairment
  - adaptive impairment
  - onset before 18 years
- severity 以 adaptive impairment 與 support need 為主。
- severe ID 常在 2 歲前就明顯，mild ID 可能到 school age 才浮現。

### 常見合併問題

- ASD
- ADHD
- learning disorders
- feeding / eating problems
- depression / anxiety / PTSD
- sleep problems
- abuse vulnerability

## 臨床表現

### 這份來源最有價值的臨床用途

- 協助把 language delay、immature self-help、school difficulty、social / adaptive difficulty 重新組織到 ID 框架。
- 強調 comorbidity 常被漏診，尤其是 ASD / ADHD / mental health。

## 評估方式

### evaluation 重點

- multidisciplinary evaluation
- developmental / medical / family / psychosocial history
- hearing / vision review
- school-based data 與 speech-language information
- cognitive testing + adaptive testing
- 針對 unexplained GDD/ID 做 genetic evaluation

### 常用測驗脈絡

- adaptive：Vineland-3、ABAS-3、DABS
- cognitive / intellectual：Bayley、WPPSI、WISC、KABC、Leiter 等
- test selection 要看 child 的語言、motor 能力與年齡

## 治療原則

### 這篇真正支持的臨床方向

- diagnosis 不應脫離 real-life adaptive function。
- 有明顯 concern 時，不應因還沒完成 full etiologic workup 而延後介入與服務。

## 限制與未定論

### 不該過度延伸的地方

- 這篇強在 diagnosis 與 evaluation，不是 etiologic test yield 或 management 細節主頁。
- 測驗工具清單有美國場域偏向；臨床上仍需依語言、文化與可近性選擇。

### frontmatter contradictions

- Global developmental delay in children younger than 5 years should not be treated as automatically equivalent to permanent intellectual disability.
- Severity of intellectual disability is defined by adaptive impairment and support needs, not IQ score alone.
- Apparent autistic-like traits in a child with intellectual disability do not automatically establish ASD.

## 臨床使用版

- 如果 child 的問題主要是 school / language / adaptive functioning，就應該把 adaptive assessment 拉到和 IQ 同等重要的位置。
- 如果 social communication 問題超出 child 的 general developmental level，再往 ASD 合併診斷思考。
