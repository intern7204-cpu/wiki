# Bentley, Newell & Bishop 2007 — Incremental Exercise Test Design and Analysis

## 一句話定義

Incremental exercise test 沒有單一最佳模板；**stage duration、starting work rate 與 increments 會系統性改變 PPO、LT/VT 與其對訓練處方的意義**，在 trained endurance athletes 尤其不能把不同 protocol 算出的 threshold 或 peak work rate 直接互相比較。

## 核心機制

### 主要貢獻

### 1. Protocol 不是中性容器

- Incremental test 改動 starting workload、increment size、stage duration，會同時影響 maximal 與 submaximal 指標。
- 因此 GXT 不只是「把受試者推到 exhaustion」；設計本身就是測量的一部分。

### 2. 短 stage 容易把 work rate-based 指標往上推

- 較短的 stages 通常得到較高的 PPO。
- LT / VT / OBLA 若用「發生時的 work rate」表示，也常因 shorter stages 而偏高。
- 若直接拿這些數值處方訓練，容易造成 **overprescription**。

### 3. 長 stage 較利於 submaximal marker，但會壓低 PPO

- Stages >3 min 通常較有利於血 lactate 與 ventilatory response 接近 steady response。
- 代價是 PPO 下降，且 test time 變長。
- 因此若主要目標是 threshold interpretation，stage duration 不應只為了追求「漂亮的 peak power」而縮短。

### 4. 在 trained athletes，VO2max 不會因 stage 稍長就自動失效

- 文中支持在 trained endurance athletes，3-min 甚至 5-min stages 仍可能得到有效的 VO2max。
- 結論不是「stage 越長越好」，而是 **VO2max validity 與 threshold validity 不必然由同一 protocol 最佳化**。

### 5. Protocol choice 必須回到 testing purpose

- 若目標是 performance diagnostics / interval prescription，PPO 與 threshold 對 protocol 很敏感。
- 若目標是 lactate/ventilatory threshold，較長 stages 常較合理。
- 若目標是同一運動員 longitudinal follow-up，protocol consistency 比追求理論最優更重要。
