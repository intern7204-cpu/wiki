# Exercise（textbook chapter）

## 一句話定義

這份 textbook chapter 的價值，在於用一個 **呼吸-循環-代謝整合視角** 解釋運動：external power 增加時，`VO2`、cardiac output、oxygen extraction 與 ventilation 必須同步上調；但其中的 `anaerobic threshold` / `oxygen debt` 用語屬 legacy framing，不能直接當作現代主結論。

## 核心機制

### 這份來源真正提供什麼

- 運動時 `VO2` 與 power 大致呈線性增加。
- 氧供增加來自：
  - cardiac output 上升
  - peripheral oxygen extraction 上升
- ventilation 從運動一開始就快速反應，不是等血氣明顯失衡才動。

### 核心內容拆解

### 1. `VO2` 不是只代表 lungs，而是整個 oxygen transport system 的輸出

- 肌肉做功增加後，需要更多 ATP。
- 這要求：
  - circulation 提高 oxygen delivery
  - working muscle 提高 oxygen extraction
  - lungs 提高 ventilation 來維持整體 gas exchange

### 2. ventilation 有明顯時間相位

- 運動開始時會立刻上升。
- moderate exercise 可達新 steady state。
- 更高強度時，會出現後續增加與 dyspnea burden 上升。

### 3. clinical exercise testing 的價值

- 章節把 shuttle test、6MWT、CPET 放進同一框架：
  - 都是在看 cardiorespiratory reserve 與 symptom-limited tolerance
  - 只是解析度與可量化程度不同

### 4. 章節中哪些要保留、哪些要降階

可保留的骨架：
- `VO2`-power 線性關係
- oxygen delivery = cardiac output + extraction
- ventilatory response 的多相性
- 高強度運動與病人運動測試的連結

要降階成 historical phrasing 的部分：
- `anaerobic threshold`
- `oxygen debt`
- 把 lactate 或 lungs 單獨當成唯一限制因子

## 限制與未定論

### 限制 / caveat

- 書章中的 threshold terminology 帶有歷史慣性。
- 對 `VO2max` / `VO2peak`、lactate 與 severe-domain physiology 的當代界定，仍需用 newer review 校正。

### frontmatter contradictions

- Legacy labels such as anaerobic threshold and oxygen debt are useful historical teaching terms but not the modern consensus framework for threshold physiology.
- Exercise limitation cannot be assigned to the lungs alone; oxygen delivery, extraction, ventilatory mechanics, and symptom perception interact.
