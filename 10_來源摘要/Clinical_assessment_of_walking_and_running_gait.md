# UpToDate — Clinical assessment of walking and running gait

## 一句話定義

這篇 UpToDate 把 adult walking / running gait assessment 定位成一套 **有順序的臨床觀察流程**，不是神奇的單一步態診斷術。

## 核心機制

### 主要貢獻

### 1. 把 gait exam 放回完整 musculoskeletal exam 之後

- 先看 posture、alignment、leg length、ROM、strength、muscle length，再進入 gait。
- 對 hip extension、ankle dorsiflexion、first MTP motion 的強調很實用。

### 2. 提供 walking / running 的 bedside checklist

- walking 看 stance、swing、arm swing、trunk、pelvis、hip、knee、ankle/foot。
- running 額外看 stride、over-stride、foot strike、heel motion、pronation timing 與 loading pattern。

### 3. 把常見臨床聯想整理得很清楚

- pelvic drop 指向 hip abductor weakness。
- straight-knee landing 常見於 over-stride。
- early heel rise 可能來自 tight gastrocnemius / Achilles、ankle restriction 或 neurologic problem。

### 4. 對 running 迷思有明確降溫

- forefoot strike 不等於比較不會受傷。
- 對沒有症狀的 rearfoot runner，不需要 routine 改 foot-strike pattern。

## 限制與未定論

### 限制 / caveat

- 這篇處理的是 adult clinical observation，不是 gait lab、prosthetic gait lab 或 complex pediatric gait analysis。
- 臨床相關性高，但不提供單一金標 scoring system。

### frontmatter contradictions

- There is no single standardized real-time adult clinical gait analysis method for routine bedside use.
- Changing an uninjured runner from rearfoot to forefoot strike is not a default injury-prevention strategy.
