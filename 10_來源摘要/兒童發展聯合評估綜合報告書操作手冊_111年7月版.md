# 兒童發展聯合評估綜合報告書操作手冊（111年7月版）

## 一句話定義

這份官方手冊的核心價值，不是提供診斷療效證據，而是把兒童發展聯評的輸出標準化成 **interprofessional report workflow**：從 child functional domains 到 family / parenting / environment，都必須被寫進綜合報告。

## 核心機制

### 這份來源真正提供什麼

- 手冊定義了聯評綜合報告書的欄位、流程與撰寫說明。
- 報告至少包含：
  - child identifying data
  - evaluation professionals
  - 壹、評估結果報告
  - 貳、評估結果與療育建議書
  - 參、病因診斷分類表

### 核心內容拆解

### 1. 聯評不是只有 child impairment checklist

- domain 涵蓋：
  - 知覺動作功能
  - 吞嚥 / 口腔功能
  - 口語溝通功能
  - 認知功能
  - 社會情緒功能
  - 日常生活功能
  - 環境支持
  - 家庭評估
  - 親職功能

### 2. team report 需要整合，不是多專業平行貼上

- 手冊明確安排不同專業評估欄位與團隊總結欄位。
- 這代表最終輸出應該是 team formulation，不是單純把各科 copy-paste。

### 3. family / parenting / resource linkage 是 report core，不是附件

- 手冊把家庭評估、親職功能、社會工作與資源連結都放進主體。
- 對臨床實作很重要：聯評結果若只剩 child deficit，報告其實是不完整的。

### 4. manual 的用途是 workflow standardization

- 它幫助：
  - report completeness
  - shared language
  - service coordination
- 它不直接證明某 diagnosis 或某療法的 validity / efficacy。

### 這份來源對 wiki 的價值

- 也可補強 [[../07_Pediatric_Development/小兒復健評估]] 的 multidisciplinary developmental assessment 架構。

## 評估方式

- 手冊支持：
  - structured reporting
  - multi-domain documentation
  - family / parenting / environment inclusion
- 手冊不支持：
  - 只用格式完整度來取代 clinical reasoning
  - 把勾選欄位當成 diagnosis proof

## 治療原則

- 這不是 treatment efficacy 文件。
- 它支持的是療育建議的書寫骨架與團隊協調流程。

## 臨床決策點

### 這份文件真正改變什麼

- 它讓 developmental joint assessment 的輸出更可執行、可追蹤、可跨專業溝通。
- 但它不能被誤讀成「只要照表填就等於完成臨床判斷」。

## 限制與未定論

### 限制 / caveat

- 這是官方 workflow / report manual，不是 research evidence synthesis。
- 對 diagnosis validity、intervention efficacy 與 prognosis accuracy 的問題，它不提供直接答案。

### frontmatter contradictions

- This manual standardizes reporting and coordination; it does not by itself establish diagnostic truth or treatment efficacy.
- Family assessment and parenting function belong in developmental reporting and should not be omitted as merely nonmedical context.

## 理解缺口

- 哪些欄位是最低必要輸出，哪些欄位需要依個案深化 narrative？
- team summary 要如何避免淪為多專業平行羅列？

## 臨床使用版

- 若要寫兒童發展聯評報告，這份手冊應該先用來定義 report structure。
- 若要回答「這個診斷是否成立」或「這個療法是否有效」，不能只靠這份手冊。
