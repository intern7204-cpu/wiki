# Running Gait Assessment

## 一句話定義

這章把 running gait analysis 放回正確位置：它是 **runner comprehensive evaluation 的最後一段**，用途是把 history、functional test 與 musculoskeletal exam 串成 mechanistic hypothesis。

## 核心機制

### 1. injury 來自 tissue tolerance 與 applied load 失衡

- 跑步傷害不只是「姿勢不良」。
- gait analysis 的價值，在於辨識可能放大組織負荷的 mechanics。

### 2. running mechanics 可拆成三層

- spatiotemporal
- kinematics
- kinetics

### 3. 高價值 global injury indicator

- high vertical GRF loading rate
- poor lower-limb dynamic alignment，特別是 hip adduction、internal rotation、pelvic drop

### 4. comprehensive runner eval 有固定順序

- detailed subjective history / training habits
- structural / postural observation
- strength、flexibility、functional tests
- gait analysis 最後做

### 5. single-leg squat 是跑者前測核心工具

- 至少做 10 次，較能看出 fatigue-related control deficit。
- 可觀察 dynamic valgus、trunk control、foot stability、arch displacement。

### 6. video gait analysis 的基本硬體條件

- 最好兩台同步相機。
- 至少 `120 fps`。
- 側面與後面視角都要有。
- treadmill 較容易固定速度與相機位置。

### 7. treadmill acclimation 與速度設定不能省

- inexperienced runner 約 6 到 10 分鐘。
- experienced runner 約 3 到 5 分鐘。
- 應在 typical training pace 或 symptom-provoking pace 觀察，因為 speed 會直接改變 mechanics。

### 8. 臨床上真正要看的不是「標準跑姿」，而是 problem-specific deviation

- initial contact：foot strike、foot inclination、heel-to-COM distance、knee flexion、tibial angle
- midstance：pelvic drop、knee window、trunk lean、step width、heel position
- full cycle：cadence、step width、ground contact time、vertical COM displacement、symmetry

## 評估方式

- 本章最值得回填的是：video setup、觀察順序、cue selection 與 injury-specific deviation map。

## 治療原則

- gait retraining 需選最能驅動問題的變項，而不是看到每個 deviation 都想改。

## 臨床決策點

### 核心 caveat

- 這章最關鍵的提醒是：**clinical gait analysis 的目標不是找出最漂亮的跑姿，而是找出最可能造成此 runner 症狀的負荷來源。**

## 限制與未定論

### frontmatter contradictions

- Running gait assessment should not begin with video alone before history and musculoskeletal examination.
- There is no universal ideal running form that should be imposed on all runners.
- Cadence and other gait cues must be interpreted in context rather than prescribed as generic rules.

## 理解缺口

- clinic 內哪些 running variable 最值得優先追？
- 哪些 deviation 可作為 intervention target，哪些只是代償結果？
- 何時需要由 2D clinical analysis 升級到更高階 biomechanical evaluation？

## 臨床使用版

- 若要做跑步評估，先把 history、strength、mobility、functional test 做完，再錄跑步。
- 若沒有明確 clinical question，錄影通常只會得到很多資訊、很少決策。
