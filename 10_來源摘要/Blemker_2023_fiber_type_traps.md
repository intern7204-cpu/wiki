# Source Summary: Fiber-type Traps

## Source Type

- Synthesis / perspective review.
- 主題範圍：skeletal muscle fiber type terminology、myosin heavy chain（MHC）classification、oxidative capacity、fiber cross-sectional area（CSA）、specific force、whole-muscle biomechanics、cross-species / sex / muscle-context interpretation。
- 本頁只處理 Blemker et al. 2023/2024 這一篇來源，不整合 Hargreaves、Smith、Poole 或其他 fiber-type review。

## Reliability Level

- 來源層級：Tier 4。
- 適用強度：適合修正 fiber type terminology、研究設計、biopsy / histology interpretation、biomechanical modeling assumptions。
- 限制：不是 guideline、不是 systematic review，也不提供 disease-specific treatment threshold 或 exercise prescription protocol。

## One-Sentence Summary

Muscle fiber type 不是單一分類軸；MHC isoform、oxidative capacity、CSA 與 force-generating capacity 來自不同測量與機制，若互相代替會造成 experimental design、computational modeling 與 exercise physiology interpretation 的錯誤。

### Concept: Muscle Fiber Types

- Existing page：[[../05_Exercise_Physiology/Muscle_Fiber_Types]]
- 單句定義：Muscle fiber type 應先說明是按 MHC、oxidative enzymes、size、mechanics 或 fatigue behavior 分類，不能把「type I / II」當成全屬性標籤。
- 來源支持：來源明確指出 fiber characteristics vary across muscles, species, sex, scale, method and disease / activity context。

## 事實

- 來源的 abstract 直接列出三個 common assumptions：MHC isoform 等同 oxidative capacity、CSA 是 MHC 或 oxidative capacity 的 surrogate、force-generating capacity 可由 MHC isoform 推出。
- 作者稱這些 assumptions 為 fiber-type traps，並指出它們會影響 experimental design、computational modeling 與 interpretation。
- MHC antibody / immunofluorescence 是當代用於 classifying fibers by myosin type 的 objective method。
- SDH 與 NADH-TR 是 oxidative metabolism / mitochondrial-related markers，但 staining interpretation 有 subjectivity 與 method timing 問題。
- Contractile speed 與 fatiguability 的 mechanistic bases 不同；slow / fast、red / white、oxidative / glycolytic 不可直接一對一映射。
- Metabolic properties across fibers form a continuum，並會隨 muscle、species、habitual activity level 與 disease state 變化。
- CSA 是 morphology measurement；它不能單獨推論 MHC isoform 或 oxidative capacity。
- Specific force measurement 受 temperature、media、fiber preparation、fiber swelling、normalization、velocity control 與 fiber length 等方法學因素影響。
- Whole-muscle force 受 architecture、musculoskeletal geometry、coordination、motor unit recruitment 與 force transmission 影響，不能由 single-fiber MHC distribution 直接推出。
- Discussion 建議研究者 recognition of experimental context、precise vocabulary、clear measurement definition、提供 absolute individual data、承認 structure-function continuum。
- 作者另外指出第四個常見風險：把不同 muscles 之間的 morphological / functional differences 過度歸因於 fiber type，而忽略 location、loading history、function、architecture、size、embryological origin 與 connective tissue。

## 推論

- 在 CPET 或 exercise metabolism 解釋中，若使用「type II fibers」作為 fatigue、VO2 slow component 或 glycolytic behavior 的原因，必須明確指的是 MHC、recruitment pattern、oxidative capacity 還是 mechanical behavior。
- Human biopsy、animal model、MRI / DTI surrogate 與 computational model 使用 fiber type 資料時，應保留 method、species、sex、muscle location 與 scale，不應把單一屬性外推到 whole muscle performance。
- 教學上應把 fiber type 改寫為多軸架構，而不是把 type I / IIa / IIx 當成 slow-oxidative-fast-glycolytic-force 的固定組合。

## 假設

- 若 wiki 把 fiber type 拆成 MHC、oxidative capacity、CSA 與 force 四軸，會降低後續 CPET、metabolism、aging、disuse、neuromuscular disease 頁面的誤讀。
- 將 fiber characteristics 視為 continuum 比二分法更能容納 hybrid fibers、sex differences、species differences 與 disease / training adaptation。

## 不確定

- 來源沒有提供各疾病或各運動項目下可直接使用的 fiber-type interpretation algorithm。
- 各實驗室在 staining、threshold、image analysis、single-fiber mechanics 與 whole-muscle modeling 的方法仍可能不同。
- 來源是 perspective / synthesis review；雖能指出概念錯誤，但不能取代 disease-specific 或 sport-specific evidence。

## 機制推導

1. Researcher 觀察到 muscle 或 fiber 之間有 functional / metabolic / morphological differences。
2. 若只量 MHC，就只能回答 myosin isoform / contraction speed axis。
3. 若研究問題是 oxidative capacity，需量 SDH、NADH-TR、mitochondrial markers 或 respiratory function。
4. 若研究問題是 fiber size，需直接量 CSA / morphology，且考慮 muscle depth、sex、species、loading history。
5. 若研究問題是 force，需量 specific force、architecture、whole-muscle mechanics 或 neuromuscular coordination。
6. 把任一軸線當成其他軸線的 surrogate，會形成 fiber-type trap。
7. 正確解讀需要 method context、species / sex / muscle context、scale context 與 precise terminology。

## 不可外推

- 不可把 human type IIb 當成常規人類 fiber category；舊文獻 human IIb 多需謹慎判讀。
- 不可把「fast」自動寫成 glycolytic 或 low oxidative。
- 不可把「type I」自動寫成 small CSA 或 low force。
- 不可把 whole-muscle strength gain 全部歸因於 fiber type shift。
- 不可把 animal muscle fiber pattern 直接外推到 human exercise physiology。
- 不可把 MRI、ultrasound、DTI 或 image morphology 直接等同於 MHC 或 metabolism。
