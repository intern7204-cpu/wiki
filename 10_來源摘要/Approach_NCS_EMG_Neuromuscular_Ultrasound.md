# Source Summary: Approach to Nerve Conduction Studies, Electromyography, and Neuromuscular Ultrasound

## Source Type

- 教科書型臨床章節；內容涵蓋 EDX 檢查設計、定位邏輯、NCS / needle EMG 判讀紀律，以及 neuromuscular ultrasound。
- 本輪僅以這篇單一來源 ingest，未混入 basic NCS、repetitive stimulation、late responses 或 disease-specific EDX criteria 等其他章節。

## Reliability Level

- 在本 wiki 對 textbook clinical chapter 的層級中屬 Tier 1。
- 強項：EDX workflow、clinical-electrophysiologic correlation、檢查中即時修正、以定位為先的判讀，以及 neuromuscular ultrasound 的補位角色。
- 限制：本來源不是 disease-specific guideline；治療閾值、疾病 criteria 與 test performance 都應另以 condition-specific 來源確認後才能用於臨床決策。

## One-Sentence Summary

EDX 應以「以定位為先的 focused 臨床檢查延伸」運作：NCS 與 needle EMG 提供生理性的 localization、severity 與 time course；neuromuscular ultrasound 在必要時補上解剖與病因細節。

## Core Concepts Extracted

### Concept: EDX 定位導向檢查流程

#### One-Sentence Definition

EDX 從 brief history 與 directed neurologic exam 開始，建立 differential 與定位假說，再以 targeted NCS、needle EMG 與檢查中的 protocol 修正回答定位問題。

#### Known Facts

- EDX 包含 NCS、repetitive nerve stimulation、late responses、blink reflex、needle EMG 與其他特殊檢查。
- NCS 與 needle EMG 是 EDX 的核心，互相補強。
- 來源指出 NCS 與 needle EMG 通常先做，並提供最大的診斷資訊。
- EDX 應依神經學檢查與 differential diagnosis 個別化，並在進行中依新資訊修正。
- 每次 EDX 的主要目標都是定位。
- 第一階定位：分 neuropathic、myopathic、NMJ 與 CNS 型態。
- 確認為 neuropathic 後，EDX 可進一步區分 neuron / root / plexus / peripheral nerve 等級、mononeuropathy / mononeuritis multiplex / polyneuropathy 型態、fiber type、demyelinating vs. axonal、嚴重度與時程。
- 來源描述的 patient encounter 順序：brief history 與 directed exam → differential → 檢查計畫 → 與病人說明 → NCS（依結果即時新增）→ needle EMG（即時選擇肌肉）。
- NCS 結果會引導 needle EMG 策略與判讀。
- 檢查需在「完整度、決策價值、病人耐受度」之間取得平衡。
- 來源引用一個大型 case series：EDX 在多數案例改變或確認診斷，並在 63% 的病人改變治療方針。

#### Mechanism Chain

```text
Focused history / directed neurologic exam
→ differential 與定位假說
→ targeted NCS
→ 依早期生理發現即時修正
→ targeted needle EMG
→ clinical-electrophysiologic correlation
→ 與管理相關的 impression 與限制
```

#### Inferences

- 固定的「routine EMG package」品質低於 targeted study：可能漏掉真正的定位問題，反而製造 incidental abnormality。
- Referral 與床邊檢查品質直接決定 EDX 產出價值。

#### Assumptions

- 操作者能進行並判讀 NCS 與 needle EMG，並可在檢查中修改計畫。
- 臨床問題夠具體，足以引導 nerve 與 muscle 的選擇。

#### Uncertainties / Limitations

- 本章提供 workflow 原則，未提供各疾病的 sensitivity / specificity。
- 即使 EDX 明顯異常，部分定位仍可能 non-localizable 或不確定。

### Concept: Clinical-electrophysiologic correlation 與 overcall 預防

#### One-Sentence Definition

EDX 異常應在臨床、NCS 與 needle EMG 都對到同一定位與病態生理時，才能被判讀為臨床診斷。

#### Known Facts

- 來源所列 cardinal rule 包含「把 NCS / EMG 視為臨床檢查的延伸」。
- 出現意外或不一致 finding 時，先 review 技術因素。
- 若仍不確定，應重新檢查病人。
- EDX 結果應在臨床症狀與 referring diagnosis 的 context 下報告。
- Mild、subclinical 或技術造成的 abnormality 不應被 overcall 為臨床有意義的診斷。
- 當臨床、NCS 與 EMG 都互相 correlate 時，診斷更穩。
- 來源警告：若不控制技術因素、limitation 與 differential，EDX 可能誤導病人與 referring clinician。

#### Mechanism Chain

```text
被放大的微小生物電訊號
→ 技術 / 生理 / 解剖三類變異
→ 可能出現的 minor abnormality
→ 需臨床 + NCS + EMG 的 convergence
→ 確診或標明不確定性的 impression
```

#### Inferences

- 報告應分開「明確定位」與「incidental / uncertain-significance」兩類 finding。
- 單一 borderline abnormality 不應主導治療，除非它與臨床型態吻合。

#### Assumptions

- 臨床檢查可信度足以作為 correlation 的 anchor。
- Normative values、temperature control、electrode placement 與刺激技術都已充分。

#### Uncertainties / Limitations

- Borderline abnormality 可能始終無法收斂；正確輸出常是「臨床意義不確定」，而不是強行給出診斷。

### Concept: Neuromuscular ultrasound 作為 EDX 補位

#### One-Sentence Definition

Neuromuscular ultrasound 在生理性定位已建立或被懷疑後，補上解剖、結構，乃至於部分病因資訊，與 EDX 互補而非取代。

#### Known Facts

- 來源明確指出 neuromuscular ultrasound 是 EDX 的補位，不取代 EDX。
- EDX 是 nerve / root / muscle function 的生理測試；ultrasound 顯示 nerve 與 muscle 的結構。
- 在 mononeuropathy 中，ultrasound 可確認定位、在 EDX 無法達到時細化 segmental 定位，並可能找出解剖原因（例如 cyst、entrapment site、bony spur 或 nerve sheath tumor）。
- 在 polyneuropathy 中，ultrasound 對評估 hypertrophic / demyelinating 型態最有用。
- 在評估 motor neuron disease 時，ultrasound 可偵測 fasciculation；當看到 nerve enlargement，可協助把 pure LMN syndrome 與 inflammatory motor neuropathy（而非 ALS / PMA）區分開來。
- 在 myopathy 中，ultrasound 可篩檢分布型態，並協助選擇「異常但尚未終末期」的肌肉作為 biopsy site。
- Ultrasound 解讀也需 technical-factor review、artifact 辨識、多平面評估，以及與臨床、電生理結果的綜合。

#### Mechanism Chain

```text
EDX 已給出生理性定位
→ 仍有解剖 / 病因不確定
→ 針對性 neuromuscular ultrasound
→ 結構、enlargement、compression、continuity 或 muscle pattern
→ 整合臨床—電生理—超音波的結論
```

#### Inferences

- Ultrasound 在「臨床檢查與 EDX 後仍剩下的具體疑問」時最有用，而不是當作全身 screen。
- 單純的結構異常不能在無臨床與電生理 correlation 下被當成症狀來源。

#### Assumptions

- 操作者有足夠的 neuromuscular ultrasound 技能，並理解 nerve / muscle 解剖。
- 在現有設備與病人條件下，目標結構可被影像化。

#### Uncertainties / Limitations

- Ultrasound 的價值可能很大、可有可無，或具關鍵性；來源指出在掃描前無法完全預測。
- Ultrasound 的 artifact 與解剖變異可能被誤判為病理。

## Clinically Useful Points

- 從定位問題出發，而不是從固定的 nerve / muscle 清單出發。
- 若病人耐受度有限，先做最可能回答 referral question 的部位。
- NCS 通常應先於 needle EMG，因 NCS 結果會改變 muscle 選擇與 EMG 判讀。
- 不一致 finding 需先做技術 review，必要時 reexamine，再下診斷。
- Mild 或 subclinical abnormality 應在臨床相關性 context 下報告。
- 在 EDX 後仍有解剖 / 病因疑問時使用 neuromuscular ultrasound，特別是 mononeuropathy 定位、demyelinating polyneuropathy 型態、pure LMN syndrome 與 myopathy biopsy 規劃。

## Research-Useful Points

- 本章把 EDX / ultrasound 的整合當作「生理—結構」對應，可作為未來診斷 pathway 研究的設計框架。
- 有用 endpoint 包括：diagnostic change、management change、overcall reduction，以及 ultrasound 在 EDX 已定位後的 incremental value。

## Conflicts With Existing Knowledge

- 與「EDX 可作為 generic screening test」衝突。
- 與「多數 neuromuscular 定位問題只用 NCS 就夠」衝突。
- 與「Minor EDX abnormality 自動等於臨床有意義的診斷」衝突。
- 與「Neuromuscular ultrasound 取代 EDX」衝突。
- 與「結構影像異常本身可確立症狀來源」衝突。
