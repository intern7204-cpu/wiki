# Developmental Delay and Intellectual Disability

## 一句話定義

這頁整理「Developmental Delay and Intellectual Disability」這份來源真正能教給住院醫師的主架構，並把可直接用於臨床決策的部分拆開。

## 核心機制

### 先用白話講懂

如果用費曼方式講，這章的重點是：**ID 不是「IQ 不夠高」而已，而是 intellectual function 和 adaptive function 都受到明顯限制；而 GDD 則是 5 歲前的早期描述，不是和 ID 完全同義。**

### 核心內容拆解

### 1. ID 的定義有三個支柱

- general intellectual function deficit
- adaptive behavior deficit
- onset before adulthood

### 2. adaptive behavior 是診斷核心，不只是附屬資訊

- 本章把 adaptive behavior 分成：
  - conceptual
  - social
  - practical
- severity 應依 adaptive function / support need，而不是單看 IQ score。

### 3. 只看 IQ 會出現診斷偏差

- chapter 明確指出 adaptive behavior criterion 的臨床效用，特別在 IQ 60 到 75 區間。
- 這能減少歷史上因 biased testing 對特定族群的過度診斷。

### 4. regression 不是 ID 的自然病程

- ID 被放在 nonprogressive framework。
- 如果 child 出現 true loss of skills、downward trajectory、new seizure、motor loss，就要想到：
  - inborn error of metabolism
  - neurodegenerative disorder
  - other progressive encephalopathy

### 5. GDD 是 early-life descriptive diagnosis

- DSM-5 把 GDD 放在 <5 歲、至少 2 個 developmental domains 顯著落後的情境。
- 不是每個 GDD 最後都會成為 ID。
- 有些 child 之後會 reclassify 成 ASD、ADHD、DCD，或隨成熟與介入改善。

### 6. etiologic workup 的方向已經進入 genetics-first era

- 本章整理出 CMA、FMR1、MECP2、PTEN、ES 等 testing 思路。
- 若沒有明顯 syndromic clue，不應因為看起來只是 delay 就完全不查原因。

## 臨床決策點

### 這章真正回答什麼問題

- GDD 和 ID 到底怎麼分。
- 為什麼 adaptive behavior 一定要納入診斷。
- 哪些情況提示不是單純 nonprogressive developmental disorder，而是另外的 progressive disease。

## 限制與未定論

### 不該過度延伸的地方

- 本章是 broad framework，不是單一 syndrome workup flowchart。
- genetic testing 技術與建議更新很快，細節仍要看 newer guideline / specialty update。
- educational label `developmental delay` 和 medical diagnosis `GDD` 不能混用。

### frontmatter contradictions

- Intellectual disability should not be reduced to IQ alone; adaptive functioning is part of the definition.
- Regression is not expected in nonprogressive intellectual disability and should trigger broader etiologic thinking.
