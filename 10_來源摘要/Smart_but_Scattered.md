# Smart but Scattered

## 一句話定義

這本科普書的價值，不在於提出新的醫學證據，而在於把 executive function 問題翻成 **家庭可操作的 coaching language**：先找 child 的 executive-skills pattern，再用環境調整、routine 與 collaborative scaffolding 降低失敗循環。

## 核心機制

### 這份來源真正提供什麼

- 作者群把 executive skills 拆成 11 項：
  - response inhibition
  - working memory
  - emotional control
  - flexibility
  - sustained attention
  - task initiation
  - planning / prioritizing
  - organization
  - time management
  - goal-directed persistence
  - metacognition
- 書的主軸是 caregiver-friendly assessment + home-based strategy。

### 核心內容拆解

### 1. 問題被翻成 skill profile，而不是道德評價

- 孩子「散」、「拖」、「忘」、「爆炸」被重新翻成 executive skill weakness。
- 這有助於降低家長把問題直接讀成懶惰、故意或不用心。

### 2. intervention 主軸是外部支架

- 常見策略包括：
  - visual cue
  - checklist
  - routine
  - task breakdown
  - advance warning
  - shared planning
- 核心不是要 child 馬上獨立，而是先提供 external structure。

### 3. 家長角色是 partner，不是單純監工

- 書中強調 collaborate with child、從 strength 出發、逐步退場。
- 這對 school-age child 與 adolescent 的家庭實作特別有用。

## 臨床表現

### 這本書對 wiki 的實際價值

- 可作為 [[../07_Pediatric_Development/Executive_Function_支持策略]] 的 caregiver strategy 來源。
- 也能補強 [[../07_Pediatric_Development/正向教養與家庭支持]] 的日常執行面。

## 評估方式

- 本書提供的是 caregiver questionnaire 與 observation logic，不是 standardized diagnostic battery。
- 因此可用來：
  - 整理 complaint pattern
  - 支持 coaching discussion
- 不可用來：
  - 取代 formal neurodevelopmental evaluation
  - 直接下 diagnosis

## 治療原則

- 本書支持的 intervention 類型：
  - environment modification
  - rehearsal and routine
  - collaborative problem solving
  - gradual independence building

## 臨床決策點

### 這本書真正適合放在哪裡

- 它適合做家長衛教與行為支架設計。
- 它不適合被當成 consensus treatment guideline 或高等級效益證據。

## 限制與未定論

### 限制 / caveat

- 這是 caregiver-facing popular book，不是 guideline。
- 11 executive skills 架構實用，但不是唯一或標準化的學術分類方式。

### frontmatter contradictions

- The 11 executive skills framework is a useful coaching taxonomy, not a universally validated diagnostic nosology.
- Practical executive-skills coaching can improve routines and task follow-through, but this book is not a formal clinical guideline.

## 理解缺口

- 哪些 child 的問題主要是 EF scaffolding 不足，哪些其實更像 language、sleep、anxiety 或 learning disorder？
- external scaffold 應該何時開始退場？

## 臨床使用版

- 若家長知道孩子問題在哪裡，卻不知道每天回家要怎麼做，這本書有實際價值。
- 若臨床目標是 diagnosis clarification，這本書只能當輔助語言，不能當主證據。
