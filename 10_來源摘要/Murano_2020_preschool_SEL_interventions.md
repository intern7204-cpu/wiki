# Murano et al. 2020 — Preschool SEL Interventions Meta-analysis

## 一句話定義

這篇 meta-analysis 的核心不是「SEL 有沒有用」而已，而是：**preschool SEL 整體上有幫助，但效果高度取決於 intervention type、risk stratification 與 home-school context；at-risk preschooler 不應只被當成 universal classroom program 的附帶受益者。**

## 核心機制

### 這份來源真正提供什麼

- 納入 48 篇文章、57 個 study、15,498 名 preschool children。
- 納入標準只接受 RCT 或有 baseline equivalence / adequate statistical control 的 quasi-experimental design。
- 主要 outcome 只看兩類：
  - social and emotional skills
  - reduction of problem behaviors

### 核心內容拆解

### 1. universal 與 targeted preschool SEL 都有整體效益

- universal SEL：
  - social and emotional skills：Hedges's `g = .34`
  - reduction of problem behaviors：`g = .32`
  - overall grand mean：`g = .35`
- targeted SEL：
  - social and emotional skills：`g = .44`
  - reduction of problem behaviors：`g = .50`
  - overall grand mean：`g = .48`

重點不是 targeted 一定「比較高級」，而是 **風險分層不同，不能把兩者混寫成同一類 intervention**。

### 2. `SEL` 不是單一 treatment label，program type 才是主要異質性來源

- 在 universal intervention 中，intervention program type 解釋了大部分 heterogeneity，meta-regression `R2 = .83`。
- 不同 program 的 point estimate 差異很大：
  - `I Can Problem Solve`：`g = .91`
  - `PATHS`：`g = .19`
  - `Tools of the Mind`：`g = .05`
- 作者明確提醒：這些 program 間比較來自 moderator analysis，**不能直接做 causal ranking**。

### 3. preschool 的情境堆疊可能比 K-12 更重要

- 在 universal intervention 中：
  - teacher-only delivery：`g = .28`
  - parent-only delivery：`g = .36`
  - outside researcher delivery：`g = .53`
  - parent + teacher 各自在 home / school delivery：`g = .53`
- 以 setting 看：
  - school-day only：`g = .32`
  - home only：`g = .41`
  - home + school：`g = .53`

作者的解讀不是「老師做不好」，而是 **preschool child 的 mesosystem 本來就同時由 home 與 school 組成，情境連續性可能比單點 classroom delivery 更重要**。

### 4. at-risk preschooler 在 universal program 下的獲益較小

- 在 universal studies 裡，被歸類為 at-risk 的樣本：
  - `g = .21`
- 非 at-risk universal samples：
  - `g = .29`
- targeted at-risk interventions：
  - overall `g = .48`
  - problem behavior reduction `g = .50`

這個結果支持一個實務訊息：**如果 child 已有 externalizing behavior、家庭 turbulence 或其他明確 risk factor，不能假設 universal classroom SEL 就足夠。**

### 5. targeted preschool SEL 多半是 parent training / home-based support

- targeted interventions 大多在 home setting 進行。
- 最常見的是 parent training model。
- `The Incredible Years` 是 targeted intervention 中最常見的 program，point estimate `g = .47`。

這使 targeted preschool SEL 與一般 school SEL 最大的結構差異，不只在「強度更高」，也在 **delivery agent 轉向家長與家庭情境**。

## 評估方式

- 這篇是 intervention outcome meta-analysis，不是 disease diagnostic paper。
- 它比較適合回答：
  - preschool SEL 要不要分 tier
  - home / school context 需不需要一起設計
  - 哪些 moderator 可能影響 program effect

## 治療原則

- 若 child 已明顯 at-risk，優先思考 targeted support，而不是只補充 universal curriculum。
- 若要做 preschool SEL design，不能直接照搬 K-12 school-day / teacher-only logic。
- 若要選 program，先看 age-specific evidence、delivery context、fidelity 與風險族群適配性。

## 臨床決策點

### 這篇真正回答什麼問題

- preschool SEL 到底值不值得做。
- at-risk child 是否只靠 universal classroom SEL 就夠。
- home 與 school 要不要被視為同一個 intervention system。

### 對現有 wiki 的意義

- 幫 [[../07_Pediatric_Development/學齡前期的自我調節與school_readiness]] 補上 intervention stratification。
- 幫 [[../07_Pediatric_Development/正向教養與家庭支持]] 補上 parent training 不只是家庭衛教，而是 preschool targeted SEL 常見 delivery architecture。

## 限制與未定論

### 不該過度延伸的地方

- program 間效果差異來自 observational moderator analysis，不可直接宣稱某個 program 普遍 superior。
- universal 與 targeted intervention 的 effect size 不能做過度簡化的 head-to-head 結論，因為 baseline risk 與 setting 不同。
- 這篇主要 outcome 只納入 social-emotional skills 與 behavior，沒有充分回答 long-term school readiness、academic achievement 或 lifespan outcome。

### frontmatter contradictions

- Preschool SEL is not a single interchangeable intervention category; program-level effects varied widely.
- Universal SEL should not be treated as equivalent to targeted intervention for at-risk preschoolers.
- K-12 implementation logic cannot be directly transplanted to preschool.

## 理解缺口

- 哪些 program component 才是真正有效成分，而不是和特定品牌 package 綁在一起？
- parent component、teacher component 與 fidelity 之間，哪一個對 preschool outcome 的貢獻最大？
- long-term school readiness、academic outcome 與 participation outcome 是否會延續？

## 臨床使用版

- 如果 preschool child 已有 behavior / regulation risk，不要只寫「建議上 SEL 課程」；要先分清他現在需要的是 universal exposure 還是 targeted support。
- 如果 intervention 只放在 classroom 而沒有 home carryover，對 preschool child 可能少了一大塊真正生活情境。
- 如果有人拿 K-12 school SEL 的 implementation rule 直接套到 preschool，這篇來源是很好的反例。
