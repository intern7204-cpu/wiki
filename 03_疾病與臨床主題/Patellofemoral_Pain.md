# Patellofemoral Pain

## 一句話定義

Patellofemoral Pain (PFP) 是以 **around / behind the patella pain during loaded flexed-knee activity** 為核心的 anterior knee pain syndrome，且本質上是 diagnosis of exclusion。

## 核心概念

### PFP 的臨床骨架

- 典型誘發活動：
  - squat
  - running
  - stairs
  - prolonged sitting
- 關鍵不是 patella 看起來有沒有「偏」，而是症狀型態、load history 與 dynamic control。

### 病理生理是 multifactorial load problem

- training overload 常是最常見背景。
- hip weakness、dynamic valgus、pelvic drop、foot loading pattern 都可能提高 patellofemoral stress。
- 單一 static alignment marker 很少足夠解釋症狀。

### PFP 不等於 chondromalacia

- chondromalacia 是 pathologic cartilage 描述，不等同整個 PFP syndrome。
- 把兩者混用，容易造成過度影像化與結構化思考。

## 臨床或研究上的重要性

- 是 runner 與 active adolescent / young adult 常見 knee complaint。
- 對 sports medicine / rehab 而言，是最常見需要把 load、strength、gait 與教育結合處理的例子之一。
- 不是所有病人都會自然痊癒；持續症狀並不少見。

## 評估方式

### history 重點

- onset 是否與 mileage、speed、hill、stairs、training block change 有關
- recent shoe / surface / orthotic change、prior injury 與 treatment adherence
- pain 是否為 anterior / retropatellar
- 有無 locking、true swelling、instability、rest pain、trauma
- prolonged sitting、squat、stairs 是否可重現

### physical examination 重點

- 先看 standing posture、single-leg stance、walk 與 squat，再進局部 exam。
- squat pain 是高價值 clinical finding。
- 看 single-leg squat / step-down 時的：
  - contralateral pelvic drop
  - hip adduction / internal rotation
  - dynamic knee valgus
  - foot pronation / supination pattern
- 補 hip abductor / external rotator strength、hamstring / calf mobility 與足部結構。

### imaging 原則

- 典型 PFP 不需 routine imaging。
- 若有 trauma、instability、effusion、prior surgery、rest pain 或 1 到 2 個月 conservative care 無改善，再考慮 plain film。
- advanced imaging 不是 initial step。

## 治療原則

### rehabilitation 主軸

- load modification，不是完全停止所有活動
- relative rest 與 nonimpact cross-training 可作 bridge，不必一律完全停動
- combined hip + knee strengthening
- CKC exercise 常較容易耐受
- 依情況加上：
  - foot orthosis
  - patellar taping
  - manual therapy
  - supervised PT

### running-specific 補充

- 若 runner 有明顯 overstride、high loading 或 frontal-plane hip control 問題，可考慮 gait retraining。
- step rate increase 應相對於個人 preferred cadence，且在固定速度下操作。
- return to run 應 symptom-guided，且先恢復基本 walking、single-leg squat 與 hop capacity。

## 臨床決策點

### 反對論點

- 「PFP 就是 patella 沒對正，調一調就好。」
- 「前膝痛先照 MRI，比較快。」
- 「只練 quadriceps 就夠了。」

### 反駁

- 現代證據更支持 multifactorial load model，而不是單一 maltracking 故事。
- 典型 PFP 是 clinical diagnosis，MRI 通常不改變第一線處置。
- combined hip + knee exercise 的支持度高於 knee-only thinking。

### 結論

- PFP 的處理重點是 **先用 history + dynamic exam 建立診斷，再做 load-based rehabilitation**，而不是被結構標籤帶著走。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- Patellofemoral pain should not be reduced to chondromalacia or a pure maltracking label.
- Q angle and patellar grind testing should not anchor diagnosis or treatment.
- Routine imaging is not first-line for typical patellofemoral pain.

## 理解缺口

- 哪些 anterior knee pain mimic 最容易被誤判成 PFP？
- 哪些 gait / strength finding 真正能改變處方，而不只是「看起來不好看」？
- 何時該把 persistent PFP 往 cartilage、instability 或 referred pain 再分流？

## 臨床使用版

- 若病人是典型 loaded flexed-knee anterior pain，先用本頁完成 clinical diagnosis 與第一線 rehab 規劃。
- 若合併 locking、明顯 effusion、instability 或 trauma，就先擴大 differential，不要直接套 PFP。
