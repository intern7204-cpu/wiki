# 神經性下泌尿道功能障礙

## 一句話定義

NLUTD management 的三大目標是 **protect upper tract、optimize social continence、minimize UTI**，而完成這三件事通常要靠 urodynamic pattern 而不是 symptom impression。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### 重要生理型態

- suprapontine：常見 urgency / frequency，較保留 coordinated relaxation。
- suprasacral：常見 detrusor overactivity + DSD，high pressure risk 較高。
- sacral / infrasacral：常見 areflexia / hypocontractility 與 incomplete emptying。

### management principles

- intermittent catheterization 是 retention pattern 的核心。
- antimuscarinic / selected pharmacologic suppression 用於 detrusor overactivity。
- onabotulinumtoxinA、external collection device、selected outlet / augmentation surgery 在特定情境有角色。
- SCI above T6 要在 bladder testing / event 中警覺 autonomic dysreflexia。

### 臨床重點

- voiding pressure > 40 cm H2O 是 upper tract deterioration risk signal。
- upper tract surveillance 不是可有可無，特別在 SCI / myelodysplasia 等高風險族群。
- functional management 要考慮 hand function、body habitus、lifestyle、caregiver support。

## 評估方式

### 評估框架

- history：voiding pattern、incontinence、retention、UTI、premorbid condition、void diary。
- physical exam：mental status、perineal sensation、pelvic floor / rectal tone、pelvic / prostate exam。
- tests：PVR、urinalysis / culture、renal ultrasound、selected CT / cystography、urodynamics。

## 治療原則

- 目前頁面尚未整理出 Non-pharmacologic、Pharmacologic、Injection / procedure、Rehabilitation program 的決策順序。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「症狀和 PVR 看一看，大概就知道 bladder 是否安全。」

### 反駁

- symptoms 與 objective findings 常不一致。
- low PVR 仍可能伴隨高 intravesical pressure。
- OAB 只是 symptom term，不等於 detrusor overactivity。
- 若要真正分辨 storage problem、emptying problem、DSD、compliance issue，通常需要 urodynamics。

### 結論

- NLUTD 的臨床決策必須回到 **lesion-informed evaluation + urodynamic confirmation + upper tract surveillance**。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- Symptoms and PVR values alone do not reliably define the underlying bladder dysfunction or bladder safety.
- OAB is a symptom syndrome and should not be conflated with detrusor overactivity, which is a urodynamic diagnosis.
