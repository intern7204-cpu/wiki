# 偏癱肩痛

## 一句話定義

偏癱肩痛（hemiplegic shoulder pain, HSP）是 **stroke 後在 paretic 上肢出現的、由 glenohumeral subluxation、spasticity、soft tissue injury（rotator cuff impingement、adhesive capsulitis）、neuropathic component（central / CRPS）、與不當護理 / positioning 多因子協同造成的肩部疼痛症候群**，發生率約 9%（有些 cohort 高達 50%），重點不是「肩痛=肩關節炎」，而是「同一個病人可能同時 subluxation + spasticity + bursitis + neuropathic + brachial plexus tractipathy——必須先查清楚哪幾條都在燒，再決定哪條先撲。」

## 已知

- **Stroke 後 HSP 發生率約 9%（住院期 cohort）**；長期追蹤可達 30–50%。
- HSP 會 **直接降低 rehab tolerance、participation、ADL、sleep、QOL**。
- 多因子病因——**單一介入很少有效**；需 **multidisciplinary** + **mechanism-targeted**。
- AHA/ASA 2016 *Adult Stroke Rehabilitation and Recovery* 提供 evidence-based 指引（Class IA–IIIC 系統）。
- **過去做的 overhead pulley exercise 已被明確 not recommended（IIIC）**——可能 over-stretch 並惡化 pain。
- 多數 case 經 systematic 評估 + targeted 介入可顯著改善。

## 核心機制

### 為什麼 stroke 後肩會痛——五條同時在燒

1. **Glenohumeral subluxation（GHS）**
   - Stroke 後 supraspinatus 與 deltoid 等 abductor 力量驟降。
   - 在直立姿勢下重力把上肢往下拉 → 股骨頭從關節盂下移。
   - 沒有韌帶支撐感（不是 ligamentous 鬆弛，是肌肉支撐失效）。
   - 嚴重 subluxation 可拉傷 capsule、stretch brachial plexus、撞擊 rotator cuff。

2. **Spasticity（subscapularis、pectoralis major、内旋肌群）**
   - Internal rotation + adduction synergy 是 stroke 上肢經典 pattern。
   - 持續高張力 → soft tissue impingement → rotator cuff、subacromial bursa 反覆受壓。
   - Spasticity 也限制 ROM → 助長 frozen shoulder（adhesive capsulitis）。

3. **Soft tissue injury**
   - **Rotator cuff impingement / tear**：高 arch 動作（特別 abduction > 90°）時 humeral head 撞擊 acromion。
   - **Subacromial bursitis**。
   - **Adhesive capsulitis**：長時間不動 + spasticity 使 capsule 沾黏。
   - **Bicipital tendinitis**。

4. **Neuropathic / central pain**
   - Stroke 本身可造成 central pain（thalamic、parietal）。
   - Stroke 後 CRPS（complex regional pain syndrome，過去稱 reflex sympathetic dystrophy）：burning、allodynia、autonomic 變化、皮膚 trophic changes。
   - Brachial plexus traction injury（subluxation 拉傷）。

5. **Iatrogenic / positioning**
   - 不當搬移（拉手扶起）→ 直接組織傷害。
   - 久坐輪椅手垂下 → subluxation 惡化。
   - 不當 sling 使用 → contracture。
   - Overhead pulley → 過度 stretch。

### 為什麼 motor recovery 不一定 = pain resolved

- Motor 恢復 ≠ structural integrity 恢復。
- Subluxation、capsular contracture、neuropathic pain 一旦建立 → 即使 motor 改善，pain 仍在。
- 預防比治療有效得多——是 IRF 期間早期 positioning 的核心理由。

## 臨床表現

### 病史

- Stroke 後開始的肩痛（多在 2 週–3 個月內）。
- ADL 配合困難、sleep disturbance。
- 肢體被搬動時痛。
- 痛的性質：sharp（subluxation、impingement）、deep ache（capsulitis、spasticity）、burning / allodynia（neuropathic / CRPS）。

### 視察

- 肩峰下凹陷（subluxation 1–3 cm 可見）。
- 上肢內收 + 內旋姿勢（spasticity pattern）。
- 皮膚變化（CRPS 紅、腫、汗、毛髮）。

### 觸診

- 肩峰下方 finger-breadth gap 量 subluxation 嚴重度。
- Subacromial / bicipital tenderness。
- MCP joint 壓痛 + 紅腫（CRPS hand finding）。

### ROM

- 主動 vs 被動 ROM 差距大 → 肌力主導。
- 被動 ROM 也受限 → spasticity / contracture / capsulitis。
- 末端 painful arc → impingement。

### 神經學

- 完整 sensorimotor exam 排除 peripheral nerve 或 nerve root injury（subluxation 拉傷的 brachial plexus）。
- Central pain：thalamic / parietal stroke + dysesthesia + allodynia。

### 特殊測試

- Neer / Hawkins：impingement。
- Painful arc（60–120°）：impingement / cuff tear。
- Speed / Yergason：bicipital tendinitis。
- MCP compression（hand pain）：CRPS。

## 評估方式

### 系統化 multidisciplinary 評估（IIaC）

- **Musculoskeletal exam**：subluxation、ROM、tendinitis、bursitis、capsulitis。
- **Spasticity assessment**（MAS、Tardieu）。
- **Subluxation quantification**：finger-breadth、X-ray AP。
- **Peripheral neurological assessment**：排除 brachial plexopathy、cervical radiculopathy。
- **CRPS screening**：MCP compression + skin / autonomic changes。

### 影像（IIbB）

- **Ultrasound**：cuff tear、bursitis、tendinitis、effusion；床邊可做。
- **MRI**：複雜 case 或 surgical planning。
- **X-ray**：subluxation 量化、骨性異常、ossification。

### 電診斷（特殊指徵）

- 懷疑 brachial plexus 或 cervical radiculopathy。
- 顯著 weakness 不符合 stroke topography。
- CRPS workup 補充。

## 治療原則

### 預防（最重要）

從 stroke 第一天開始：

- **正確 positioning**：仰臥 + 側臥時保護肩部 neutral / slight abduction。
- **AHA/ASA 指引**：「將 hemiplegic shoulder 放在最大可耐 external rotation 30 分鐘 / 天」（IIaB）—— 預防 capsular contracture。
- **教育家屬與護理**：搬動不可拉手；用軀幹支撐。
- **避免 overhead pulley exercise**（IIIC）。
- **適度 sling**：在站立、轉位時 high-risk 期使用；不 routine 使用避免 contracture。
- **早期 PROM**：每天溫和被動 ROM 全 range。

### 介入階梯（已發生 HSP）

1. **Mechanism 釐清**：哪幾條在燒？
2. **Spasticity-targeted**：
   - **Botulinum toxin** for hypertonic muscles（subscapularis、pectoralis major、teres major）（**IIaA**）。
   - 結合 PT 拉伸與強化拮抗肌。
3. **Subluxation-targeted**：
   - **NMES**（neuromuscular electrical stimulation）：對 subluxation 有效（IIbA），對 pain / function 證據較弱。
   - **Implantable peripheral nerve stimulator** 是新興選項，部分試驗顯示優於 surface NMES。
   - **Supportive sling / device**：站立、轉位時用（IIaC）。
4. **Pain-modulating**：
   - **Neuropathic pain** signs（allodynia、dysesthesia）→ amitriptyline、nortriptyline、pregabalin、gabapentin（**IIaA** for neuropathic stroke pain）。
   - 多數 systemic anticholinergic effect 兒童不耐受 → 用 less anticholinergic TCA（nortriptyline）。
5. **Soft tissue injection**：
   - **Subacromial / glenohumeral steroid injection**（IIbB）：confirmed bursitis、capsulitis 可考慮。
   - **Suprascapular nerve block**（IIbB）：refractory case。
6. **Modalities + adjunct**：
   - **Acupuncture**（IIbB）。
7. **CRPS-specific** 若 confirmed：
   - **Oral steroid** course。
   - **Bisphosphonate**。
   - **Mirror visual feedback / motor imagery**。
   - **Stellate ganglion block**。
8. **Adhesive capsulitis-specific**：
   - **Hydraulic distention** ± steroid（fluoroscopic / US-guided）。
9. **Surgical**（refractory + 嚴重 ROM 限制）：
   - **Tenotomy of internal rotators**（IIbC）—— 嚴重 contracture。

### 不要做的事

- **不要做 overhead pulley exercise**（明確 IIIC）。
- **不要把 sling 當 routine 全天使用**——helps subluxation 短期但 contracture 長期。
- **不要拉病人 paretic 手扶他起來** —— iatrogenic subluxation 加重。
- **不要假設 subluxation 改善就 pain 改善** —— NMES 可改善前者但 pain effect 微弱。
- **不要長期 oral steroid 治 HSP**（除非 confirmed CRPS）—— side effect 高、HSP benefit 不確定。

## 臨床決策點

### 「他的肩痛是哪一條在燒？」

依 dominant feature 分流：

- **Subluxation 主導**：肩峰下空隙、被動下拉痛、subluxation gap > 1 cm → NMES + sling + positioning + Botox to subscapularis（如 spasticity 共存）。
- **Spasticity 主導**：internal rotation + adduction posture、ROM 限制 → Botox + 拉伸 + 拮抗強化。
- **Impingement / bursitis 主導**：painful arc 60–120°、Neer/Hawkins +、subacromial tenderness → activity modification + 短期 NSAID + subacromial injection。
- **Capsulitis 主導**：所有方向 ROM 嚴重限制、被動 = 主動 → hydraulic distention + steroid + intensive PT。
- **Neuropathic 主導**：burning、allodynia → TCA / gabapentinoid。
- **CRPS 主導**：MCP compression +、skin / autonomic changes → CRPS pathway。

多數病人有 ≥ 2 條同時——分流不是排他，是優先序。

### 「Botox 適合嗎？」

- spasticity 主導 + 干擾 function、care、positioning 的 hypertonic 上肢 → 強烈考慮（IIaA）。
- Pure subluxation without spasticity → Botox 對 subluxation 本身無用。
- Neuropathic pain only → 部分研究支持 BoNT 對 neuropathic pain，但不是 first-line。

### 「Sling 該不該用？」

- 站立、轉位 high-risk 時刻使用（IIaC）。
- 不 routine 全天使用。
- 教育家屬：用 + 卸 + 不依賴的正確時機。

### 「NMES 該做嗎？」

- 對 subluxation 改善有效（IIbA），對 pain / function 改善 evidence 弱。
- 若 subluxation 是 dominant + pain 主因 → 可試。
- 若 spasticity / capsulitis 是主因 → 先處理那些。

### 反對論點與反駁

- 「他不痛，反正會走就好。」 → HSP 隱性影響 sleep / participation / 復健量；早期辨識可預防 chronic pain syndrome。
- 「給張力高 stroke 患者吃 baclofen 就解決了。」 → systemic baclofen 對局部肩部 spasticity 不夠 targeted；BoNT 才是。
- 「肩痛開 steroid injection 一勞永逸。」 → 只在 confirmed bursitis / capsulitis 適合；多次 steroid 影響 cuff integrity。
- 「Sling 一直戴最安全。」 → 24/7 sling 反而 contracture 與 disuse。

## 限制與未定論

- **Implantable peripheral nerve stimulator**（如 IM stim）的長期 cost-effectiveness 與適合 candidate 仍累積中。
- **Botox 在 subluxation-related pain（無顯著 spasticity）** 證據較弱。
- **Suprascapular nerve block** 的最佳重複頻率與 long-term outcome 尚不確定。
- **CRPS 在 stroke 後**的 incidence、presentation 與 stroke phenotype（thalamic、parietal、MCA）的關聯仍研究中。
- **Mirror therapy / virtual reality** 對 HSP 的 evidence 持續累積但未進入 routine guideline。
- **Telehealth-based positioning education** 對家屬訓練的真實效果。

## 理解缺口

- 為什麼有些 stroke 患者完全沒 HSP，有些反覆？個體 protective vs susceptibility 因子？
- **Implantable peripheral nerve stimulator** 何時取代 surface NMES？
- **Pre-stroke shoulder pathology**（OA、cuff tear、impingement）對 HSP 嚴重度的 modifying effect？
- **CRPS 在 stroke 後**的早期 biomarker 與 prevention strategies。
- **Telehealth-based caregiver education** 的 dose-response。
- **Genetic / inflammatory markers** 是否能預測 HSP 與 CRPS 風險。

> 標記為下一輪要補的方向：Implantable nerve stim 在 stroke 的 RCT、CRPS 在 stroke 的 phenotype-specific evidence、telehealth caregiver training。

## 臨床使用版

- 教住院醫師時，先說一句：「**偏癱肩痛不是一個診斷，是五條病因同時在燒：subluxation、spasticity、soft tissue injury、neuropathic、iatrogenic。**」
- 第二步：「**先預防：正確 positioning、教家屬不要拉手、避免 overhead pulley、early PROM。**」
- 第三步：「**已痛了，分流：哪一條 dominant？看姿勢、ROM、痛的性質、subluxation gap、神經學徵象。**」
- 第四步：「**Spasticity 主導 → Botox。Subluxation 主導 → NMES + sling + positioning。Capsulitis → hydraulic distention。Neuropathic → TCA / pregabalin。CRPS → 完整 pathway。**」
- 第五步：「**Overhead pulley 是 IIIC，不要做。Sling 不 routine，high-risk 時段才用。**」
- 第六步：「**Multidisciplinary 才會贏：PT、OT、physiatrist、pain specialist、有時神經科 / 骨科。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 五條病因 + 對應 dominant-feature 分流 — 能用一張表講清 → ✅
- 預防（positioning、不拉手、避免 overhead pulley、early PROM）— 能講 → ✅
- AHA/ASA 主要 evidence levels（Botox IIaA、NMES IIbA for subluxation、neuropathic pain meds IIaA、overhead pulley IIIC、subacromial steroid IIbB、tenotomy IIbC）— 能背 → ✅
- 但 **「CRPS 在 stroke 後的早期辨識與最佳介入時機」** 我目前只能講「skin / autonomic + MCP compression + 完整 pathway（steroid / bisphosphonate / mirror / stellate block）」，更具體的 phenotype-specific approach 還沒整理通 → 標為[理解缺口](#理解缺口) 的優先補強項。
- **「Implantable peripheral nerve stimulator vs surface NMES 的 candidate selection」** 我自己沒整理過 → 同上。
