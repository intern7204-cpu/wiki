# 跑者膝部疼痛

## 一句話定義

跑者膝部疼痛是 **region-based differential diagnosis problem**；臨床重點是依 pain location、load history 與 functional exam 先做分流，再決定要進哪個單病種頁。

## 核心概念

### 先用 pain region 分組

- anterior：PFP、patellar tendon、fat pad、PF OA
- lateral：ITBS、lateral meniscus、popliteus、biceps femoris insertion
- medial：meniscus、pes anserine、MCL、medial compartment overload
- posterior：Baker cyst、hamstring / gastrocnemius / popliteus、referred pain
- inferior / superior：patellar tendon、quadriceps tendon、apophysitis

### 跑者常見放大因子

- mileage jump
- speed / hill / downhill 增加
- dynamic valgus
- contralateral pelvic drop
- hip / core control 不足
- footwear / surface 變化

### PFP 與 ITBS 是高頻，但不能吃掉其他 differential

- anterior knee pain 常見 PFP，但不是所有 runner knee pain 都是 PFP。
- lateral knee pain 常見 ITBS，但也不能忽略 meniscus、popliteus 或 referred source。

## 臨床或研究上的重要性

- 這頁是 runner knee complaint 的入口頁。
- 能避免一開始就被俗稱「runner's knee」綁成單一 diagnosis。

## 評估方式

### history 重點

- pain exact location
- load change 與 symptom time course
- recent shoes / orthotics / surface、downhill / hill block、prior injury / adherence
- impact tolerance、squat、stairs、sitting、turning
- swelling、locking、instability、night pain、rest pain

### physical examination 重點

- 先看 standing posture、single-leg stance、walking 與 squat，再進局部 knee exam。
- inspection、palpation、ROM、effusion
- single-leg squat / step-down
- dynamic valgus、pelvic drop、trunk control
- hip、foot / ankle、core 與整條 kinetic chain 都要看

### imaging 原則

- 影像應回答具體問題，不是 routine 起手式。
- trauma、effusion、instability、persistent atypical pain 或 diagnostic uncertainty 才提高 imaging 門檻。

## 治療原則

### 共同 rehab 主軸

- irritability reduction 與 load modification
- nonimpact cross-training 可在不能跑時維持 conditioning
- hip / core / lateral stabilizer strengthening
- neuromuscular reeducation
- 漸進增加 knee load
- 視 diagnosis 加入 plyometric 與 return-to-run progression

### 不同 diagnosis 要走不同頁面

- anterior pain pattern：看 [[Patellofemoral_Pain]]
- lateral knee pattern：看 [[Iliotibial_Band_Syndrome]]
- superior patellar / anterior thigh pattern：看 [[Quadriceps_肌肉與肌腱傷害]]
- 若非典型或高風險：先擴大 differential，不要硬分流到單一 overuse page

## 臨床決策點

### 反對論點

- 「跑者膝痛多半就是 PFP。」
- 「special test 陽性就夠診斷。」
- 「先照影像再說。」

### 反駁

- runner knee pain 的 differential 很廣，pain region 與 load pattern 比單一俗稱更重要。
- 很多 overuse knee special test 診斷力有限，不能脫離臨床情境單獨使用。
- 影像不是分流的起點，history 與 functional exam 才是。

### 結論

- 跑者膝部疼痛 的第一步應是 **區域化 differential + kinetic-chain evaluation + selective escalation**。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- Runner knee pain is a region-based differential problem, not a single diagnosis.
- Special tests for overuse knee pain have limited diagnostic power when used in isolation.
- Imaging should follow risk stratification and diagnostic uncertainty rather than routine ordering.

- 當病人只說「跑步膝蓋痛」，先用這頁把 pain region、load pattern 與 risk 分流清楚。
- 分不清前，不要急著開一套 generic knee exercise。
