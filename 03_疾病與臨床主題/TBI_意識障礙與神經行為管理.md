# TBI 意識障礙與神經行為管理

## 一句話定義

severe TBI rehabilitation 的主軸之一，是用 structured assessment 分清 disorders of consciousness 與 neurobehavioral complication，因為這兩類問題都會直接改變 rehab participation。

## Definition and Boundary

- 這個 concept 聚焦在 coma、unresponsive wakefulness syndrome、minimally conscious state、posttraumatic confusional state 與相關 neurobehavioral issue。
- 它不是只把 TBI 當成 CT 或 GCS 的急診診斷問題。

## Fact

- severe TBI rehabilitation 從 acute care 就開始，包含 complication prevention、positioning、splinting、ROM、stimulation planning 與 family guidance。
- minimally conscious state 的誤判率高，因此需要 structured bedside assessment。
- 章節整理 DoC 狀態分類，並指出 amantadine 在 severe TBI neurorecovery / DoC management 中具臨床重要性。
- agitation、PSH、sleep-wake disturbance、pituitary dysfunction、vision problem 都常直接干擾 rehab participation。
- Reina-Guerra 章節將 coma、vegetative state、minimally conscious state、posttraumatic confusional state 放進 phase of recovery / care environment / assessment tool 的連續表。
- PTCS 的 core features 包含 disorientation、attention impairment、memory encoding / recall impairment、fluctuation；associated features 可包含 agitation、hypoactivity、irritability、impulsivity、disinhibition、aggression、affective lability、sleep-wake disturbance、delusions、illusions、hallucinations、confabulation。
- DoC 介入重點包含 secondary complication prevention、spasticity / contracture management、upright positioning、pain observation、seizure vigilance、environmental control 與 carefully selected sensory stimulation。
- RLA I-II 的 examination 以 body functions 為主；RLA III 開始觀察 consistent response；RLA IV-VI 的 agitation / confusion 會直接決定 examination and intervention。

## Mechanism Chain

```text
Severe TBI
→ altered consciousness + neurobehavioral complication
→ participation barrier and misclassification risk
→ phase-specific structured assessment
→ secondary complication prevention + arousal / behavior / sleep / pain / seizure / environment management
→ participation readiness
```

## Inference

- 若只靠非結構化印象判斷「病人沒反應」或「只是躁動」，很容易漏掉可恢復的意識狀態與可處理的 participation barrier。
- RLA level 應被用來調整 examination and intervention，不只是拿來描述病人「現在第幾級」。
- 對 MCS 或無法清楚表達者，pain、seizure、orthostasis、spasticity、環境刺激與 sleep-wake disruption 都可能被誤讀成單純 agitation 或 nonparticipation。

## Assumption

- 團隊能持續追蹤 consciousness state 與 neurobehavioral change，而不是只看單次觀察。

## Uncertainty

- endocrine dysfunction prevalence 可觀，但 acute admission 並非對所有病人一律普篩。
- sensory stimulation 在臨床常用，但系統性回顧未能建立強證據；限制主要來自研究品質、設計差異與 outcome measures 不一致。
- DoC standards of care 與 intervention effect 仍有證據缺口；臨床仍需整合 best available evidence、clinical expertise 與合理照護義務。

## Clinical Use

- severe TBI 病人在 rehab participation 突然變差時，要同時想 consciousness、agitation、sleep、PSH 與 endocrine 問題。
