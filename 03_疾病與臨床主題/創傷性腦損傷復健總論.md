# 創傷性腦損傷復健總論

## 一句話定義

TBI rehabilitation 的核心是把 **injury severity、disorders of consciousness、neurobehavioral syndrome、secondary complications 與 long-term participation goals** 放進同一條照護路徑。

## 核心機制

### Acute 到 postacute 的主軸

- severe TBI：salvageable 病人需注意 ICP / cerebral perfusion / secondary injury control。
- PM&R 在 acute stage 就要介入 positioning、ROM、splinting、prevention of contracture、stimulation planning、family education。
- mild TBI：重點是正確診斷、追蹤 persistent symptoms、return-to-learn / return-to-play / return-to-work 分級規劃。
- moderate to severe TBI rehab 應用 [[TBI_ICF照護連續體與Task_Analysis]]：先判斷 phase of recovery，再把 body functions、activity、participation、environmental / personal factors 串成目標與 intervention。
- Primary injury 是 initial mechanical insult；secondary injury 是隨後 minutes-to-hours 的 biochemical、cellular、physiologic cascade，例如 ICP、hypoxia / ischemia、hemorrhage、seizure、infection、neuroinflammation。
- Prognosis 不可只靠單一 GCS；需結合 age、pupillary reactivity、CT abnormalities、secondary insults、duration of coma、PTA、Time to Follow Commands、prior function、support system、rehab access 與 early recovery trajectory。

## 臨床表現

### Disorders of Consciousness

- 主要狀態包括 coma、unresponsive wakefulness syndrome、minimally conscious state、posttraumatic confusional state。
- bedside 誤判率不低，需使用 structured behavioral assessment。
- amantadine 在 severe TBI neurorecovery / DoC management 有重要臨床角色。

### 常見 rehab complications

- posttraumatic seizures / posttraumatic epilepsy
- heterotopic ossification
- spasticity 與 contracture
- paroxysmal sympathetic hyperactivity
- agitation
- sleep-wake disturbance
- pituitary / endocrine dysfunction
- sexual dysfunction / altered sexual behavior
- visual dysfunction、photophobia、tracking / fixation problem、dizziness / imbalance

### 臨床重點

- endocrine dysfunction 雖常見，但 acute hospitalization 不代表所有病人都要一律普篩。
- agitation treatment 應先從環境、結構化日程、刺激控制與行為策略開始，再談藥物。
- sleep management 應先做 nonpharmacologic optimization。
- 「normal study」或「normal imaging」不能直接等於症狀無效或不需追蹤。

## 評估方式

### History / medical record

- Injury mechanism / nature、initial GCS、injury date、age、medical interventions、duration of unconsciousness、stage of consciousness、overall recovery progress。
- Education、family support、living circumstances、preinjury function、comorbid disease、coexisting injuries、complications、caregiver capacity、discharge context。
- Pediatric TBI 要追蹤 developmental demand；早期 physical recovery 不等於日後 school / executive / social function 沒問題。

### Phase-specific examination

- RLA I-II / coma or vegetative state：body functions、joint mobility、tone、positioning tolerance、stimulus-induced/reflexive response、secondary complication risk。
- RLA III / MCS emerging：reproducible but inconsistent response、simple command following、arousal fluctuation。
- RLA IV-VI / PTCS：agitation、confusion、orientation、attention、memory encoding、sleep-wake fluctuation、safety、cooperation。
- Postconfusional / outpatient：functional mobility、ADL/IADL、community mobility、dual-task gait、vestibular symptoms、endurance、fatigue、pain、mood、cognition、participation。

### Measures / task analysis

- Consciousness / behavior / attention：CRS-R、Rancho Los Amigos Levels、ABS、Moss Attention Rating Scale、GOAT / COAT / PTA measures。
- Basic function：FIM / FAM、Barthel Index、WeeFIM。
- Mobility / balance：6-minute walk test、10 m walk test、Berg Balance Scale、Community Balance and Mobility Scale、HiMAT、Functional Gait Assessment。
- Participation / quality of life：Community Integration Questionnaire、DRS、QOL / satisfaction measures，依臨床問題選用。
- Activity limitation 要做 task analysis：先觀察 task performance，再推估真正限制活動的 body-function impairment；不要假設改善 isolated impairment 一定改善 activity。

## 治療原則

### Acute / ICU / trauma center

- 主要目標是 preservation of life and neural tissue、secondary complication prevention、early mobility、DoC arousal / awareness support。
- 介入前確認 activity order、vital sign / ICP range、lines / drains / ventilator / craniectomy precautions、spine / weight-bearing / aspiration / behavior / seizure precautions、lab values、staffing and equipment。
- 所有設定都要預防 pneumonia、pressure sores、adaptive shortening、disuse atrophy、HO、contracture、DVT。

### Step-down / inpatient rehabilitation

- 目標轉向 mobility、meaningful interaction、functional mobility、ADL、safety、appropriate interaction。
- Cognition / behavior management 需要 consistency、repetition、orientation cue、memory strategy、communication support、behavior strategy；PT/OT/SLP/nursing/psychology 的策略需一致。
- Disorders of consciousness 介入包含 positioning、ROM、splinting / casting if needed、tone management、upright positioning、pain observation、seizure vigilance、graded sensory / environmental stimulation；sensory stimulation 常用但證據品質有限。

### Task-oriented / outpatient / lifelong care

- Motor recovery 以 intense, repetitive, task-oriented training 為主；treadmill / robotic / VR 可作工具，但不能假設優於 dose-matched conventional practice。
- Dual-task training 要根據病人生活角色和環境需求設計；直線 gait speed 正常不代表 community mobility 安全。
- Vestibular / visual-vestibular symptom 不應漏查；TBI 後可有 peripheral、central 或 mixed vestibular pathology。
- Aerobic exercise 可支持 health、mood、sleep、cognition 與 secondary prevention，但 acute timing / intensity 要謹慎，避免在 metabolically vulnerable stage 過度訓練。
- Chronic TBI 需要 periodic reassessment and lifelong support，追蹤 exercise、sleep、mood、pain、cognition、endurance、community participation、caregiver burden 與 return-to-school/work。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「CT 正常、沒有明顯出血，就不算真正的腦損傷。」
- 「GCS 分數已經說明輕中重，後續功能大致就知道了。」

### 反駁

- mild TBI / concussion 是臨床診斷，不需要 CT 異常才能成立。
- GCS 對 acute triage 很重要，但對 heterogeneity 與長期功能預後的解釋力有限。
- PTA、coma duration、pupillary reactivity、midline shift、DoC status、behavioral recovery 都會改變預後判讀。
- task analysis 可避免把 rehab 變成 isolated impairment checklist；skill learning 需要 whole-task, context-specific practice。

### 結論

- TBI 必須被視為 **動態功能性診斷**，不是單靠初始 CT 或單一 GCS score 就能結案。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- GCS-based mild/moderate/severe labels remain standard but inadequately capture injury heterogeneity and prognosis, so severity labels should not substitute for longitudinal functional assessment.

## 理解缺口

- 創傷性腦損傷復健總論 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- VR、robotic gait、NBS、sensory stimulation、aerobic exercise timing / intensity 等 intervention 的 TBI-specific evidence 仍需分開追蹤。
- pediatric TBI 的長期 developmental / school / participation outcome 需要 periodic reassessment。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 創傷性腦損傷復健總論 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
