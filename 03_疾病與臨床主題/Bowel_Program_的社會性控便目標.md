# Bowel Program 的社會性控便目標

## 一句話定義

NBD bowel program 的核心目標不是單純排便，而是建立可預測、可接受、time-efficient 的 social continence。

## Definition and Boundary

- social continence 是 participation-level goal。
- 它不是只看 stool frequency 或「有排出來就算成功」。

## Fact

- 本章明確把 social continence 視為重要功能目標。
- supraconal / reflexic pattern 與 infraconal / hyporeflexic pattern 需要不同策略。
- 評估要問 timing、technique、time burden、incontinence、pain、medication、premorbid bowel habit，並搭配 bowel diary、stool form、腹部與肛門直腸檢查。
- treatment 是 stepwise pyramid：從 schedule、oral / rectal medication、digital technique，到 transanal irrigation、ACE、colostomy。

## Mechanism Chain

```text
Lesion pattern
→ bowel program design
→ predictable evacuation with acceptable burden
→ social continence and participation
```

## Inference

- bowel program 的成敗應用 predictability 與 care burden 來衡量，而不只是排便次數。

## Assumption

- patient 或 caregiver 有能力持續執行固定程序，且 program 會隨 aging / disease progression 調整。

## Uncertainty

- 本章沒有提供所有 pattern 的單一最佳 regimen；實際配置仍需反覆微調。

## Clinical Use

- 若 bowel care 很耗時或常失禁，即使 technically 有排便，也代表 program 還沒成功。
