# 高海拔肺水腫

## 一句話定義

高海拔肺水腫（high-altitude pulmonary oedema, HAPE）是 **未經 acclimatization 的人在快速上升到 >2500–3000 m 後，因 hypoxia 引發 patchy 過強 pulmonary vasoconstriction → 局部 capillary stress failure → non-cardiogenic、non-inflammatory 的肺水腫**，未治療死亡率近 50%，及時下撤 + 氧氣可降到 < 3%。

## 已知

- 發生率隨海拔、上升速度、運動量與個體 susceptibility 而變；**個體易感性**是強預測因子（再次上升復發率 50–70%）。
- 多在抵達高海拔後 **2–4 天內**發病，主要在 **夜間**。
- **未治療死亡率 ~50%；治療得當時 < 3%**。
- 與 [[急性高山症]] 與 [[高海拔腦水腫]] 可共存，但機制不同，三者不是同一條進展軸。
- 經典臨床三聯：**運動耐力突降 + 乾咳/粉紅泡沫痰 + 休息時 dyspnoea + hypoxia**。
- 影像（CXR）顯示 **patchy** 浸潤，常從右中肺野起，**不是經典的 batwing 心因性肺水腫**。

## 核心機制

### 不是單純 cardiogenic edema

- **PCWP 正常**、**LV 功能正常**。
- 病理重點不在「壓力把水擠出血管」，而在「血管自己破」。

### 過強且不均勻的 Hypoxic Pulmonary Vasoconstriction (HPV)

- HPV 在所有人都會發生（hypoxia → 局部血管收縮以匹配通氣不良區域），是 normal 的氣體交換調控。
- HAPE 易感者：**HPV 反應過度且 patchy**。原本應均勻的 vasoconstriction 變成「有些區域強烈收縮 + 有些區域幾乎沒收縮」。
- 結果：未收縮區承擔幾乎全部 cardiac output → 局部 pulmonary capillary 高壓、高流量。

### Stress failure of pulmonary capillaries

- 高流量、高壓加上 endothelium / basement membrane 機械應力 → **capillary stress failure**（structural disruption，不只是 leak）。
- 滲出液富含 protein 與紅血球（hemorrhagic edema），與 cardiogenic edema 的低 protein 滲出液不同。

### 內皮失衡的分子層面

- HAPE-susceptible 個體：
  - **吐氣 NO 濃度較低** → vasodilator 不足。
  - **endothelin-1 較高** → vasoconstrictor 過剩。
  - 對 hypoxia 的 **sympathetic response 較強**。
- 這些不是 inflammation 主導；inflammation 在 severe / late case 才出現，且常因合併下呼吸道感染惡化。

### 為什麼運動會誘發

- exercise → cardiac output 大幅上升 → 通過未收縮區的血流更高 → capillary stress 加劇。
- 這也解釋為什麼 elite 登山者並不豁免，反而因更高 CO 風險更大。

## 臨床表現

### 早期（容易被誤認為 AMS / 體能不佳）

- **運動耐力突然下降**（同一段路忽然喘到不行，是常見第一個訊號）。
- 乾咳、運動時 dyspnoea。
- 休息後恢復比平常慢。
- SpO2 在同海拔下顯著低於同行者。

### 進展期

- **休息時 dyspnoea**（重要警訊：mild AMS 不會休息時喘）。
- 咳嗽變濕、出現粉紅色或血絲泡沫痰。
- 聽診聞 crackles，常從 **右中肺野** 開始。
- 心搏過速、呼吸過速、發紺。
- **意識通常清楚** —— 若意識變化，要警覺合併 [[高海拔腦水腫]]。

### 影像

- CXR：**patchy, often asymmetric** 浸潤；無 cardiomegaly、無 Kerley B lines、無經典 batwing。
- 超音波：B-lines 增多，可在山區用 portable device 早期偵測。

## 評估方式

### 高山現場「夠用就好」的辨識

- **三問**：
  1. 上升速度與最近睡眠海拔？
  2. 休息時會喘嗎？SpO2 比同伴低多少？
  3. 咳嗽？痰的顏色？

- **三看**：
  1. 走幾步後 SpO2 是否大幅下降？
  2. 聽診右中肺是否聞到 crackles？
  3. 有沒有 ataxia 或意識變化（合併 HACE 警訊）？

### 影像不是現場必要

- 若有 portable echo / lung US：B-lines 與 PASP 可量化追蹤，但不是診斷必要。
- CXR 只在能下撤到醫療據點時做；在山上不能用「沒有 CXR 不能下診斷」拖延處置。

### 鑑別診斷

- 下呼吸道感染（pneumonia、bronchitis）：發燒、局部化症狀、白血球變化。
- 心因性肺水腫：PCWP 高、LV 衰、JVP 升高、symmetric edema。
- 過度通氣 / 焦慮：SpO2 通常正常或偏高。
- Pulmonary embolism：突發、單側胸痛、心搏過速但聽診常乾淨。

## 治療原則

### 第一線：下撤 + 氧氣

- **任何 HAPE 疑慮 → 立即下撤 + 給氧**，這兩者沒有「擇一」。
- 下撤 500–1000 m 通常就能戲劇性改善。
- 若下撤受地形或天候限制 → **portable hyperbaric chamber（Gamow bag）** 模擬下撤 2000 m，作為橋樑。

### 藥物（輔助，不是替代下撤）

- **Nifedipine SR 30 mg BID**（或 20 mg q8h）：calcium channel blocker → 降低 pulmonary arterial pressure。是 HAPE 治療與預防的經典藥。
- **Sildenafil / Tadalafil**：PDE5 inhibitor → 選擇性肺血管擴張。已證實能降 hypoxia 引起的 PASP，作為 HAPE 治療的新興選項。
- **Acetazolamide / Dexamethasone**：對 HAPE 本身效果有限；若合併 [[急性高山症]] / [[高海拔腦水腫]] 才併用。
- **Diuretics 與 morphine 不是 first-line**（與 cardiogenic edema 不同，volume status 通常並未過剩；morphine 會抑制 ventilation 反而有害）。

### 機械性支持

- 持續氧氣維持 SpO2 > 90% 為目標。
- 重度時可考慮 CPAP / NIV：減少呼吸功 + 改善 V/Q。
- ICU 級別處置只在無法下撤、合併重度 ARDS-like 後期才需要。

### 預防（給高風險者）

- **慢上升 + 良好 acclimatization**：絕對是最重要的。
- 高風險（既往 HAPE 病史）：**Nifedipine SR 30 mg BID** from 24 hr 上升前到抵達最高睡眠海拔後 5 天。
- **Sildenafil / Tadalafil**：作為 nifedipine alternative。
- Salmeterol（β2 agonist 增強 alveolar fluid clearance）：證據較弱，不是常規。

## 臨床決策點

### 「這是 HAPE 還是體能不佳？」

- **Resting dyspnoea + 同海拔 SpO2 顯著低於同伴 + 咳嗽**這三個一起出現 → 不是體能問題。
- 給氧 5–10 分鐘後 SpO2 戲劇性回升 + 症狀緩解 → 高度符合 HAPE。

### 「藥物能不能取代下撤？」

- **不能**。藥物縮短時間、降低死亡率，但只要還在 hypoxia 環境，誘因持續存在。在野外只用 nifedipine 不下撤 = 玩命。

### 「之後還能不能再回高海拔？」

- 既往 HAPE 病史 = **個體 susceptibility**，再上升復發率高。
- 不是絕對禁忌，但必須：
  - 慢得多的 ascent profile。
  - 預防性 nifedipine 或 tadalafil。
  - 個體化 risk-benefit 討論（特別是工作型登山者）。

### 反對論點與反駁

- 「先觀察看看，明天看會不會自己好。」 → HAPE **夜間死亡率最高**，等到清晨再下撤可能來不及。
- 「沒 CXR 不能診斷。」 → 在野外 clinical + SpO2 + 聽診 + 治療反應就能下診斷；CXR 是事後確認。

## 限制與未定論

- **HAPE-susceptible 的 biomarker**（NO、endothelin、HIF 路徑變異）尚無 prospective 可用的臨床測試。
- **Sildenafil / Tadalafil 治療 HAPE 的相對效力與 nifedipine 比較**：證據較少，多數來自 prevention trial 與肺動脈高壓族群外推。
- **Inflammation 的角色**：到底是 trigger 還是 amplifier？目前共識是 amplifier，但部分動物模型暗示在某些 phenotype 是 trigger。
- **兒童 HAPE** 與 **re-entry HAPE**（高海拔居民暫時下山再回來發病）的辨識指引較少，可能被低估。

## 理解缺口

- **為什麼 HPV 在 HAPE 易感者是 patchy？** 是 vascular 結構差異還是 endothelial signaling 差異主導？
- **NO supplementation（吸入或飲食前驅物）** 的真實臨床效益還在不一致。
- **HAPE 後的 long-term pulmonary vascular consequences**（chronic PH？）還缺長期追蹤資料。
- **portable lung ultrasound B-lines 的早期 cut-off** 在不同海拔還沒標準化。

> 標記為下一輪要補的方向：HAPE biomarker 研究進度、Sildenafil vs Nifedipine head-to-head trial、re-entry HAPE。

## 臨床使用版

- 教住院醫師時，先說一句：「**HAPE 不是心因性肺水腫，是肺血管收縮太兇、收縮太不均勻，把毛細管壓爆了。**」
- 第二步：「**辨識三聯：休息時喘 + SpO2 比同伴低 + 咳嗽（甚至粉紅泡沫痰），夜間最危險。**」
- 第三步：「**處置兩件事：下撤、氧氣。藥（nifedipine、sildenafil）是 buffer，不是替代。**」
- 第四步：「**Diuretic、morphine 在這裡不是朋友。**」
- 第五步：「**有過 HAPE 的人，下次上去要慢、要預防性吃藥。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 「為什麼 PCWP 正常還會肺水腫」這個典型 board 題 — 能用 patchy HPV + stress failure 兩句講完 → ✅
- 「現場怎麼判斷 vs pneumonia」 — 能用 fever、locality、治療反應差別講完 → ✅
- 但 **「HAPE-susceptible 與 normal HPV 反應的具體血管 phenotype 差異」**目前我只能說「NO 少、ET-1 高、交感強」這個層次，更深的分子機制我自己沒讀通 → 標為[理解缺口](#理解缺口) 的優先補強項。
