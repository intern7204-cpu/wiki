# PM&R 評估總論

## 一句話定義

PM&R assessment 的任務是回答三件事：**病灶在哪裡、它如何限制功能、要怎麼把這些限制轉成可執行的 rehabilitation plan**。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### 常用 intervention framing

- prevention / correction of additional disability
- enhancement of affected systems
- enhancement of unaffected systems
- adaptive equipment
- environmental modification
- psychological techniques 與 patient / family education

### 臨床重點

- 同一 diagnosis 在不同 home / work / school context 可能代表完全不同 rehabilitation priority。
- diagnosis 清楚但 functional formulation 不清楚，計畫仍然會失敗。
- 反過來說，完全沒有 lesion localization 也會讓 plan 漂浮；兩者都需要。
- 對 TBI、stroke、SCI、amputation 這類多系統診斷，PM&R H&P 更需要把 acute medical risk 與 long-term participation 放在同一張 problem list。

## 評估方式

### History 的核心

- chief complaint 要用病人語言描述，但最後要翻譯成 impairment / activity / participation 問題。
- HPI 除 symptom timing / severity 外，必須補 functional status：mobility、ADLs、IADLs、communication、cognition、work、recreation。
- psychosocial / environmental history 不是附錄；home accessibility、caregiver support、substance use、sexuality、finances、return-to-work 都會改變 plan。

### Physical examination 的核心

- neurologic exam 要定位 lesion、區分 UMN / LMN、辨識 organic pattern 與 nonorganic inconsistency。
- musculoskeletal exam 要找 pain generator、ROM、joint stability、secondary complication 與 movement strategy。
- gait exam 是整合輸出，至少要看 sit-to-stand、balance、walking speed、step / stride、arm / leg posture、tandem / heel / toe walking。
- bedside 組織方式要標準化；MMT、superficial / primitive / deep tendon reflexes、common gait disturbance tables 可降低遺漏與描述漂移。

### 評估輸出

- 輸出不是只有 diagnosis，而是 medical problem list + functional problem list。
- 每個問題都要對應 precaution、treatment target、assistive technology、環境調整與 team referral。
- 目標要分 short-term 與 long-term，並清楚說明時間框架。
- orthosis、wheelchair/seating、assistive technology、exercise prescription 常是 assessment 後的直接處方輸出，不應留到最後才想。
- 當議題牽涉 workability、return to work、formal impairment/disability documentation 時，評估輸出還要說清楚工作需求、限制、功能證據與醫師角色邊界。

## 治療原則

- 目前頁面尚未整理出 Non-pharmacologic、Pharmacologic、Injection / procedure、Rehabilitation program 的決策順序。

## 臨床決策點

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

- 目前頁面尚未明確寫出證據限制、教材未講清楚處或不同來源可能衝突之處。

## 理解缺口

- PM&R 評估總論 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 PM&R 評估總論 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
