# 下肢義肢 K Level 處方邏輯

## 一句話定義

K-level 是下肢義肢組件選擇的重要骨架，但不能脫離 residual limb、skin、balance、vision、hand function 與真實目標單獨使用。

## Definition and Boundary

- 這個 concept 聚焦在 prosthetic prescription 的 functional classification logic。
- 它不是把 K-level 當成唯一決策器，也不是把較遠端截肢一律視為較好。

## Fact

- 本章指出 partial foot 不必然優於 transtibial，因為 deformity、prosthetic difficulty 與 skin problem 可能讓結果更差。
- preprosthetic phase 的 wound healing、edema control、ROM 與 contracture prevention 會直接影響後續 fit 與 energy cost。
- K-level / Medicare Functional Classification 仍是 prosthetic component 選擇的重要骨架。
- socket、interface、suspension、foot / knee unit 應同時考慮 skin quality、balance、vision、hand function、goal 與 durability。

## Mechanism Chain

```text
Residual limb and baseline function
→ K-level estimate
→ component / socket matching
→ gait efficiency and skin tolerance
→ long-term prosthetic function
```

## Inference

- 保留較長殘肢本身不是目標；若 soft-tissue coverage 與 fit 失敗，功能可能反而更差。

## Assumption

- K-level 會隨恢復、去條件化與併發症變動，因此不是一次評估後永遠不變。

## Uncertainty

- 本章承認 TMR、RPNI、AMI、osseointegration 等新技術重要，但未把它們視為所有個案的標準答案。

## Clinical Use

- 開義肢處方時，先寫 functional classification，再回頭檢查 socket 與 component 是否真的相配。
