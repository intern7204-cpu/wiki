# 急性高山症

## 一句話定義

急性高山症（acute mountain sickness, AMS）是 **未經 acclimatization 的人，在快速登上 >2000–2500 m 後出現的一組以「頭痛 + 至少一個全身性症狀（噁心、疲倦、頭暈、睡不好）」為核心的臨床症候群**，其本質是 hypobaric hypoxia 對腦部與全身代謝的早期反應，重點不在海拔多高，而在「上升多快、睡多高、原本撐多少」。

## 已知

- 症狀通常在 >2000 m（6600 ft）後開始，>4500 m（14760 ft）發生率明顯陡升，約一半 trekker 會發病。
- 主要風險因子：**absolute altitude（特別是睡眠海拔）、rate of ascent、exertion 量、individual susceptibility**。
- AMS 是一個 **譜系（spectrum）**：輕度只是頭痛 + 身體不舒服 → 嚴重時會進展到 [[高海拔腦水腫]] 或合併 [[高海拔肺水腫]]。
- 抽菸者在到達高海拔的前幾天 AMS 發生率較低，但抽菸本身會 impair long-term acclimatization。
- Lake Louise questionnaire 是研究與臨床上最常使用的標準化量表。

## 核心機制

### 起點：barometric pressure 下降 → inspired PO2 下降

- altitude 上升 → barometric pressure 下降。
- `FiO2` 仍 0.21，但 `inspired PO2 = 0.21 × (Pb − 47 mmHg)` 直接被拉低。
- alveolar / arterial PO2 跟著下降，整條 [[oxygen transport chain]] 被往下推。

### 急性反應：hypoxic ventilatory response 不夠強

- 初期 hypoxia 刺激 ventilation，但因為 hypocapnia + hypoxic ventilatory decline，30 分鐘內 ventilation 會回落到只略高於 normoxic baseline。
- 結果是顯著 arterial hypoxaemia 持續存在，這就是早期幾小時到幾天 symptom load 的生理基礎。

### 大腦端的機制

- hypoxia 直接抑制 cortical function。
- hypocapnia 引起 cerebral vasoconstriction，又加深局部 cerebral hypoxia。
- 部分病人有 mild cerebral oedema，未達 [[高海拔腦水腫]] 的程度，但已經足以產生頭痛、噁心與認知遲鈍。

### 睡眠期惡化

- >4000 m 多數人會出現 periodic breathing（中樞型 apnoea），夜間 SaO2 進一步下降，所以 **睡眠海拔比白天活動海拔更關鍵**。
- 這也是為什麼「climb high, sleep low」是 AMS 預防的核心口訣。

## 臨床表現

### 主症狀（Lake Louise 必要條件）

- **Headache**（必要） + 至少一項：
  - Gastrointestinal（食慾不振、噁心、嘔吐）
  - Fatigue / weakness
  - Dizziness / lightheadedness
  - Difficulty sleeping

### 嚴重度分級（Lake Louise 1991 score 經典版）

| Lake Louise score | 嚴重度 | 處置原則 |
| --- | --- | --- |
| ≤ 4 | mild | 不需下撤；rest + hydration + 對症藥物 |
| ≥ 5 | moderate / severe | 考慮藥物治療；持續惡化或出現 ataxia / 意識變化即下撤 |

### 警訊：已不再是「單純 AMS」

- ataxia（heel-to-toe walk 失敗） → 高度懷疑 [[高海拔腦水腫]]。
- 休息時 dyspnoea、咳嗽、咳粉紅色泡沫痰 → 高度懷疑 [[高海拔肺水腫]]。
- 上述兩者都屬 life-threatening，**不適用 mild AMS 的 watch-and-wait**。

## 評估方式

### 病史聚焦

- absolute sleeping altitude 與 rate of ascent（每天爬升 m 數，特別是 sleeping altitude 增加幅度）。
- 既往 AMS / HAPE / HACE 病史 → 強烈 individual susceptibility 訊號。
- 是否有上呼吸道感染、脫水、過量酒精或鎮靜劑（會加重）。

### 床邊評估

- Lake Louise questionnaire 計分。
- **Heel-to-toe gait** 測 ataxia → 篩 HACE 的快速床邊測試。
- 聽診（爆裂音）、SpO2（同海拔基準下顯著偏低）、呼吸頻率 → 篩 HAPE。
- 神經學：意識、定向感、認知遲緩。

### 不需要的檢查

- 在山區現場，**影像不是 first-line**。臨床表現 + 海拔脈絡 + 對下撤/oxygen 的反應就足以判斷主要決策。

## 治療原則

### Mild AMS（Lake Louise ≤ 4）

- **不需強制下撤**：在原海拔休息、避免再上升 24 小時、補水、止痛（acetaminophen / NSAID）、止吐。
- 多數 case 隨 acclimatization 在 1–3 天緩解。

### Moderate–Severe AMS（Lake Louise ≥ 5）

- **Acetazolamide** 125–250 mg PO BID（治療劑量）：carbonic anhydrase inhibition → 腎排 bicarbonate → 代謝性酸中毒 → 刺激 ventilation。
- **Dexamethasone** 4 mg PO/IM/IV q6h：機制不完全清楚，可能 sympatholysis、anti-inflammatory、reduce ROS、attenuate HPV；對症狀緩解快，但**不加速 acclimatization**，停藥後可能 rebound。
- 若惡化或合併神經學徵象 → 立即下撤。

### 任何形式的 severe altitude illness（HAPE / HACE 疑慮）

- **Oxygen + Descent**：兩個都是必要，不是擇一。
- 可用 **portable hyperbaric chamber（Gamow bag）** 模擬下撤約 2000 m，作為等待真實下撤的橋樑。

### 預防

- **Slow ascent**：>3000 m 後每天 sleeping altitude 上升 ≤ 300–500 m，每 1000 m 加一個 rest day。
- **Acetazolamide 125 mg PO BID** 預防：上升前 24 小時起，到達最高睡眠海拔後 48 小時停。
- 高風險者（既往 HAPE）可加 **Nifedipine SR 30 mg BID** 預防 [[高海拔肺水腫]]。

## 臨床決策點

### 「能不能繼續上升？」

- Mild AMS + 症狀穩定 → 在原海拔再休息 1 天，可以繼續。
- 任何 ataxia / dyspnoea at rest / 意識變化 → **不要再上升，立即下撤**。

### 「現在就要下撤嗎？」

- 用「治療反應」替代過度測量：給氧 + 休息 + 藥物後，30–60 分鐘內症狀**沒改善或惡化** → 下撤。
- 夜間出現新的 ataxia 或 SpO2 大幅下降 → 即使天黑也應啟動下撤計畫。

### 「該不該預防性吃 acetazolamide？」

- 過去有 AMS 病史、預計快速上升（飛機/車到 >3000 m 後直接睡）、高風險工作（救難、軍事）→ 應預防。
- 慢速登山、過去 acclimatize 順利者 → 預防不是必須。

### 反對論點與反駁

- 「AMS 只是高山感冒，扛一下就好。」 → 確實多數 mild case 可自限，但 **5–10% 會進展**到 HAPE/HACE，第一批徵象（ataxia, severe dyspnoea）就是不可逆的時鐘起點。
- 「給氧就好，不必下撤。」 → 給氧只是 buffer；只要還在海拔，誘因就還在，下撤是唯一移除病因的處置。

## 限制與未定論

- **個體易感性**目前沒有可靠 biomarker 或 prediction rule，仍以「過去病史」為主。
- **Hypoxic ventilatory response (HVR)** 高低與 AMS 風險的關聯方向**不一致**：高 HVR 者 ventilation 多但 hypocapnia 也重；低 HVR 者 hypoxia 較深 → 兩端都可能有風險。
- **Dexamethasone 是否能取代 acetazolamide 作為一線預防**仍有爭議；目前共識是 dexamethasone 副作用譜較廣，僅在 sulfa allergy 或 acetazolamide 無法使用時優先。
- AMS、HAPE、HACE 三者的 **共同 vs 分流機制**仍未完全釐清；HACE 與 severe AMS 的界線是 spectrum 還是不同實體尚有爭議。

## 理解缺口

- **能不能用 sea-level 一個簡單測試（HVR、心肺反應）預測誰會在 4500 m 發病？** 目前無臨床可用版本。
- **periodic breathing 的嚴重度與 AMS 嚴重度的因果方向**：誰先誰後？
- **acetazolamide 的 ventilation 刺激效應 vs 直接腦/CSF 機制**何者主導 AMS 預防？
- **小孩 AMS 的辨識**：症狀與成人不一致（哭鬧、食慾差），但缺乏可靠 paediatric Lake Louise。

> 標記為下一輪要補的方向：兒童 AMS 評估、acetazolamide 的多重機制比重、AMS 的 biomarker 研究進度。

## 臨床使用版

- 教住院醫師時，先說一句：「**頭痛 + 一個其他症狀 + 最近上山，先想 AMS。**」
- 第二步：「**要不要下撤，看的不是分數，是有沒有 ataxia / 休息時喘 / 意識改變。**」
- 第三步：「**藥（acetazolamide / dexamethasone）是 buffer，不是 substitute。下撤 + 氧氣才是治本。**」
- 第四步：「**預防永遠比治療便宜：慢上升、不睡太高、有病史就預防性吃藥。**」

### 「我能不能把這段清楚教給住院醫師？」自我檢查

- 流行病學 + 必要條件 + 警訊 + 處置 + 預防 — 全部能用一張白板講完 → ✅
- 機制（HVR 不足 → hypocapnia → cerebral vasoconstriction → 加深 hypoxia）能用「一條箭頭線」畫完 → ✅
- 但是 **Acetazolamide 為什麼比 dexamethasone 更慢起效但效果更持久**這一段還沒寫到「我覺得我真的懂」 → 標為[理解缺口](#理解缺口) 的優先補強項。
