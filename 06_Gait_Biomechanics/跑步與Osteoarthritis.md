# 跑步與Osteoarthritis

## 一句話定義

跑步與 OA 的關係不能用「跑步傷膝」一句話概括；對多數 recreational runner，**low-to-moderate dose running 未必增加 OA risk，甚至可能有保護性**，但高風險族群仍需個別化分流。

## 核心概念

### 先分清病人是哪一種問題

- 想開始跑，但擔心未來 OA
- 已有 radiographic OA，想知道能不能繼續跑
- 曾有 ACL / meniscus / hip structural injury，怕跑步讓 OA 更快惡化

### 真正會把風險往上推的因子

- obesity
- prior ACL / meniscal injury
- poor biomechanics / conditioning
- heavy occupational load
- high cumulative running dose 或 elite-level exposure

### 對一般 runner 的較合理結論

- recreational / moderate dose running 不應被預設為 harmful
- walk-jog、self-selected dose、cross-training 往往比「完全禁止跑步」更合理

## 臨床或研究上的重要性

- 這頁用來校正常見 OA 恐嚇式敘事。
- 也能幫助運動醫學門診做 shared decision-making。

## 評估方式

### 初診需要的關鍵資訊

- joint-specific symptoms：pain、stiffness、swelling、24-hour response
- prior injury / surgery
- body mass 與 weight trajectory
- running goals、running dose、surface、footwear
- 是否已影響 daily function

### 高風險訊號

- recurrent effusion
- progressive night pain
- recent traumatic event
- rapid function loss
- suspected surgical pathology

## 治療原則

### 較合理的 counseling 路徑

- 低風險且無明顯症狀者：可從低至中等 dose 開始
- symptom-limited OA runner：用 walk-jog、cross-training、strength、load monitoring
- 高風險或 post-traumatic OA：更重視 preconditioning、gait / biomechanics、shared decision

## 臨床決策點

### 反對論點

- 「有 OA 就不該跑。」
- 「跑步一定把膝關節磨壞。」

### 反駁

- 目前較好的說法是：風險與收益取決於 dose、risk profile、症狀與 injury history，而不是只看『有沒有跑』。

### 結論

- 跑步與 OA 的建議應是 **risk-stratified participation counseling**，不是 blanket prohibition。

## 限制與未定論

### frontmatter contradictions

- Recreational running is not synonymous with inevitable osteoarthritis progression.
- Prior joint injury, obesity, and symptom response should drive counseling more than generic fear of running.

## 理解缺口

- 哪一種 OA 患者最適合保留 running，哪一種應改成其他 aerobic modality？
- high-dose running 的風險曲線，還需要哪些更好的 dose definition？

## 臨床使用版

- 當病人把「關節保養」等同「不要跑」時，先用這頁把問題拆回 dose 與 risk profile。
- 但若病人是 post-traumatic high-risk knee，就不能用這頁當鼓勵所有人都跑的理由。
