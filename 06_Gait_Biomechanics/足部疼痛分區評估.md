# 足部疼痛分區評估

## 一句話定義

Foot pain evaluation 最有效率的起點，是先把症狀放進 **forefoot、midfoot、hindfoot** 的解剖區域，再決定 differential 與影像需求。

## 核心機制

- 目前頁面尚未把已知與機制拆開；需回源補成可教學的病理生理或方法原理。

## 臨床表現

### forefoot：球部與前足趾列

- 常見主訴：
  - 「像踩到石頭」要想到 metatarsalgia。
  - burning / radiating pain 要想到 Morton neuroma。
  - 特定鞋子誘發 great toe pain，要想 bunion 或 hallux rigidus。
- 檢查重點：
  - toe deviation、hammer toe、callus、plantar plate flattening、Mulder sign、metatarsal shaft tenderness。
- red flag：
  - acute swelling + focal shaft pain 要排 stress fracture 或 fracture。

### midfoot：足弓與 Lisfranc / navicular 區

- 問題焦點：
  - pain 是 medial arch、lateral midfoot、dorsal 還是 plantar。
  - 是否 landing on outside of foot 會不穩。
- 檢查重點：
  - longitudinal arch、navicular tuberosity / N spot、Lisfranc line、cuboid、base of fifth metatarsal。
- red flag：
  - navicular pain 不應被輕率標成 arch strain。
  - Lisfranc injury、stress fracture、tarsal coalition 要保留。
  - navicular stress fracture、Jones fracture 與 talar dome fracture 屬 high-risk stress fracture / osteochondral concern，若 course、focal tenderness 或 weight-bearing tolerance 不合理，需降低影像與轉介門檻。

### hindfoot：後足與 heel

- 建議用 five-region map：anterior、posterior、medial、lateral、plantar。
- posterior 常見 Achilles-related pain、Haglund deformity、retrocalcaneal bursitis。
- plantar heel 常見 plantar fasciitis，但也要保留 calcaneal stress fracture、fat-pad syndrome、tarsal tunnel。
- anterior / lateral / medial pain 則常與 impingement、peroneal pathology、posterior tibial pathology 或 subtalar problem 有關。

### 臨床重點

- history 要問 activity change、鞋子、夜痛、麻木、體重、systemic disease、近期懷孕或 medication。
- 先看 standing 與 gait，再做 palpation；barefoot 與 in-shoe 觀察都很有價值。
- 若合併 bilateral pain、back stiffness、fever、neuropathy、malignancy history 或 wound，要提高 systemic differential。
- runner 的 foot pain 若忽略鞋況、hindfoot alignment、navicular drop、heel raise 與 first MTP mobility，常會少掉關鍵線索。
- ankle / foot pain 若伴隨 locking、persistent swelling、recurrent sprain、peroneal snapping 或 focal bony tenderness，不應只延續 ankle sprain / plantar fasciitis label。

## 評估方式

### 影像原則

- plain radiograph：先處理 fracture、Lisfranc concern、OA / bossing 等骨性問題。
- ultrasound：可看 tendon / ligament / bursae，但高度依賴 operator。
- MRI：用在 persistent pain、stress injury、coalition、osteochondral or soft tissue ambiguity。

- 目前頁面尚未整理出 Non-pharmacologic、Pharmacologic、Injection / procedure、Rehabilitation program 的決策順序。

## 臨床決策點

### 反對論點 → 反駁 → 結論

### 反對論點

- 「足痛先照 X-ray 或 MRI，比較快。」
- 「heel pain 幾乎就是 plantar fasciitis。」

### 反駁

- location、pain timing、footwear relationship、callus pattern、palpation 與 gait，常常已能把診斷縮小很多。
- heel pain 還可能來自 Achilles insertion、retrocalcaneal bursitis、fat-pad contusion、stress fracture、tarsal tunnel 或 systemic disease。

### 結論

- 足痛先做 **anatomy-based history + exam**，再決定是否需要 radiograph、ultrasound 或 MRI。

- 什麼情況要治療？先看是否真的改變 pain、function、safety、participation 或訓練輸出。
- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
- 什麼情況不該做？當證據不足、機制不合、風險高於預期收益，或結果不會改變決策時。

## 限制與未定論

### frontmatter contradictions

- Foot pain evaluation should not begin with imaging alone; region-based history and examination often narrow the differential first.
- Heel pain is not synonymous with plantar fasciitis, and navicular-region pain should not be casually labeled as generic arch strain.

## 理解缺口

- 足部疼痛分區評估 最容易和哪幾個 mimic / differential 混淆？差異機制是什麼？
- 哪些 bedside finding 真的會改變 treatment threshold，而不是只增加診斷把握？
- 哪些量表或影像異常和功能障礙不一定一致？原因是什麼？
- 目前缺少明確處置順序：何時觀察、何時介入、何時轉介仍需補強。

## 臨床使用版

- 若病人的症狀、檢查與功能限制符合 足部疼痛分區評估 的框架，先用本頁的 History / Physical / red flags 決定是否需要影像、介入或轉介。
- 若只有名詞相像、但機制或時序對不上，先回 differential，不要直接套用診斷與治療。
