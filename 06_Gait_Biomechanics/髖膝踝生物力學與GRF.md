# 髖膝踝生物力學與GRF

## One-Sentence Definition

髖膝踝生物力學的核心，是用 thigh / shank / foot segment kinematics 決定 ground reaction force（GRF）相對於 ankle、knee、hip 的 line of action，進而產生 external joint moments；下肢矯具與鞋具的作用，是把這條力學鏈調到更接近功能目標。

## Definition and Boundary

本頁只處理一個 concept：**lower-limb stance phase 中 segment alignment、GRF 與 joint moment 的關係**。

不處理：

- 全部正常步態週期細節
- 每一種 AFO / KAFO 的完整處方
- 足部疼痛或跑步傷害的 differential diagnosis
- 個別疾病的完整 rehab protocol

這個 concept 的使用場景是：看到 gait deviation、AFO / KAFO / footwear prescription、knee hyperextension、crouch tendency、toe clearance 或 terminal stance instability 時，先問「GRF 通過關節哪一側？外在 moment 是幫忙穩定，還是製造代償？」

## Why It Matters

下肢矯具常被誤解為「支撐弱掉的地方」。這個說法太粗糙。

更精確地說，orthosis-footwear combination 會同時產生：

- direct effect：在被包覆的 segment / joint 上施加 force system。
- indirect effect：改變 foot contact、shank inclination、thigh inclination 與 GRF line of action，進而改變 proximal knee / hip moment。

若只看 brace type，不看 GRF 與 segment alignment，可能出現兩種錯誤：

- over-stabilization：站得住，但 gait progression、energy cost 或 proximal compensation 變差。
- under-stabilization：局部支撐看似足夠，但 midstance / terminal stance 仍無法產生有效 support。

## Preconditions or Conditions

使用此模型前，至少要確認：

- stance phase 的主要問題是 sagittal plane、coronal plane、transverse plane，或多平面組合。
- shank-to-vertical angle（SVA）在 midstance / terminal stance 是否足夠 inclined。
- thigh 是否能同步達到足夠 inclination。
- ankle ROM、gastrocnemius length、hamstring length、hip flexor length 是否限制 segment kinematics。
- footwear heel height、sole stiffness、rocker、pitch 是否已納入處方。
- 目標是 stability、clearance、progression、energy efficiency、pain reduction，還是 contracture prevention。

## Mechanism

### 1. Force、pressure、moment

Force 是物體間的 push / pull。Pressure 是 force 分布到接觸面積後的 tissue load；同樣 force 若接觸面積太小，skin / soft tissue tolerance 會下降。

Moment 是 force 乘上垂直 lever arm。對下肢矯具而言，越能增加有效 lever arm，就越能用較小 force 產生需要的 rotational control。

### 2. Three-point force system

控制單一關節 angular motion 至少需要三個力：一個主要 corrective force，加上兩個 counterforces 形成 equilibrium。

相鄰兩關節同時控制時，counterforces 可重疊共享；因此不一定是「每個關節各三點」的機械相加，而是可以用較少但位置策略化的 force system 控制 hip-knee 或 knee-ankle 關係。

### 3. Segment kinematics 決定 GRF alignment

正常 stance 中，shank 由 initial contact 的 reclined position 逐漸前移到 inclined position，midstance 附近 shank forward progression 會放慢。來源指出，midstance 需要約 10-12 degrees forward shank inclination，並需要 thigh 也達到合適 inclination，才容易讓 GRF 在 knee 與 hip 產生有利的 external extension moments。

鞋跟高度會改變達成 SVA 所需的 ankle dorsiflexion：heel height 越高，需要的 ankle dorsiflexion 可能越少。

### 4. GRF 的三個必要讀法

讀 GRF 不能只說「力變大」；至少要分三件事：

- point of application：GRF 從 foot 的哪個接觸點起始。
- magnitude：垂直分量是否能在 early stance / terminal stance 形成足夠 peaks。
- line of action：相對於 ankle、knee、hip 通過哪一側。

GRF line of action 相對於關節中心的位置，決定 external flexion / extension moment 的方向與大小。

### 5. Midstance / terminal stance 的 hip-knee stability

當 shank 與 thigh 都有合適 inclination，GRF 較容易在 knee 前方與 hip 後方形成 external extension moments。此時 joint stability 主要來自 GRF alignment，而不只是 extensor muscle activity。

Terminal stance 的有效 support 需要 ankle plantarflexion / forefoot loading 將 GRF point of application 推向前足，進而協助 knee 與 hip 產生有利 moment。

### 6. Gastrocnemius contracture 的連動

Gastrocnemius 跨 ankle 與 knee。若 gastrocnemius length 受限，允許過多 ankle dorsiflexion 可能「偷走」 knee extension 所需長度，導致 knee extension 受限或 crouch burden 增加。

在這種情境中，限制 dorsiflexion、採 plantarflexed alignment、加 heel raise 或 heel wedge，可能反而更有利於 knee extension 與 shank alignment。這不是因為 plantarflexion 永遠好，而是因為 biarticular muscle length 與 segment kinematics 必須一起解讀。

## Observable Patterns

| 觀察 | 可能的 biomechanical interpretation | 臨床意義 |
| --- | --- | --- |
| Midstance shank 不夠 inclined | GRF 可能無法形成合適 knee / hip extension moment | 容易 terminal stance instability 或 proximal compensation |
| Midstance shank 過度 inclined | GRF 可能在 knee / hip 產生不利 flexion moments | 可能增加 crouch / knee-flexion burden |
| Thigh 未達合適 inclination | 即使 shank 良好，hip moment 仍可能不利 | 不能只調 ankle / AFO，還要看 hip / trunk / contracture |
| Early stance GRF peak 過高、terminal stance second peak 不足 | 患側 terminal stance support 不足，對側可能 heavy contact | 矯具目標可能是改善 terminal stance stability，而非只限制 foot drop |
| Knee hyperextension | GRF 相對 knee 過度 anterior 或 direct knee control 不足 | 先找 ankle ROM、PF contracture、heel height、AFO-footwear tuning |
| Gastrocnemius contracture + allowed dorsiflexion | ankle dorsiflexion 可能犧牲 knee extension | 需個別化限制 dorsiflexion或調整 heel raise / AFO alignment |
| Same AFO 換不同鞋後 gait 改變 | footwear 改變 heel height、sole stiffness、rocker、pitch 與 GRF | 處方應寫 orthosis-footwear combination，而非單寫 brace |

## Clinical / Research Implication

### Clinical implication

下肢矯具評估應從「brace 名稱」上升到「力學輸入與輸出」：

- 輸入：joint ROM、muscle length、tone、strength、segment alignment、shoe geometry、skin tolerance。
- 輸出：SVA、thigh inclination、GRF line of action、external joint moment、terminal stance support、energy cost、comfort/adherence。

處方語言應避免只寫「AFO」。更精確的記錄應包含 AFO-footwear combination、heel/sole modifications、intended SVA / knee moment effect、以及 tuning plan。

### Research implication

這個 source 提供的是 textbook biomechanical framework，不是 randomized outcome evidence。研究上若要驗證 orthotic intervention，應至少回報：

- segment kinematics
- GRF / external moments
- footwear configuration
- orthosis alignment and tuning
- functional outcomes

否則「同一種 AFO」可能其實是不同 biomechanical intervention。

## Fact

- Lower-limb orthoses 具有 direct biomechanical effects 與 indirect biomechanical effects。
- Three-point force system 是控制單一關節 angular motion 的基本力學模型。
- GRF 應以 point of application、magnitude、line of action 三個元素分析。
- Shank 與 thigh 的 inclination 會影響 GRF 相對於 knee / hip 的 line of action。
- Midstance 約 10-12 degrees forward shank inclination 對 stance stability 有重要意義。
- Footwear 是 lower-limb orthotic prescription 的一部分；heel height、sole stiffness、sole profile、pitch 會改變 kinematics 與 kinetics。
- Orthoses 需要 dynamic tuning；小幅度 alignment 或 footwear 改變可明顯改變 neurologic gait 或兒童 secondary skeletal condition 的力學表現。

## Inference

- 若一個 AFO 改善 toe clearance 但惡化 knee / hip moment，它不是單純「成功」或「失敗」，而是局部目標與 proximal biomechanics 之間需要重新 tuning。
- Knee hyperextension 不應只用膝部三點力硬擋；若主因是 GRF 過度 anterior，應優先評估 ankle / footwear / SVA。
- Gait video 若沒有足夠慢速或沒有 GRF visualization，仍可做臨床判斷，但不應把細微 moment interpretation 說成確定事實。

## Assumption

- 病人的 gait deviation 可被 stance phase mechanics 合理解釋；若主要限制來自疼痛、spasticity、ataxia、vestibular disorder、cognition 或 cardiopulmonary endurance，需把這些因素納入。
- Skin tolerance、donning ability、adherence、cost 與目標活動情境已被納入決策。
- 本頁使用 textbook consensus 作為 biomechanical reasoning framework，不等同個別病種 guideline。

## Uncertainty

- 來源未提供各疾病族群中不同 tuning strategy 的 comparative outcome data。
- 「接近正常 kinematics / kinetics」是否必然轉換成 long-term functional gain，需依族群與 outcome 驗證。
- Motor learning benefit 是合理假說，但不能由本章單獨視為已證實的臨床效果。

## Limitations and Misreadings

### Misreading 1: AFO 有 hinge 就比較生理

反駁：是否能達成 near-normal shank kinematics，不只由 ankle hinge 決定；fixed AFO 搭配 footwear 和 tuning 也可能改變 GRF 與 SVA。

結論：比較 AFO 不能只比較 hinge，有沒有達成目標 kinematics / kinetics 才是核心。

### Misreading 2: Knee hyperextension 就加強 knee brace

反駁：若 knee hyperextension 來自 GRF 過度 anterior，單純增加 direct knee force 可能壓力大且耐受差。

結論：先評估 ankle ROM、plantarflexion contracture、heel height、AFO alignment 與 SVA，再決定是否需要直接 knee control。

### Misreading 3: 鞋子只是配件

反駁：鞋跟高度、sole stiffness、rocker、pitch 都會改變 GRF point of application 與 line of action。

結論：下肢矯具處方應視為 orthosis-footwear combination。
