# 足部扭轉彈簧機制

## One-Sentence Definition

足部扭轉彈簧機制，是 closed-chain stance 中 foot plate 先 `untwist` 以吸收能量，再由 plantar aponeurosis、plantar intrinsic muscles、peroneus longus 與 first ray recoil 共同形成 terminal-stance `twist` 和 spring-like push-off 的機制。

## Definition and Boundary

本頁只處理 `Richie Jr. — Foot biomechanics` 對 foot spring / torsional recoil 的 biomechanical explanation。

不處理：

- plantar fasciitis、adult acquired flatfoot deformity、hallux valgus、metatarsalgia 或 surgical correction 的完整診療。
- 跑步鞋、orthosis 或 tendon transfer 的 outcome。
- `Dang - Biomechanics of the Foot and Ankle` 的 supple-to-rigid transition；該概念另見 [[足部柔性到剛性轉換]]。

## Why It Matters

若只把 foot 當作 terminal stance 的 rigid lever，會漏掉 early stance 的 energy absorption、midfoot / forefoot torsion、plantar aponeurosis strain、intrinsic muscle activity、first ray plantarflexion 與 medial load transfer。這會讓 flatfoot / cavus foot、posterior tibial tendon dysfunction、first ray dysfunction 或 footwear / orthosis 判讀變成只看靜態外觀。

## Preconditions or Conditions

- 適用於 typical walking stance phase 的 biomechanical reasoning。
- 需要 closed kinetic chain 條件：plantar surface 與地面接觸、talus 在 ankle mortise 中受限、tibial rotation 可傳到 foot plate。
- 需要足夠的 plantar aponeurosis continuity、plantar intrinsic muscle activity、peroneus longus function、first ray mobility / stability 與 first MTP dorsiflexion。
- 若有 severe pain avoidance、neuropathy、recent surgery、arthrodesis、major deformity 或 neurologic gait，需另用 disease-specific 來源校正。

## Mechanism

### Definition

Foot spring 不是單純 arch height，也不是單純 windlass mechanism。它是 lamina pedis / calcaneopedal unit 在 stance phase 中的 torsional deformation、elastic strain storage、muscle-assisted stiffening 與 recoil。

### Known Facts

- Source 把 talus 下方的 foot bones 視為 `lamina pedis` / `calcaneopedal unit`。
- Closed kinetic chain 中，external leg rotation induces calcaneal inversion；internal leg rotation induces calcaneal eversion。
- Rearfoot 與 forefoot 會 reciprocal coupling：external leg rotation 時 rearfoot supinates、forefoot pronates；internal leg rotation 時 rearfoot pronates、forefoot supinates。
- Source 描述 longitudinal arch stiffness 由 plantar intrinsic muscles、plantar aponeurosis 與 plantar ligaments 調節。
- Passive plantar ligament structures 可儲存 strain energy 並 elastic recoil，這被描述為 `foot spring`。
- Human foot 在 stance 前半段 `untwists` 以吸收能量、分散衝擊並適應地面。
- Foot 之後 recoil 並 `twists` into rearfoot inversion and forefoot pronation。
- Source 指出 arch height 在 stance 最後 15% 明顯增加。
- Source 指出 first ray 從 terminal stance 開始到 pre-swing 結束約有 15 degrees plantarflexion。
- Heel rise 時 plantar fascia tensile strain 達最大，並伴隨 peak intrinsic muscle activity。
- Peroneus longus 有助於 first ray stiffening，並把 load 從 lateral 轉向 medial、通過 first MTP joint 以參與 windlass mechanism。
- Source 明確指出 windlass mechanism by itself 不能完整解釋 terminal stance / pre-swing 的 arch elevation and shortening。

### Mechanism Chain

Initial contact / loading response：foot 在 slight supination 接觸地面 -> pronation moment 出現 -> subtalar eversion / foot pronation 增加 flexibility -> arch-supporting structures 被拉伸 -> foot plate untwists -> energy absorption and shock dissipation。

Midstance to terminal stance：tibia advancing over talus -> posterior tibialis 參與 navicular control -> foot 逐漸走向 peak supination / hindfoot inversion -> plantar aponeurosis、plantar ligaments 與 intrinsic muscles 張力增加 -> stored elastic energy 增加。

Terminal stance / pre-swing：heel rise -> plantar fascia tensile strain and intrinsic muscle activity peak -> peroneus longus stiffens first ray and shifts load medially -> first ray plantarflexes -> forefoot pronation couples with rearfoot inversion -> foot twists and recoils -> arch height rises and spring-like push-off occurs。

## Observable Patterns

- Early stance 若 foot 無法 untwist / pronate：可能降低 shock absorption，造成 lateral loading 或 proximal compensation。
- Terminal stance 若 foot 無法 twist / recoil：可能出現 weak lever、early heel rise、medial column collapse、first ray instability 或 inefficient push-off。
- 只用 windlass 檢查解釋 arch raising 可能不足，因為 source 指出 arch raising 可早於 windlass engagement。
- Posterior tibial tendon dysfunction 不應只看 inversion weakness；source 將其放在 restraining tibial internal rotation / foot pronation 與 transverse-plane control 中。
- Peroneus longus function 不只代表 eversion，也可能關係到 first ray stiffening 與 medial forefoot load transfer。

## Clinical / Research Implication

- 臨床評估應同時看 open-chain mobility 與 closed-chain load response；兩者不能直接等同。
- 觀察 gait 時應問：foot 是在哪個 timing 失去應有的 torsion、stiffening 或 recoil，而不是只問 arch 高或低。
- Orthosis、shoe、taping 或 strengthening 的 biomechanical rationale 應指出要改變的是 early-stance shock absorption、terminal-stance stiffness、first ray control、medial load transfer，或 plantar aponeurosis / intrinsic contribution。
- 研究上應區分 arch height、arch stiffness、torsional deformation、energy storage / return 與 plantar pressure path，避免把它們當成同一個 proxy。

## Fact

- 本頁事實只來自 `Foot biomechanics` textbook chapter。
- Source 明確描述 `calcaneopedal unit` / `lamina pedis`。
- Source 明確描述 closed-chain tibial rotation、rearfoot motion 與 forefoot reciprocal motion 的 coupling。
- Source 明確描述 transverse arch curvature 對 foot stiffness 的重要性。
- Source 明確描述 plantar aponeurosis、plantar ligaments 與 intrinsic foot muscles 對 dynamic arch stiffness 的角色。
- Source 明確描述 foot first untwists, then recoils / twists during stance。
- Source 明確指出 windlass mechanism alone cannot fully explain terminal-stance arch elevation。

## Inference

- Static arch posture 是不完整 proxy；真正的 functional stiffness 需要看 closed-chain timing 與 segmental coupling。
- Foot push-off 比「rigid lever」模型更接近 spring-like recoil plus segmental motion。
- 若 intervention 改變 first ray、peroneus longus、plantar aponeurosis tension 或 tibial-rearfoot coupling，可能會連帶改變 terminal stance propulsion。

## Assumption

- 本頁假設討論對象是 typical adult walking gait。
- 本頁假設沒有 major neurologic impairment、arthrodesis、severe deformity、acute injury 或 protective pain behavior。
- 本頁假設臨床可透過 gait observation、heel rise、toe walking、single stance、foot posture 與鞋底磨耗等方式間接觀察機制。

## Uncertainty

- Source 未提供治療門檻，也未比較 orthosis、shoe、exercise 或 surgery outcome。
- Source 對 triceps surae / plantarflexor activity around pre-swing 的敘述有內部張力；不可由本來源單獨得出「calf 完全不參與 push-off」或「push-off 主要靠 calf 主動收縮」的硬結論。
- Windlass、intrinsic muscle、plantar fascia 與 Achilles recoil 的相對貢獻需用其他 biomechanical studies 進一步校正。

## Limitations and Misreadings

- 誤讀一：「arch 高低就是 foot function。」反駁：source 強調 closed-chain coupling、transverse arch、dynamic stiffness 與 stance-phase torsion。
- 誤讀二：「windlass mechanism 解釋全部 terminal stance arch raising。」反駁：source 明確說 windlass alone 不足，plantar fascia tightening 與 intrinsic muscle activity 也重要。
- 誤讀三：「push-off 就是 rigid lever 加 calf contraction。」反駁：source 將 human foot 描述為 spring-like structure，且 terminal stance / pre-swing 仍有 considerable motion。
- 誤讀四：「open-chain pronation / supination 就等於 gait 中的 pronation / supination。」反駁：source 明確區分 open kinetic chain 與 closed kinetic chain。
