# 跑步步頻調整

## 一句話定義

跑步步頻調整是以 **固定速度下，相對於個人 preferred cadence 做小幅增加** 的 gait retraining 方法，用來改變特定 running load 與 kinematic pattern。

## 核心概念

### 什麼叫 step rate modification

- 先測 runner 在特定速度下的 preferred cadence。
- 再把 cadence 以百分比方式上調，通常先抓 `2%` 到 `8%`，單次多半不超過 `10%`。
- 臨床上常先從 `<=5%` increase 開始，以兼顧 biomechanical effect 與 running economy。
- 這不是追求某個固定神奇數字，而是為了得到明確的 biomechanical target。

## 機制 / 原理

### 常見 biomechanical 變化

- stride length 縮短
- overstriding 減少
- tibia 在 initial contact 時更 vertical
- knee flexion at initial contact 增加
- peak knee flexion at midstance 減少
- vertical COM excursion 減少
- peak hip adduction 與 contralateral pelvic drop 減少

### 常見 kinetic 變化

- impact peak、loading rate、braking impulse、peak vertical GRF 下降
- knee negative work 下降
- patellofemoral joint force / loading rate / contact pressure 下降
- hip absorbed energy 下降
- ankle generated energy 下降

### cumulative load 與 metabolic cost

- 雖然每公里步數會增加，但 cumulative knee load 仍可能下降，特別是 patellofemoral 與 extensor-mechanism load。
- 小幅 increase 通常不帶來長期 running economy penalty；較大的改變才較可能增加短期 metabolic cost。

## 臨床或研究上的重要性

- 是目前最容易在 clinic 中落地的 running gait retraining 方法之一。
- 對有明確 load-related target 的 runner，常比抽象的「修正跑姿」更可操作。
- 常被用來處理：
  - patellofemoral pain
  - Iliotibial Band Syndrome
  - anterior exertional lower-leg pain / tibial stress injury pattern
  - 部分 hip / low back load-related running pain

## 方法學重點

### implementation 流程

- treadmill 常是最穩定的起點，因為較容易固定速度。
- clinician 可用 metronome、audio cue、video feedback、watch / accelerometer。
- 若 runner 脫離 feedback 後仍可重現 target cadence，才代表真正學會。
- overground 訓練要同時監測 speed，避免 runner 只是跑更快。

### 什麼情況比較適合

- 有明確的 overstride / high loading rate / patellofemoral load / frontal-plane hip mechanics 問題。
- 症狀與 running load 有明顯關聯，且 differential 已做過基本分流。

## 證據層級與來源

- 主框架來源：textbook chapter，Tier 1
- 目前較強的是 biomechanical / kinetic 共識；對 broad injury prevention 的高等級結局證據仍較有限。

## 目前限制 / 爭議點

- 並非所有 runner 都需要 cadence retraining。
- 沒有 universal `180 spm` 規則。
- 不先固定速度，就可能做成「加快跑速」而不是 `step rate modification`。
- 這只是 running rehab 的一個旋鈕，不能取代 diagnosis、strength / capacity work 與 load management。
