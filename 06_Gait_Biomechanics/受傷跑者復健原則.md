# 受傷跑者復健原則

## 一句話定義

受傷跑者復健的主軸是 **同時恢復 tissue capacity 與降低或重新分配 running load per stride**，並用 staged return-to-run 把兩者接回真實訓練。

## 核心概念

### 受傷跑者 rehab 有兩個旋鈕

- restore tissue tolerance for load
- reduce / redistribute load per stride

兩者常要同時做，而不是二選一。

### acute painful phase 不等於完全停擺

- 當 runner 對 load 很敏感時，可先從 isometric 開始。
- 目的不是「撐久一點」，而是：
  - 降低 pain reactivity
  - 恢復正常 recruitment
  - 重新建立 self-efficacy

### progressive loading 可以允許有限疼痛

- 可接受的邊界可用以下三條：
  - pain increase 不超過 `2/10`
  - symptoms 不持續超過 `24 小時`
  - 相似活動重複後不應逐次惡化

### return to run 前要先過最低功能門檻

- walk `30 分鐘` without increased symptoms
- single-leg squat `10 次` without increased symptoms
- single-leg hop `10 次` without increased symptoms

## 臨床或研究上的重要性

- 這頁是 runner-specific rehab 的主幹頁。
- 可把 [[跑者下肢傷害評估總論]] 的評估結果，轉成實際的 rehab path。
- 也可作為 [[跑者膝部疼痛]]、[[跑者運動性下腿痛]]、[[跑者髖骨盆與大腿疼痛]] 的共同 return-to-run 骨架。

## 評估方式

### 先分清 runner 卡在哪一層

- tissue irritability 很高，連 walking 都痛？
- 已能日常活動，但還不能跑？
- 可以跑，但某個 structure 一直被 overload？

### 高價值 functional test

- walk tolerance
- single-leg squat
- single-leg hop
- weight-bearing lunge test
- heel-elevated single-leg squat

### 何時補做 gait analysis

- 若 runner 還能跑，且症狀明顯與 load per stride / form 有關，應回 [[跑步步態評估]]。
- 若連 hopping 都做不到，先不要急著談跑姿微調。

## 治療原則

### staged loading progression

- acute painful phase：以可控制的 loading 重新建立 tolerance
- subacute phase：漸進恢復 strength、single-leg capacity 與 plyometric tolerance
- return-to-run phase：walk/jog progression，通常 every other day

### gait retraining 只在問題明確時使用

- cadence increase 是常用旋鈕，但目標是縮短 step length、改變 load，不是追求 `180 spm`
- forward lean、quiet steps、step width 或 foot strike change 都可能有用
- 但每種改法都可能把 load 轉到其他組織

### progression heuristic 要降階使用

- `10% rule` 可作 conservative guardrail
- `ACWR` 可提醒過高 spike 或過低 trough
- 兩者都不是安全或危險的絕對生理邊界

### recurrence prevention 不只看 running spreadsheet

- cross-training 與 strength training 可協助維持 conditioning 並降低單一路徑 overload。
- footwear change 應被當成 load-redistribution tool，而不是獨立治療。
- stretching 本身不是高確定度 injury-prevention 核心；比它更重要的是 capacity 與 load tolerance。
- 對 bone stress risk 高的 runner，要同步處理 nutrition、energy availability 與 recovery，不然 return-to-run 常反覆失敗。

## 臨床決策點

### 反對論點

- 「不痛再開始動比較安全。」
- 「跑者受傷主要是姿勢問題，改跑姿就好。」
- 「照 10% rule 慢慢加就一定安全。」

### 反駁

- 長期完全 unloading 常讓 tissue tolerance、movement confidence 與 running-specific capacity 都更差。
- 單改 biomechanics 而不補 capacity，常只是把問題延後或轉位。
- 任何 progression rule 都要放回 diagnosis、morbidity risk、runner 目標與實際反應解讀。

### 結論

- 受傷跑者復健的真正核心是 **capacity restoration + selective load redistribution + criteria-based return to run**。

## 限制與未定論

### frontmatter contradictions

- Rest until completely pain free is not the default rehabilitation strategy for most injured runners.
- Gait retraining should not replace progressive tissue loading and capacity restoration.
- The 10 percent rule and acute-to-chronic workload ratio can guide progression but do not determine safe return by themselves.

## 理解缺口

- 哪些 injury pattern 最應先用 gait retraining，哪些最應先補 strength / plyometric capacity？
- acceptable pain rule 在 bone stress injury 或 tendon partial tear 應如何調整？
- sRPE 與 ACWR 對 recreational injured runner 的真實增益還有多少？

## 臨床使用版

- 當你已知道診斷，但不知道 runner 應怎麼回到跑步，先用這頁。
- 當 runner 還在高 irritability 期，就不要過早開 long return-to-run spreadsheet。
