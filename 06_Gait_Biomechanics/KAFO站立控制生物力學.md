# KAFO站立控制生物力學

## One-Sentence Definition

KAFO stance-control biomechanics 是用 knee-ankle-foot orthosis 在 stance phase 提供 knee / ankle complex stability，同時盡量保留 swing phase knee motion，以減少 locked-knee gait 造成的 compensations。

## Definition and Boundary

本頁只處理 `Murphy, Lovegreen, Lovegreen — Lower Limb Orthoses` 中 KAFO 的 biomechanical reasoning：KAFO 如何在 loading response、midstance、terminal stance 與 swing phase 之間平衡 stability 與 mobility。

不處理：

- HKAFO / reciprocating gait orthosis。
- powered exoskeleton。
- disease-specific KAFO trial 或 guideline。
- post-polio、stroke、SCI、peripheral neuropathy 的完整處方流程。

## Why It Matters

KAFO 的臨床目的不是把 knee 永久鎖死，而是在需要時提供 stance stability，並盡量減少對 normal knee / ankle ROM 的干擾。若只追求穩定，locked-knee gait 會迫使 hip hiking、circumduction 或 contralateral vaulting 來完成 swing limb advancement。

## Preconditions or Conditions

- 使用者需要 knee、ankle、subtalar joint 在 ambulation 中取得外部 stability。
- 目標可能是 loading response 防止 excessive knee flexion，或 midstance-to-terminal stance 防止 knee hyperextension。
- 通常需要足夠 trunk control 與 upper body strength，因為 KAFO 常需搭配 walker 或 forearm crutches。
- 某些人仍需 wheelchair 支援 longer-distance mobility。
- device choice 必須同時看 stance safety、swing clearance、energy cost、skin tolerance、donning ability 與 assistive device compatibility。

## Mechanism

### Definition

KAFO 是跨 knee、ankle 與 foot 的 orthosis，用於在 ambulation 中提供 knee-ankle complex stability。

### Known Facts

- KAFO 被設計來提供 knee and ankle complex stability during ambulation。
- KAFO 可能在 loading response 防止 excessive knee flexion，也可能在 midstance-to-terminal stance 防止 knee hyperextension。
- 理想 KAFO 應在提供必要 stability 的同時，最小化對 normal knee and ankle ROM during gait 的干擾。
- KAFO 可用於 functional ambulation、exercise，或兩者。
- 部分使用者會用 KAFO 搭配 wheelchair 作長距離 mobility。
- KAFO ambulation 通常需要 good trunk control 與 upper body strength，因為常搭配 walkers 或 forearm crutches。
- KAFO 可納入 AFO 可用的 ankle joint / ankle joint system。
- Double upright ankle design 最常見；外接 shoe stirrup 可容納 edema 並可用於 sensory impairment，但較重且換鞋困難。
- Molded plastic ankle joint with or without articulation 讓換鞋較容易，並可能提供較細緻的 ankle-foot control。
- Straight single-axis knee joint 允許 free flexion，但防止 knee hyperextension。
- Free-swinging knee joint 適用於需要 medial-lateral support 且 knee extensor strength 足夠者；必要時可搭配 drop lock。
- Polycentric knee joint 用 double-axis system 模擬 femur 在 tibia 上的 flexion-extension 與 gliding motion，但較不常用。
- Posterior offset knee joint 在 swing phase 允許 knee free flexion / extension；stance phase 則藉 posterior offset 讓 orthotic GRF 維持在 knee axis 前方以提供 stability，並應有 hyperextension stop。
- Knee locks 可提供額外 stability；傳統類型包括 drop lock、ratchet lock、dial lock、bail lock。
- Stance-control lock mechanisms 在 stance phase lock，但允許 swing phase knee flexion / extension。
- Dynamic control systems 可在 stance 與 swing phases 提供不同程度的 knee motion control，例如 pneumatic 或 hydraulic systems。
- Microprocessor / hydraulic dynamic systems 可提供 swing and stance flexion / extension dampening，並快速回應不同 gait situations 與 sensor feedback。
- Source 指出 stance control 與 dynamic knee control units 的 benefits 包含 uneven terrain stability、reduced metabolic costs、減少 hip hiking / circumduction 等 gait deviations，可能降低 back 與 contralateral limb 長期 complications。

### Mechanism Chain

Lower limb weakness、knee instability、hyperextension 或 impaired motor control -> KAFO 以 thigh / calf bands、shell、ankle-foot component 與 knee joint / lock 提供外部控制點 -> stance phase 限制 excessive knee flexion 或 hyperextension -> 使用者可安全承重與前進 -> 若 knee 在 swing phase 仍被鎖住，limb advancement 需要 hip hiking、circumduction 或 contralateral vaulting -> stance-control / dynamic-control mechanisms 讓 knee 在 stance lock 或受控，在 swing 釋放或阻尼 -> stability 與 gait efficiency 較可能同時保留。

## Observable Patterns

- Loading response knee collapse：stance 初期 excessive knee flexion，需外部 knee stability。
- Midstance-to-terminal stance knee hyperextension：需控制 genu recurvatum 或防止 posterior structure overload。
- Locked-knee gait：swing phase 膝蓋無法 flexion，常出現 hip hiking、circumduction、contralateral vaulting。
- Free-swinging joint 適合 knee extensor strength 足夠、但需要 medial-lateral support 的人。
- Stance-control KAFO 目標是 stance locked / stable、swing unlocked / mobile，而不是全 gait cycle knee immobilization。

## Clinical / Research Implication

- KAFO prescription 應先寫出主要 instability 發生的 gait phase：loading response collapse、midstance hyperextension、terminal stance instability，或 swing advancement problem。
- `locked knee` 可解決 stance safety，但會製造 swing-phase clearance burden；這是 biomechanical tradeoff，不是小副作用。
- Stance-control 或 dynamic-control KAFO 的價值在於減少 locked-knee compensations，但仍需評估 strength、motor control、sensory status、hand dexterity、terrain、cost、weight 與 maintenance。
- 若需要 walkers 或 forearm crutches，KAFO 成功與否也取決於 upper limb strength、trunk control 與 assistive-device training。
- 對 sensory impairment 或 edema，外接 stirrup / double upright 可能有 fit 優勢，但重量與 shoe-switching difficulty 需列入處方風險。

## Fact

- 本頁事實只來自 `Lower Limb Orthoses` textbook chapter。
- Source 明確說 KAFO 的目的在 ambulation 中提供 knee and ankle complex stability。
- Source 明確說 KAFO 可在 loading response 防止 excessive knee flexion，或在 midstance-to-terminal stance 防止 knee hyperextension。
- Source 明確說理想 KAFO 應提供 required stability while minimally interfering with normal knee and ankle ROM during gait。
- Source 明確說 traditional locked-knee KAFO 可讓 very unstable knee 的人安全站立與行走，但 swing phase locked knee 會需要 hip hiking、circumduction 或 contralateral vaulting。
- Source 明確描述 stance control lock mechanisms 在 stance phase lock，並允許 swing phase knee motion。

## Inference

- KAFO assessment 應優先描述 gait phase-specific failure，而不是只用 diagnosis 推導 device。
- 若病人可用 AFO 或 KO 解決主要問題，KAFO 可能是過度限制；但若 knee、ankle、subtalar stability 同時不足，KAFO 才符合 biomechanical target。
- Stance-control KAFO 的處方價值取決於能否在不犧牲安全的前提下降低 locked-knee gait compensations。

## Assumption

- 本來源為 textbook chapter，不是 device-comparison guideline。
- 本頁假設使用者具備足夠 cognitive / motor capacity 或 caregiver support 來操作 locks、don/doff device 並安全使用 ambulation aid。
- 本頁假設處方者會檢查 skin、fit、shoe interface、assistive device use 與動態 gait。

## Uncertainty

- Source 未提供不同 KAFO joint / lock design 的 disease-specific comparative outcome。
- Microprocessor stance-control / dynamic-control KAFO 的實際效益仍取決於病人選擇、地形、訓練、成本、維修與 adherence。
- Reduced metabolic cost 與 reduced compensatory gait deviations 不能自動外推為所有使用者的 long-term participation improvement。
- 若 sensory impairment、severe spasticity、contracture、hand dexterity limitation 或 poor trunk control 存在，device selection 需要更細分來源支持。

## Limitations and Misreadings

- 誤讀一：「KAFO 越穩越好。」反駁：source 的理想目標是 stability with minimal interference；過度鎖定會干擾 gait。
- 誤讀二：「locked knee 解決 knee instability 就代表成功。」反駁：locked knee during swing phase 可能造成 hip hiking、circumduction、contralateral vaulting。
- 誤讀三：「stance-control KAFO 等於所有 KAFO 使用者都適合。」反駁：source 只描述機制與可能 benefits，未提供 universal indication。
- 誤讀四：「KAFO 只是膝關節支架。」反駁：source 將 KAFO 定義為 knee、ankle、subtalar stability 的 ambulation device，且 ankle-foot component 與 shoe interface 會影響結果。
