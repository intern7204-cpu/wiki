# AFO處方生物力學

## One-Sentence Definition

AFO prescription biomechanics 是利用 ankle position、ankle stops、foot plate、shoe interface 與 trimline 來控制 ankle-foot complex，並透過 GRF line of action 改變 stance phase 的 knee flexion / extension moment。

## Definition and Boundary

本頁只處理 `Murphy, Lovegreen, Lovegreen — Lower Limb Orthoses` 對 AFO 的 biomechanical reasoning：AFO 如何直接控制 ankle-foot motion，並間接影響 knee control。

不處理：

- disease-specific AFO outcome trial。
- stroke、CP、SCI、diabetic foot 的完整處方 guideline。
- KAFO、HKAFO、powered exoskeleton 的完整設計邏輯。
- functional electrical stimulation 與 AFO 的比較療效。

## Why It Matters

AFO 若只被理解為「避免 foot drop」，會漏掉 stance phase 的核心作用：它可以把 GRF 調到 knee axis 前方或後方，藉此減少 knee collapse 或 knee hyperextension。

## Preconditions or Conditions

- 使用者有 foot / ankle biomechanical 或 neurophysiological problem。
- 問題可能出現在 swing phase toe clearance，也可能出現在 stance phase knee control。
- 處方前需界定 functional goal：toe clearance、mediolateral stability、spasticity control、contracture positioning、offloading、knee moment control，或上述組合。
- AFO 效果必須連同 shoe interface 與 gait reassessment 一起判讀。

## Mechanism

### Definition

AFO 是跨過 ankle joint、但止於 knee joint 以下的 orthosis；它直接控制 ankle dorsiflexion / plantarflexion、subtalar / mediolateral stability 與 foot alignment。

### Known Facts

- AFO 可用於 biomechanical 或 neurophysiological foot / ankle problem，診斷範圍從 ankle sprain 到 stroke management。
- AFO 提供 dorsiflexion / plantarflexion control，也提供 mediolateral stability。
- Eversion 包含 ankle dorsiflexion、subtalar pronation 與 forefoot abduction；inversion 則包含 ankle plantarflexion、subtalar supination 與 forefoot adduction。
- AFO 直接控制 ankle motion，但也會影響 gait 中的 knee control。
- Foot strike 時，GRF 作用於 foot；若 GRF 位於 knee 後方，會傾向促進 knee flexion；若 GRF 位於 knee 前方，會協助 knee extension。
- AFO 可以藉由調整 ankle position 或 ankle stops，使 GRF 位於 knee 前方或後方。
- Foot dorsiflexion 傾向讓 GRF 位於 knee 後方並增加 knee flexion tendency。
- Foot plantarflexion 傾向讓 GRF 位於 knee 前方並增加 knee extension tendency。
- 對 quadriceps weakness 且 stance 有 knee collapse tendency 的人，dorsiflexion stop 可調向較 plantarflexed 的 stance position，使 GRF 移到 knee axis 前方以幫助 knee extension。
- 對 stance phase knee hyperextension 的人，plantarflexion stop 可調整使 ankle 保持較 dorsiflexed，使 GRF 移到 knee 後方，以鼓勵 knee flexion 並減少 hyperextension。
- Correction of one gait issue may leave other issues less well managed；rigid brace 可能保護 wound / fracture，但增加 walking difficulty 與 energy expenditure。
- Metal AFO 的 proximal calf band 應至少低於 fibular neck 1 inch，以避免 peroneal nerve compression。
- Plastic AFO 的 style、material、joint、spring-assisted dorsiflexion、trimline 與 foot plate length 都可影響支撐與功能。
- Orthotic checkout 需確認 fit、function、comfort、cosmesis；若目標是改善 gait dysfunction，必須重新評估 gait 是否真的達成目標。

### Mechanism Chain

Ankle-foot problem 或 neurologic weakness -> AFO 控制 ankle-foot alignment 與 motion -> shoe-ground interaction 改變 foot strike 後的 GRF line of action -> GRF 相對於 knee axis 的前後位置改變 external knee moment -> stance phase knee collapse 或 hyperextension 被增加或減少 -> gait safety、toe clearance、energy cost 或 wound / joint protection 可能改善。

## Observable Patterns

- Foot drop：swing phase toe clearance 不足；AFO 可提供 dorsiflexion assist 或限制 plantarflexion。
- Knee collapse tendency：loading response 或 stance 期 knee flexion 過多；可透過較 plantarflexed 的 AFO setting 讓 GRF 較 anterior to knee。
- Genu recurvatum / knee hyperextension：stance phase knee extension 過多；可透過較 dorsiflexed 的 AFO setting 讓 GRF 較 posterior to knee。
- Mediolateral instability：需要控制 subtalar / frontal plane alignment，而不只是 sagittal plane ankle stop。
- Skin risk 或 insensate foot：checkout 後需檢查壓紅是否超過 5-10 分鐘，是否有 skin breakdown。

## Clinical / Research Implication

- AFO 處方不應只寫「AFO for foot drop」；至少要寫出 target gait problem 與希望改變的 biomechanical effect。
- 若病人主要問題是 stance phase knee hyperextension，AFO setting 可能比單純 knee brace 更接近問題來源。
- 若病人主要問題是 quadriceps weakness 下的 knee collapse，AFO 可被設定為協助 knee extension，但須監測是否犧牲 toe clearance、comfort 或其他 gait phase。
- Rigid AFO、wound-protective AFO 或 fracture-protective AFO 的 goal 可能與 efficient gait 衝突，因此 outcome 不能只看 walking speed。
- AFO checkout 應包含 static fit、dynamic gait reassessment、skin inspection、patient acceptance 與 shoe compatibility。

## Fact

- 本頁事實只來自 `Lower Limb Orthoses` textbook chapter。
- Source 將 AFO 定義為跨 ankle joint、但未跨 knee joint 的 orthosis。
- Source 明確說明 AFO 可直接控制 ankle motion，並影響 gait 中的 knee control。
- Source 明確描述 GRF 位於 knee 前方會協助 knee extension，位於 knee 後方會促進 knee flexion。
- Source 明確描述 ankle dorsiflexion / plantarflexion setting 可透過 GRF 位置影響 knee moment。
- Source 明確提醒 correction of one issue may leave other issues less well attended to。

## Inference

- AFO 處方的最低必要內容應包含：目標 phase、目標 joint moment、ankle stop / ankle angle logic、shoe interface、skin risk 與 gait reassessment plan。
- `hinged AFO` 是否較好不能只靠「可動」判定；若 goal 是控制 knee collapse 或 hyperextension，stop setting 與 GRF effect 比是否 hinged 更關鍵。
- 若沒有觀察 gait 或確認 GRF / segment alignment，AFO setting 的 biomechanical rationale 只能算假設，不應寫成已證實效果。

## Assumption

- 來源提供的是 textbook biomechanical framework，不是 disease-specific guideline。
- 本頁假設臨床人員能評估 stance phase、swing phase、knee axis、ankle position 與 shoe-AFO fit。
- 本頁假設病人沒有未處理的 acute fracture instability、severe skin breakdown、uncontrolled pain 或其他需要優先醫療處置的狀況。

## Uncertainty

- Source 沒有提供不同 AFO setting 在特定疾病中的 comparative outcome。
- Source 沒有建立 universal ankle angle；同一設定在不同 diagnosis、tone、contracture、strength、shoe 與 walking speed 下可能效果不同。
- Functional electrical stimulation、carbon fiber AFO、metal AFO、plastic AFO 與 custom dynamic AFO 的相對療效需另用 disease-specific studies 判斷。
- Energy cost、walking speed、fall risk、pain、adherence 與 skin outcome 可能方向不一致，不能用單一指標代表處方成功。

## Limitations and Misreadings

- 誤讀一：「AFO = foot drop brace。」反駁：source 明確說 AFO 也可透過 GRF 影響 knee control。
- 誤讀二：「Dorsiflexion 越多越自然。」反駁：dorsiflexion bias 可促進 knee flexion；對 quadriceps weakness 可能加重 collapse。
- 誤讀三：「Plantarflexion stop 只是避免 toe drag。」反駁：plantarflexion stop 也可讓 ankle 保持較 dorsiflexed，進而讓 GRF 後移以減少 knee hyperextension。
- 誤讀四：「Rigid brace 保護越多越好。」反駁：source 提醒保護性 rigid brace 可能增加 walking difficulty 與 energy expenditure。
