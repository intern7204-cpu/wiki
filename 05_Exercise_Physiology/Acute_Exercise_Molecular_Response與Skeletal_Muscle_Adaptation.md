# Acute Exercise Molecular Response 與 Skeletal Muscle Adaptation

## 一句話定義

Acute exercise molecular response 是每一次 exercise session 造成的 transient signal-transduction 與 regulatory cascade；它可解釋 training adaptation 的一部分，但不是能直接從單次 biomarker 推算長期 phenotype 的線性公式。

## 概念邊界

本頁只處理 skeletal muscle 中 acute exercise molecular response 如何連到 training adaptation。它不處理全身 exerkines、cardiovascular adaptation、CPET threshold 判讀或完整 exercise prescription。

## 反對論點

「如果 acute exercise 後某個 mRNA、phosphorylation 或 MPS 指標上升，就能推論這個 protocol 會造成對應的長期適應。」

## 反駁

Egan & Sharples 2023 明確把 acute response to chronic adaptation 視為 working model。Acute response 同時包含 homeostasis restoration、stress response、repair、protein turnover 與真正可能促成 adaptation 的 regulatory processes。尤其在 untrained 或 unfamiliar exercise condition，first bout effect 可能讓 response 反映 muscle damage / inflammation / generalized stress，而非未來 phenotype 的精準預測。

## 結論

Acute molecular data 可以提高 exercise prescription 的 mechanistic literacy，但臨床與訓練決策仍必須回到 FITT、progressive overload、recovery、function、symptom、safety 與長期 outcome tracking。

## 事實

- Repeated skeletal muscle contractions 是 structured exercise training 的基本單位。
- 每一次 acute exercise 會造成 neuronal、mechanical、metabolic、hormonal stimuli。
- Intrinsic signals 包含 Ca2+ flux、ATP / ADP / Pi、redox state、glycogen availability、pH、PO2、RONS、temperature、mechanical load / tension。
- Extrinsic signals 包含 catecholamines、cytokines、GH、IGF-I、testosterone、glucose、amino acids、free fatty acids。
- Sensor proteins 與 receptors 將這些 signals 轉成 intracellular signal transduction。
- Effector processes 包含 transcription、epigenetic regulation、mRNA handling、protein translation、protein degradation、autophagy / lysosome 與 satellite-cell-related regulation。
- Training status 會改變 acute molecular response；訓練後許多 response 會 attenuate，但不是所有 response 都下降。
- Acute mRNA response 的 individual repeatability 有限制，且 baseline variability 與 biopsy methodology 會影響解讀。

## 推論

- 同一個 exercise protocol 在 sedentary、trained、clinical disease、low glycogen、poor recovery 或 medication-influenced state 下，可能造成不同 molecular perturbation。
- 在 rehabilitation 場景，molecular response 應被視為機制解釋，而不是單獨決定 exercise dose 的臨床工具。
- 若長期 outcome 沒有改善，單次 biomarker response 不能替代重新檢查 load、specificity、recovery 與 adherence。

## 假設

- 反覆 acute molecular response 在足夠 recovery 與 progressive overload 下，可逐步改變 protein abundance / activity。
- 這些 protein-level change 和 neural、metabolic、structural adjustment 一起產生 measurable phenotype。
- 這條鏈合理，但目前仍不是完全驗證的 deterministic model。

## 機制鏈

```text
exercise stimulus
  -> homeostatic perturbation
  -> intrinsic / extrinsic signals
  -> sensors and receptors
  -> signal transduction networks
  -> transcription / epigenetic regulation / translation / degradation
  -> repeated sessions with recovery and progressive overload
  -> protein abundance or activity changes
  -> skeletal muscle phenotype
```

## 臨床使用

- 若目標是 endurance phenotype，處方仍要先定義 mode、domain、duration、frequency、recovery 與可追蹤 outcome。
- 若目標是 hypertrophy / strength，處方仍要先定義 load、volume、proximity to failure、range of motion、protein / recovery context 與 function outcome。
- Molecular language 可用來解釋為何 training status、glycogen availability、nutrition timing、circadian timing 或 exercise mode 可能改變 response。
- 它目前不應被用來替代 clinical monitoring 或 patient-specific risk screen。

## 常見誤用

- 把 mRNA response 當成 adaptation。
- 把 single pathway activation 當成 causal proof。
- 把 untrained first bout response 外推到 trained patient。
- 把 aerobic 與 resistance exercise 說成完全不同且互斥的分子分類。
- 把 exercise mimetic 視為可以取代 exercise 的治療。

## 限制與未定論

- Acute-to-chronic continuity 尚未完全建立。
- Human biopsy 的 sampling time、fiber type distribution、technical variability 與 day-to-day biological variability 會影響結果。
- In vitro / animal model 可建立 pathway hypotheses，但不必然能解釋 human whole-body training outcome。
- Biological sex、circadian rhythm、gut microbiome、EV cargo 與 multi-omics pattern 的 practical clinical value 仍未確定。

### Furrer 2023 的補充

- Voluntary whole-body exercise 不等於 isolated muscle contraction；animal / in vitro data 可提供 causal clues，但不能直接替代 human training outcome。
- Chronic trained muscle 不應被視為 acute exercise bouts 的簡單加總或持續版。
- AMPK、mTOR、PGC-1alpha 等 pathway 在模型中可能因 compensation 顯得可被取代；這表示 biological networks 有 redundancy，不等於這些 pathway 對 human exercise adaptation 不重要。
- Elite athlete phenotype 還受到 training history、periodization、recovery、nutrition、sleep、chronotype、technology、social support 與 injury prevention 影響，不能由單一 acute biomarker 推回完整 performance。

### Smith 2023 的補充：shared early signals, modality divergence later

- Acute exercise 觸發 metabolic、hormonal、growth factor、inflammatory 與 mechanosensitive events 的整合反應。
- Sprint / resistance exercise 的 whole-body stress 與 muscle phosphoproteome perturbation 通常比 continuous endurance exercise 更強，但 immediate post-exercise signature 仍有共享成分。
- 多種 exercise modalities 可共同改變超過 400 個 phosphorylation sites、超過 200 個 proteins；共享 kinases 包含 CaMK、AMPK、mTOR、MAPK、PKA、PKC。
- Modality divergence 在 recovery 3 小時左右更明顯；resistance exercise 較強化 mTORC1 / p38 MAPK related signaling。
- Sarcomere shortening 可招募 ZAKbeta 至 Z-disc 並啟動 p38 / JNK；這可能連到 resistance-type adaptation 與 myostatin-SMAD inhibition，但 human 長期因果鏈仍需保留限制。
- AMPK-mediated mTORC1 blunting 有 biochemical basis；但 meta-analyses 顯示 concurrent training 對 hypertrophy 的 interference 並不穩定，不能用單一路徑直接推論臨床 outcome。
- Acute exercise / training 會造成 histone modification、DNA methylation、miRNA / lncRNA changes；部分 sustained methylation events 可能和 muscle memory 有關，但許多 epigenetic marks 的 functional role 尚未確定。
- Training 後 acute molecular response attenuation 可能代表更 refined adaptive state，不應自動解讀為 stimulus 失效。
