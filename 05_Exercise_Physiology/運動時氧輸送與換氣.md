# 運動時氧輸送與換氣

## 一句話定義

運動時的 physiologic challenge，不是單看 lungs 或 heart，而是 **oxygen delivery、peripheral extraction、ventilation 與代謝需求** 必須同步拉高；任何一段跟不上，都可能變成 dyspnea、fatigue 或 performance limitation。

## 核心機制

### `VO2` 代表的是整體氧運輸鏈

- 外在功率上升時，`VO2` 大致隨之線性增加。
- 但 `VO2` 不是單一器官的輸出，而是整條路徑的整合結果：
  - lungs 提供 alveolar gas exchange
  - heart 提高 cardiac output
  - blood 攜帶 oxygen
  - muscle 增加 oxygen extraction 與 ATP resynthesis

### Fick equation 是骨架

`VO2 = Q × (a-vO2 diff)`

- `Q` = cardiac output
- `(a-vO2 diff)` = arterial-venous oxygen content difference

費曼式理解：
- 想像要把更多氧送到肌肉，不是只有「吸更大口氣」。
- 你還需要：
  - pump 送得更快
  - capillary / mitochondria 用得更乾淨

### ventilation 的反應很快，而且有相位

- phase I：運動一開始就快速上升
- phase II：繼續調整
- phase III：moderate intensity 可達 steady state

若進入更高強度：
- ventilation burden 增加
- lactate-related acid load 與 chemostimulation 變明顯
- severe domain 會出現持續上升而非穩定的平台

### 環境修飾：hypobaric hypoxia 會把整條鏈往下拉

- 在 [[高海拔與飛行低氧生理]] 中，真正改變的是 barometric pressure，不是 `FiO2`。
- 這會讓 inspired `PO2`、alveolar `PO2`、arterial `PO2` 依序下降。
- commercial flying 只是較溫和的 altitude physiology：
  - cabin altitude 通常 `<2400 m`
  - 約等於 sea level 吸 `15% O2`
- 對 healthy subject 影響常有限，但對已有 respiratory reserve 降低者，這就是 clinically relevant hypoxic challenge。

### moderate / heavy / severe 要用現代 domain 讀

- historical chapter 常用 `anaerobic threshold` 當教學起點。
- 但在現代 wiki 框架中應拆開：
  - [[../04_CPET/Lactate_Threshold]] / [[../04_CPET/Gas_Exchange_Threshold]]：moderate-heavy 邊界
  - [[../04_CPET/Critical_Power]]：heavy-severe 邊界

### 運動限制不是只看 lungs

在 healthy person：
- lungs 通常不是首要瓶頸
- 真正限制常來自整體 oxygen transport 與 peripheral metabolism

在 elite athlete：
- exercise-induced arterial hypoxemia
- ventilatory mechanics
- work of breathing

在 cardiorespiratory disease：
- reduced cardiac reserve
- ventilatory inefficiency
- lower tolerable ventilatory fraction
- symptoms 提早出現

## 臨床或研究上的重要性

- 這頁是把 exercise physiology 與 CPET 連起來的教學頁。
- 它能解釋：
  - 為什麼 6MWT、shuttle test、CPET 都在看「運動耐受」
  - 為什麼 `VO2peak` 下降不等於一定是 lung disease
  - 為什麼 perioperative risk、sports cardiology 與 exercise prescription 都會用到運動測試

## 方法學重點

### `VO2peak` 與 `VO2max` 不要混用

- 單次 GXT 測到的最高值，常是 `VO2peak`。
- 要確認 `VO2max`，通常要回到 [[../04_CPET/VO2max_Measurement]] 的 verification logic。

### exercise test 的選擇要看問題

- functional screen：6MWT / shuttle test
- integrated physiology：CPET
- threshold / performance / domain prescription：更需要標準化 protocol 與 modern interpretation

## 限制與爭議點

- 舊教材的 `anaerobic threshold`、`oxygen debt` 可當歷史 teaching scaffold，但不該直接當現代終局解釋。
- 呼吸限制、循環限制、peripheral limitation 與 symptom perception 常是疊加，不是彼此排斥。
