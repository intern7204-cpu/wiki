# 運動時氧供調節的整合視角

## 一句話定義

external power 增加時，`VO2`、cardiac output、oxygen extraction 與 ventilation 必須同步上調；`VO2` 不是只代表 lungs，而是整個 oxygen transport system 的輸出。

## Definition and Boundary

- 這個 concept 保留的是 integrated oxygen transport frame。
- `anaerobic threshold` 與 `oxygen debt` 在本來源屬 legacy phrasing，不作現代主結論。

## Fact

- 運動時 `VO2` 與 external power 大致呈線性增加。
- 氧供增加來自 cardiac output 上升與 peripheral oxygen extraction 上升。
- ventilation 從運動一開始就快速反應，不是等血氣明顯失衡才上升。
- moderate exercise 可達新的 steady state；更高強度時 dyspnea burden 與後續 ventilatory increase 會上升。
- Critical power 進一步顯示 oxygen transport / utilization system 的上限：CP 以上時，VO2、lactate、PCr、Pi、pH 等無法維持 steady state。
- Convective O2 delivery、diffusive O2 delivery 與 muscle O2 utilization kinetics 都可影響 CP。

## Mechanism Chain

```text
External work increase
→ ATP demand increase
→ cardiac output + oxygen extraction + ventilation rise
→ VO2 increase and gas exchange maintenance
→ if O2 delivery / diffusion / utilization cannot stabilize intracellular milieu
→ CP boundary crossed and severe-domain non-steady state emerges
```

## Inference

- 若只把運動限制歸因於 lungs，會漏掉 circulation 與 peripheral extraction 的角色。
- 若只看 VO2max，也會漏掉 transition kinetics、diffusion、regional blood flow 與 motor unit recruitment 對 exercise tolerance 的影響。

## Assumption

- 現代解讀會保留本章的整合生理骨架，但不直接沿用其 legacy threshold wording。

## Uncertainty

- 本章可作 textbook physiology frame，但較新 threshold / domain 爭議需回到後續 CPET 文獻更新。

## Clinical Use

- 解釋運動測試時，可先用 integrated oxygen transport 視角，而不是把 `VO2` 縮成單一器官指標。
