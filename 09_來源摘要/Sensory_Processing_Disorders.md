# Sensory Processing Disorders

## 一句話定義

這章 textbook chapter 把 SPD 放在 **participation-limiting sensory processing pattern** 的框架下整理，但同時提醒：這是一組臨床表現與 formulation 工具，不是可以脫離 broader developmental differential 單獨成立的一鍵解釋。

## 核心機制

### 這份來源真正提供什麼

- 它把 SPD 拆成三大群：
  - sensory modulation disorders
  - sensory-based motor disorders
  - sensory discrimination disorders
- 它強調 child 的困難必須已經影響 daily life activity、school performance 或 participation，才值得臨床上進一步處理。
- 它把 detailed history、parent interview、OT assessment 放在核心位置，而不是靠單一 lab test 或 imaging。

### 核心內容拆解

### 1. sensory modulation 不只是「挑」

- overresponsivity 可表現為 touch / sound / smell / food defensiveness、transition difficulty、tantrum、avoidance。
- underresponsivity 或 sensory seeking 也可能造成 participation problem、safety concern 或 disorganized behavior。
- 章節明示 arousal、organization 與 context 很重要，不能只用單一 sensory label 解釋所有 behavior。

### 2. sensory-based motor disorder 把 postural problem 與 dyspraxia 拉出來

- vestibular-based postural disorder：balance、postural stability、bilateral coordination、ocular motor difficulty。
- dyspraxia：motor planning、skilled movement、multistep action learning 困難。
- 這些表現容易和 DCD、neurologic disorder 或 broader developmental issue 交疊，因此 differential diagnosis 不能省。

### 3. sensory discrimination problem 比較像感覺品質判讀困難

- child 可能難以分辨 tactile / vestibular / proprioceptive 等 sensory qualities。
- 這會影響 object manipulation、body-in-space awareness 與 task accuracy。

### 4. assessment 以 family narrative + OT evaluation 為主

- 歷史重點：
  - infant temperament
  - eating / sleeping problem
  - specific sensory antecedents
  - behavioral pattern across contexts
- referral to occupational therapist 可用 standardized sensory-motor-perceptual tools 補強 occupational performance assessment。

### 5. intervention 不只針對 child，也針對 family 與 environment

- priority 包括：
  - improve adaptive response
  - help parents reframe the problem
  - environmental modification
  - compensatory strategy
- chapter 也提到 Ayres Sensory Integration 類介入在 selected population，特別是 ASD individualized goal / participation outcome，有較可用的訊號；但這不等於所有 sensory complaint 都該被同樣處理。

## 評估方式

- 本章支持的評估重點：
  - history-driven formulation
  - parent interview
  - OT functional assessment
  - participation impact
- 本章不支持的誤用：
  - 把所有 behavior / language / feeding complaint 直接收斂成 sensory problem
  - 用 SPD label 取代 neurologic、language、ASD、hearing 或 broader developmental evaluation

## 治療原則

- 本章支持：
  - family psychoeducation
  - sensory-informed environmental adjustment
  - OT-guided intervention
  - participation-oriented goals

## 臨床決策點

### 這章真正改變什麼

- 它讓臨床上可以更精確描述 sensory-related participation problem。
- 但它同時也提醒：sensory formulation 只能是 broader developmental workup 的一部分，不能單獨取代 diagnosis。

## 限制與未定論

### 限制 / caveat

- SPD 概念本身在 diagnostic boundary 與 intervention generalizability 上仍有爭議。
- 章節可作為臨床整理工具，但不能把 textbook chapter 直接等同 consensus guideline。

### frontmatter contradictions

- SPD-style sensory profiles can guide formulation, but they should not replace broader developmental or neurologic differential diagnosis.
- Sensory-based intervention evidence is condition-specific and should not be generalized to all behavior, feeding, or language complaints.

## 理解缺口

- 哪些 sensory complaint 最需要先回 differential，而不是先下 sensory label？
- participation gain 與 impairment label 之間，哪一個才是真正治療 target？

## 臨床使用版

- 若 child 的 sensory complaint 已經影響 dressing、feeding、school participation 或 co-regulation，這章很適合拿來建立 history 與 OT referral 骨架。
- 但若 clinician 想用 sensory 取代 hearing、language、ASD 或 neurologic workup，這章其實不支持那種做法。
