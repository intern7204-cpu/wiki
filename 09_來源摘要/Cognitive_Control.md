# David Badre 2025 — Cognitive Control

## 一句話定義

這篇 Annual Review 的主要價值，是把 cognitive control 從「一組 executive skills」提升成 **control-systems framework**：核心不只在 inhibition，而在 context-dependent controllability、monitoring / feedback control，以及 task representation 的結構。

## 核心機制

### 這份來源真正提供什麼

- review 明確指出 cognitive control 與 executive function 多半重疊，但語義重心不同：
  - executive function 較像 skill set
  - cognitive control 較像 mechanism / control-systems framing
- 作者聚焦兩個主特徵：
  - context-dependent stimulus-response controllability
  - monitoring and feedback control

### 核心內容拆解

### 1. flexible behavior 來自 context-dependent control

- 同一 stimulus 在不同 goal / context 下可導向不同 response。
- 這不是單純的「努力忍住」，而是 control input 被 top-down knowledge 調整。

### 2. task representation 是這篇的主軸

- review 強調 representational accounts 正在取代單純的 stage / bottleneck thinking。
- 關鍵不是只有 process，而是 task information 如何被編碼、組織、轉換。

### 3. cognitive control 不是 open-loop

- system 會監測：
  - action
  - error
  - effort
  - reward
- 這些 signal 會回饋到 control mechanism，形成 closed-loop adjustment。

### 4. knowledge-action connection 是更大的外圈

- 人不只是控制動作，也在用知識、規則、prediction 與 world model 去選行動。
- 作者把這個 outer-loop connection 點出來，但本篇主要還是聚焦 inner-loop control。

## 臨床表現

### 這篇對 wiki 主幹最重要的補強

- 可直接升級 [[../07_Pediatric_Development/Executive_Function_總論]]，讓 EF 不再只剩 inhibition / planning 清單。
- 也支持新頁 [[../07_Pediatric_Development/Executive_Function_支持策略]]：介入要回到 task representation、monitoring 與 context design，而不是只叫孩子更自律。

## 評估方式

- 這篇不是臨床 guideline，但它提供的評估思路是：
  - 先定義 task demand
  - 再看 representation / monitoring / feedback 哪一段出問題
  - 不要把所有 complaint 都壓扁成「衝動」或「不專心」

## 治療原則

- 本篇不是 treatment chapter。
- 但它強烈支持把 intervention 放回 real-world task structure、feedback loop 與 adaptive context，而不是只找單一訓練模組。

## 臨床決策點

### 這篇真正改變什麼

- 它幫 EF 頁面補上概念深度。
- 最大收穫不是多一個名詞，而是避免把 executive complaint 過度簡化成 inhibition deficit。

## 限制與未定論

### 限制 / caveat

- 這是高品質 review article，但屬理論與機制整合，不是 pediatric practice guideline。
- representational accounts 雖然有力，但仍是活躍發展中的研究方向。

### frontmatter contradictions

- Cognitive control and executive function overlap, but they are not perfectly synonymous.
- Inhibitory control is only one slice of the field; task representations and monitoring/feedback are equally central to the framework.

## 理解缺口

- 哪些 pediatric EF complaint 真正更像 monitoring problem，而不是 inhibition problem？
- representational framing 要怎麼轉譯成 school / home assessment language？

## 臨床使用版

- 若使用 EF 這個詞時，心中只有 inhibition、working memory、planning 三格，這篇能把框架補完整。
- 若個案主訴是「懂規則但做不出來」，通常更值得回頭看 context representation 與 feedback loop。
