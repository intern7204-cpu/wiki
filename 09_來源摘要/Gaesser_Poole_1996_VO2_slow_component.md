# Gaesser & Poole 1996 — The V̇O₂ Slow Component

## 一句話定義

V̇O₂ 與 work rate 的關係**並非對全部 submaximal 範圍都是線性**；在 >T_Lac 之上出現「V̇O₂ slow component」——在快速 exponential 上升之後再疊加一個延遲出現、可達 >1 L/min 的 V̇O₂ 上升；這是 exercise physiology 長期被教科書忽略的重要現象，定義了 heavy/severe intensity domain 的核心特徵。

## 核心機制

### 核心主張

### 1. 「V̇O₂–work rate 線性」是不完整的教科書敘述

- 快速 incremental ramp（<10 min）下 V̇O₂ 看起來線性升至 V̇O₂max。
- 但對於任何 >T_Lac 的 **constant-load** 運動，會出現 slow component → V̇O₂ 最終高於「sub-T_Lac gain × WR」預測。
- 「V̇O₂ drift」（長時間 moderate 運動的小幅上升 <200 mL）與 slow component **不同**，不應混用。

### 2. V̇O₂ kinetics 三相結構

以 constant-load 運動為例：
- **Phase 1（cardiodynamic delay, ~15–25 s）**：心輸出量增加驅動肺血流上升；早期延遲相。
- **Phase 2（fundamental, exponential）**：V̇O₂ ≈ V̇O₂_ss × (1 − e^(−(t−δ)/τ))；τ ~45 s（健康中年）。
- **Phase 3（steady state 或 slow component）**：
  - moderate：steady state 於 ~3 min 達成。
  - heavy / severe：出現額外的 slow component（從 ~80–110 s 後開始發展）。

Phase 2 的 pulmonary V̇O₂ 與 muscle V̇O₂ 動力學高度一致（Grassi 研究：半時 25.5 vs 27.9 s）。

### 3. 三域定義與 V̇O₂ 行為

與 Poole 2020 的三域一致：
- **Moderate（<T_Lac）**：V̇O₂ 單指數 → steady state；efficiency 穩定（gain 9–11 mL·W⁻¹·min⁻¹）。
- **Heavy（T_Lac ↔ W-t asymptote = CP）**：V̇O₂ slow component 出現但可穩定於 submaximal；efficiency 下降；[La⁻] 達 delayed steady state；slow component 與 [La⁻] 在時間與量級上高度對應。
- **Severe（>CP）**：V̇O₂ 與 [La⁻] 無 steady state；slow component 把 V̇O₂ 推至 V̇O₂max 才 exhaustion。

### 4. 量級與臨床意涵

- slow component 可高達 **1.0–1.5 L/min**。
- 因此在 heavy/severe 域內「%V̇O₂max」並非獨特 anchor（不同時間點會對應不同 V̇O₂），應改以**域**描述（moderate / heavy / severe）。
- 常見的「以 %V̇O₂max 或 %HRmax 開處方」在跨越 LT 後失真。

### 5. 機制（1996 當時整理）

Slow component 的可能來源：
- 多餘 type 2 fiber recruitment（efficiency 較低）。
- 已募集 fiber 因疲勞而效率下降（type 1 fiber 於高強度效率掉至接近 0）。
- 體溫上升、乳酸-buffer-ventilation 耗能（極小比例）。
- 血液 lactate shuttle 相關代謝耗能。
- 呼吸、心臟肌肉本身 V̇O₂ 上升（整合 contribution 通常 <10%）。

大部分（~86%）slow component V̇O₂ 來源於 **exercising muscle 本身**（Poole 1991）。

### 6. 訓練適應

- Endurance training：同一 >T_Lac 絕對功率下 slow component amplitude 顯著下降。
- 此適應與同時發生的 T_Lac 右移、mitochondrial 容量提升、type 1 fiber 徵召效率提升有關。

## 臨床表現

### 為何重要

- 是 heavy/severe domain 的操作性定義基礎。
- 與 [Pi] 累積、muscle efficiency 下降、W' 耗盡在機制上互相耦合（見 [[Goulding_2021_VO2_kinetics_exercise_tolerance]]）。
- 臨床 CPET 判讀應意識到：heavy constant-load work 的 V̇O₂ 不是固定值。
