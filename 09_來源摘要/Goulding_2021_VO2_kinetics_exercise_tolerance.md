# Goulding et al. 2021 — Bioenergetic Mechanisms Linking V̇O₂ Kinetics and Exercise Tolerance

## 一句話定義

本文提出「**critical threshold + positive feedback loop**」統整模型：V̇O₂ kinetics（τV̇O₂）決定肌肉代謝物（[Pi]）累積速率；一旦超過 critical [Pi]（~18 mM），觸發正回饋 → 效率下降 → ATP 需求上升 → 更多 [Pi] 累積，最終限制運動耐受度。由此**CP 不是單一 power / V̇O₂，而是 metabolite 累積的閾值**。

## 核心機制

### 核心論點（推理鏈）

1. 運動起始時 V̇O₂ 以指數上升（time constant τV̇O₂，~12 s elite 到 ~120 s COPD 老年），期間以 O₂ deficit（PCr + glycolysis + O₂ store）填補 ATP 需求。
2. O₂ deficit 量級 ≈ ΔV̇O₂ × τV̇O₂（穩態條件下）。
3. 穩態下 V̇O₂–power gain ≈ 9–11 mL·min⁻¹·W⁻¹，跨性別/年齡/訓練狀態穩定；τV̇O₂ 才是差異主因。
4. O₂ deficit 大 → [Pi]、[ADP]、[H⁺] 累積快 → 若跨過 critical [Pi]，啟動正回饋：
   - [Pi] 抑制 cross-bridge power stroke、降低 Ca²⁺ sensitivity、與 SR Ca²⁺ 共沉澱。
   - 肌肉疲勞 → 效率下降（W/P ↓） → 同樣 power 的 ATP 需求上升 → [Pi] 更高。
5. 正回饋可達穩定（heavy-intensity）或不穩地發散至 peak [Pi] ~25 mM（very-heavy / severe）。
6. 由此推導出 hyperbolic power–duration 關係：CP = ATP 使用活性維持 metabolic stability 的上限；W' = critical → peak [Pi] 的有限 volume。

### 方法學與延伸重點

- **W' 並非單純「anaerobic capacity」**；hyperoxia/intermittent exercise 等情境下 W' 可與氧化供能協同變化。
- Intermittent exercise（Davies 2017）：同樣 110% V̇O₂peak 下，work:recovery 16:32 s 將 V̇O₂ 峰值限制在 LT 以下 → 行為如 moderate intensity，可維持 >30 min。
- Group III/IV afferents 調節肌肉 metabo/mechano signals：fentanyl 抑制後可讓 peak [Pi] 與 W' 增加 → 中樞也參與 W' 的實質上限決定。
- 模型本質是「**chimeric cell**」，實際 in vivo 邊界是 phase transition（不是 sharp threshold，Pethick 2020）。

## 臨床表現

### 臨床含義

- 舊 CPET 報表僅看 V̇O₂max / AT，忽略 τV̇O₂；後者對日常活動 metabolic stability 更貼近。
- 老年、COPD、HF、T1D 患者 τV̇O₂ 顯著延長 → 即便 V̇O₂max 尚可，日常低階任務（如起身、爬梯）仍造成大 metabolite 累積 → 早期疲勞。
- Priming exercise（warm-up）臨床價值：短時 heavy-intensity 暖身可加快後續 τV̇O₂、提升 CP → 可作為復健課程設計變項。

## 治療原則

### 主要證據（橫斷性 + 介入性）

- **Korzeniewski & Rossiter 2020 in silico**：以單一 critical [Pi] 即可產出實驗觀察到的 P–duration 曲線與 V̇O₂ slow component。
- τV̇O₂ 與 CP 跨人群呈強負相關（R² 0.90；Murgatroyd 2011）：elite athletes、健康、elderly、COPD、diabetes 整合 35 研究資料一致。
- 介入：
  - Endurance training → τV̇O₂ ↓、CP ↑。
  - Hypoxia → τV̇O₂ ↑、CP ↓。
  - Hyperoxia → τV̇O₂ ↓、CP ↑（直立姿勢）。
  - Priming exercise → τV̇O₂ ↓、CP ↑（含 T1D 患者）。
  - 提高 pedal cadence（多招募 type 2）→ τV̇O₂ ↑、CP ↓。
- V̇O₂SC 與 W'：amplitude 正相關；endurance training、glycogen depletion、prior severe exercise 同時降低兩者。

## 限制與未定論

### 限制 / 爭議

- critical [Pi]、peak [Pi] 的絕對值會因肌纖維型、運動模式、個體而變（文獻範圍 ~16–20 mM / ~22.5–27.5 mM）。
- Phase transition vs threshold 的爭論尚未完全收斂（Pethick 2020）。
- Supine exercise 下的 τV̇O₂–CP 關係變弱，受 baseline perfusion 影響。
- 單一代謝物（[Pi]）解釋複雜整合生理屬於簡化，雖對 P–duration 曲線擬合良好。
