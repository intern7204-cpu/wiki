# Yang, Grover, Raval — Quality and Outcome Measures for Medical Rehabilitation

## 一句話定義

這章的核心不是列工具清單，而是澄清 **outcome / process / performance measure 的差異、Donabedian structure-process-outcome logic、risk adjustment、value-based care 與 QI methodology** 在 rehabilitation 裡怎麼接起來。

## 核心機制

### 主要貢獻

### 1. 釐清 measure taxonomy

- clinical outcome measures、process measures、performance measures 各自回答不同問題。
- functional outcome measures 要回到 ICF level 判斷：body function / activity / participation。

### 2. Donabedian 與 IOM 六大 aims 是 quality language 的骨架

- structure、process、outcome 三分法仍是理解品質問題的起點。
- IOM 六大 aims：safety、timeliness、effectiveness、equity、efficiency、patient-centeredness。

### 3. value 與 accountability 不能被簡化成「便宜就是好」

- value = outcomes / total cost of full episode of care，不是單一服務成本。
- accountability measures 要有 evidence、proximity、accuracy、minimal adverse effect。

### 4. outcome measure selection 需要方法學紀律

- validity、reliability、responsiveness、feasibility、floor / ceiling effect 都要評估。
- patient-reported 與 clinician-assessed measure 的組合常比單一觀點更合理。
- risk adjustment 是跨機構比較的必要條件。
