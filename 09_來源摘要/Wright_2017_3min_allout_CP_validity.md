# Wright et al. 2017 — The reliability and validity of the 3-minute all-out cycling critical power test

## 一句話定義

這篇 original article 的核心訊息是：**3-min all-out test 的 `EP` 可能可靠，但其 validity 受 ergometer mode 影響；而 `WEP` 在 isokinetic 與 linear mode 都低估 `W'`。**

## 核心機制

### 研究設計

- 12 位 male cyclists。
- 共完成 8 次測試：
  - 1 次 ramp test
  - 3 次 fixed-power tests 建立 `CP` 與 `W'`
  - 4 次 3-min all-out tests
    - 2 次 isokinetic
    - 2 次 linear
- 比較：
  - `EP` vs `CP`
  - `WEP` vs `W'`
  - 並分析 reliability

### 主要發現

### 1. isokinetic `EP` 可接近 `CP`

- `EP-isokinetic` 與 `CP` 無顯著差異。
- reliability 也不差：
  - CoV 約 `1.93%`

### 2. linear `EP` 雖可靠，但會高估 `CP`

- `EP-linear` 與 `CP` 有顯著差異。
- 雖然 test-retest reliability 也很好：
  - CoV 約 `1.17%`
- 但 **reliable 不等於 valid**。

### 3. `WEP` 在兩種模式都低估 `W'`

- `WEP-isokinetic` 明顯低於 `W'`
- `WEP-linear` 也明顯低於 `W'`
- 因此作者的結論很直接：
  - **3-min all-out test 不應拿來估 `W'`**

## 臨床表現

### 對 wiki 的直接價值

- 這篇直接補強 [[../04_CPET/CP_Test_Reliability]]：
  - 3-min all-out 的 reliability 與 validity 要分開看
- 也補強 [[../04_CPET/Critical_Power]]：
  - `EP` 與 `WEP` 不能被當成一組同樣可靠的替代指標

## 評估方式

### 方法學重點

- 原始 linear mode resistance 設定很吃 cadence selection。
- 作者也討論：
  - preferred cadence 的小偏差
  - 可能就足以改變 `EP`
- 因此 3-min all-out 的 protocol setup 不能只抄名稱，不抄細節。

## 治療原則

- practical take-home：
  - 若只想快速抓 `CP`，3-min all-out 還有角色。
  - 若你要的是 `W'`，這篇叫你保守一點。

## 臨床決策點

### 這篇真正改變什麼

- 它不是說 3-min all-out 完全不能用。
- 它是在把結論拆開：
  - `EP` 可能有用
  - `WEP` 不應自動被當成 `W'`

## 限制與未定論

### 限制 / caveat

- sample size 小。
- 只看 trained male cyclists。
- 參與者做了很多次 exhaustive tests，可能有疲勞與學習效應。

### frontmatter contradictions

- Reliable end power does not guarantee valid critical power estimation across ergometer modes; linear mode overestimated CP here.
- WEP underestimated W' in both modes, so the 3-minute all-out test should not be assumed to provide valid W' just because EP appears stable.

## 理解缺口

- 在其他 ergometer、其他 resistance-setting strategy 下，linear mode 能否改善 validity？
- 對不同訓練程度或臨床族群，3-min all-out 的 external validity 如何？

## 臨床使用版

- 3-min all-out 若要用，先問你要的是 `CP` 還是 `W'`。
- 這篇支持前者可有限使用，不支持後者直接替代。
