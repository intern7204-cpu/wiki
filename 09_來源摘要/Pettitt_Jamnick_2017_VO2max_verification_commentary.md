# Pettitt & Jamnick 2017 — Commentary on Measurement of the maximum oxygen uptake VO2max

## 一句話定義

這篇 commentary 的核心訊息是：**作者支持 verification exercise bout，但提醒 ramp 與 verification 的一致性應放在 measurement variability 內解讀，而不是只靠外推公式。**

## 核心機制

### 這篇在補什麼

- 它不是反對 Poole & Jones 2017。
- 它同意：
  - secondary criteria 不夠
  - verification bout 很重要
- 但另外補了兩個 practical issue：
  - ramp duration / slope 會影響結果
  - 如果 verification 沒過，下一步該怎麼處理

### 主要主張

### 1. ramp 與 VEB 的 peak `VO2` 應看 measurement variability

- 作者建議：
  - 如果 ramp 與 VEB 的 peak `VO2` 在 measurement variability 內，
    就可接受該值
  - practical example：`<3%` 的差異
- 這個邏輯比只拿 ramp extrapolated expected `VO2` 當準繩更穩健。

### 2. ramp protocol duration 應被個體化

- 作者支持 ramp 目標落在 **8–12 min**。
- 但也直接提醒：
  - ramp 中的最高 work rate 本來就受 protocol duration 影響
  - 所以 ramp slope 不是任意背景設定

### 3. 若 verification 沒通過，應考慮重設 ramp slope

- 作者建議可用 ramp 或 VEB 中較高的 peak `VO2`
  反推較合適的 power output / ramp slope。
- 目標是讓下次 ramp duration 更接近理想範圍，而不是只把第一次結果丟掉。

- 這篇屬 commentary。
- 它提供的是：
  - protocol refinement
  - result interpretation caveat
- 不是新的 Tier 1 framework。

## 治療原則

- practical take-home：
  - verification bout 不是只有「過 / 不過」
  - 還要問：
    - ramp 是否設計合理
    - 差異是否已超出 measurement noise

## 臨床決策點

### 這篇真正改變什麼

- 它讓 verification workflow 更完整：
  - 不是只判定 ceiling
  - 也能反過來檢查 ramp design

## 限制與未定論

### 限制 / caveat

- commentary，不是 original trial。
- `<3%` 是實務建議，不應被誤寫成 universal biologic law。

### frontmatter contradictions

- Verification should be judged against measurement variability between ramp and VEB, not only against extrapolated expectations from the ramp test.
- Failed verification may reflect suboptimal ramp design, so protocol redesign can be more appropriate than simply rejecting the original value.

## 理解缺口

- 不同 modality 與不同病人族群，measurement variability cut-off 是否一致？
- VEB 強度與休息時間的最佳組合在臨床族群如何調整？

## 臨床使用版

- 如果 verification 沒過，不要只急著說病人沒做到 max。
- 先回頭檢查 ramp slope、duration 與 measurement variability。
