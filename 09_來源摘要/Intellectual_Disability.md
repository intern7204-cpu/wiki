# Intellectual Disability

## 一句話定義

這章把 Intellectual Disability 放回現代框架：**ID 是 intellectual function + adaptive function + developmental-period onset 的組合，且臨床重點是 supports，而不是單一 IQ 數字**。

## 核心機制

### 這份 textbook chapter 的主框架

- AAIDD、DSM 與 WHO 都已改用 `intellectual disability`。
- 現代定義把 adaptive behavior 放進核心，而不是附屬條件。
- adaptive domain 包含：
  - conceptual
  - social
  - practical
- 功能與 support need 會隨時間、環境與介入改變，不是固定不變的 trait。

### etiologic 與 lifespan 視角

- 病因可來自 genetic、metabolic、infectious、toxic、traumatic、environmental 與 idiopathic。
- genetics 已成為重要主軸，但 social determinant、poverty、adversity 也不可忽略。
- 這章特別強調：
  - person-centered support system
  - community inclusion
  - school / work participation
  - supported decision-making 與 transition

## 臨床表現

### 這份來源最有價值的臨床用途

- 提供 `ID ≠ 低 IQ` 的主框架。
- 幫助把 pediatric evaluation 連到 adult outcome、guardianship / rights、community participation。
- 提醒 regression、ataxia、new neurologic findings 不應被塞回「只是 ID」的框架。

## 評估方式

### textbook chapter 提供的 evaluation anchor

- prenatal / perinatal / postnatal history
- regression 與 neurologic deterioration
- 3-generation pedigree
- dysmorphology 與 general neurologic exam
- sensory evaluation
- genetic testing thinking：CMA、fragile X、selected syndrome test、possible exome / genome

## 治療原則

### 這章真正支持的 treatment frame

- 早期與持續 supports
- family-centered / person-centered care
- health care、education、employment、community resource 的整合
- 不等待 definitive etiology 才開始功能支持

## 臨床決策點

### 這篇對 wiki 主幹的價值

- 補強 [[../07_Pediatric_Development/發展遲緩與Intellectual_Disability]] 的定義與 lifespan 視角。
- 讓 [[../07_Pediatric_Development/小兒復健評估]]、[[../07_Pediatric_Development/兒童神經學評估]] 不只停在 diagnosis，也能連到 supports 與 participation。

## 限制與未定論

### 不該過度延伸的地方

- 這章是 broad framework，不是最新 first-line testing algorithm。
- genetics 細節更新很快，實際檢查順序仍要由較新的 UpToDate / guideline 校正。
- 各系統對 developmental-period cutoff 有不同定義；AAIDD 用 before 22，DSM 用 before 18。

### frontmatter contradictions

- Intellectual disability should not be diagnosed from IQ score alone without adaptive-function framing.
- Regression is not part of the expected course of nonprogressive intellectual disability and should widen the differential.
- Support needs and functioning are dynamic and should not be treated as fixed traits.

## 臨床使用版

- 這份來源適合拿來建立主頁骨架，不適合單獨決定某個 genetic test 的最新排序。
- 若 child 有 regression、new seizure、ataxia、systemic clue，就要離開單純 ID 框架，重新做 etiologic workup。
