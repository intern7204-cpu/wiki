# Speech and language impairment in children: Evaluation, treatment, and prognosis

## 一句話定義

這篇 UpToDate 把 speech / language impairment 的處理整理成 **PCP identification → medical evaluation → formal audiology → SLP in-depth assessment → early intervention / prognosis counseling** 的完整路徑。

## 核心機制

### 這份來源真正提供什麼

- evaluation 的三個目標：
  - determine whether impairment exists
  - specify the nature of impairment
  - initiate intervention
- primary care clinician 不只負責發現，也要先做 medical screen 與 referral routing。

### 核心內容拆解

### 1. medical evaluation 不能漏 formal audiologic testing

- 所有 child with speech / language impairment 都應接受：
  - comprehensive history
  - physical examination
  - formal audiologic testing
- 這不是 optional add-on，而是 initial evaluation 的固定部分。

### 2. SLP assessment 是 profile definition 的核心

- SLP 會做 quantitative + qualitative assessment。
- questionnaire、parent interview、teacher input、prior reports 都屬於必要資料來源。
- standardized test 有價值，但不能單獨代表全部 communication function。

### 3. bilingual assessment 需在正確語言脈絡下進行

- dominant / primary language assessment 很重要。
- 若沒有 fluent SLP，就需要 trained interpreter。
- bilingual exposure 不是 postponing assessment 的理由。

### 4. treatment 是多軸介入，不是單一 therapy slot

- 依 etiology 與 profile 決定：
  - SLP intervention
  - medical / surgical referral
  - developmental support
  - school or special education resource
- early intervention 整體上有幫助，但不同 subgroup 的 long-term outcome 不完全相同。

### 5. prognosis 不是只看「會不會自己追上」

- isolated speech problem 往往比 speech + language 混合困難預後較好。
- persistent difficulty 到 4 至 5 歲後，通常代表較高的長期 academic / literacy risk。
- receptive language weakness、broader developmental issue 與 social-communication problem 會拉低預後。

## 評估方式

### 這篇最值得直接回填的評估點

- history：birth / medical / developmental / family / environmental
- physical exam：head and neck、neurologic clues、dysmorphism、growth
- formal audiology：固定要件
- SLP assessment：in-depth profile
- teacher / caregiver input：school-age child 特別重要

## 治療原則

### 這篇最明確的邊界

- standardized tests 不能取代 social-interactive assessment。
- auditory integration、Fast ForWord、sensory integration 等非標準療法，不應被包裝成 routine standard treatment。

## 臨床決策點

### 這篇真正改變什麼

- 它把 speech / language problem 的第一線處理流程講清楚。
- 對臨床最重要的是：不要因為 screen、雙語或「再等等」而跳過 audiology 與 SLP referral。

## 限制與未定論

### 限制 / caveat

- UpToDate 以一般臨床路徑為主，沒有展開每一種 therapy protocol 的細節。
- early intervention 雖然整體有幫助，但不同 phenotype 的長期成效仍有差異。

### frontmatter contradictions

- All children with speech or language impairment require formal audiologic testing as part of the initial medical evaluation.
- Assessment in a bilingual child should include the dominant or primary language and appropriate interpreter support when needed.
- Nonstandard therapies such as auditory integration, Fast ForWord, or sensory integration should not be framed as routine standard treatment for speech or language impairment.

## 理解缺口

- 哪些 child 只需要 surveillance，哪些其實已經到 formal referral threshold？
- 什麼時候 prognosis counseling 應該更明確談 literacy / school-age risk？

## 臨床使用版

- 一旦 child 已被辨識出 speech / language impairment，接下來不是「觀察看看」，而是按流程補 medical evaluation、formal audiology 與 SLP assessment。
- bilingual child 若只用英語快速看過，常常不是完成評估，而是完成誤差。
