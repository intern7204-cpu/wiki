# Developmental-behavioral surveillance and screening in primary care

## 一句話定義

這頁整理「Developmental-behavioral surveillance and screening in primary care」這份來源真正能教給住院醫師的主架構，並把可直接用於臨床決策的部分拆開。

## 核心機制

### 先用白話講懂

如果要把這篇 UpToDate 濃縮成一句話，就是：**surveillance 是 routine clinical responsibility，screening 是 standardized risk detection，而 positive screen 的下一步一定是 evaluation / referral，不是等下次再說。**

### 核心內容拆解

### 1. surveillance 與 screening 的角色被重新講得更清楚

- surveillance：caregiver concern、risk/resilience factor、developmental history、observation、collaboration。
- screening：用 standardized test 在沒有明顯症狀的 child 中找 risk。
- evaluation：positive screen 或持續 concern 後的 comprehensive assessment。

### 2. 做 screening 的理由是整體 detection 會更好

- UpToDate 強調 surveillance + screening 的組合比單靠任一項更能提升早期辨識。
- 也可能減少某些族群因 clinician impression 而被漏掉的 disparity。

### 3. 要承認 screening 有 cost 與 limitation

- harms 包括：
  - false positive
  - false negative
  - workflow burden
  - referral burden
- 但這些不是不做 screening 的理由，而是要做好 follow-up design。

### 4. tool 不能亂選

- topic 建議工具最好有大約 >=70% 的 sensitivity / specificity。
- 也要考慮語言、可近性、家長 literacy 與 practice workflow。

### 這篇真正回答什麼問題

- 在當代 primary care，surveillance、screening、evaluation 三者怎麼分工。
- 為什麼即使有 false positive / false negative，screening 仍值得做。
- 如何把 benefit、harm 與 implementation burden 一起看。

- 什麼情況要轉介？遇到 red flags、診斷不確定、需要程序性介入或超出本頁可處理範圍時。
